どれ

どれ
pronoun
which one
1. which one
A question word asking to identify one item from a group of three or more. Used when choices are not directly attached to nouns.
あなたのかばんはどれですか？
Which one is your bag?
どれが一番(いちばん)好(す)きですか？
Which one do you like the best?
どれでもいいです。
Any one is fine.
どれでも = any one (of them)
この中(なか)でどれが一番(いちばん)安(やす)いですか？
Which one of these is the cheapest?
ケーキがたくさんあるけど、どれを食(た)べたいか決(き)められない。
There are many cakes, but I can't decide which one I want to eat.

Used for choosing among three or more items. For two items, use どちら (dochira). Part of the こそあど series: これ (this one), それ (that one), あれ (that one over there), どれ (which one).
