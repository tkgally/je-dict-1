問題(もんだい)

もんだい
noun
problem, question
1. question, problem (on a test)
A question to be answered or a problem to be solved, typically in an academic context such as on exams or homework.
この問題(もんだい)は難(むずか)しいです。
This problem is difficult.
問題(もんだい)が分(わ)からなかったら、先生(せんせい)に聞(き)いてください。
If you don't understand the question, please ask the teacher.
問題(もんだい)を解(と)いてみてください。
Please try solving the problem.
Sense 1: test problem
この問題(もんだい)の答(こた)えは何(なん)ですか。
What is the answer to this question?
Sense 1: test question
全部(ぜんぶ)で十(じゅう)問(もん)の問題(もんだい)があります。
There are ten questions in total.
Sense 1: questions (on test)
2. problem, issue, trouble
A matter that needs to be addressed or solved, a difficulty or concern.
この問題(もんだい)は難(むずか)しいです。
This problem is difficult.
問題(もんだい)ありません。
No problem.
Very common expression meaning 'it's fine' or 'don't worry'
それは大(おお)きな問題(もんだい)です。
That is a big problem.
何(なに)か問題(もんだい)がありましたか。
Was there any problem?
問題(もんだい)を解決(かいけつ)しなければならない。
We must solve the problem.
Sense 2: issue/problem
環境(かんきょう)問題(もんだい)について話(はな)し合(あ)った。
We discussed environmental issues.
Sense 2: issue

問題(もんだい)ない (no problem) is a very common casual expression. In academic contexts, 問題(もんだい) refers to questions or exercises. In everyday use, it often means 'issue' or 'trouble'. 問題(もんだい)を解(と)く means 'to solve a problem'.
