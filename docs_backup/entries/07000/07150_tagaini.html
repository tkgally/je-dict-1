互(たが)いに

たがいに
adverb
mutually; each other; one another
1. mutually; each other; one another
Indicates that an action or state is reciprocal between two or more parties.
互(たが)いに助(たす)け合(あ)おう。
Let's help each other.
チームのメンバーは互(たが)いに尊敬(そんけい)し合(あ)っている。
The team members respect each other.
長(なが)い付(つ)き合(あ)いで、互(たが)いのことをよく知(し)っている。
We know each other well from our long relationship.
互(たが)いの + noun = each other's

FORMATION:
互(たが)い (mutual) + に (adverb particle)

GRAMMAR PATTERNS:

  • 互(たが)いに〜合(あ)う - to do ~ to each other (reciprocal verb)
  • 互(たが)いの + noun - each other's ~
  • 互(たが)いに理解(りかい)する - to understand each other

COLLOCATIONS:

  • 互(たが)いに助(たす)け合(あ)う - to help each other
  • 互(たが)いに尊重(そんちょう)する - to respect each other
  • 互(たが)いに信頼(しんらい)する - to trust each other
  • お互(たが)いに - mutually (polite form)

SIMILAR WORDS:

  • お互(たが)いに - more polite/common in conversation
  • 相互(そうご)に - mutually (formal/written)
