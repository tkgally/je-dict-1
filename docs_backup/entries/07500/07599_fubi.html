不備(ふび)

ふび
noun, na-adjective
deficiency; inadequacy; incompleteness
1. deficiency; inadequacy
A state where something necessary is lacking or insufficient.
設備(せつび)の不備(ふび)を指摘(してき)された。
The inadequacies in the facilities were pointed out.
不備(ふび)がございましたら、ご連絡(れんらく)ください。
Please contact us if there are any deficiencies.
2. incompleteness; defect
A flaw or problem with documentation, preparation, or systems.
書類(しょるい)に不備(ふび)があったため、申請(しんせい)が却下(きゃっか)された。
The application was rejected because the documents were incomplete.

ETYMOLOGY:
不(ふ) (not) + 備(び) (preparedness) - literally "not prepared"

COMMON COLLOCATIONS:

  • 書類(しょるい)の不備(ふび) - incomplete documents
  • 設備(せつび)の不備(ふび) - inadequate facilities
  • 体制(たいせい)の不備(ふび) - systemic deficiency
  • 不備(ふび)を補(おぎな)う - to make up for deficiencies

USAGE IN APOLOGIES:

  • 不備(ふび)がありましたことをお詫(わ)び申(もう)し上(あ)げます - We apologize for any deficiencies

RELATED:

  • 不手際(ふてぎわ) - mishandling (active failure)
  • 欠陥(けっかん) - defect, flaw
  • 不足(ふそく) - shortage, insufficiency
