真実(しんじつ)

しんじつ
noun, na-adjective
truth; reality
1. truth; reality; fact
What is actually the case; the real state of affairs.
真実(しんじつ)を明(あき)らかにする。
To reveal the truth.
真実(しんじつ)を語(かた)る。
To tell the truth.
真実(しんじつ)の愛(あい)を見(み)つけた。
I found true love.

真実(しんじつ) is composed of 真(しん) (true) + 実(じつ) (reality).

SIMILAR WORDS:

  • 事実(じじつ): fact (objective reality)
  • 本当(ほんとう): truth, really
  • 真理(しんり): universal truth (philosophical)

COMMON PATTERNS:

  • 真実(しんじつ)を知(し)る: to learn the truth
  • 真実(しんじつ)の〜: true ~, real ~
  • 真実(しんじつ)を隠(かく)す: to hide the truth
