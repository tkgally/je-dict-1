# Workflow & Autonomy — Prompt 11: Create daily workflow documentation

**Source:** Agent 2 Report (Workflow & Autonomy), Phase 4, Prompt 11
**Priority:** Low (Phase 4: User Workflow Integration)
**Effort:** Low

---

Create `pipeline/DAILY_WORKFLOW.md` documenting the new workflow for the user. Cover:
(1) how to configure and launch a pipeline run, (2) how to review the summary report
and PR, (3) how to do periodic spot-check reviews, (4) how to handle validation
failures, (5) how to add new task types. Include example daily routines: "morning
launch" (configure pipeline, start it, go to work), "evening review" (check PR, merge,
adjust config for next day), "weekend audit" (thorough quality review of week's work).
