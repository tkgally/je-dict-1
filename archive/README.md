# Archive

Files from earlier stages of the project (January–September 2026) that the current process no
longer uses, kept as a record. Nothing in the build, the checks or the scheduled Routine reads
them. The current process is described in `CLAUDE.md`, `prompts/routine2.md` and
`enhancement/assessment-2026-09-02.md`.

- `prompts/`: task prompts from before the unified Routine (targeted polishing passes, entry
  creation from the corpus, cross-reference and link passes run by hand, the refactoring series,
  batch scripts), with their tracking and corpus data.
- `enhancement/`: the April 2026 enhancement plan and its prompts, and the June 2026 Routine plans
  that the September 2 assessment replaced.
- `brainstorming/`: the "think of related words" candidate runs (February–August 2026).
- `agent_team_proposals/`: February 2026 proposals for parallel agent teams.
- `polishing/sessions/`: session logs up to August 2026 and of the retired task types. Current
  logs are in `polishing/sessions/`.
- `polishing/`: READMEs describing the earlier polishing process.
- `reviews/`: one-time sweep snapshots (September 2 holdout lists) and the April review
  calibration report.

Moved here on 2026-09-26. Files deleted at the same time (the unused pipeline/orchestrator
system, one-off sweep output, the furigana screener's per-entry reports) remain in the git
history.
