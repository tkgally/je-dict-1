### Tooling fixes (both verified, with regression cases)
- `build/score_note_quality.py` `normalize_pos()`: `'verb' in pos.split(',')[0]` matched the
  substring inside **"adverb"**, so every adverb entry was scored against the verb note
  template. Fixed with a `\bverb\b` word-boundary match. 1,039 entries had an adverb-first
  POS string; 334 changed template. Real verbs re-checked and unchanged.
- `build/score_note_quality.py` `has_bare_kanji()`: stripped furigana but not the
  `→baseform：id` tail of inline word links, so the baseform's kanji counted as "bare".
  Every entry with a kanji-bearing inline link in its notes silently lost the 5-point
  furigana component — **adding the tier-1-required inline links lowered an entry's score**.
  6,195 entries affected. Fixed; genuine bare kanji is still detected (5 test cases).
- Combined: 6,529 / 29,993 entries (22%) were mis-scored; corpus average 81.7 → 82.9.
  `make priorities` regenerated with the fixed scorer and the priority cursor reset to
  `line: 1`, since the old line numbers ranked the wrong entries.
