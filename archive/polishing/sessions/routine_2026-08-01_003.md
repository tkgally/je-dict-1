### Applied (53 decisions)

**Politeness batch defect — the run's main finding.** `politeness` is the keigo
field (`honorific | humble | polite | plain`). Blocks **22504–22526** and
**22670–22729** were created with `politeness: "polite"` on ordinary plain
vocabulary — nouns like {県民|けんみん}, {庁舎|ちょうしゃ}, グランドピアノ,
{原子爆弾|げんしばくだん}, and plain-form verbs like {待|ま}ち{伏|ふ}せる,
{古|ふる}ぼける, {推|お}し{量|はか}る. **79 of the dictionary's 252 `polite`
entries sat inside this single 566-entry range**, which is a batch-creation
defect rather than a distribution.

All 79 were inspected individually (headword + POS + gloss). **78 changed to
`plain`**; お{稽古|けいこ} (22419) was kept as `polite` because the honorific お-
prefix makes it genuine 美化語. `plain` is the project's dominant convention for
nouns (13,510 of 17,602 noun-only entries).

**Off-vocabulary semantic tags — 35 entries.** `check_tag_drift.py` reported 34
`unknown-semantic` flags in the range; per the §A semantic-tag policy a tag that
is not in `VALID_SEMANTIC` is wrong by definition, so each was migrated to the
best in-list tag after reading the entry. None was in the detector's 9-entry
`TAG_MIGRATION` map, so all were per-entry choices — e.g. `location` →
`direction` / `daily-life`, `object` → `tool` / `media` / `communication`,
`degree` → `quantity`, `space` → `size`, `status` → `descriptive`, `reading` →
`cognition`, `body` → `body-part` / `health`, `place` → `furniture`,
`time-holiday` → `time-period`, `grammar-expression` → `grammatical`,
`loanword` → dropped (an origin marker, not a semantic field).

Three further in-list tags were factually inapplicable rather than merely broad,
and were also corrected: 22403 {冷汗|れいかん} `body-part` → `health` (cold sweat
is a secretion, not a body part), 22706 オーブンレンジ `food` → `electronics` (an
appliance is not food), 22635 {急浮上|きゅうふじょう} `media` → `movement`.
