## Note for the next accuracy-review run

The review scripts run at roughly 1.5–2.6 entries/minute against OpenRouter, so
generating reviews for a 500-entry range takes 3–5 hours — far more wall clock
than one Routine run has. This run started passes over 08347–08850, got ~130
entries in, and stopped them once it became clear that **most of the range
already had accuracy reviews on disk from 2026-06-22 that had simply never been
adjudicated**. Checking for existing `reviews/accuracy/{id}.json` coverage
*before* launching a pass would let the mode go straight to adjudication, which
is where the value is. Logged as a `[tooling]` observation.
