# Cross-Reference Links Test Entries

This document lists the 100 entries selected for testing the cross-reference links feature.

## Selection Criteria

Entries were selected to provide comprehensive testing coverage:

1. **Varied vocabulary tiers** - Basic, Core, and General tier entries
2. **Rich examples** - Entries with many example sentences for thorough testing
3. **Diverse parts of speech** - Verbs (godan/ichidan), nouns, adjectives, particles, adverbs
4. **Entries with notes** - To test link processing in notes fields
5. **Cross-referencing potential** - Common words that appear in other entries' examples

## Link Format Reference

When adding links to these entries, use the following format:

```
⟦{surface|reading}→baseform：entry_id⟧
```

Examples:
- `⟦{食|た}べる→食べる：00396_taberu⟧` - verb with furigana
- `⟦を→を：00422_wo⟧` - particle
- `⟦コード→コード：00241_koodo⟧` - katakana word
- `⟦{矍鑠|かくしゃく}→矍鑠：noentry⟧` - word not in dictionary

## Notes

- The headword in its own examples doesn't need to link to itself
- Punctuation (。、？！) should not be linked
- Use `noentry` for words that don't have dictionary entries
- For conjugated forms, link to the dictionary form (e.g., 食べました → 食べる)
