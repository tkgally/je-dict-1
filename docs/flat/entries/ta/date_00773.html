〜建(だ)て

だて
suffix
storied, -story building

Definitions

1. storied, -story (building)
Indicates the number of floors in a building.

Examples

二階建(にかいだ)ての家(いえ)に住(す)んでいる。
I live in a two-story house.
この建物(たてもの)は五階建(ごかいだ)てだ。
This building is five stories.
一戸建(いっこだ)てを買(か)いたい。
I want to buy a detached house.

Notes

〜建(だ)て indicates building structure.

COMMON USES:

  • 二階建(にかいだ)て: two-story
  • 三階建(さんがいだ)て: three-story
  • 一戸建(いっこだ)て: detached house
  • 平屋建(ひらやだ)て: single-story

NOTE:

  • Also written as 〜建(た)て
  • 建(た)てる: to build (related verb)
