今回(こんかい)

こんかい
noun
this time

Definitions

1. this time, now
The present occasion or instance.

Examples

今回(こんかい)は失敗(しっぱい)した。
I failed this time.
今回(こんかい)の旅行(りょこう)はどうでしたか。
How was this trip?

Notes

Compare with:\n- 前回(ぜんかい) - last time\n- 次回(じかい) - next time\n- 毎回(まいかい) - every time
