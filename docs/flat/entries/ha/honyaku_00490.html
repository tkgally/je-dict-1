翻訳(ほんやく)

ほんやく
noun, verb (suru)
translation

Definitions

1. translation
Converting written text from one language to another.

Examples

この本(ほん)は英語(えいご)から翻訳(ほんやく)されました。
This book was translated from English.
翻訳(ほんやく)の仕事(しごと)をしています。
I work as a translator.
日本語(にほんご)に翻訳(ほんやく)してください。
Please translate it into Japanese.

Notes

翻訳(ほんやく) refers specifically to written translation.

翻訳(ほんやく) vs 通訳(つうやく):

  • 翻訳(ほんやく): written translation
  • 通訳(つうやく): oral interpretation

COMMON PATTERNS:

  • 〜を翻訳(ほんやく)する: to translate ~
  • 〜から〜に翻訳(ほんやく)する: to translate from ~ to ~
  • 翻訳(ほんやく)者(しゃ)/翻訳(ほんやく)家(か): translator
  • 機械|きかい}翻訳(ほんやく): machine translation

RELATED TERMS:

  • 訳(やく)す: to translate (verb)
  • 原文(げんぶん): original text
  • 訳文(やくぶん): translated text
