もし

もし
adverb
if; in case

Definitions

1. if; in case
Introduces a hypothetical condition, typically used with conditional forms like ～たら or ～ば.

Examples

もし雨(あめ)が降(ふ)ったら、行(い)きません。
If it rains, I won't go.
もし時間(じかん)があれば、手伝(てつだ)ってください。
If you have time, please help me.
もしよかったら、一緒(いっしょ)に行(い)きませんか。
If you'd like, would you like to go together?
Polite invitation

Notes

もし is typically used with conditional endings like ～たら, ～ば, or ～なら.

COMMON PATTERNS:

  • もし〜たら: if (casual/neutral)
  • もし〜ば: if (slightly formal)
  • もし〜なら: if (topical condition)
  • もしよかったら: if you'd like (polite offer)
