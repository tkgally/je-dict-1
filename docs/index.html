TKG Japanese-English Learner's Dictionary

Results

The TKG Japanese-English Learner's Dictionary (TKGJE) is an explanatory dictionary designed for learners of Japanese as a second language. It currently contains 7,959 entries organized into three vocabulary tiers: 795 basic words for beginners, 1,998 core vocabulary for intermediate learners, and 5,166 general vocabulary for advanced study. Each entry includes explanatory definitions, natural example sentences optimized for learning, usage notes covering grammar, register, and common patterns, and furigana readings for all kanji. The dictionary is under active development.
