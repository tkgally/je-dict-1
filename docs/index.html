TKG Japanese-English Learner's Dictionary

Results

The TKG Japanese-English Learner's Dictionary (TKGJE) is an explanatory dictionary designed for learners of Japanese as a second language. It currently contains 13,244 entries, including 801 basic words for beginners and 1,998 core vocabulary for intermediate learners, as well as 53,355 natural example sentences optimized for learning. Each entry includes explanatory definitions; usage notes covering grammar, register, common patterns, and related expressions; and furigana readings for all kanji. The dictionary is under active development.
