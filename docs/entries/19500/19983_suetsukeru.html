据(す)え付(つ)ける

すえつける
verb
to install; to set up; to fix in place
1. to install; to set up; to fix in place
To permanently place or mount equipment, machinery, or fixtures in a fixed position.
エアコンを据(す)え付(つ)ける。
To install an air conditioner.
新(あたら)しい機械(きかい)を工場(こうじょう)に据(す)え付(つ)けた。
We installed new machinery in the factory.
庭(にわ)に大(おお)きな石灯籠(いしどうろう)を据(す)え付(つ)けるのに半日(はんにち)かかった。
It took half a day to set up the large stone lantern in the garden.

A compound verb of 据(す)える (to set, to place) and 付(つ)ける (to attach). Describes the permanent installation or mounting of something heavy or fixed, as opposed to simply placing a portable item.

TRANSITIVITY:
Transitive. The intransitive counterpart is 据(す)え付(つ)く, though it is rarely used.

COMMON COLLOCATIONS:

  • エアコンを据(す)え付(つ)ける — to install an air conditioner
  • 機械(きかい)を据(す)え付(つ)ける — to install machinery
  • 据(す)え付(つ)け工事(こうじ) — installation work
  • 据(す)え付(つ)け型(がた) — built-in type, fixed type

SIMILAR WORDS:

  • 設置(せっち)する — to set up, to install (more formal/official)
  • 取(と)り付(つ)ける — to attach, to install (broader usage, including smaller items)
