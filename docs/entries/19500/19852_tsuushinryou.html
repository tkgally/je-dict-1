通信料(つうしんりょう)

つうしんりょう
noun
communication charges; data charges
1. communication charges; data charges; telecom fees
Fees charged for telecommunications services such as phone calls, text messages, and mobile data usage.
通信料(つうしんりょう)が高(たか)い。
The data charges are high.
月(つき)の通信料(つうしんりょう)を確認(かくにん)した。
I checked the monthly communication charges.
海外(かいがい)では通信料(つうしんりょう)が高額(こうがく)になることがあるので注意(ちゅうい)が必要(ひつよう)だ。
You need to be careful because communication charges can become very expensive overseas.

Refers to charges for phone, data, and other telecommunications services. In everyday use, often refers specifically to mobile phone data charges.

COMMON COLLOCATIONS:

  • 通信料(つうしんりょう)が掛(か)かる — communication charges are incurred
  • 通信料(つうしんりょう)無料(むりょう) — free of data charges
  • 月額(げつがく)通信料(つうしんりょう) — monthly communication fee
  • 通信料(つうしんりょう)を節約(せつやく)する — to save on data charges

SIMILAR WORDS:

  • 通話料(つうわりょう) — call charges (voice calls specifically)
  • 通信費(つうしんひ) — communication expenses (broader, used in accounting)
  • データ使用量(しようりょう) — data usage amount
