手順書(てじゅんしょ)

てじゅんしょ
noun
procedure manual; instruction document
1. procedure manual; instruction document; step-by-step guide
A document that describes the steps to be followed to complete a task or process. Common in workplaces, technical fields, and quality management.
手順書(てじゅんしょ)に従(したが)って作業(さぎょう)する。
To work according to the procedure manual.
手順書(てじゅんしょ)を作成(さくせい)してください。
Please create a procedure document.
手順書(てじゅんしょ)が古(ふる)くなっていたので、最新(さいしん)の内容(ないよう)に更新(こうしん)した。
The procedure manual was outdated, so I updated it with the latest information.

Compound of 手順(てじゅん) (procedure, steps) and 書(しょ) (document, writing). A standard workplace term for written instructions that ensure tasks are performed consistently and correctly.

COMMON COLLOCATIONS:

  • 手順書(てじゅんしょ)を作成(さくせい)する — to create a procedure manual
  • 手順書(てじゅんしょ)に従(したが)う — to follow the procedure manual
  • 手順書(てじゅんしょ)を更新(こうしん)する — to update the procedure manual
  • 手順書(てじゅんしょ)通(どお)りに — as written in the procedure manual
  • 作業(さぎょう)手順書(てじゅんしょ) — work procedure document

SIMILAR WORDS:

  • マニュアル — manual; broader term, can include non-procedural content
  • 説明書(せつめいしょ) — instruction manual; usually for products, not work processes
  • 取扱説明書(とりあつかいせつめいしょ) — user manual; operation manual (for equipment)
  • 仕様書(しようしょ) — specification document; describes requirements, not steps
