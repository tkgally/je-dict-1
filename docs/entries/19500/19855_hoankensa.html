保安検査(ほあんけんさ)

ほあんけんさ
noun
security check; security screening
1. security check; security screening
A security inspection of passengers and their belongings, typically at airports before boarding, to ensure safety. Also used for security inspections at other facilities.
保安検査(ほあんけんさ)を通(とお)った。
I passed through the security check.
保安検査(ほあんけんさ)場(じょう)は混雑(こんざつ)していた。
The security screening area was crowded.
出発(しゅっぱつ)の1時間前(じかんまえ)までに保安検査(ほあんけんさ)を済(す)ませてください。
Please complete the security screening at least one hour before departure.

Most commonly used in the context of airport security screening. At Japanese airports, signs and announcements use 保安検査(ほあんけんさ) as the standard term.

COMMON COLLOCATIONS:

  • 保安検査(ほあんけんさ)場(じょう) — security screening area
  • 保安検査(ほあんけんさ)を受(う)ける — to undergo a security check
  • 保安検査(ほあんけんさ)を済(す)ませる — to complete security screening
  • 保安検査(ほあんけんさ)締(し)め切(き)り — security screening cutoff time

SIMILAR WORDS:

  • 手荷物検査(てにもつけんさ) — baggage inspection
  • 身体検査(しんたいけんさ) — body search, physical examination
  • セキュリティチェック — security check (loanword, less formal)
