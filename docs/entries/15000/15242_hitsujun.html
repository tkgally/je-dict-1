筆順(ひつじゅん)

ひつじゅん
noun
stroke order
1. stroke order
The correct order in which the strokes of a kanji or kana character should be written.
筆順(ひつじゅん)を覚(おぼ)える。
To learn the stroke order.
この漢字(かんじ)の筆順(ひつじゅん)を間違(まちが)えていた。
I had been writing this kanji in the wrong stroke order.
小学校(しょうがっこう)では漢字(かんじ)の筆順(ひつじゅん)を正(ただ)しく教(おし)えることが重視(じゅうし)されている。
In elementary school, teaching the correct stroke order for kanji is considered important.

FORMATION: 筆(ひつ) (writing brush, writing) + 順(じゅん) (order, sequence).

COMMON COLLOCATIONS:

  • 筆順(ひつじゅん)を覚(おぼ)える: to learn stroke order
  • 正(ただ)しい筆順(ひつじゅん): correct stroke order
  • 筆順(ひつじゅん)を間違(まちが)える: to get the stroke order wrong
  • 筆順(ひつじゅん)辞典(じてん): stroke order dictionary

SIMILAR WORDS:

  • 筆順(ひつじゅん): stroke order (more common term)
  • 書(か)き順(じゅん): stroke order (more colloquial synonym)
  • 画数(かくすう): stroke count (number of strokes, not their order)
