周期表(しゅうきひょう)

しゅうきひょう
noun
periodic table
1. periodic table (of elements)
The tabular arrangement of chemical elements organized by atomic number, showing periodic trends in their properties.
周期表(しゅうきひょう)を覚(おぼ)えた。
I memorized the periodic table.
周期表(しゅうきひょう)で元素(げんそ)の位置(いち)を確認(かくにん)した。
I checked the element's position on the periodic table.
化学(かがく)の授業(じゅぎょう)で周期表(しゅうきひょう)の見方(みかた)を習(なら)い、元素(げんそ)の性質(せいしつ)の規則性(きそくせい)を学(まな)んだ。
In chemistry class, we learned how to read the periodic table and studied the patterns in element properties.

The standard term for the periodic table of elements. Composed of 周期(しゅうき) (period, cycle) + 表(ひょう) (table, chart). A fundamental concept in chemistry education.

COMMON COLLOCATIONS:

  • 周期表(しゅうきひょう)の元素(げんそ): elements on the periodic table
  • 周期表(しゅうきひょう)を暗記(あんき)する: to memorize the periodic table
  • 周期表(しゅうきひょう)の族(ぞく): groups on the periodic table
  • 周期表(しゅうきひょう)の周期(しゅうき): periods on the periodic table

RELATED TERMS:

  • 元素(げんそ): element
  • 原子番号(げんしばんごう): atomic number
  • 化学記号(かがくきごう): chemical symbol
  • 周期律(しゅうきりつ): periodic law

CULTURAL NOTE:
Japanese students commonly memorize the periodic table using mnemonics based on the Japanese readings of element names. The phrase "水兵(すいへい)リーベ僕(ぼく)の船(ふね)" (H, He, Li, Be, B, C, N, O, F, Ne) is one of the most famous.
