1. to use up completely, to exhaust
To consume or spend something entirely so that none remains.
ポイントを使(つか)い切(き)った。
I used up all my points.
食材(しょくざい)を使(つか)い切(き)ってから買(か)い物(もの)に行(い)く。
I go shopping after using up all the ingredients.
予算(よさん)を使(つか)い切(き)らないと来年(らいねん)の予算(よさん)が減(へ)らされる。
If we don't use up the budget, next year's budget will be cut.

A compound verb: 使(つか)う (to use) + 切(き)る (to finish completely). The 〜切(き)る suffix adds the meaning of doing something thoroughly or to completion.

TRANSITIVITY:

  • Type: 他動詞(たどうし) (transitive)
  • Pattern: Xを使(つか)い切(き)る (to use up X)

ASPECT (ている):
使(つか)い切(き)っている means "has used up" (resulting state — nothing remains).

COMMON COLLOCATIONS:

  • 予算(よさん)を使(つか)い切(き)る: use up the budget
  • 食材(しょくざい)を使(つか)い切(き)る: use up the ingredients
  • 体力(たいりょく)を使(つか)い切(き)る: exhaust one's stamina
  • ポイントを使(つか)い切(き)る: use up points
  • 使(つか)い切(き)れない: can't use it all up (potential negative — very common)

OTHER 〜切(き)る COMPOUNDS:

  • 読(よ)み切(き)る: to read through completely
  • 走(はし)り切(き)る: to run the entire way
  • 食(た)べ切(き)る: to eat up everything
