今頃(いまごろ)

いまごろ
adverb
about now; by this time
1. about now; around this time
Refers to the approximate present time, often used to speculate about what is happening elsewhere at this moment.
今頃(いまごろ)彼(かれ)は空港(くうこう)だろう。
He's probably at the airport about now.
今頃(いまごろ)の季節(きせつ)は桜(さくら)がきれいだ。
The cherry blossoms are beautiful around this time of year.
日本(にほん)は今頃(いまごろ)もう朝(あさ)になっているはずだ。
It should already be morning in Japan by now.
2. at this late stage; only now
Used with a tone of reproach or exasperation to indicate that something is being done too late or should have been done earlier.
今頃(いまごろ)言(い)われても困(こま)る。
Even if you tell me now, it's too late.
今頃(いまごろ)になって後悔(こうかい)しても遅(おそ)い。
It's too late to have regrets at this point.
今頃(いまごろ)気(き)づくなんて、君(きみ)らしいね。
Noticing only now — that's so like you.

Can function as both an adverb and a noun. When used with の, it modifies nouns: 今頃(いまごろ)の時間(じかん) (around this time).

Sense 2 carries a critical or exasperated tone. The pattern 今頃(いまごろ)になって... emphasizes that an action comes too late.

COMMON PATTERNS:

  • 今頃(いまごろ)になって — at this late stage; only now
  • 今頃(いまごろ)の季節(きせつ) — around this season
  • 今頃(いまごろ)はもう... — by now (something) should already...
