件数(けんすう)

けんすう
noun
number of cases; count (of incidents, orders)
1. number of cases; number of items; count
The count of discrete instances of something — incidents, orders, accidents, complaints, dispatches, etc. Used when 件(けん) (case, matter) is the natural counter for the things being counted, especially in statistics and business reporting.
事故(じこ)の件数(けんすう)が減(へ)った。
The number of accidents decreased.
今月(こんげつ)の注文件数(ちゅうもんけんすう)を確認(かくにん)した。
I checked this month's order count.
救急車(きゅうきゅうしゃ)の出動件数(しゅつどうけんすう)は年々(ねんねん)増加(ぞうか)している。
The number of ambulance dispatches is increasing year by year.

Compound of 件(けん) (case, matter) + 数(すう) (number). Commonly attaches to nouns to form statistical terms like 注文件数(ちゅうもんけんすう) (order count) and 問(と)い合(あ)わせ件数(けんすう) (number of inquiries).

COMMON COLLOCATIONS:

  • 件数(けんすう)が増(ふ)える / 減(へ)る: the number of cases increases / decreases
  • 件数(けんすう)を集計(しゅうけい)する: to tally the number of cases
  • 問(と)い合(あ)わせ件数(けんすう): number of inquiries
  • 相談件数(そうだんけんすう): number of consultations
  • 出動件数(しゅつどうけんすう): number of dispatches

SIMILAR WORDS:

  • 回数(かいすう): number of times — for repeated events (利用回数(りようかいすう) 'number of uses')
  • 数量(すうりょう): quantity — for amounts of physical goods or stock
  • 人数(にんずう): number of people
