線形(せんけい)

せんけい
noun
linear; linear form
1. linear; linear form (math/science)
Of or relating to a straight line, or to a relationship in which one quantity changes in direct proportion to another. Used in math, physics, and engineering.
線形(せんけい)代数(だいすう)を学(まな)ぶ。
To study linear algebra.
このグラフは線形(せんけい)関係(かんけい)を示(しめ)している。
This graph shows a linear relationship.
線形(せんけい)モデルでは、入力(にゅうりょく)と出力(しゅつりょく)が比例(ひれい)関係(かんけい)にあると仮定(かてい)する。
In a linear model, we assume the input and output are in a proportional relationship.

Almost always used in technical or academic contexts. Pairs with の or appears as a noun-modifier.

COMMON COMPOUNDS:

  • 線形(せんけい)代数(だいすう): linear algebra
  • 線形(せんけい)方程式(ほうていしき): linear equation
  • 線形(せんけい)関数(かんすう): linear function
  • 線形(せんけい)回帰(かいき): linear regression
  • 非線形(ひせんけい): nonlinear

SIMILAR WORDS:

  • 直線(ちょくせん): straight line — refers to the line itself, not the property
  • 一次(いちじ): first-order; first-degree — used in 一次(いちじ)方程式(ほうていしき) (linear equation), overlapping in math with 線形(せんけい)
