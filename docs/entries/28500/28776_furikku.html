フリック

ふりっく
noun
flick (touchscreen gesture)
1. flick; flicking motion (on a touchscreen)
A quick sliding gesture on a touchscreen, especially the input method used in Japanese smartphone keyboards where the user slides from a base kana in one of four directions to select related kana.
フリックで文字(もじ)を入力(にゅうりょく)する。
I enter characters by flicking.
慣(な)れるとフリック入力(にゅうりょく)はとても速(はや)い。
Once you get used to it, flick input is very fast.
画面(がめん)を上(うえ)にフリックすると次(つぎ)のページに移動(いどう)する。
If you flick the screen upward, you move to the next page.

From English "flick". In Japan, most commonly refers to フリック入力(にゅうりょく), the standard Japanese smartphone keyboard input method.

COMMON COLLOCATIONS:

  • フリック入力(にゅうりょく): flick input
  • 上(うえ)にフリックする: to flick upward
  • フリックで切(き)り替(か)える: to switch by flicking

FLICK INPUT:
Japanese smartphone keyboards display あ、か、さ、た、な、は、ま、や、ら、わ as base keys. Flicking left, up, right, or down from a base selects い、う、え、お (and equivalent rows for other consonants).
