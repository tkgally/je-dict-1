本題(ほんだい)

ほんだい
noun
main topic, main subject
1. main topic, main subject, real issue
The central or primary topic of a conversation, meeting, or presentation. Often used when transitioning from preliminary remarks or small talk to the actual matter at hand.
では、本題(ほんだい)に入(はい)りましょう。
Well then, let's get to the main topic.
話(はなし)が逸(そ)れたので、本題(ほんだい)に戻(もど)ります。
The conversation got off track, so let me return to the main point.
前置(まえお)きが長(なが)くなりましたが、本題(ほんだい)に入(はい)らせていただきます。
I've been going on with the preamble, but allow me to move on to the main subject.

USAGE:
Almost always appears in the fixed phrases 本題(ほんだい)に入(はい)る (to get to the main topic) and 本題(ほんだい)に戻(もど)る (to get back to the main topic). A very useful expression for meetings, presentations, and formal conversations. Often marks the transition from 前置(まえお)き (preamble) or 雑談(ざつだん) (small talk) to substantive discussion.

COMMON COLLOCATIONS:

  • 本題(ほんだい)に入(はい)る: to get to the main topic
  • 本題(ほんだい)に戻(もど)る: to return to the main topic
  • 本題(ほんだい)から逸(そ)れる: to stray from the main topic
