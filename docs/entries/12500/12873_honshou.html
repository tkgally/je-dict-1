本性(ほんしょう)

ほんしょう
noun
true nature, true character
1. true nature, true character
A person's innate character or nature that is normally hidden beneath a social mask. Often implies that the true nature is negative or surprising when revealed.
酔(よ)うと本性(ほんしょう)が出(で)る。
When drunk, one's true nature comes out.
ついに彼(かれ)の本性(ほんしょう)が現(あらわ)れた。
His true nature finally showed itself.
追(お)い詰(つ)められると人(ひと)は本性(ほんしょう)を見(み)せるものだ。
When cornered, people tend to show their true colors.

USAGE:
Often carries a negative connotation — the true nature revealed is usually worse than expected. Common in the pattern 本性(ほんしょう)が出(で)る / 現(あらわ)れる (one's true nature emerges). Distinguished from the reading ほんせい, which is more neutral or Buddhist in tone.

COMMON COLLOCATIONS:

  • 本性(ほんしょう)が出(で)る: one's true nature comes out
  • 本性(ほんしょう)を現(あらわ)す: to reveal one's true colors
  • 本性(ほんしょう)を見(み)せる: to show one's true nature

SIMILAR WORDS:

  • 本性(ほんせい): true nature (more neutral, sometimes Buddhist usage)
  • 正体(しょうたい): true identity, true form (often used for disguised or unknown entities)
  • 素顔(すがお): bare face, true self (less negative)
