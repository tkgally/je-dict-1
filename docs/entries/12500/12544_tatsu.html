1. to be built, to be erected, to be constructed
Used for buildings and structures when they come into existence or stand in a location. An intransitive verb — the building is the subject.
新(あたら)しいビルが建(た)った。
A new building was built.
駅前(えきまえ)にマンションが次々(つぎつぎ)と建(た)っている。
Condominiums are being built one after another in front of the station.
この寺(てら)は鎌倉(かまくら)時代(じだい)に建(た)てられたが、何度(なんど)も再建(さいけん)され、今(いま)の建物(たてもの)は江戸(えど)期(き)に建(た)ったものだ。
This temple was originally built in the Kamakura period, but it was rebuilt many times, and the current structure was erected in the Edo period.

Godan verb ending in つ: 建(た)たない, 建(た)ちます, 建(た)って, 建(た)てば.

USAGE:
An intransitive verb — the building itself is the subject (ビルが建(た)つ). The transitive counterpart is 建(た)てる (to build something). Do not confuse with the homophone 立(た)つ (to stand up) or 経(た)つ (time passes), which use different kanji.

TRANSITIVITY PAIR:

  • 建(た)つ (intransitive): A building is built / stands
  • 建(た)てる (transitive): Someone builds a building
