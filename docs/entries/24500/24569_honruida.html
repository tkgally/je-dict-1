本塁打(ほんるいだ)

ほんるいだ
noun
home run
1. home run
a hit in baseball where the batter circles all the bases and scores a run
本塁打(ほんるいだ)を打(う)った！
He hit a home run!
今季(こんき)三十(さんじゅう)号(ごう)本塁打(ほんるいだ)を達成(たっせい)した。
He reached his thirtieth home run of the season.
満塁(まんるい)本塁打(ほんるいだ)で一気(いっき)に四点(よんてん)を奪(うば)い、試合(しあい)の流(なが)れが変(か)わった。
A grand slam scored four runs at once, and the momentum of the game shifted.

Composed of 本塁(ほんるい) (home plate) and 打(だ) (hit/strike). The standard Japanese baseball term for a home run. Baseball is extremely popular in Japan, and this term appears frequently in sports news and conversations. The loanword ホームラン is used interchangeably in casual conversation.

COMMON COLLOCATIONS:

  • 本塁打(ほんるいだ)を打(う)つ: to hit a home run
  • 満塁(まんるい)本塁打(ほんるいだ): grand slam
  • 本塁打(ほんるいだ)王(おう): home run champion
  • 逆転(ぎゃくてん)本塁打(ほんるいだ): go-ahead/come-from-behind home run
  • 本塁打(ほんるいだ)数(すう): number of home runs

SIMILAR WORDS:

  • ホームラン: home run — loanword, more casual and equally common
  • 安打(あんだ): base hit — a hit where the batter reaches base safely
  • 打点(だてん): RBI (run batted in) — runs scored by a batter's hit
