全問(ぜんもん)

ぜんもん
noun
all (test) questions
1. all questions; every question
The total set of questions on a test, quiz, or exam. Most commonly used in 全問(ぜんもん)正解(せいかい) (all correct) and similar collocations.
全問(ぜんもん)正解(せいかい)だった。
I got all the questions right.
全問(ぜんもん)解(と)くのに一時間(いちじかん)かかった。
It took me an hour to solve all the questions.
今回(こんかい)のテストは難(むずか)しくて、全問(ぜんもん)答(こた)えられた生徒(せいと)は一人(ひとり)もいなかった。
This test was hard, and not a single student was able to answer every question.

Compound of 全(ぜん) (all) + 問(もん) (question/problem, used as a counter). Almost always used in school and test contexts.

COMMON COLLOCATIONS:

  • 全問(ぜんもん)正解(せいかい): all answers correct; perfect score
  • 全問(ぜんもん)不正解(ふせいかい): all answers wrong
  • 全問(ぜんもん)解答(かいとう): answering every question
  • 全問(ぜんもん)必答(ひっとう): all questions must be answered

RELATED TERMS:

  • 一問(いちもん): one question
  • 設問(せつもん): a (test) question
  • 満点(まんてん): perfect score
