登録済(とうろくず)み

とうろくずみ
noun
registered; registration completed
1. registered; registration completed
Indicates that a registration process has been completed. Used for accounts, products, documents, and any official registration. Functions as a no-adjective to modify nouns.
登録済(とうろくず)みのアカウント。
A registered account.
この商品(しょうひん)は商標(しょうひょう)登録済(とうろくず)みです。
This product is trademark registered.
会員(かいいん)登録済(とうろくず)みの方(かた)は、ログインしてください。
If you have already completed member registration, please log in.
住所(じゅうしょ)変更(へんこう)の届(とど)け出(で)は登録済(とうろくず)みですので、ご安心(あんしん)ください。
The address change notification has been registered, so please rest assured.

Compound of 登録(とうろく) (registration) + 済(す)み (completed). The suffix 済(す)み attaches to nouns (especially suru-verb stems) to indicate that the action has been finished. This pattern is extremely productive:

  • 確認(かくにん)済(す)み: confirmed/verified
  • 支払(しはら)い済(す)み: paid
  • 完了(かんりょう)済(す)み: completed
  • 予約(よやく)済(す)み: reserved/booked

Very common in business, administrative, and digital contexts (websites, apps, forms).

COMMON COLLOCATIONS:

  • 登録済(とうろくず)みの住所(じゅうしょ): registered address
  • 登録済(とうろくず)みのメールアドレス: registered email address
  • 商標(しょうひょう)登録済(とうろくず)み: trademark registered

SIMILAR WORDS:

  • 登録(とうろく)完了(かんりょう): registration complete — more explicit phrasing, common in system messages
  • 届出(とどけで)済(す)み: notification filed — similar pattern with a different action
