可動式(かどうしき)

かどうしき
noun
movable; adjustable
1. movable; adjustable; mobile
A design or mechanism that allows something to be moved, adjusted, or repositioned.
可動式(かどうしき)の棚(たな)を設置(せっち)した。
I installed adjustable shelves.
この橋(はし)は可動式(かどうしき)で、大(おお)きな船(ふね)が通(とお)れる。
This bridge is movable, allowing large ships to pass.
可動式(かどうしき)の間仕切(まじき)りで部屋(へや)のレイアウトを自由(じゆう)に変(か)えられる。
You can freely change the room layout with movable partitions.

Combines 可動(かどう) (movable) with 式(しき) (type; style; model). Used as a noun modifier to describe things designed to be moved, adjusted, or reconfigured. Common in architecture, furniture, engineering, and product descriptions.

COMMON COLLOCATIONS:

  • 可動式(かどうしき)の棚(たな): adjustable shelves
  • 可動式(かどうしき)の橋(はし): movable bridge
  • 可動式(かどうしき)の壁(かべ): movable wall
  • 可動式(かどうしき)の座席(ざせき): movable seats
  • 可動式(かどうしき)フィギュア: posable figure/action figure

THE SUFFIX 式(しき):

The suffix 式(しき) indicates a type, style, or method:

  • 固定式(こていしき): fixed type
  • 折(お)りたたみ式(しき): folding type
  • 自動式(じどうしき): automatic type
  • 手動式(しゅどうしき): manual type

SIMILAR WORDS:

  • 固定式(こていしき): fixed type — the opposite; cannot be moved or adjusted
  • 移動式(いどうしき): portable; mobile — emphasizes the ability to relocate the entire unit, not just adjust parts
