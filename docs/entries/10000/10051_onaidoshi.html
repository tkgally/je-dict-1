同(おな)い年(どし)

おないどし
noun, adjective-no
same age
1. same age, of the same age
Being born in the same year; having the same age as someone else.
私(わたし)たちは同(おな)い年(どし)だ。
We are the same age.
同(おな)い年(どし)の友達(ともだち)。
A friend of the same age.
彼(かれ)と彼女(かのじょ)は同(おな)い年(どし)らしい。
Apparently he and she are the same age.
同(おな)い年(どし)だと知(し)って親近感(しんきんかん)がわいた。
I felt a sense of closeness when I learned we were the same age.

同(おな)い年(どし) means being the same age.

PRONUNCIATION:
Note the unusual reading おない for 同(おな)い, which only appears in this word.

USAGE:
Commonly used when discovering someone shares your birth year, often creating a sense of connection or equality.

COMMON PATTERNS:

  • 同(おな)い年(どし)だ: to be the same age
  • 同(おな)い年(どし)の: of the same age (attributive)

CULTURAL NOTE:
In Japan, discovering someone is 同(おな)い年(どし) often shifts the relationship dynamic, as age-based hierarchies (先輩(せんぱい)/後輩(こうはい)) become less relevant.

RELATED:

  • 同年代(どうねんだい): same generation
  • 同期(どうき): same year (school/work entry)
  • タメ: same age (casual slang)
