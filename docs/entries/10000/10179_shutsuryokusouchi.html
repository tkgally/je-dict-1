出力装置(しゅつりょくそうち)

しゅつりょくそうち
noun
output device
1. output device
A piece of equipment that receives data from a computer and presents it in a usable form, such as a monitor, printer, or speaker.
プリンターは出力装置(しゅつりょくそうち)だ。
A printer is an output device.
出力装置(しゅつりょくそうち)に問題(もんだい)がある。
There is a problem with the output device.
モニターやスピーカーは代表的(だいひょうてき)な出力装置(しゅつりょくそうち)です。
Monitors and speakers are typical output devices.

WORD FORMATION:
出力(しゅつりょく) (output) + 装置(そうち) (device, apparatus)

COMMON EXAMPLES:

  • モニター/ディスプレイ (monitor/display)
  • プリンター (printer)
  • スピーカー (speaker)
  • プロジェクター (projector)

RELATED TERMS:

  • 入力装置(にゅうりょくそうち): input device
  • 周辺機器(しゅうへんきき): peripheral device
  • 出力(しゅつりょく)する: to output
