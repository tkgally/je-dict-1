外部機器(がいぶきき)

がいぶきき
noun
external device, peripheral
1. external device, peripheral
A hardware device that connects to a computer or electronic system from the outside, such as a printer, external hard drive, or USB device.
外部機器(がいぶきき)を接続(せつぞく)する。
Connect an external device.
外部機器(がいぶきき)が認識(にんしき)されない。
The external device is not recognized.
このパソコン(ぱそこん)は複数(ふくすう)の外部機器(がいぶきき)を同時(どうじ)に使(つか)える。
This computer can use multiple external devices simultaneously.

WORD FORMATION:
外部(がいぶ) (external, outside) + 機器(きき) (device, equipment)

COMMON EXAMPLES:

  • USBメモリ(めもり) (USB memory stick)
  • 外付(そとづ)けハードディスク (external hard drive)
  • プリンター (printer)
  • スキャナー (scanner)

RELATED TERMS:

  • 周辺機器(しゅうへんきき): peripheral device
  • 入力機器(にゅうりょくきき): input device
  • 出力機器(しゅつりょくきき): output device
