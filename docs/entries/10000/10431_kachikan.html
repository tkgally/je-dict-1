価値観(かちかん)

かちかん
noun
sense of values, values
1. sense of values, values, value system
One's set of beliefs about what is important in life. Used to describe personal, cultural, or generational perspectives on what matters.
価値観(かちかん)が違(ちが)う。
Our values are different.
古(ふる)い価値観(かちかん)はもう通用(つうよう)しない。
Old values no longer hold up.
世代(せだい)によって価値観(かちかん)は大(おお)きく異(こと)なる。
Values differ greatly depending on the generation.

価値観(かちかん) is composed of 価値(かち) (value) + 観(かん) (view, perspective).

COMMON COLLOCATIONS:

  • 価値観(かちかん)が違(ちが)う: to have different values
  • 価値観(かちかん)が合(あ)う: to share the same values
  • 価値観(かちかん)が変(か)わる: values change
  • 価値観(かちかん)の多様化(たようか): diversification of values
