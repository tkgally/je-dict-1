ように

ように
expression
so that, in order to
1. so that, in order to
Expresses purpose or goal; used to indicate doing something with the aim of achieving a certain state.
忙(いそが)しくても、日課(にっか)だけは欠(か)かさないようにしている。
Even when busy, I make sure not to miss my daily routine.
Purpose usage with している
忘(わす)れないようにメモ(めも)する。
I take notes so that I don't forget.
風邪(かぜ)を引(ひ)かないように気(き)をつけてください。
Please be careful not to catch a cold.
2. like, as
Used to make comparisons or describe similarity.
鳥(とり)のように空(そら)を飛(と)びたい。
I want to fly through the sky like a bird.
Comparison usage

GRAMMAR PATTERNS:

1. PURPOSE (〜ように):

  • V(dictionary/ない) + ように (so that V / so that not V)
  • 間(ま)に合(あ)うように早(はや)く出(で)る (leave early so as to be on time)
  • 忘(わす)れないようにする (make sure not to forget)

2. COMPARISON (〜のように):

  • N + のように (like N)
  • 子(こ)どものように (like a child)
  • 言(い)ったように (as I said)

COMMON EXPRESSIONS:

  • ようにする (to make sure to, to try to)
  • ようになる (to come to, to become able to)
  • ように言(い)う (to tell someone to)

DISTINCTION:

  • ように (purpose/manner) - this entry
  • ために (purpose/reason) - implies more direct causation
