両替機(りょうがえき)

りょうがえき
noun
change machine, currency exchange machine
1. change machine
A machine that exchanges bills for coins or breaks larger denominations into smaller ones. Common at arcades, laundromats, and vending machine areas.
両替機(りょうがえき)で小銭(こぜに)に換(か)える。
Exchange for coins at the change machine.
ゲームセンターには両替機(りょうがえき)がある。
There are change machines at the arcade.
コインランドリーの両替機(りょうがえき)は千円札(せんえんさつ)しか使(つか)えない。
The change machine at the laundromat only accepts 1,000 yen bills.

WORD FORMATION:
両替(りょうがえ) (exchange, changing money) + 機(き) (machine)

COMMON LOCATIONS:

  • ゲームセンター (arcade)
  • コインランドリー (laundromat)
  • 駐車場(ちゅうしゃじょう) (parking lot)
  • 自販機(じはんき)コーナー (vending machine area)

RELATED TERMS:

  • 両替(りょうがえ): money exchange
  • 両替(りょうがえ)する: to exchange money
  • 小銭(こぜに): small change, coins
