仕組(しく)む

しくむ
verb (godan)
to devise, to plot, to set up
1. to devise, to plot, to scheme
To plan or arrange something in advance, especially something secretive or strategic. Often implies a hidden agenda or a carefully laid plan.
罠(わな)を仕組(しく)む。
To set a trap.
誰(だれ)かが裏(うら)で仕組(しく)んだことだ。
Someone plotted this behind the scenes.
最初(さいしょ)から仕組(しく)まれた計画(けいかく)だったらしい。
It seems it was a scheme planned from the very beginning.
2. to set up, to construct (a mechanism or system)
To build or arrange a mechanism, device, or system so that it functions in a particular way.
時計(とけい)の中(なか)を仕組(しく)む。
To construct the mechanism inside a clock.
ボタンを押(お)すと音(おと)が鳴(な)るように仕組(しく)んだ。
I set it up so that a sound plays when the button is pressed.
自動(じどう)で水(みず)がまかれるように仕組(しく)んである。
It is set up so that water is sprinkled automatically.

CONJUGATION: 仕組(しく)む is a godan verb (む row). Te-form: 仕組(しく)んで. Passive: 仕組(しく)まれる.

COMMON COLLOCATIONS:

  • 罠(わな)を仕組(しく)む (to set a trap)
  • 陰謀(いんぼう)を仕組(しく)む (to hatch a conspiracy)
  • 仕組(しく)まれた事件(じけん) (a staged incident)

RELATED: The noun 仕組(しく)み (mechanism, system, structure) is derived from this verb and is extremely common.
