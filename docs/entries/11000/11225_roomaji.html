ローマ字(じ)

ろーまじ
noun
Roman letters, romaji
1. Roman letters, romaji, the Latin alphabet
The Latin alphabet (A-Z) used to write Japanese phonetically. Also refers to the romanization system itself.
名前(なまえ)をローマ字(じ)で書(か)く。
Write your name in Roman letters.
パスポートにはローマ字(じ)で氏名(しめい)が記載(きさい)される。
Names are written in Roman letters on passports.
ローマ字(じ)入力(にゅうりょく)とかな入力(にゅうりょく)のどちらを使(つか)っていますか。
Do you use romaji input or kana input?

ローマ字(じ) literally means "Roman characters" and refers to the Latin alphabet as used to represent Japanese.

COMMON COLLOCATIONS:

  • ローマ字(じ)で書(か)く: to write in romaji
  • ローマ字(じ)入力(にゅうりょく): romaji input (typing method)
  • ローマ字(じ)表記(ひょうき): romaji notation

ROMANIZATION SYSTEMS:
There are several romanization systems, including 訓令式(くんれいしき) (Kunrei-shiki, taught in Japanese schools) and ヘボン式(しき) (Hepburn, used on passports and signs). Hepburn is the most widely recognized internationally.

NOTE:
Most Japanese people type using ローマ字(じ)入力(にゅうりょく), where they type romanized letters that are automatically converted to kana.
