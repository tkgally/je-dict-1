ダミー

だみー
noun
dummy, fake, stand-in
1. dummy, fake, stand-in
Something that imitates or substitutes for the real thing. Used for placeholders, decoys, fake items, or test objects.
ダミーのデータを使(つか)う。
To use dummy data.
防犯(ぼうはん)カメラはダミーだった。
The security camera was a dummy.
テスト用(よう)にダミーの会社名(かいしゃめい)を入力(にゅうりょく)して動作(どうさ)確認(かくにん)をした。
I entered a dummy company name for testing to verify the system worked.

USAGE:
ダミー is used as a noun or as a modifier (ダミーの〜). Common in technology, security, and testing contexts. Unlike English "dummy," it is not used as an insult for a person in Japanese.

COMMON COLLOCATIONS:

  • ダミーデータ: dummy data, placeholder data
  • ダミー会社(かいしゃ): dummy company, shell company
  • ダミーの防犯(ぼうはん)カメラ: dummy security camera
  • ダミー人形(にんぎょう): crash test dummy, mannequin
