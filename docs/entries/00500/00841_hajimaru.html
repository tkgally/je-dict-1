始(はじ)まる

はじまる
verb (godan)
to begin, to start
1. to begin, to start
For something to commence or start happening. An intransitive verb describing the beginning of an event, action, or state.
授業(じゅぎょう)は9時(じ)に始(はじ)まります。
Class starts at 9 o'clock.
映画(えいが)が始(はじ)まりました。
The movie has started.
春(はる)が始(はじ)まりましたね。
Spring has begun, hasn't it?

TRANSITIVITY: 自動詞(じどうし) (intransitive). Pair: 始(はじ)める (transitive). Pattern: Xが始(はじ)まる (X begins).

ASPECT: ている indicates ongoing state. 始(はじ)まっている = 'has started (and is ongoing).'

COMMON PATTERNS:

  • 授業(じゅぎょう)が始(はじ)まる (class starts)
  • 映画(えいが)が始(はじ)まる (movie starts)
  • 春(はる)が始(はじ)まる (spring begins)
  • もうすぐ始(はじ)まる (will start soon)

PAIR: 始(はじ)める (transitive) - 授業(じゅぎょう)を始(はじ)めた (started class). Opposite: 終(お)わる (to end).
