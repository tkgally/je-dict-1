本当(ほんとう)

ほんとう
noun
truth, reality
1. truth, reality
What is true or real, as opposed to what is false or imaginary.
本当(ほんとう)ですか。
Is that true? / Really?
Very common expression of surprise or confirmation
それは本当(ほんとう)の話(はなし)です。
That's a true story.
本当(ほんとう)の事(こと)を教(おし)えてください。
Please tell me the truth.
2. really, truly (adverbial use)
Used adverbially to emphasize sincerity or confirm something is true.
本当(ほんとう)にすみません。
I'm really sorry.
本当(ほんとう)においしいです。
It's really delicious.
本当(ほんとう)にありがとう(ありがとう)ございます。
Thank you so much. (Really, thank you.)

本当(ほんとう) means 'truth' as a noun, but is very commonly used adverbially and in set expressions.

COMMON EXPRESSIONS:

  • 本当(ほんとう)ですか: Is that true? / Really?
  • 本当(ほんとう)に: really, truly (adverb)
  • 本当(ほんとう)の事(こと): the truth
  • 本当(ほんとう)の話(はなし): a true story

CASUAL FORMS:

  • ほんと?: Really? (casual)
  • ほんとに: Really (casual adverb)
  • マジ?: Seriously? (slang, similar meaning)

USAGE AS MODIFIER:

本当(ほんとう)の + noun = real/true ~

  • 本当(ほんとう)の友達(ともだち): a true friend
  • 本当(ほんとう)の気持(きも)ち: one's true feelings

NOTE:
本当(ほんとう)ですか can express either genuine inquiry or surprise, depending on intonation.
