直(なお)る

なおる
verb (godan)
to be fixed, to recover
1. to be repaired, to be fixed
Describes something being restored to working condition (intransitive). The transitive pair is 直(なお)す (to fix/repair).
時計(とけい)が直(なお)りました。
The clock was fixed.
すぐに直(なお)ると思(おも)います。
I think it will be fixed soon.
この電話(でんわ)はまだ直(なお)っていません。いつ直(なお)りますか。
This phone isn't fixed yet. When will it be fixed?
車(くるま)が直(なお)ったので、明日(あした)から使(つか)えます。
The car is fixed, so I can use it starting tomorrow.
パソコンが壊(こわ)れて困(こま)っていましたが、やっと直(なお)りました。今日(きょう)から仕事(しごと)ができます。
I was having trouble because my computer was broken, but it's finally fixed. I can work starting today.
2. to recover, to get better
Describes recovering from illness or injury. Written as 治(なお)る for this meaning.
風邪(かぜ)が治(なお)りましたか。
Have you recovered from your cold?
Using 治る for illness
熱(ねつ)が治(なお)りました。
My fever went away.
Using 治る for illness
足(あし)が治(なお)るまで、歩(ある)けません。
I can't walk until my leg heals.
病気(びょうき)が治(なお)ったら、また学校(がっこう)に行(い)きます。
When my illness is cured, I will go back to school.
頭(あたま)が痛(いた)いですが、薬(くすり)を飲(の)めば治(なお)ると思(おも)います。
I have a headache, but I think it will go away if I take medicine.
体(からだ)が悪(わる)かったですが、もう治(なお)りました。ありがとうございます。
I wasn't feeling well, but I've recovered now. Thank you.

TRANSITIVITY: 自動詞(じどうし) (intransitive). Pair: 直(なお)す (transitive). Pattern: Xが直(なお)る (X is fixed/heals).

ASPECT: ている indicates resulting state. 直(なお)っている = 'is fixed/has recovered.'

COMMON PATTERNS:

  • パソコンが直(なお)った (computer was fixed)
  • 風邪(かぜ)が治(なお)る (recover from cold)
  • 癖(くせ)が直(なお)る (habit is corrected)
  • すぐ直(なお)る (will be fixed soon)

PAIR: 直(なお)す (transitive) - 車(くるま)を直(なお)した (fixed the car). Two kanji: 直(なお)る (repair), 治(なお)る (health).
