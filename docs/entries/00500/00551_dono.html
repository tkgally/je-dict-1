どの

どの
pre-noun adjectival
which (+ noun)
1. which
A question word used before a noun to ask which specific item. Always followed by a noun.
どの本(ほん)が欲(ほ)しいですか？
Which book do you want?
どの電車(でんしゃ)に乗(の)りますか？
Which train will you take?
どの人(ひと)が田中(たなか)さんですか？
Which person is Mr. Tanaka?
どの色(いろ)が好(す)きですか？私(わたし)は青(あお)が好(す)きです。
Which color do you like? I like blue.
どの道(みち)を行(い)けばいいか分(わ)からなくて、人(ひと)に聞(き)きました。
I didn't know which road to take, so I asked someone.

どの is a pre-noun adjectival meaning "which," always followed by a noun.

こそあど SERIES:

  • この: this ~ (near speaker)
  • その: that ~ (near listener)
  • あの: that ~ (far from both)
  • どの: which ~ (question)

COMMON PATTERNS:

  • どの人(ひと): which person
  • どの本(ほん): which book
  • どの電車(でんしゃ): which train
  • どのくらい/どのぐらい: how much, how long

DISTINCTION:

  • どの + noun: which ~ (modifies noun)
  • どれ: which one (stands alone as pronoun)

EXAMPLE CONTRAST:
どの本(ほん)が欲(ほ)しい？(Which book do you want?)
どれが欲(ほ)しい？(Which one do you want?)
