お願(ねが)いします

おねがいします
expression
please
1. please (when requesting)
A polite expression used when making a request or asking someone to do something.
お願(ねが)いします。
Please.
手伝(てつだ)いをお願(ねが)いします。
Please help me.
よろしくお願(ねが)いします。
Nice to meet you. / Thank you in advance.
Very common set phrase
静(しず)かにお願(ねが)いします。授業(じゅぎょう)中(ちゅう)です。
Please be quiet. We're in class.
早(はや)くお願(ねが)いします。時間(じかん)がありません。急(いそ)いでいただけると助(たす)かります。
Please hurry. There's no time. It would help if you could hurry.
2. I'll have... / I'd like...
Used when ordering at a restaurant or shop.
水(みず)をお願(ねが)いします。
Water, please.
コーヒーをお願(ねが)いします。
Coffee, please.
これをお願(ねが)いします。
I'll have this, please.
定食(ていしょく)を一(ひと)つお願(ねが)いします。
One set meal, please.
すみません、これ全部(ぜんぶ)でお願(ねが)いします。今日(きょう)はたくさん買(か)いました。
Excuse me, I'll take all of these please. I bought a lot today.

お願(ねが)いします is one of the most essential polite expressions in Japanese, literally meaning 'I make a request' (from 願(ねが)う, to wish/request).

FORMALITY LEVELS:

  • お願(ねが)い: casual (among friends)
  • お願(ねが)いします: polite (standard)
  • お願(ねが)いいたします: humble/formal (business)
  • お願(ねが)い申(もう)し上(あ)げます: very formal (written)

COMMON SET PHRASES:

  • よろしくお願(ねが)いします: please treat me well (greetings, requests)
  • ご確認(かくにん)をお願(ねが)いします: please confirm
  • ご協力(きょうりょく)をお願(ねが)いします: please cooperate

USAGE:
When ordering, use [item]をお願(ねが)いします. When requesting actions, the request is implied from context. Often used standalone as a polite closer to any request.
