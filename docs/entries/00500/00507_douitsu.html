同一(どういつ)

どういつ
noun/no-adjective
same, identical, identity

Definitions

1. same, identical
Being exactly the same as another.
2. identity, sameness
The state of being the same.

Examples

同一(どういつ)人物(じんぶつ)だと判明(はんめい)した。
It was determined to be the same person.
二(ふた)つの事件(じけん)は同一(どういつ)犯(はん)の仕業(しわざ)だ。
The two cases are the work of the same criminal.
品質(ひんしつ)の同一(どういつ)性を保(たも)つ。
To maintain uniformity of quality.

Notes

同一(どういつ) means same or identical.

FORMS:

  • Noun: 同一(どういつ) (sameness, identity)
  • No-adjective: 同一(どういつ)の (same, identical)

COMMON PATTERNS:

  • 同一(どういつ)人物(じんぶつ) (same person)
  • 同一(どういつ)条件(じょうけん) (same conditions)
  • 同一(どういつ)性 (identity, sameness)
  • 同一(どういつ)視する (regard as identical)

SIMILAR WORDS:

  • 同(おな)じ: same (common, everyday)
  • 同一(どういつ): identical (formal, precise)
  • 同様(どうよう): similar, same manner
