1. to run
To move quickly on foot. Faster than walking (歩(ある)く).
毎朝(まいあさ)公園(こうえん)で走(はし)っています。
I run in the park every morning.
バスに乗(の)るために走(はし)りました。
I ran to catch the bus.
廊下(ろうか)を走(はし)らないでください。
Please don't run in the hallway.
Negative request
子供(こども)たちが公園(こうえん)で走(はし)っています。
The children are running in the park.
電車(でんしゃ)に遅(おく)れそうだったので、駅(えき)まで走(はし)りましたが、もう出(で)てしまいました。
I was about to miss the train, so I ran to the station, but it had already left.

TRANSITIVITY: 自動詞(じどうし) (intransitive). No pair verb. Pattern: Xが走(はし)る (X runs) / Xを走(はし)る (run through X).

ASPECT: ている indicates ongoing action. 走(はし)っている = 'is running.'

COMMON PATTERNS:

  • 公園(こうえん)で走(はし)る (run in the park)
  • 道(みち)を走(はし)る (run along the road)
  • 走(はし)り出(だ)す (start running)
  • 走(はし)り回(まわ)る (run around)

Used for people, animals, vehicles. Faster than 歩(ある)く (walk). Godan verb - te-form: 走(はし)って.

Related Words

See also: 歩(ある)く
Synonym: 駆(か)ける (literary, vivid)
