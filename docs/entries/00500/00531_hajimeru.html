始(はじ)める

はじめる
verb (ichidan)
to begin, to start
1. to begin, to start (something)
To cause something to begin. A transitive verb - you start something. The intransitive pair is 始(はじ)まる (hajimaru).
授業(じゅぎょう)を始(はじ)めましょう。
Let's start the class.
新(あたら)しい仕事(しごと)を始(はじ)めました。
I started a new job.
食(た)べ始(はじ)める。
To start eating.
Compound verb: verb stem + 始める
来週(らいしゅう)から日本語(にほんご)の勉強(べんきょう)を始(はじ)めます。
I'll start studying Japanese from next week.
会社(かいしゃ)は来年(らいねん)から新(あたら)しいサービスを始(はじ)める予定(よてい)だと聞(き)きました。
I heard the company plans to start a new service next year.

TRANSITIVITY: 他動詞(たどうし) (transitive). Pair: 始(はじ)まる (intransitive). Pattern: Xを始(はじ)める (start X).

ASPECT: ている indicates ongoing state. 始(はじ)めている = 'has started (and is ongoing).'

COMMON PATTERNS:

  • 仕事(しごと)を始(はじ)める (start work)
  • 授業(じゅぎょう)を始(はじ)める (start class)
  • V-stem + 始(はじ)める (start V-ing)
  • 食(た)べ始(はじ)める (start eating)

PAIR: 始(はじ)まる (intransitive) - 授業(じゅぎょう)が始(はじ)まった (class started). Opposite: 終(お)わる/終(お)える.
