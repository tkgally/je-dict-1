図書館(としょかん)

としょかん
noun
library
1. library
A building containing books and other materials for reading and borrowing.
図書館(としょかん)で勉強(べんきょう)します。
I study at the library.
図書館(としょかん)で本(ほん)を借(か)りました。
I borrowed a book from the library.
図書館(としょかん)は静(しず)かです。
The library is quiet.
図書館(としょかん)の本(ほん)は二週間(にしゅうかん)借(か)りることができます。
You can borrow library books for two weeks.
私(わたし)は毎週(まいしゅう)土曜日(どようび)に図書館(としょかん)に行(い)きます。本(ほん)を借(か)りたり、新聞(しんぶん)を読(よ)んだりします。
I go to the library every Saturday. I borrow books and read newspapers.

図書館(としょかん) is a library where books and materials can be read or borrowed.

COMMON EXPRESSIONS:

  • 図書館(としょかん)で勉強(べんきょう)する: to study at the library
  • 図書館(としょかん)で本(ほん)を借(か)りる: to borrow a book from the library
  • 図書館(としょかん)に本(ほん)を返(かえ)す: to return a book to the library

TYPES:

  • 公立(こうりつ)図書館(としょかん): public library
  • 大学(だいがく)図書館(としょかん): university library
  • 国立(こくりつ)図書館(としょかん): national library
  • 電子(でんし)図書館(としょかん): digital library

RELATED:

  • 司書(ししょ): librarian
  • 貸出(かしだし): lending, checkout
  • 返却(へんきゃく): return
