どれ

どれ
pronoun
which one
1. which one
A question word asking to identify one item from a group of three or more. Used when choices are not directly attached to nouns.
あなたのかばんはどれですか？
Which one is your bag?
どれが一番(いちばん)好(す)きですか？
Which one do you like the best?
どれでもいいですから、好(す)きなのを選(えら)んでください。
Any one is fine, so please choose the one you like.
どれでも = any one (of them)
たくさんのスマホがありますが、この中(なか)でどれが一番(いちばん)人気(にんき)がありますか？
There are many smartphones, but which one of these is the most popular?
ケーキがたくさんあるけど、どれを食(た)べたいか決(き)められないので、友達(ともだち)に選(えら)んでもらいました。
There are many cakes, but I couldn't decide which one I wanted to eat, so I had my friend choose for me.

どれ is a question word for selecting one item from three or more options.

KO-SO-A-DO SYSTEM:

  • これ: this one (near speaker)
  • それ: that one (near listener)
  • あれ: that one over there (far from both)
  • どれ: which one? (question)

COMMON PATTERNS:

  • どれが一番(いちばん)〜: which one is the most ~?
  • どれでも: any one (of them)
  • どれでもいい: any one is fine

NOTE:
For two items, use どちら instead. どれ implies three or more choices.

RELATED:

  • どの + noun: which ~ (attributive form)
