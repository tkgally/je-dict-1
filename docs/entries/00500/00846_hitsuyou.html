必要(ひつよう)

ひつよう
adjective (na-adjective)
necessary, needed
1. necessary, needed, required
Essential or required for a purpose. Can function as a na-adjective or noun.
お金(かね)が必要(ひつよう)です。
I need money.
それは必要(ひつよう)ありません。
That's not necessary.
必要(ひつよう)な物(もの)を買(か)いました。
I bought the things I needed.
na-adjective modifying noun
この仕事(しごと)には車(くるま)が必要(ひつよう)です。
A car is necessary for this job.
日本(にほん)に行(い)くなら、日本語(にほんご)を勉強(べんきょう)する必要(ひつよう)があります。まず言葉(ことば)を覚(おぼ)えましょう。
If you're going to Japan, you need to study Japanese. Let's start by learning the language.
必要がある = there is a need to

必要(ひつよう) functions as both a na-adjective and a noun meaning 'necessary' or 'necessity.'

USAGE:
必要(ひつよう) works as both a na-adjective and a noun. As a na-adjective it predicates with だ/です (時間(じかん)が必要(ひつよう)です, "time is needed") and modifies a noun with な (必要(ひつよう)な物(もの), "necessary things"). As a noun it heads phrases like 必要(ひつよう)がある ("there is a need to"). Note the frame XがYに必要(ひつよう)だ = "X is necessary for Y."

GRAMMATICAL PATTERNS:

  • [noun]が必要(ひつよう)だ: [noun] is necessary
  • 必要(ひつよう)な[noun]: necessary [noun]
  • 必要(ひつよう)がある: there is a need (to)
  • 必要(ひつよう)はない: there is no need (to)
  • 必要(ひつよう)に応(おう)じて: as needed, according to necessity

COMMON EXPRESSIONS:

  • 必要(ひつよう)書類(しょるい): required documents
  • 必要(ひつよう)最低限(さいていげん): bare minimum necessity
  • 必要(ひつよう)経費(けいひ): necessary expenses

OPPOSITE:
不必要(ふひつよう) (unnecessary)

NOTE:
When expressing personal need, the pattern XがYに必要(ひつよう)だ (X is necessary for Y) is common. For 'I need X,' Japanese often uses Xが要(い)る or Xが欲(ほ)しい instead.
