今月(こんげつ)

こんげつ
noun, adverb
this month
1. this month
The current month; the month we are in now. Used to talk about events or plans within the present month.
今月(こんげつ)は忙(いそが)しいです。
I'm busy this month.
今月(こんげつ)の天気(てんき)はどうですか。
How's the weather this month?
今月(こんげつ)は誕生日(たんじょうび)です。
My birthday is this month.
今月(こんげつ)の終(お)わりに友達(ともだち)と旅行(りょこう)に行(い)く予定(よてい)なので、今(いま)から楽(たの)しみです。
I'm planning to go on a trip with friends at the end of this month, so I'm already looking forward to it.
今月(こんげつ)は雨(あめ)が多(おお)かったですが、来月(らいげつ)は晴(は)れる日(ひ)が多(おお)いので、出(で)かけることが楽(たの)しみです。
There was a lot of rain this month, but next month will have many sunny days, so I'm looking forward to going out.

TIME REFERENCE SERIES:

  • 先月(せんげつ): last month
  • 今月(こんげつ): this month
  • 来月(らいげつ): next month

The prefix こん- ("this, current") forms a pattern with other time words:

  • 今日(きょう): today (irregular reading)
  • 今週(こんしゅう): this week
  • 今年(ことし): this year (irregular reading)
  • 今朝(けさ): this morning (irregular reading)

USAGE:
Can function as both a noun (今月(こんげつ)は忙(いそが)しい, "this month is busy") and adverbially with no particle (今月(こんげつ)届(とど)く, "it arrives this month").

No particle is needed when it modifies a verb; に is not used with 今月(こんげつ) the way it is with a specific date.
