プログラミング

ぷろぐらみんぐ
noun
programming
1. programming
The process of writing, testing, and maintaining computer programs; coding.
プログラミングを勉強(べんきょう)している。
I'm studying programming.
プログラミング言語(げんご)を習得(しゅうとく)する。
To master a programming language.
小学校(しょうがっこう)でプログラミング教育(きょういく)が必修化(ひっしゅうか)された。
Programming education became mandatory in elementary schools.
Refers to Japan's 2020 curriculum change

USAGE:
プログラミング has become increasingly common in everyday Japanese, especially after programming education became part of the elementary school curriculum in Japan in 2020.

COMMON PATTERNS:

  • プログラミングを学(まな)ぶ/勉強(べんきょう)する (learn/study programming)
  • プログラミング言語(げんご) (programming language)
  • プログラミング教育(きょういく) (programming education)
  • プログラミングスクール (programming school/bootcamp)

SYNONYMS:

  • コーディング (coding) - more technical, refers to the act of writing code

POPULAR LANGUAGES:

  • Python, JavaScript, Java, Ruby, etc.

Related Words

Related: コーディング (coding)
