駆(か)け下(お)りる

かけおりる
verb (ichidan, intransitive)
to run down; to dash down
1. to run down; to dash down
To run quickly downward, such as descending stairs, a hill, or a slope at speed.
階段(かいだん)を駆(か)け下(お)りる。
To run down the stairs.
彼(かれ)は山道(やまみち)を駆(か)け下(お)りてきた。
He came running down the mountain path.
危(あぶ)ないから駆(か)け下(お)りないで。
It's dangerous, so don't run down.

COMPOUND VERB:
駆(か)ける (to run, to gallop) + 下(お)りる (to go down, to descend)

TRANSITIVITY:
自動詞(じどうし) (intransitive) - takes を for the path being traversed

ALTERNATE FORMS:
Also written as 駆(か)け降(お)りる using a different kanji for おりる.

RELATED COMPOUND VERBS:

  • 駆(か)け上(あ)がる: to run up
  • 駆(か)け込(こ)む: to rush in
  • 駆(か)け回(まわ)る: to run around

COMMON COLLOCATIONS:

  • 階段(かいだん)を駆(か)け下(お)りる: to run down the stairs
  • 坂(さか)を駆(か)け下(お)りる: to run down a slope
