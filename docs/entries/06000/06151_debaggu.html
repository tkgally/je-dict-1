デバッグ

でばっぐ
noun, suru verb
debugging; bug fixing

Definitions

1. debugging
The process of finding and fixing errors (bugs) in computer programs or systems.

Examples

プログラムのデバッグに時間(じかん)がかかった。
Debugging the program took a long time.
エラーを見(み)つけてデバッグする。
To find errors and debug them.
デバッグ作業(さぎょう)は開発(かいはつ)の重要(じゅうよう)な部分(ぶぶん)だ。
Debugging is an important part of development.

Notes

LOANWORD:
From English 'debug.'

REGISTER:
Technical. Used in software development and IT contexts.

RELATED TERMS:

  • バグ: bug (error)
  • コーディング: coding
  • テスト: testing
  • エラー: error

COMMON COLLOCATIONS:

  • デバッグする: to debug
  • デバッグ作業(さぎょう): debugging work
  • デバッグツール: debugging tool
  • デバッグモード: debug mode

DERIVATION:
The term 'bug' in computing allegedly originated from an actual moth found in an early computer at Harvard in 1947, though the term was used earlier.
