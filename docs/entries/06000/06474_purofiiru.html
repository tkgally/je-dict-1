プロフィール

ぷろふぃーる
noun
profile, bio

Definitions

1. profile, biographical information
Personal information or description about someone, especially as displayed on social media, websites, or official materials. Can also refer to a side view outline of someone's face.

Examples

SNSのプロフィールを更新(こうしん)した。
I updated my social media profile.
プロフィール写真(しゃしん)を変更(へんこう)してください。
Please change your profile photo.
出演者(しゅつえんしゃ)のプロフィールはパンフレットに載(の)っています。
The performers' profiles are in the pamphlet.

Notes

ETYMOLOGY: From French/English "profile."

COMMON COLLOCATIONS:

  • プロフィール写真(しゃしん)/プロフィール画像(がぞう) (profile picture)
  • プロフィールを設定(せってい)する (to set up a profile)
  • プロフィールを更新(こうしん)する (to update a profile)
  • プロフィールを見(み)る (to view a profile)
  • 自己(じこ)プロフィール (self-profile, bio)

COMMON PROFILE ELEMENTS:

  • 名前(なまえ) (name)
  • 年齢(ねんれい)/生年月日(せいねんがっぴ) (age/date of birth)
  • 出身地(しゅっしんち) (hometown)
  • 趣味(しゅみ) (hobbies)
  • 職業(しょくぎょう) (occupation)

ABBREVIATIONS:

  • プロフ: common abbreviation (casual)
  • プロフ画(が): profile picture (casual)
  • プロフ欄(らん): profile section
