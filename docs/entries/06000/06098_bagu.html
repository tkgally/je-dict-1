バグ

ばぐ
noun
bug (software)
1. bug (software error)
An error, flaw, or unintended behavior in a computer program or system.
プログラムにバグが見(み)つかった。
A bug was found in the program.
バグを修正(しゅうせい)する。
To fix a bug.
2. glitch, malfunction
More broadly, any unexpected problem or malfunction, especially in games or apps.
このゲームにはバグが多(おお)い。
This game has many bugs.

USAGE:
バグ is a loanword from English 'bug'. The term originated from an actual moth found in an early computer causing a malfunction.

COMMON PATTERNS:

  • バグを見(み)つける (find a bug)
  • バグを修正(しゅうせい)する (fix a bug)
  • バグを直(なお)す (fix a bug - casual)
  • バグが発生(はっせい)する (a bug occurs)
  • バグ報告(ほうこく) (bug report)

RELATED TERMS:

  • デバッグ (debug)
  • エラー (error)
  • 不具合(ふぐあい) (malfunction - more formal)
  • バグる (to glitch - slang verb form)
