敷金(しききん)

しききん
noun
security deposit

Definitions

1. security deposit, damage deposit
A refundable deposit paid when renting an apartment in Japan, typically 1-2 months' rent. Used to cover repairs for damages beyond normal wear and tear.

Examples

敷金(しききん)は家賃(やちん)の2ヶ月分(かげつぶん)です。
The security deposit is two months' rent.
退去時(たいきょじ)に敷金(しききん)の一部(いちぶ)が返(かえ)ってきた。
Part of the security deposit was returned when I moved out.
敷金(しききん)礼金(れいきん)なしの物件(ぶっけん)を探(さが)している。
I'm looking for a property with no deposit or key money.
Common when apartment hunting

Notes

COMPOUND: 敷(し)く (to spread, lay) + 金(きん) (money)

JAPANESE RENTAL SYSTEM:

  • 敷金(しききん) (security deposit) - refundable
  • 礼金(れいきん) (key money) - non-refundable
  • Both are typically paid upfront when signing a lease

COMMON PATTERNS:

  • 敷金(しききん)を払(はら)う (pay the security deposit)
  • 敷金(しききん)が戻(もど)る (security deposit is returned)
  • 敷金(しききん)ゼロ (zero deposit)

NOTE: In recent years, more '0ゼロ物件(ぶっけん)' (zero-zero properties) with no 敷金(しききん) or 礼金(れいきん) have become available.
