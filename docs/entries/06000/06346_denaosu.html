1. to start over; to make a fresh start; to try again
To begin something again from the beginning, often after a failed attempt.
一(いち)から出直(でなお)す。
To start over from scratch.
人生(じんせい)を出直(でなお)したい。
I want to start my life over.
失敗(しっぱい)したので最初(さいしょ)から出直(でなお)すことにした。
Since I failed, I decided to start over from the beginning.
計画(けいかく)がうまくいかなかったので、ゼロから出直(でなお)そう。
The plan didn't work out, so let's start over from zero.
会社(かいしゃ)を辞(や)めて、新(あたら)しい気持(きも)ちで出直(でなお)すつもりだ。
I plan to quit the company and make a fresh start with a new attitude.
2. to come back again; to return at a better time
To leave and return later, usually when the timing wasn't right the first time.
また出直(でなお)します。
I'll come back again.
Polite expression used when leaving to return later
相手(あいて)が留守(るす)だったので出直(でなお)した。
The person was out, so I came back later.
店(みせ)が混(こ)んでいたので、時間(じかん)を変(か)えて出直(でなお)した。
The store was crowded, so I changed the time and came back.
今日(きょう)は忙(いそが)しいので、明日(あした)出直(でなお)してもいいですか。
I'm busy today, so may I come back tomorrow?
担当者(たんとうしゃ)が不在(ふざい)だったので、午後(ごご)に出直(でなお)すことにした。
The person in charge was absent, so I decided to come back in the afternoon.

TRANSITIVITY: 自動詞(じどうし) (intransitive). Compound verb: 出(で)る + 直(なお)す.

NUANCE: The 直(なお)す component suggests "doing over" or "redoing." This verb implies going back to the beginning and trying again with a fresh approach.

COMMON PATTERNS:

  • ゼロから出直(でなお)す: to start over from zero
  • 一(いち)から出直(でなお)す: to start over from scratch
  • また出直(でなお)します: I'll come back again (polite)

SIMILAR:

  • やり直(なお)す: to redo, to do over (more general)
