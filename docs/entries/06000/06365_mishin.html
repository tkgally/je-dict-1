ミシン

みしん
noun
sewing machine
1. sewing machine
A machine used for stitching fabric together, typically using a needle and thread.
ミシンで服(ふく)を縫(ぬ)う。
To sew clothes with a sewing machine.
母(はは)はミシンを使(つか)ってカーテンを作(つく)った。
My mother made curtains using a sewing machine.
このミシンは糸(いと)が絡(から)まりやすい。
This sewing machine tends to get the thread tangled.

ETYMOLOGY: From English 'machine', via 'sewing machine'. The Japanese word ミシン is a shortened and altered form of the English word 'machine'.

COMMON COLLOCATIONS:

  • ミシンで縫(ぬ)う (to sew with a sewing machine)
  • ミシンをかける (to use/operate a sewing machine)
  • ミシン目(め) (machine stitching)
  • ミシン糸(いと) (sewing machine thread)

TYPES:

  • 家庭用(かていよう)ミシン - home sewing machine
  • 工業用(こうぎょうよう)ミシン - industrial sewing machine
  • 電動(でんどう)ミシン - electric sewing machine
  • 足踏(あしぶ)みミシン - treadle sewing machine

RELATED TERMS:

  • 裁縫(さいほう) - sewing, needlework
  • 縫(ぬ)う - to sew
  • 針(はり) - needle
  • 糸(いと) - thread
