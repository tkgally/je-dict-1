プッシュ通知(つうち)

ぷっしゅつうち
noun
push notification

Definitions

1. push notification
An automated message sent by an app or website to a user's device, appearing even when the app isn't open. Commonly used for alerts, updates, and promotional messages.

Examples

プッシュ通知(つうち)をオンにすると最新(さいしん)情報(じょうほう)が届(とど)きます。
If you turn on push notifications, you'll receive the latest information.
プッシュ通知(つうち)が多(おお)すぎて煩(わずら)わしい。
There are too many push notifications and it's annoying.
設定(せってい)からプッシュ通知(つうち)をオフにできます。
You can turn off push notifications in the settings.

Notes

COMPOSITION:

  • プッシュ (push - from English) + 通知(つうち) (notification)

COMMON COLLOCATIONS:

  • プッシュ通知(つうち)をオン/オフにする (to turn push notifications on/off)
  • プッシュ通知(つうち)を受(う)け取(と)る (to receive push notifications)
  • プッシュ通知(つうち)を許可(きょか)する (to allow push notifications)
  • プッシュ通知(つうち)の設定(せってい) (push notification settings)

RELATED TERMS:

  • 通知(つうち): notification (general)
  • アラート: alert
  • リマインダー: reminder
  • 通知音(つうちおん): notification sound
  • 通知(つうち)センター: notification center

USAGE NOTES:

In app settings, users often see options like:

  • プッシュ通知(つうち)を受(う)け取(と)る ✓
  • 全(すべ)ての通知(つうち)をオフ
  • 重要(じゅうよう)な通知(つうち)のみ
