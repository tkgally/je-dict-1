駆(か)け上(あ)がる

かけあがる
verb (godan, intransitive)
to run up; to dash up
1. to run up; to dash up
To run quickly upward, such as climbing stairs, a hill, or a slope at speed.
階段(かいだん)を駆(か)け上(あ)がる。
To run up the stairs.
子供(こども)たちが丘(おか)を駆(か)け上(あ)がっていった。
The children ran up the hill.
急(きゅう)いで坂道(さかみち)を駆(か)け上(あ)がった。
I hurried and ran up the slope.

COMPOUND VERB:
駆(か)ける (to run, to gallop) + 上(あ)がる (to go up)

TRANSITIVITY:
自動詞(じどうし) (intransitive) - takes を for the path being traversed

RELATED COMPOUND VERBS:

  • 駆(か)け下(お)りる: to run down
  • 駆(か)け込(こ)む: to rush in
  • 駆(か)け回(まわ)る: to run around
  • 駆(か)け抜(ぬ)ける: to run through

COMMON COLLOCATIONS:

  • 階段(かいだん)を駆(か)け上(あ)がる: to run up the stairs
  • 坂(さか)を駆(か)け上(あ)がる: to run up a slope
