既読(きどく)

きどく
noun, no-adjective
read (message status)

Definitions

1. read, already read (message status)
Indicates that a message has been read by the recipient. Originally a feature of LINE messaging app, now widely used across various messaging platforms.

Examples

メッセージが既読(きどく)になった。
The message has been read.
既読(きどく)がついているのに返信(へんしん)がない。
It shows as read but there's no reply.
既読(きどく)スルーされた。
I was left on read.
既読(きどく)スルー = read and ignored
既読(きどく)無視(むし)はやめてほしい。
I wish they would stop ignoring my messages after reading them.

Notes

COMPOSITION: 既(き) (already) + 読(どく) (reading) = already read

ORIGIN: This term became widely used with the LINE messaging app's read receipt feature, which shows "既読(きどく)" when a message has been seen.

COMMON EXPRESSIONS:

  • 既読(きどく)がつく - to show as read
  • 既読(きどく)になる - to become read (status changes to read)
  • 既読(きどく)スルー - to leave someone on read, to read but not reply
  • 既読(きどく)無視(むし) - to ignore after reading

ANTONYM:

  • 未読(みどく) - unread

CULTURAL NOTE: The 既読(きどく)スルー phenomenon has become a social issue in Japan, especially among young people, as ignoring messages after reading them is seen as rude or can cause anxiety about the relationship.

Related Words

Antonym: 未読(みどく) (unread)
