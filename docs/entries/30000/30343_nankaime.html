何回目(なんかいめ)

なんかいめ
noun
which time (in a series); what number time
1. which time in a sequence
Asks for the ordinal position of an occasion — whether something is the second, third, fifth time, and so on. English has no single word for it, so it is usually translated with a full question.
今回(こんかい)で何回目(なんかいめ)ですか。
How many times is this now?
日本(にほん)に来(く)るのは何回目(なんかいめ)ですか。
Is this your first time in Japan, or have you been before?
同(おな)じ失敗(しっぱい)を繰(く)り返(かえ)すのは、これで何回目(なんかいめ)だろう。
I wonder how many times this makes that I have repeated the same mistake.

Formed from 何回(なんかい) (how many times) plus the ordinal suffix 〜目(め). The 〜目(め) is what makes it ordinal: 何回(なんかい) asks for a total count, 何回目(なんかいめ) asks for a position in a series.

COMMON PATTERNS:

  • 何回目(なんかいめ)ですか: which time is this?
  • これで何回目(なんかいめ): how many times does this make
  • 何回目(なんかいめ)の挑戦(ちょうせん): which attempt (in a series)

ANSWERING:
Answers use the same 〜目(め) pattern: 一回目(いっかいめ) (the first time), 二回目(にかいめ) (the second time), 三回目(さんかいめ) (the third time).
