感染者数(かんせんしゃすう)

かんせんしゃすう
noun
number of infected people; case count
1. number of infected people; number of cases
How many people have been confirmed to have caught a particular infectious disease, usually reported for a given day or region.
感染者数(かんせんしゃすう)が減(へ)ってきた。
The number of infected people has been falling.
昨日(きのう)の感染者数(かんせんしゃすう)は百人(ひゃくにん)を超(こ)えた。
Yesterday's case count exceeded one hundred people.
検査(けんさ)の数(かず)が限(かぎ)られているため、発表(はっぴょう)された感染者数(かんせんしゃすう)は実際(じっさい)より少(すく)ないとみられる。
Because the number of tests is limited, the announced case count is thought to be lower than the real figure.

感染者(かんせんしゃ) (infected person) + 数(すう) (number, count). Became everyday news vocabulary during the coronavirus pandemic and is now the standard way of reporting case figures.

COMMON COLLOCATIONS:

  • 感染者数(かんせんしゃすう)が増(ふ)える: for the number of cases to rise
  • 新規(しんき)感染者数(かんせんしゃすう): the number of new cases
  • 感染者数(かんせんしゃすう)を発表(はっぴょう)する: to announce the case count

SIMILAR WORDS:

  • 感染率(かんせんりつ): infection rate — a proportion rather than a headcount
  • 死者数(ししゃすう): death toll — the same 数(すう) pattern applied to deaths
