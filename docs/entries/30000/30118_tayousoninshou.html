多要素認証(たようそにんしょう)

たようそにんしょう
noun
multi-factor authentication; MFA
1. multi-factor authentication; MFA
A login method that requires two or more independent kinds of proof — a password, a code sent to a phone, a fingerprint — before granting access. Now standard on banking and workplace systems.
多要素認証(たようそにんしょう)を設定(せってい)した。
I set up multi-factor authentication.
社内(しゃない)システムでは多要素認証(たようそにんしょう)が必須(ひっす)となった。
Multi-factor authentication has become mandatory for internal systems.
パスワードが漏(も)れても、多要素認証(たようそにんしょう)があれば不正(ふせい)ログインを防(ふせ)ぎやすい。
Even if a password leaks, multi-factor authentication makes unauthorized logins easier to prevent.

Often abbreviated MFA in Japanese technical writing as well. 二要素認証(にようそにんしょう) (two-factor authentication, 2FA) is the common special case.

COMMON COLLOCATIONS:

  • 多要素認証(たようそにんしょう)を導入(どうにゅう)する: to introduce multi-factor authentication
  • 多要素認証(たようそにんしょう)を有効(ゆうこう)にする: to enable multi-factor authentication
  • 多要素認証(たようそにんしょう)が必須(ひっす): multi-factor authentication is required

SIMILAR WORDS:

  • 二段階認証(にだんかいにんしょう): two-step verification — two steps that may use the same kind of factor, so slightly weaker in principle
  • 生体認証(せいたいにんしょう): biometric authentication — one possible factor within MFA
