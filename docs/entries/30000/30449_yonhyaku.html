四百(よんひゃく)

よんひゃく
number
four hundred
1. four hundred (400)
The number 400. 四(よん) + 百(ひゃく), with no sound change.
四百(よんひゃく)円(えん)の弁当(べんとう)を買(か)った。
I bought a 400-yen boxed lunch.
この本(ほん)は四百(よんひゃく)ページもある。
This book is a full 400 pages long.
駅(えき)からホテルまでは四百(よんひゃく)メートルほどで、歩(ある)いてもすぐだ。
It is about 400 meters from the station to the hotel, so it's a short walk.

四(よん) + 百(ひゃく). Both parts keep their normal shape.

SOUND CHANGES IN THE HUNDREDS:

Only three of the hundreds change:

  • 三百(さんびゃく): ひゃく → びゃく
  • 六百(ろっぴゃく): ろく → ろっ, ひゃく → ぴゃく
  • 八百(はっぴゃく): はち → はっ, ひゃく → ぴゃく

All the others, including 四百(よんひゃく), are regular.

READING NOTE:
The older reading しひゃく survives only in a few set expressions such as 四百四病(しひゃくしびょう) (the ills that flesh is heir to). For counting, always say よんひゃく.

COMMON COLLOCATIONS:

  • 四百(よんひゃく)字(じ)詰(づ)め原稿(げんこう)用紙(ようし): the standard 400-character manuscript sheet
  • 四百(よんひゃく)メートル走(そう): the 400-meter dash
