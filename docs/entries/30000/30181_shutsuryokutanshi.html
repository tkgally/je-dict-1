出力端子

しゅつりょくたんし
noun
output terminal; output jack; output port
1. output terminal; output jack; output port
The socket or connector on a device from which a signal or current is sent out. Standard wording in manuals and specification sheets for audio, video, and electrical equipment.
出力端子(しゅつりょくたんし)にケーブルをつなぐ。
Connect the cable to the output terminal.
この機種(きしゅ)には音声(おんせい)出力端子(しゅつりょくたんし)が二(ふた)つある。
This model has two audio output terminals.
音(おと)が出(で)ないときは、出力端子(しゅつりょくたんし)に正(ただ)しく差(さ)し込(こ)まれているか確(たし)かめてください。
If there is no sound, please check that the plug is properly inserted in the output terminal.

Formed from 出力(しゅつりょく) (output) plus 端子(たんし) (terminal, connector).

COMMON COLLOCATIONS:

  • 音声(おんせい)出力端子(しゅつりょくたんし): audio output terminal
  • 出力端子(しゅつりょくたんし)に接続(せつぞく)する: to connect to the output terminal
  • 出力端子(しゅつりょくたんし)が付(つ)いている: to be equipped with an output terminal

SIMILAR WORDS:

  • 入力端子(にゅうりょくたんし): input terminal — the direct counterpart
  • 差(さ)し込(こ)み口(くち): socket, jack — plainer everyday wording
  • コネクタ: connector — the plug or fitting itself rather than the socket on the device
