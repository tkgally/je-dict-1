分校(ぶんこう)

ぶんこう
noun
branch school; branch campus
1. branch school; branch campus
A small satellite campus operated by a main school (本校(ほんこう)), typically set up in a remote area so that local children do not have to travel far. Many are tiny, with a handful of pupils and combined-grade classes.
島(しま)に小(ちい)さな分校(ぶんこう)がある。
There is a small branch school on the island.
この分校(ぶんこう)の生徒(せいと)は五人(ごにん)だけだ。
This branch school has only five pupils.
子(こ)どもの数(かず)が減(へ)ったため、村(むら)の分校(ぶんこう)は来年(らいねん)閉校(へいこう)することになった。
Because the number of children has fallen, the village branch school is to close next year.

Composed of 分(ぶん) (divided, branch) + 校(こう) (school). Always defined against a 本校(ほんこう) (main campus), which handles administration and record-keeping.

COMMON COLLOCATIONS:

  • 分校(ぶんこう)に通(かよ)う: to attend a branch school
  • 分校(ぶんこう)を閉(と)じる: to close a branch school
  • 小学校(しょうがっこう)の分校(ぶんこう): an elementary-school branch campus
  • 分校(ぶんこう)から本校(ほんこう)へ移(うつ)る: to transfer from the branch to the main campus

CULTURAL CONTEXT:
Branch schools are strongly associated with mountain villages and small islands. As rural populations age and shrink, closures (閉校(へいこう)) are frequent local news, and a closing 分校(ぶんこう) is a common shorthand in Japanese media for depopulation.
