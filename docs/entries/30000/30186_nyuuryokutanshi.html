入力端子

にゅうりょくたんし
noun
input terminal; input jack
1. input terminal; input jack; input port
The socket on a device through which a signal comes in — the audio, video, or data connector you plug an incoming cable into. The counterpart of 出力端子(しゅつりょくたんし).
入力端子(にゅうりょくたんし)にケーブルを差(さ)し込(こ)む。
You plug the cable into the input jack.
このアンプには入力端子(にゅうりょくたんし)が四(よっ)つある。
This amplifier has four input terminals.
映像(えいぞう)が映(うつ)らないときは、まず入力端子(にゅうりょくたんし)の接続(せつぞく)を確(たし)かめてください。
If the picture does not appear, first check the connection at the input terminal.
古(ふる)いテレビなので、入力端子(にゅうりょくたんし)の種類(しゅるい)が今(いま)の機器(きき)と合(あ)わない。
Because the TV is old, the type of input terminal does not match today's devices.

端子(たんし) is the general word for an electrical terminal or connector, so the pattern 入力(にゅうりょく)／出力(しゅつりょく) + 端子(たんし) names the direction the signal travels.

COMMON COLLOCATIONS:

  • 入力端子(にゅうりょくたんし)に接続(せつぞく)する: to connect to an input terminal
  • 入力端子(にゅうりょくたんし)が足(た)りない: to not have enough input jacks
  • 音声(おんせい)入力端子(にゅうりょくたんし): audio input jack

SIMILAR WORDS:

  • 出力端子(しゅつりょくたんし): output terminal — where the signal leaves the device
  • 差(さ)し込(こ)み口(ぐち): socket, outlet — everyday word, often for electrical power rather than signals
