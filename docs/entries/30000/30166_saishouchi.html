最小値

さいしょうち
noun
minimum value; smallest value
1. minimum value; smallest value; minimum
The smallest number in a set of data or the lowest value a function or measurement takes. Used in mathematics, statistics, and any context involving recorded figures.
最小値(さいしょうち)は0だった。
The minimum value was zero.
このデータの最小値(さいしょうち)を求(もと)めてください。
Please find the minimum value of this data.
今週(こんしゅう)の気温(きおん)の最小値(さいしょうち)と最大値(さいだいち)を記録(きろく)しておいた。
I recorded this week's minimum and maximum temperatures.

Formed from 最小(さいしょう) (smallest) plus 値(ち) (value). The 値(ち) reading is used in this technical family of words; the same kanji read 値(あたい) is the everyday word for "value" or "price."

COMMON COLLOCATIONS:

  • 最小値(さいしょうち)を求(もと)める: to find the minimum value
  • 最小値(さいしょうち)を取(と)る: to take its minimum value
  • 最小値(さいしょうち)を下回(したまわ)る: to fall below the minimum

RELATED TERMS:

  • 最大値(さいだいち): maximum value — the direct opposite
  • 平均値(へいきんち): average value, mean
  • 中央値(ちゅうおうち): median
