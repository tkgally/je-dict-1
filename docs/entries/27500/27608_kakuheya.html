各部屋(かくへや)

かくへや
noun
each room; every room
1. each room; every room
Refers to each individual room in a building, hotel, house, etc. Common in descriptions of facilities, amenities, or rules that apply to every room.
各部屋(かくへや)にエアコンがある。
There is an air conditioner in each room.
各部屋(かくへや)の鍵(かぎ)はフロントで受(う)け取(と)ってください。
Please pick up the keys for each room at the front desk.
このホテルは各部屋(かくへや)に専用(せんよう)のバルコニーが付(つ)いている。
This hotel has a private balcony attached to each room.

Prefix 各(かく) (each) + 部屋(へや) (room). The prefix 各(かく) attaches to nouns to mean 'each' or 'every,' typically referring to distinct units.

COMMON COLLOCATIONS:

  • 各部屋(かくへや)に〜がある: there is ~ in each room
  • 各部屋(かくへや)に備(そな)え付(つ)けられている: provided in each room
  • 各部屋(かくへや)の広(ひろ)さ: the size of each room

SIMILAR PATTERNS:

The 各(かく) prefix appears in many similar compounds:

  • 各国(かっこく): each country
  • 各地(かくち): each area
  • 各自(かくじ): each person
