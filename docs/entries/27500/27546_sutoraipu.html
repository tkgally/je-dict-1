ストライプ

すとらいぷ
noun
stripe; striped pattern
1. stripe; striped pattern
A pattern of parallel lines, typically used to describe fabrics, clothing, ties, or wallpaper. From English "stripe."
青(あお)いストライプのシャツを着(き)た。
I wore a blue striped shirt.
細(ほそ)いストライプのネクタイが好(す)きだ。
I like ties with thin stripes.
今年(ことし)の春(はる)はストライプ柄(がら)のワンピースが流行(はや)っている。
Striped one-piece dresses are in fashion this spring.

Loanword from English "stripe." Used mostly for clothing and accessories. Always written in katakana.

COMMON COLLOCATIONS:

  • ストライプ柄(がら): striped pattern
  • 細(ほそ)いストライプ: thin stripes
  • 太(ふと)いストライプ: thick stripes
  • ストライプのシャツ: striped shirt
  • 縦(たて)ストライプ: vertical stripes

SIMILAR WORDS:

  • 縞(しま): stripes (native Japanese word) — slightly more general; can refer to natural patterns like 縞馬(しまうま) (zebra)
  • チェック: check; plaid pattern
  • 水玉(みずたま): polka dot
