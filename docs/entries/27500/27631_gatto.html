ガット

がっと
noun
gut; gut string (for racket or instrument)
1. gut; gut string (for racket or instrument)
String made from animal intestines (or synthetic equivalent), used to string tennis rackets, badminton rackets, and stringed musical instruments.
ラケットのガットが切(き)れた。
The strings on my racket broke.
新(あたら)しいガットを張(は)ってもらった。
I had new strings put on (the racket).
テニスのガットは硬(かた)さによって打(う)ち心地(ごこち)が変(か)わる。
The feel of tennis strings changes depending on their tension.

From English 'gut'. Originally referred to strings made from animal intestines; today most strings are nylon or synthetic, but the term ガット is still used for racket strings in general.

COMMON COLLOCATIONS:

  • ガットを張(は)る: to string (a racket)
  • ガットが切(き)れる: (strings) to break
  • ガットの張(は)り替(か)え: restringing
  • ナチュラルガット: natural gut (true animal-gut string)

NOTE: Not to be confused with the homophone GATT (関税(かんぜい)及(およ)び貿易(ぼうえき)に関(かん)する一般協定(いっぱんきょうてい), the pre-WTO trade agreement), which is written the same way in katakana.
