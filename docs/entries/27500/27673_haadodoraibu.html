ハードドライブ

はーどどらいぶ
noun
hard drive; hard disk
1. hard drive; hard disk drive
A storage device inside or attached to a computer that holds the operating system, programs, and files on rotating magnetic disks.
ハードドライブが壊(こわ)れた。
The hard drive broke.
データを外付(そとづ)けのハードドライブに保存(ほぞん)する。
Save the data to an external hard drive.
このパソコンはハードドライブの容量(ようりょう)が足(た)りなくなってきた。
This computer is starting to run out of hard drive space.

A loanword from English "hard drive". Often shortened to ハード in casual speech.

COMMON COLLOCATIONS:

  • 外付(そとづ)けハードドライブ: external hard drive
  • ハードドライブの容量(ようりょう): hard drive capacity
  • ハードドライブにデータを保存(ほぞん)する: to save data to a hard drive
  • ハードドライブが壊(こわ)れる: the hard drive breaks down

SIMILAR WORDS:

  • ハードディスク: hard disk — nearly synonymous; refers to the disk component itself
  • SSD: solid-state drive — newer storage with no moving parts, faster than a hard drive
