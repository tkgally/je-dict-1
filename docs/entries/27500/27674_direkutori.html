ディレクトリ

でぃれくとり
noun
directory; folder
1. directory; folder (in computing)
A named location in a computer's file system used to organize and group files. Equivalent to a folder.
ディレクトリを作成(さくせい)する。
Create a directory.
ファイルを別(べつ)のディレクトリに移動(いどう)した。
I moved the file to a different directory.
このコマンドで現在(げんざい)のディレクトリの中身(なかみ)が表示(ひょうじ)される。
This command displays the contents of the current directory.

A loanword from English "directory", used mainly in technical and programming contexts. In everyday computer use, フォルダ (folder) is far more common; ディレクトリ sounds more technical.

COMMON COLLOCATIONS:

  • 現在(げんざい)のディレクトリ: current directory
  • ディレクトリを作成(さくせい)する: to create a directory
  • ルートディレクトリ: root directory
  • ディレクトリ構造(こうぞう): directory structure

SIMILAR WORDS:

  • フォルダ: folder — the everyday term, especially in graphical interfaces
  • ファイル: file — a single document, stored inside a directory
