メモリースティック

めもりーすてぃっく
noun
memory stick; USB flash drive
1. memory stick; USB flash drive
A small, portable data-storage device, especially a USB flash drive. "Memory Stick" is also the name of a memory-card format developed by Sony.
メモリースティックにデータを保存(ほぞん)した。
I saved the data to a memory stick.
メモリースティックをパソコンに差(さ)し込(こ)む。
I plug the memory stick into the computer.
発表(はっぴょう)の資料(しりょう)はメモリースティックに入(い)れて持(も)って行(い)った。
I put the presentation materials on a memory stick and took them with me.

A loanword from English. In everyday Japanese it usually means a USB flash drive; it is also the name of a memory-card format developed by Sony.

USAGE:

  • メモリースティックに保存(ほぞん)する: to save to a memory stick
  • メモリースティックを差(さ)し込(こ)む: to insert a memory stick

SIMILAR WORDS:

  • USBメモリ: USB flash drive — the more common everyday term in Japan
  • メモリーカード: memory card — a flat card used in cameras and other devices
