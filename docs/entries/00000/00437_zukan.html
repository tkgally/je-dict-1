図鑑(ずかん)

ずかん
noun
illustrated reference book
1. illustrated reference book, pictorial encyclopedia
A book with pictures and descriptions of items in a particular category, such as animals, plants, or insects.
子供(こども)に昆虫(こんちゅう)図鑑(ずかん)を買(か)ってあげた。
I bought an insect encyclopedia for my child.
植物(しょくぶつ)図鑑(ずかん)で花(はな)の名前(なまえ)を調(しら)べた。
I looked up the flower's name in a plant reference book.
恐竜(きょうりゅう)図鑑(ずかん)は子供(こども)たちに人気(にんき)がある。
Dinosaur encyclopedias are popular with children.

図鑑(ずかん) is an illustrated reference book, typically organized by category (animals, plants, etc.) with pictures and descriptions.

Common types:

  • 昆虫(こんちゅう)図鑑(ずかん) (insect encyclopedia)
  • 植物(しょくぶつ)図鑑(ずかん) (plant encyclopedia)
  • 動物(どうぶつ)図鑑(ずかん) (animal encyclopedia)
  • 恐竜(きょうりゅう)図鑑(ずかん) (dinosaur encyclopedia)
  • 魚(さかな)図鑑(ずかん) (fish encyclopedia)
  • 鳥(とり)図鑑(ずかん) (bird encyclopedia)

Related words:

  • 百科事典(ひゃっかじてん) (encyclopedia - text-focused)
  • 辞典(じてん) (dictionary)
  • 絵本(えほん) (picture book - for stories)
