同様(どうよう)

どうよう
na-adjective, noun
same, similar, identical

Definitions

1. same, similar, identical
Being alike or of the same kind. Used to indicate similarity between things.

Examples

去年(きょねん)と同様(どうよう)の結果(けっか)でした。
The result was the same as last year.
同様(どうよう)に考(かんが)えています。
I think the same way.
これも同様(どうよう)です。
This is the same too.

Notes

同様(どうよう) indicates sameness or similarity.

FORMS:

  • Adverbial: 同様(どうよう)に (similarly, likewise)
  • Noun modifier: 同様(どうよう)の/な + noun

COMMON PATTERNS:

  • Xと同様(どうよう)に (the same as X)
  • 同様(どうよう)の理由(りゆう) (the same reason)
  • ～と同様(どうよう) (just like ~)

SIMILAR WORDS:

  • 同(おな)じ: same (casual, everyday)
  • 同様(どうよう): same (formal)
  • 類似(るいじ): similarity (technical)
