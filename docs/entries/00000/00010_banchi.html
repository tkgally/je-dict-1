番地(ばんち)

ばんち
noun
house number, street address number
1. house number, lot number, address number
The number assigned to a building or plot of land as part of the Japanese address system.
この建物(たてもの)の番地(ばんち)は何番(なんばん)ですか。
What is the house number of this building?
住所(じゅうしょ)には番地(ばんち)まで書(か)いてください。
Please include the house number in the address.
3丁目(ちょうめ)5番地(ばんち)に住(す)んでいます。
I live at 5 banchi, 3-chome.

番地(ばんち) is the lot/house number in the Japanese address system. Japanese addresses work differently from Western ones, typically going from large to small: prefecture → city → ward → district → block → lot number.

Address structure example:
東京都(とうきょうと)渋谷区(しぶやく)神宮前(じんぐうまえ)1丁目(ちょうめ)2番地(ばんち)3号(ごう)
(Tokyo, Shibuya Ward, Jingumae, 1-chome, 2-banchi, 3-go)

Related terms:

  • 住所(じゅうしょ) (address)
  • 丁目(ちょうめ) (district number within a neighborhood)
  • 号(ごう) (building number within a lot)
