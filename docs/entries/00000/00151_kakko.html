括弧(かっこ)

かっこ
noun
parentheses; brackets
1. parentheses; brackets; braces
Punctuation marks used in pairs to set off supplementary, explanatory, or qualifying information within text.
答(こた)えを括弧(かっこ)の中(なか)に書(か)いてください。
Please write the answer inside the parentheses.
括弧(かっこ)内(ない)の語(ご)を使(つか)って文(ぶん)を作(つく)りなさい。
Make a sentence using the word in parentheses.
[Note: Common instruction in language exercises]
引用(いんよう)は鍵(かぎ)括弧(かっこ)で囲(かこ)む。
Enclose quotations with quotation marks.
[Note: 鍵括弧 = 「」 Japanese quotation marks]
括弧(かっこ)を閉(と)じ忘(わす)れた。
I forgot to close the brackets.
注釈(ちゅうしゃく)を括弧(かっこ)に入(い)れる。
Put the annotation in parentheses.

TYPES OF BRACKETS:

  • ( ) 丸(まる)括弧(かっこ)/小(しょう)括弧(かっこ) (parentheses)
  • 「 」 鍵(かぎ)括弧(かっこ) (single quotation marks - Japanese)
  • 『 』 二重(にじゅう)鍵(かぎ)括弧(かっこ) (double quotation marks)
  • [ ] 角(かく)括弧(かっこ)/大(だい)括弧(かっこ) (square brackets)
  • } {波(なみ)括弧(かっこ)/中(ちゅう)括弧(かっこ) (curly braces)
  • 〈 〉 山(やま)括弧(かっこ) (angle brackets)

PATTERNS:

  • 括弧(かっこ)を付(つ)ける (to add brackets)
  • 括弧(かっこ)で囲(かこ)む (to enclose in brackets)
  • 括弧(かっこ)内(ない) (inside the brackets)
  • 括弧(かっこ)を閉(と)じる (to close brackets)

NOTE: In Japanese, quotation marks 「」 are used instead of Western " ". Double marks 『』 are used for nested quotes or titles.
