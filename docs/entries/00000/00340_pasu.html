パス

ぱす
noun
pass; path
1. pass (in sports)
Throwing or kicking a ball to a teammate.
2. pass (ticket)
A ticket or permit that allows entry or use of transportation.
3. skip; pass on
To decline or skip one's turn.
4. path (computing)
A file path in computer systems.
サッカーでパスを出(だ)す。
To make a pass in soccer.
定期(ていき)パスを買(か)う。
To buy a commuter pass.
今回(こんかい)はパスする。
I'll pass this time.

パス has multiple meanings derived from different English words.

SPORTS USAGE (pass):

  • パスを出(だ)す (to make a pass)
  • パスを受(う)ける (to receive a pass)
  • パス回(まわ)し (passing the ball around)

TICKET USAGE (pass):

  • 定期(ていき)パス (commuter pass)
  • フリーパス (unlimited pass)
  • 入場(にゅうじょう)パス (entry pass)

SKIP/DECLINE USAGE:

  • パスする (to pass on something, to skip)
  • This usage is common in casual speech

COMPUTING USAGE (path):

  • ファイルパス (file path)
