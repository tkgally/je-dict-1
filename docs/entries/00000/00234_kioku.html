記憶(きおく)

きおく
noun, suru verb
memory, recollection
1. memory, recollection
The faculty by which the mind stores and remembers information.
記憶(きおく)があいまいです。
My memory is vague.
その日(ひ)のことをよく記憶(きおく)している。
I remember that day well.
記憶(きおく)から消(け)す。
To erase from memory.

記憶(きおく) refers to memory as a cognitive faculty or the act of remembering.

COMMON EXPRESSIONS:

  • 記憶(きおく)にある/ない: to have/not have in memory
  • 記憶(きおく)を失(うしな)う: to lose memory
  • 記憶(きおく)から消(け)す: to erase from memory
  • 記憶(きおく)に新(あたら)しい: fresh in one's memory
  • 記憶(きおく)をたどる: to trace one's memory

RELATED COMPOUNDS:

  • 記憶(きおく)力(りょく): memory ability
  • 記憶(きおく)喪失(そうしつ): amnesia

CONTRAST:

  • 思(おも)い出(で): memories (emotional, nostalgic)
  • 覚(おぼ)える: to memorize, learn

As a suru verb: 記憶(きおく)する means to memorize or commit to memory.
