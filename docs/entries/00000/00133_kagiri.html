限(かぎ)り

かぎり
noun
limit, extent, as far as
1. limit, bounds, extent
The furthest point or boundary of something.
2. as far as, as long as
To the extent that something is true or continues.
力(ちから)の限(かぎ)り走(はし)った。
I ran with all my might.
知(し)っている限(かぎ)りでは、彼(かれ)は来(こ)ないはずだ。
As far as I know, he shouldn't be coming.
時間(じかん)がある限(かぎ)り手伝(てつだ)います。
I'll help as long as I have time.

限(かぎ)り is used for limits and conditional expressions.

COMMON PATTERNS:

  • ～の限(かぎ)り: to the limit of ~
  • 力(ちから)の限(かぎ)り: with all one's might
  • 声(こえ)の限(かぎ)り: at the top of one's voice
  • ～限(かぎ)り: as far as ~, as long as ~
  • 知(し)っている限(かぎ)り: as far as I know
  • できる限(かぎ)り: as much as possible
  • ～ない限(かぎ)り: unless ~
  • 努力(どりょく)しない限(かぎ)り: unless you make an effort

SET PHRASES:

  • 限(かぎ)りなく: endlessly, infinitely
  • 限(かぎ)りがある: there is a limit
  • 限(かぎ)りがない: there is no limit
