コード

こーど
noun
code; cord; chord
1. code
A system of words, symbols, or rules for communication or programming.
コードを書(か)く。
I write code.
プログラムのコードを見(み)た。
I looked at the program code.
このコードには問題(もんだい)がある。直(なお)さなければならない。
There's a problem with this code. I have to fix it.
2. cord, cable
An electrical wire or cable.
コードをつなぐ。
I connect the cord.
電源(でんげん)コードをコンセントに差(さ)す。
I plug the power cord into the outlet.
延長(えんちょう)コードがないので、掃除機(そうじき)が届(とど)かない。
I don't have an extension cord, so the vacuum cleaner won't reach.
3. chord
A combination of musical notes played together.
コードを弾(ひ)く。
I play chords.
ギターのコードを覚(おぼ)えた。
I learned guitar chords.
この曲(きょく)のコードは難(むずか)しいが、練習(れんしゅう)すれば弾(ひ)けるようになる。
The chords for this song are difficult, but with practice I'll be able to play them.

コード is a versatile loanword with three distinct meanings from different English words:

1. CODE (programming/secret):

  • ソースコード: source code
  • 暗号(あんごう)コード: secret code
  • QRコード: QR code
  • コードを書(か)く: to write code

2. CORD (electrical):

  • 電源(でんげん)コード: power cord
  • 延長(えんちょう)コード: extension cord
  • コードレス: cordless

3. CHORD (music):

  • コード進行(しんこう): chord progression
  • コードを弾(ひ)く: to play chords

Context usually makes the meaning clear.
