コード

こーど
noun
code; cord; chord

Definitions

1. code
A system of words, symbols, or rules for communication or programming.
2. cord, cable
An electrical wire or cable.
3. chord
A combination of musical notes played together.

Examples

プログラムのコードを書(か)く。
I write program code.
電源(でんげん)コードをコンセントに差(さ)す。
I plug the power cord into the outlet.
ギターでコードを弾(ひ)く。
I play chords on the guitar.

Notes

コード is a versatile loanword with three distinct meanings from different English words:

1. CODE (programming/secret):

  • ソースコード: source code
  • 暗号(あんごう)コード: secret code
  • QRコード: QR code
  • コードを書(か)く: to write code

2. CORD (electrical):

  • 電源(でんげん)コード: power cord
  • 延長(えんちょう)コード: extension cord
  • コードレス: cordless

3. CHORD (music):

  • コード進行(しんこう): chord progression
  • コードを弾(ひ)く: to play chords

Context usually makes the meaning clear.
