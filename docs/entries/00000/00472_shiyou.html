仕様(しよう)

しよう
noun
way, method; specifications
1. way, method, means
A way or method of doing something.
仕様(しよう)がないから諦(あきら)めよう。
There's nothing we can do about it, so let's give up.
[Note: 仕様(しよう)がない is a common expression meaning 'can't be helped']
2. specifications
Detailed description of requirements, dimensions, or features (technical).
この製品(せいひん)の仕様(しよう)を確認(かくにん)してください。
Please check the specifications of this product.
仕様(しよう)書(しょ)に従(したが)って開発(かいはつ)を進(すす)める。
We'll proceed with development according to the specifications document.

仕様(しよう) has two main uses:

1. WAY/METHOD:

  • 仕様(しよう)がない: it can't be helped, there's no way
  • どうしようもない: there's nothing to be done (related expression)

2. SPECIFICATIONS (technical):

  • 仕様(しよう)書(しょ): specification document, specs
  • 製品(せいひん)仕様(しよう): product specifications
  • 技術(ぎじゅつ)仕様(しよう): technical specifications

NOTE: This is a homophone with 私用(しよう) (personal use) and 使用(しよう) (use).
