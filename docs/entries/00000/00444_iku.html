幾(いく)〜

いく
prefix
several ~, how many ~
1. several, some
A prefix indicating an indefinite but notable number.
2. how many, how much
A prefix used in questions about quantity.
幾度(いくど)も失敗(しっぱい)した。
I failed many times.
幾人(いくにん)かが賛成(さんせい)した。
Several people agreed.
お幾(いく)つですか。
How old are you?

幾(いく)〜 is a prefix meaning 'several' or 'how many.'

COMMON COMPOUNDS:

  • 幾(いく)つ: how many, several
  • 幾度(いくど): many times, how many times
  • 幾人(いくにん): several people, how many people
  • 幾分(いくぶん): somewhat, partially
  • 幾日(いくにち): several days, how many days
  • 幾(いく)ら: how much (price/quantity)

SET EXPRESSIONS:

  • 幾(いく)らか: somewhat, to some extent
  • 幾(いく)らでも: as much as you want
  • 幾度(いくど)となく: countless times

QUESTION FORM:
お幾(いく)つ is the polite way to ask someone's age.
