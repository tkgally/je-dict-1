基本(きほん)

きほん
noun
basis, foundation
1. basis, foundation, basics
The fundamental or essential part of something.
基本(きほん)を学(まな)ぶ。
To learn the basics.
基本(きほん)的(てき)な知識(ちしき)が必要(ひつよう)です。
Basic knowledge is necessary.
料理(りょうり)の基本(きほん)を教(おし)える。
To teach the basics of cooking.

基本(きほん) refers to the fundamental elements or essentials of something.

COMMON PATTERNS:

  • 基本(きほん)を学(まな)ぶ: to learn the basics
  • 基本(きほん)を押(お)さえる: to grasp the fundamentals
  • 基本(きほん)的(てき)な〜: basic ~
  • 基本(きほん)から始(はじ)める: to start from the basics
  • 基本(きほん)に立(た)ち返(かえ)る: to go back to basics

COMPOUNDS:

  • 基本(きほん)給(きゅう): base salary
  • 基本(きほん)料金(りょうきん): basic fee
  • 基本(きほん)方針(ほうしん): basic policy

SIMILAR WORDS:

  • 基礎(きそ): foundation (often interchangeable, but 基礎(きそ) emphasizes underlying structure)
  • 土台(どだい): base, foundation (more physical/concrete)
