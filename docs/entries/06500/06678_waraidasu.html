笑(わら)い出(だ)す

わらいだす
verb (godan, intransitive)
to start laughing; to burst out laughing

Definitions

1. to start laughing; to burst out laughing
To suddenly begin laughing. The action of laughter starting, often implying a spontaneous or uncontrolled onset.

Examples

彼(かれ)は急(きゅう)に笑(わら)い出(だ)した。
He suddenly burst out laughing.
みんなが一斉(いっせい)に笑(わら)い出(だ)した。
Everyone started laughing all at once.
彼女(かのじょ)の顔(かお)を見(み)たら、笑(わら)い出(だ)さずにはいられなかった。
When I saw her face, I couldn't help but start laughing.

Notes

CONJUGATION:

  • 笑(わら)い出(だ)す → 笑(わら)い出(だ)さない (negative)
  • 笑(わら)い出(だ)す → 笑(わら)い出(だ)して (te-form)
  • 笑(わら)い出(だ)す → 笑(わら)い出(だ)した (past)

FORMATION:
Compound verb: 笑(わら)う (to laugh) + 出(だ)す (to begin)

The ～出(だ)す pattern attaches to the masu-stem of verbs to indicate the beginning of an action, often with the nuance of suddenness or spontaneity.

PATTERN:
笑(わら)い出(だ)さずにはいられない - can't help but start laughing

SIMILAR COMPOUND VERBS:

  • 泣(な)き出(だ)す - to start crying
  • 走(はし)り出(だ)す - to start running
  • 降(ふ)り出(だ)す - to start raining
  • 話(はな)し出(だ)す - to start talking
