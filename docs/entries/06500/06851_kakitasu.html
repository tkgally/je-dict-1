1. to add in writing; to write more
To supplement existing text by writing additional content.
報告書(ほうこくしょ)に補足(ほそく)を書(か)き足(た)した。
I added a supplement to the report.
先生(せんせい)に言(い)われて、説明(せつめい)を書(か)き足(た)した。
I added more explanation as the teacher told me to.
日記(にっき)に昨日(きのう)の出来事(できごと)を書(か)き足(た)す。
I'll add yesterday's events to my diary.
申込書(もうしこみしょ)に連絡先(れんらくさき)を書(か)き足(た)すように言(い)われた。
I was told to add my contact information to the application form.
手紙(てがみ)の最後(さいご)に「また会(あ)いましょう」と書(か)き足(た)した。
I added "let's meet again" at the end of the letter.

A compound verb meaning to add something in writing to what already exists. From 書(か)く (to write) + 足(た)す (to add, to supplement). The base text is already there; this verb covers only the increment.

TRANSITIVITY:

  • Type: 他動詞(たどうし) (transitive)
  • Takes を for the content added: 説明(せつめい)を書(か)き足(た)す
  • Takes に for what it is added to: メモに書(か)き足(た)す

ASPECT (ている):
書(か)き足(た)している means "is in the process of adding" (ongoing action).

COMMON PATTERNS:

  • 文章(ぶんしょう)を書(か)き足(た)す (to add to a text)
  • 理由(りゆう)を書(か)き足(た)す (to add reasons in writing)
  • メモに書(か)き足(た)す (to add to notes)
  • 一言(ひとこと)書(か)き足(た)す (to add a brief note)

THE ～足(た)す PATTERN:

As a second element, 足(た)す means "do some more of it on top of what is already there":

  • 言(い)い足(た)す (to add verbally)
  • 付(つ)け足(た)す (to append, to add on)
  • 買(か)い足(た)す (to buy additional items)
