完封(かんぷう)

かんぷう
noun
shutout, blanking
1. shutout (sports)
A game in which one team prevents the opposing team from scoring any points or runs. In baseball, typically refers to a pitcher allowing no runs for the entire game.
エースが9回(かい)完封(かんぷう)した。
The ace pitcher threw a complete game shutout.
相手(あいて)を完封(かんぷう)して優勝(ゆうしょう)を決(き)めた。
They clinched the championship with a shutout win.
3対(たい)0で完封(かんぷう)勝(が)ちした。
They won 3-0 in a shutout victory.

USAGE IN BASEBALL:

  • 完封(かんぷう)勝利(しょうり)/完封(かんぷう)勝(が)ち (shutout win)
  • 9回(かい)完封(かんぷう) (9-inning complete game shutout)
  • 継投(けいとう)完封(かんぷう) (combined shutout by multiple pitchers)

RELATED PITCHING TERMS:

  • 完投(かんとう) (complete game - but may allow runs)
  • 無失点(むしってん) (scoreless)
  • 完全(かんぜん)試合(しあい) (perfect game - no baserunners)
  • ノーヒットノーラン (no-hitter)

COLLOCATIONS:

  • 完封(かんぷう)する (to shut out)
  • 完封(かんぷう)を達成(たっせい)する (to achieve a shutout)
  • 完封(かんぷう)負(ま)け (shutout loss)
  • 完封(かんぷう)リレー (combined shutout)
