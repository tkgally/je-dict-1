付(つ)け足(た)す

つけたす
verb (godan, transitive)
to add on; to supplement; to append
1. to add on; to supplement; to append
To add something extra to what already exists.
説明(せつめい)を付(つ)け足(た)してもいいですか。
May I add an explanation?
スープの味(あじ)が薄(うす)いので塩(しお)を付(つ)け足(た)した。
The soup was bland so I added more salt.
最後(さいご)に一言(ひとこと)付(つ)け足(た)しておく。
Let me add one more thing at the end.

CONJUGATION:

  • 付(つ)け足(た)す → 付(つ)け足(た)さない (negative)
  • 付(つ)け足(た)す → 付(つ)け足(た)して (te-form)
  • 付(つ)け足(た)す → 付(つ)け足(た)した (past)

FORMATION:
Compound verb: 付(つ)ける (to attach) + 足(た)す (to add)

USAGE:

  • 情報(じょうほう)を付(つ)け足(た)す (to add information)
  • 注釈(ちゅうしゃく)を付(つ)け足(た)す (to add notes)
  • 調味料(ちょうみりょう)を付(つ)け足(た)す (to add seasonings)

SIMILAR WORDS:

  • 書(か)き足(た)す - to add in writing
  • 言(い)い足(た)す - to add verbally
  • 追加(ついか)する - to add (more formal)
