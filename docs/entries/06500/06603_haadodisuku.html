ハードディスク

はーどでぃすく
noun
hard disk; hard drive; HDD
1. hard disk; hard drive; HDD
A data storage device that uses magnetic storage to store and retrieve digital information using rapidly rotating platters.
ハードディスクの容量(ようりょう)が足(た)りなくなった。
The hard disk ran out of storage capacity.
外付(そとづ)けハードディスクにバックアップを取(と)る。
I back up data to an external hard drive.
ハードディスクがSSDに置(お)き換(か)わりつつある。
Hard disks are gradually being replaced by SSDs.

ABBREVIATIONS:

  • HDD（エイチディーディー）- commonly used abbreviation
  • ハードドライブ - alternate term

CONTRAST WITH SSD:

  • SSD（ソリッドステートドライブ）- uses flash memory, faster and more durable but typically more expensive
  • HDD - uses magnetic platters, larger capacity at lower cost

RELATED TERMS:

  • 記憶(きおく)装置(そうち) (storage device)
  • 容量(ようりょう) (storage capacity)
  • 外付(そとづ)け～ (external ~)
  • 内蔵(ないぞう)～ (internal/built-in ~)
