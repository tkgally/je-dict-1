尚更(なおさら)

なおさら
adverb
all the more; even more; especially
1. all the more; even more; still more
Indicates that something intensifies a situation or makes it even more applicable. Used when one condition makes another condition even stronger.
雨(あめ)の日(ひ)は尚更(なおさら)外(そと)に出(で)たくない。
On rainy days, I want to go out even less.
病気(びょうき)の時(とき)は尚更(なおさら)栄養(えいよう)を取(と)らなければならない。
When you're sick, you need to get nutrition all the more.
彼(かれ)が反対(はんたい)すると、彼女(かのじょ)は尚更(なおさら)やりたくなる。
The more he opposes it, the more she wants to do it.

USAGE:
尚更(なおさら) says that a fact already true becomes *more* true once some further condition is added. It needs that earlier condition to lean on — either stated in the same sentence or clear from context — so it rarely opens a conversation. It sits directly before the part of the clause it intensifies.

COMMON PATTERNS:

  • AならBは尚更(なおさら)だ: if A, then B all the more
  • 尚更(なおさら)〜ない: even less likely to ~
  • 尚更(なおさら)のこと: all the more reason
  • ましてや〜は尚更(なおさら)だ: let alone ~, which is more so still

WRITING NOTE:
Usually written in kana as なおさら. The kanji spelling 尚更(なおさら) is the more formal choice and is common in writing.

SIMILAR ADVERBS:

  • ますます: increasingly — describes a trend continuing, with no conditional step
  • 一層(いっそう): all the more — close in meaning but formal, and usable without a stated condition
  • 尚更(なおさら) differs from both in requiring a prior fact that it builds on.
