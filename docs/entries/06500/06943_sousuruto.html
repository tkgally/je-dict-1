そうすると

そうすると
conjunction
if so; in that case; then
1. if so; in that case
Draws a logical conclusion from the previous statement.
2. then; and then
Indicates what happened next in a sequence of events.
「電車(でんしゃ)が止(と)まっている。」「そうすると、バスで行(い)くしかないね。」
"The trains aren't running." "In that case, we have no choice but to take the bus."
窓(まど)を開(あ)けた。そうすると、涼(すず)しい風(かぜ)が入(はい)ってきた。
I opened the window. Then, a cool breeze came in.
彼(かれ)は来(こ)ないんですか。そうすると、計画(けいかく)を変(か)える必要(ひつよう)がありますね。
He's not coming? If so, we need to change the plan.

STRUCTURE:
そう (so) + する (to do) + と (when/if)

USAGE:

  • Beginning of a sentence, responding to previous information
  • Links cause and effect or condition and result

SIMILAR EXPRESSIONS:

  • すると - then (more for narrative sequences)
  • それなら - if that's the case (emphasis on condition)
  • だとすると - if that's true (more hypothetical)
  • ということは - that means (drawing conclusions)
