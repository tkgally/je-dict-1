1. to be doable; to be possible; to work out
Colloquial expression indicating something is feasible or acceptable.
「いける？」「うん、いける。」
"Can you do it?" "Yeah, I can."
もうちょっとでいけそうだ。
I think we can almost make it.
「明日(あした)、来(こ)れる？」「うん、いけると思(おも)う。」
"Can you come tomorrow?" "Yeah, I think I can make it."
今(いま)から出(で)ればまだいけるよ。
If you leave now, you can still make it.
この量(りょう)なら一人(ひとり)でもいけると思(おも)うけど、手伝(てつだ)おうか。
I think I can handle this amount alone, but shall I help?
2. to be good; to be tasty; to be not bad
Used to express that something (food, drink) is surprisingly good or acceptable.
このワイン、いけるね。
This wine is pretty good.
この料理(りょうり)、結構(けっこう)いけるね。
This dish is pretty good, isn't it?
安(やす)い店(みせ)だけど、味(あじ)は結構(けっこう)いける。
It's a cheap place, but the food is surprisingly good.
見(み)た目(め)は変(へん)だけど、食(た)べてみたらいけた。
It looked weird, but when I tried it, it was good.
このラーメン、思(おも)ったよりいけるから食(た)べてみて。
This ramen is better than I expected, so give it a try.

ORIGIN:
Derived from 行(い)ける (potential form of 行(い)く), extended to mean "things can go/work."

USAGE PATTERNS:

  • いける？ / いけます？ - Can you do it? / Does it work?
  • いけると思(おも)う - I think it'll work
  • いけそう - looks doable
  • 結構(けっこう)いける - pretty good (unexpectedly)

REGISTER:
Casual/colloquial. Common in everyday conversation.

SIMILAR:

  • 大丈夫(だいじょうぶ) - okay, all right
  • できる - can do
  • 行(い)ける - can go (literal meaning)
