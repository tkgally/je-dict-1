物覚(ものおぼ)え

ものおぼえ
noun
memory (ability); ability to remember

Definitions

1. memory (ability); ability to learn and remember things
One's capacity to memorize and retain information. Often used with adjectives like good or bad to describe someone's memory skills.

Examples

彼(かれ)は物覚(ものおぼ)えがいい。
He has a good memory.
最近(さいきん)、物覚(ものおぼ)えが悪(わる)くなった。
My memory has gotten worse lately.
物覚(ものおぼ)えが早(はや)いので、仕事(しごと)をすぐ覚(おぼ)えた。
I'm a quick learner, so I picked up the job quickly.

Notes

FORMATION:
物(もの) (things) + 覚(おぼ)え (remembering)
→ The ability to remember things

COMMON PATTERNS:

  • 物覚(ものおぼ)えがいい/いい - to have a good memory
  • 物覚(ものおぼ)えが悪(わる)い - to have a bad memory
  • 物覚(ものおぼ)えが早(はや)い - to be a quick learner
  • 物覚(ものおぼ)えが遅(おそ)い - to be a slow learner

USAGE:
Refers specifically to the practical ability to memorize and learn things, rather than memories themselves (思(おも)い出(で)) or the mental faculty of memory (記憶(きおく)).

SIMILAR WORDS:

  • 記憶力(きおくりょく) - Memory capacity/power (more formal)
  • 暗記力(あんきりょく) - Memorization ability

Related Words

Related: 記憶力(きおくりょく) (memory power)
