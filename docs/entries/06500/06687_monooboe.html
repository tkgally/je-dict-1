物覚(ものおぼ)え

ものおぼえ
noun
memory (ability); ability to remember
1. memory (ability); ability to learn and remember things
One's capacity to memorize and retain information. Often used with adjectives like good or bad to describe someone's memory skills.
彼(かれ)は物覚(ものおぼ)えがいい。
He has a good memory.
最近(さいきん)、物覚(ものおぼ)えが悪(わる)くなった。
My memory has gotten worse lately.
物覚(ものおぼ)えが早(はや)いので、仕事(しごと)をすぐ覚(おぼ)えた。
I'm a quick learner, so I picked up the job quickly.

FORMATION:
物(もの) (things) + 覚(おぼ)え (remembering) → the ability to take things in and retain them

COMMON PATTERNS:

The word is almost always the subject of an evaluating adjective, marked with が:

  • 物覚(ものおぼ)えがいい - to have a good memory
  • 物覚(ものおぼ)えが悪(わる)い - to have a bad memory
  • 物覚(ものおぼ)えが早(はや)い - to be a quick learner
  • 物覚(ものおぼ)えが遅(おそ)い - to be a slow learner

It is rarely the object of a verb, and it does not take a plural or a count.

USAGE:
物覚(ものおぼ)え names the practical knack of picking things up — a new job, a set of names, a route — not memories themselves (思(おも)い出(で)) and not the mental faculty of memory in the abstract (記憶(きおく)).

Saying 物覚(ものおぼ)えが悪(わる)い of yourself is an ordinary, mildly self-deprecating remark. Said of someone else it is a criticism of their competence, so it is best avoided to their face.

SIMILAR WORDS:

  • 記憶力(きおくりょく) - memory capacity; more formal and more clinical, and the word used in test results or medical contexts
  • 暗記力(あんきりょく) - the ability to memorize by rote, as for an exam; narrower than 物覚(ものおぼ)え
