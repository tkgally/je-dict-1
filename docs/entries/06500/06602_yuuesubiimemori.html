USBメモリ

ゆーえすびーめもり
noun
USB flash drive; USB memory stick
1. USB flash drive; USB memory stick
A small portable data storage device that uses flash memory and connects to devices via USB port.
USBメモリにデータを保存(ほぞん)する。
I save data to a USB flash drive.
USBメモリを紛失(ふんしつ)しないように気(き)をつけて。
Be careful not to lose your USB flash drive.
会議(かいぎ)資料(しりょう)はUSBメモリで配布(はいふ)します。
The meeting materials will be distributed via USB flash drives.

A portable data storage device that connects via USB. USBメモリ is the standard Japanese term; English speakers more commonly say "USB drive" or "flash drive."

ALTERNATE NAMES:

  • USBメモリー: variant with long vowel
  • USBフラッシュメモリ: USB flash memory (more formal)
  • USBスティック: USB stick

COMMON COLLOCATIONS:

  • USBメモリに保存(ほぞん)する: to save to a USB drive
  • USBメモリを挿(さ)す: to insert a USB drive
  • USBメモリを抜(ぬ)く: to remove a USB drive
  • USBメモリを紛失(ふんしつ)する: to lose a USB drive

RELATED TERMS:

  • USBポート: USB port
  • 外付(そとづ)けハードディスク: external hard drive
  • クラウドストレージ: cloud storage

NOTE:
In many Japanese companies, USB memory usage is restricted for 情報(じょうほう)セキュリティ (information security) reasons.
