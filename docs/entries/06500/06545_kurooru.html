クロール

くろーる
noun
front crawl, freestyle
1. front crawl, freestyle
A swimming stroke performed face-down with alternating arm strokes and a flutter kick. The fastest and most commonly used stroke, also called freestyle in competitive swimming.
クロールは最(もっと)も速(はや)い泳法(えいほう)だ。
The front crawl is the fastest swimming stroke.
水泳(すいえい)教室(きょうしつ)でまずクロールを習(なら)った。
I learned the front crawl first at swimming class.
クロールで25メートル泳(およ)げるようになった。
I can now swim 25 meters doing the front crawl.

TERMINOLOGY:

  • クロール (crawl) - refers to the stroke technique
  • 自由形(じゆうがた) (freestyle) - competitive event name where any stroke is allowed (but crawl is always used as it's fastest)

TECHNIQUE TERMS:

  • 息継(いきつ)ぎ (breathing technique)
  • バタ足(あし) (flutter kick)
  • ストローク (arm stroke)
  • 手(て)のかき (arm pull)

FOUR SWIMMING STROKES (4泳法(よんえいほう)):

  • クロール/自由形(じゆうがた) (freestyle/front crawl)
  • 平泳(ひらおよ)ぎ (breaststroke)
  • 背泳(せおよ)ぎ (backstroke)
  • バタフライ (butterfly)

COLLOCATIONS:

  • クロールを泳(およ)ぐ (to swim front crawl)
  • クロールで泳(およ)ぐ (to swim using front crawl)
  • クロールの息継(いきつ)ぎ (breathing in crawl)
