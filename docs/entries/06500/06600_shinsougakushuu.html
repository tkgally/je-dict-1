深層(しんそう)学習(がくしゅう)

しんそうがくしゅう
noun
deep learning
1. deep learning
A subset of machine learning using neural networks with multiple layers to learn patterns from large amounts of data.
深層(しんそう)学習(がくしゅう)は画像(がぞう)認識(にんしき)で高(たか)い性能(せいのう)を発揮(はっき)する。
Deep learning demonstrates high performance in image recognition.
AIの発展(はってん)には深層(しんそう)学習(がくしゅう)が欠(か)かせない。
Deep learning is essential for the advancement of AI.
深層(しんそう)学習(がくしゅう)モデルを訓練(くんれん)するには大量(たいりょう)のデータが必要(ひつよう)だ。
Training deep learning models requires large amounts of data.

TECHNICAL TERMS:

  • ニューラルネットワーク (neural network)
  • 機械(きかい)学習(がくしゅう) (machine learning)
  • 人工(じんこう)知能(ちのう)/AI (artificial intelligence)
  • 畳(たた)み込(こ)み (convolution)

APPLICATIONS:

  • 画像(がぞう)認識(にんしき) (image recognition)
  • 自然(しぜん)言語(げんご)処理(しょり) (natural language processing)
  • 音声(おんせい)認識(にんしき) (speech recognition)
  • 自動(じどう)運転(うんてん) (autonomous driving)

ORIGIN: English "deep learning," coined around 2006.
