担保(たんぽ)

たんぽ
noun, suru verb
collateral; security; guarantee
1. collateral; security
Assets or property pledged as security for a loan, which can be seized if the borrower fails to repay.
不動産(ふどうさん)を担保(たんぽ)に融資(ゆうし)を受(う)けた。
I received a loan using real estate as collateral.
担保(たんぽ)なしでローンを組(く)むのは難(むずか)しい。
It's difficult to get a loan without collateral.
2. guarantee; assurance
Something that serves as a guarantee or assurance that something will happen.
成功(せいこう)を担保(たんぽ)するものは何(なに)もない。
There is nothing that guarantees success.

FINANCIAL CONTEXT:

COMMON TYPES:

  • 不動産担保(ふどうさんたんぽ): real estate collateral
  • 人的担保(じんてきたんぽ): personal guarantee
  • 物的担保(ぶってきたんぽ): property collateral

RELATED TERMS:

  • 担保権(たんぽけん): security interest
  • 担保物件(たんぽぶっけん): collateralized property
  • 無担保(むたんぽ): unsecured; without collateral
  • 抵当(ていとう): mortgage (similar concept)

VERB USAGE:

  • 担保(たんぽ)に入(い)れる: to put up as collateral
  • 担保(たんぽ)を設定(せってい)する: to establish collateral
  • Xを担保(たんぽ)する: to guarantee X (sense 2)
