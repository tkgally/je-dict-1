図書室(としょしつ)

としょしつ
noun
library room; school library

Definitions

1. library room; school library
A room in a school that functions as a library where students can read and borrow books.

Examples

昼休(ひるやす)みに図書室(としょしつ)で本(ほん)を読(よ)む。
I read books in the library during lunch break.
図書室(としょしつ)で勉強(べんきょう)する。
I study in the library room.
図書室(としょしつ)から本(ほん)を借(か)りた。
I borrowed a book from the library.

Notes

図書室 is the term for a school library (a room within a school), while 図書館 (としょかん) is a standalone library building.

DISTINCTION:

  • 図書室: library room (in a school)
  • 図書館: library (as a building/institution)

COMMON ACTIVITIES:

  • 本を借りる: to borrow books
  • 勉強する: to study
  • 調べ物をする: to do research
