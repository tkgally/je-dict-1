九九(くく)

くく
noun
multiplication table

Definitions

1. multiplication table
The multiplication table from 1×1 to 9×9, traditionally memorized by Japanese elementary students through rhythmic chanting.

Examples

小学生(しょうがくせい)のとき九九(くく)を覚(おぼ)えた。
I learned the multiplication table when I was in elementary school.
九九(くく)を暗唱(あんしょう)できる。
I can recite the multiplication table.
九九(くく)の練習(れんしゅう)をする。
To practice the multiplication table.

Notes

ORIGIN:
Called 九九(くく) because it goes up to 9×9=81.

HOW IT'S TAUGHT:

Japanese students memorize the multiplication table through rhythmic chanting. Each multiplication has a traditional reading:

  • 2×2=4: ににんがし
  • 3×3=9: さざんがく
  • 7×7=49: しちしちしじゅうく

COMMON COLLOCATIONS:

  • 九九(くく)を覚(おぼ)える: to memorize the multiplication table
  • 九九(くく)の表(ひょう): multiplication table chart
  • 九九(くく)を唱(とな)える: to chant the multiplication table

RELATED TERMS:

  • 掛(か)け算(ざん): multiplication
  • 暗算(あんざん): mental arithmetic
