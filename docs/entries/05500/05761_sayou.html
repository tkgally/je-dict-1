作用(さよう)

さよう
noun, suru verb
action; effect; function

Definitions

1. action; effect; function
The process by which something influences or affects something else; the operating mechanism of something.

Examples

この薬(くすり)には副作用(ふくさよう)がある。
This medicine has side effects.
重力(じゅうりょく)の作用(さよう)で物(もの)は落(お)ちる。
Objects fall due to the action of gravity.
消化(しょうか)作用(さよう)を助(たす)ける。
To aid digestive function.

Notes

COMMON COLLOCATIONS:

  • 副作用(ふくさよう): side effect
  • 相互(そうご)作用(さよう): interaction
  • 作用(さよう)を及(およ)ぼす: to exert an effect
  • 作用(さよう)する: to act upon, function
  • 心理(しんり)作用(さよう): psychological effect

SCIENTIFIC CONTEXTS:

  • 化学(かがく)作用(さよう): chemical action
  • 光合成(こうごうせい)作用(さよう): photosynthesis
  • 酵素(こうそ)作用(さよう): enzyme action

PRINCIPLE:

  • 作用(さよう)反作用(はんさよう)の法則(ほうそく): Newton's third law (action-reaction)
