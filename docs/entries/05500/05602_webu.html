ウェブ

うぇぶ
noun
web; World Wide Web
1. web; World Wide Web
The internet system of interconnected documents and resources.
ウェブで情報(じょうほう)を検索(けんさく)する。
To search for information on the web.
ウェブサイトを作成(さくせい)する。
To create a website.
ウェブ会議(かいぎ)に参加(さんか)する。
To participate in a web conference.

ウェブ is from English 'web' (World Wide Web), referring to internet content and services.

COMMON COMPOUNDS:

  • ウェブサイト: website
  • ウェブページ: web page
  • ウェブ会議(かいぎ): web conference/meeting
  • ウェブブラウザ: web browser
  • ウェブデザイン: web design
  • ウェブサービス: web service

COMMON PATTERNS:

  • ウェブで検索(けんさく)する: to search on the web
  • ウェブ上(じょう)で: on the web
  • ウェブを閲覧(えつらん)する: to browse the web

ALTERNATE:
インターネット is broader; ウェブ specifically refers to web pages/sites.

Related Words

Related: サイト (website)
Related: インターネット (internet (broader))
