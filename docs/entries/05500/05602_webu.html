ウェブ

うぇぶ
noun
web; World Wide Web

Definitions

1. web; World Wide Web
The internet system of interconnected documents and resources.

Examples

ウェブで情報(じょうほう)を検索(けんさく)する。
To search for information on the web.
ウェブサイトを作成(さくせい)する。
To create a website.
ウェブ会議(かいぎ)に参加(さんか)する。
To participate in a web conference.

Notes

ウェブ is from English "web," short for World Wide Web.

COMMON COMPOUNDS:

  • ウェブサイト: website
  • ウェブページ: web page
  • ウェブ会議(かいぎ): web conference
  • ウェブブラウザ: web browser
