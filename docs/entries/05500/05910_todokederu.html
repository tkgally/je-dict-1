届(とど)け出(で)る

とどけでる
verb (ichidan)
to report; to notify; to file
1. to report; to notify; to file
To formally report or notify authorities or an organization about something, such as filing official documents or reporting incidents.
転居(てんきょ)を届(とど)け出(で)た。
I filed a change of address notice.
紛失(ふんしつ)を警察(けいさつ)に届(とど)け出(で)た。
I reported the loss to the police.
婚姻届(こんいんとどけ)を届(とど)け出(で)る。
To file a marriage registration.

届(とど)け出(で)る is used for formal notifications to authorities or organizations.

COMMON OBJECTS:

  • 転居届(てんきょとどけ)を届(とど)け出(で)る: to file a change of address
  • 婚姻届(こんいんとどけ)を届(とど)け出(で)る: to file a marriage registration
  • 紛失届(ふんしつとどけ)を届(とど)け出(で)る: to file a loss report
  • 退職届(たいしょくとどけ)を届(とど)け出(で)る: to submit a resignation

GRAMMAR NOTE:
This is a compound verb combining 届(とど)ける (to deliver) and 出(で)る (to come out/submit).
