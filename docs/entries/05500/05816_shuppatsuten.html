出発点(しゅっぱつてん)

しゅっぱつてん
noun
starting point; point of departure

Definitions

1. starting point; point of departure
The place or point where something begins; can be used both literally (for journeys) and figuratively (for arguments, careers, etc.).

Examples

ここが議論(ぎろん)の出発点(しゅっぱつてん)だ。
This is the starting point of the discussion.
出発点(しゅっぱつてん)に戻(もど)る。
To return to the starting point.
新(あたら)しい出発点(しゅっぱつてん)に立(た)つ。
To stand at a new starting point.

Notes

COMMON COLLOCATIONS:

  • 出発点(しゅっぱつてん)に立(た)つ: to stand at a starting point
  • 出発点(しゅっぱつてん)に戻(もど)る: to return to the starting point
  • 新(あたら)しい出発点(しゅっぱつてん): new starting point

RELATED TERMS:

  • 起点(きてん): starting point, origin
  • 原点(げんてん): origin, starting point
  • 出発(しゅっぱつ): departure
