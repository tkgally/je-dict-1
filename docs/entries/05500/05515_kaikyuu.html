階級(かいきゅう)

かいきゅう
noun
class; rank; social class
1. social class; class system
A division of society based on social or economic status.
社会(しゃかい)の階級(かいきゅう)構造(こうぞう)を研究(けんきゅう)する。
To research the class structure of society.
2. rank; grade (military)
A level in a hierarchy, especially in military or martial arts.
軍(ぐん)の階級(かいきゅう)は何(なん)ですか？
What is your military rank?
ボクシングの階級(かいきゅう)を変(か)える。
To change boxing weight class.

階級(かいきゅう) means class, rank, or grade in various hierarchies.

SOCIAL CLASS:

  • 労働者(ろうどうしゃ)階級(かいきゅう): working class
  • 中産(ちゅうさん)階級(かいきゅう): middle class
  • 上流(じょうりゅう)階級(かいきゅう): upper class
  • 支配(しはい)階級(かいきゅう): ruling class
  • 階級(かいきゅう)社会(しゃかい): class society
  • 階級(かいきゅう)闘争(とうそう): class struggle

MILITARY RANKS:

  • 将校(しょうこう)階級(かいきゅう): officer ranks
  • 下士官(かしかん)階級(かいきゅう): non-commissioned officer ranks
  • 階級(かいきゅう)章(しょう): rank insignia

SPORTS (WEIGHT CLASS):

  • ボクシングの階級(かいきゅう): boxing weight class
  • ヘビー級(きゅう): heavyweight
  • ライト級(きゅう): lightweight
  • 階級(かいきゅう)を上(あ)げる: to move up a weight class

RELATED WORDS:

  • 等級(とうきゅう): grade, class, rank
  • 身分(みぶん): social status
  • ランク: rank (loanword)
