端末(たんまつ)

たんまつ
noun
terminal; device; endpoint

Definitions

1. terminal; device; endpoint
A device or equipment used to access a computer system or network; any electronic device used for communication or data processing.

Examples

携帯(けいたい)端末(たんまつ)で操作(そうさ)できる。
You can operate it with a mobile device.
端末(たんまつ)からデータ(でーた)を入力(にゅうりょく)する。
To input data from a terminal.
決済(けっさい)端末(たんまつ)を設置(せっち)する。
To install a payment terminal.

Notes

端末(たんまつ) is widely used in IT and technology contexts.

COMMON COLLOCATIONS:

  • 携帯(けいたい)端末(たんまつ): mobile device
  • 情報(じょうほう)端末(たんまつ): information terminal
  • 端末(たんまつ)機器(きき): terminal equipment
