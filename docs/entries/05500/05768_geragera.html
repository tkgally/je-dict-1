げらげら

げらげら
adverb
laughing loudly, guffawing
1. laughing loudly, guffawing
Laughing in a loud, boisterous manner.
げらげら笑(わら)っていた。
They were laughing loudly.
げらげら笑(わら)い転(ころ)げた。
They rolled around laughing.
何(なに)がそんなにおかしいの？げらげら笑(わら)わないで。
What's so funny? Stop laughing so loudly.

げらげら is an onomatopoeia for loud, boisterous laughter.

REGISTER:
Casual. Can sound somewhat crude or impolite - implies unrestrained, possibly inappropriate laughter.

COMMON PATTERNS:

  • げらげら笑(わら)う: to laugh loudly
  • げらげら笑(わら)い転(ころ)げる: to roll around laughing

CONTRAST WITH OTHER LAUGHTER WORDS:

  • げらげら: loud guffawing (crude)
  • くすくす: quiet giggling (stifled)
  • にこにこ: smiling (no sound)
  • けらけら: cackling (similar to げらげら but higher pitch)
  • ははは/あはは: regular laughing sounds

USAGE NOTE:
Using げらげら to describe someone's laughter can be unflattering, implying lack of refinement.
