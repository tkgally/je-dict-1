技術的(ぎじゅつてき)

ぎじゅつてき
na-adjective
technical
1. technical, technological
Relating to practical skills, techniques, or technology.
技術的(ぎじゅつてき)な問題(もんだい)が発生(はっせい)した。
A technical problem occurred.
技術的(ぎじゅつてき)には可能(かのう)だ。
It's technically possible.
技術的(ぎじゅつてき)なサポートが必要(ひつよう)です。
Technical support is needed.

技術的(ぎじゅつてき) is a na-adjective meaning "technical" or "technological."

FORMS:

  • 技術的(ぎじゅつてき)な + noun: technical ~
  • 技術的(ぎじゅつてき)に: technically

COMMON EXPRESSIONS:

  • 技術的(ぎじゅつてき)な問題(もんだい): technical problem
  • 技術的(ぎじゅつてき)に可能(かのう): technically possible
  • 技術的(ぎじゅつてき)なサポート(さぽーと): technical support
  • 技術的(ぎじゅつてき)な困難(こんなん): technical difficulty

WORD FORMATION:
技術(ぎじゅつ) (technique/technology) + 的(てき) (suffix forming na-adjectives)

RELATED:

  • 技術(ぎじゅつ): technique, technology, skill
  • 技術者(ぎじゅつしゃ): engineer, technician
  • 技術革新(ぎじゅつかくしん): technological innovation
