リハーサル

りはーさる
noun, verb (suru)
rehearsal
1. rehearsal; practice run
A practice session for a performance, presentation, or event, done to prepare and refine the execution.
本番前(ほんばんまえ)にリハーサルを行(おこな)う。
We'll hold a rehearsal before the actual performance.
リハーサルでミスが見(み)つかった。
We found mistakes during the rehearsal.
結婚式(けっこんしき)のリハーサルをした。
We had a wedding rehearsal.

ETYMOLOGY:
From English "rehearsal."

ABBREVIATION:

  • リハ - common short form

例(れい): 「今日(きょう)リハある？」 - "Do we have rehearsal today?"

COMMON COLLOCATIONS:

  • リハーサルをする/を行(おこな)う - to have/hold a rehearsal
  • 通(とお)しリハーサル - run-through rehearsal
  • ゲネプロ - dress rehearsal (from German "Generalprobe")
  • リハーサル室(しつ) - rehearsal room
  • リハーサル{スタジオ} - rehearsal studio

CONTEXTS:

  • 音楽(おんがく) - music (band, orchestra, concert)
  • 演劇(えんげき) - theater
  • 映画(えいが)/テレビ - film/TV
  • プレゼン - presentations
  • 結婚式(けっこんしき) - weddings
  • イベント - events

RELATED TERMS:

  • 練習(れんしゅう) - practice (more general)
  • 稽古(けいこ) - practice (traditional arts)
  • 本番(ほんばん) - actual performance
