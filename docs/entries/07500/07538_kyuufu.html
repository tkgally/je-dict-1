休符(きゅうふ)

きゅうふ
noun
rest (music)
1. rest; musical rest
A symbol in musical notation indicating silence for a specified duration.
休符(きゅうふ)の長(なが)さを正確(せいかく)に数(かぞ)える。
Count the length of the rest accurately.
四分(しぶん)休符(きゅうふ)は四分(しぶん)音符(おんぷ)と同(おな)じ長(なが)さだ。
A quarter rest is the same length as a quarter note.
休符(きゅうふ)も音楽(おんがく)の一部(いちぶ)だ。
Rests are also part of the music.

WORD STRUCTURE:
休(きゅう) (rest, pause) + 符(ふ) (symbol, mark)

TYPES OF RESTS:

  • 全(ぜん)休符(きゅうふ) - whole rest
  • 二分(にぶん)休符(きゅうふ) - half rest
  • 四分(しぶん)休符(きゅうふ) - quarter rest
  • 八分(はちぶん)休符(きゅうふ) - eighth rest
  • 十六分(じゅうろくぶん)休符(きゅうふ) - sixteenth rest

RELATED TERMS:

  • 音符(おんぷ) - note (musical)
  • 楽譜(がくふ) - musical score/sheet music
  • 拍子(ひょうし) - time signature, beat
  • 小節(しょうせつ) - measure, bar

COLLOCATIONS:

  • 休符(きゅうふ)を守(まも)る - to observe the rest (not play during it)
  • 休符(きゅうふ)を数(かぞ)える - to count the rest
