前置(まえお)き

まえおき
noun
preamble; preface; preliminary remarks
1. preamble; preface; preliminary remarks
Introductory statements made before getting to the main point.
前置(まえお)きはいいから本題(ほんだい)に入(はい)ってください。
Skip the preamble and get to the main point.
前置(まえお)きが長(なが)くなりましたが、本題(ほんだい)に移(うつ)ります。
The preamble got long, but let me move to the main topic.
前置(まえお)きなしで言(い)うね。
I'll say it without any preface.

ETYMOLOGY:
前(まえ) (before) + 置(お)き (placing) - placing something before (the main topic)

COMMON EXPRESSIONS:

  • 前置(まえお)きが長(なが)い - the preamble is long
  • 前置(まえお)きなしで - without any preface
  • 前置(まえお)きはいいから - skip the preamble

RELATED:

  • 本題(ほんだい) - main topic
  • 導入(どうにゅう) - introduction
  • 序文(じょぶん) - preface (written)
