冗長(じょうちょう)

じょうちょう
na-adjective
redundant; verbose; long-winded
1. redundant; verbose; long-winded; tediously lengthy
Containing unnecessary repetition or excess; using more words or elements than needed.
冗長(じょうちょう)な文章(ぶんしょう)は読(よ)みにくい。
Verbose writing is hard to read.
この説明(せつめい)は少(すこ)し冗長(じょうちょう)だ。
This explanation is a bit long-winded.
冗長性(じょうちょうせい)を排除(はいじょ)して文章(ぶんしょう)を簡潔(かんけつ)にした。
I removed the redundancy and made the text concise.

FORMS:

  • 冗長(じょうちょう)な〜 (na-adjective modifier)
  • 冗長(じょうちょう)に - verbosely
  • 冗長性(じょうちょうせい) - redundancy (noun form)

TECHNICAL USE:
In computing, 冗長性(じょうちょうせい) (redundancy) can be positive, referring to backup systems that prevent data loss. 冗長(じょうちょう)構成(こうせい) means "redundant configuration" for fault tolerance.

ANTONYM:
簡潔(かんけつ) - concise, brief
