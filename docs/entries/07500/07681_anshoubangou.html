暗証番号(あんしょうばんごう)

あんしょうばんごう
noun
PIN number; personal identification number; security code
1. PIN number; personal identification number; security code
A secret numerical code used to verify identity, typically for bank cards, credit cards, or electronic locks.
暗証番号(あんしょうばんごう)を入力(にゅうりょく)してください。
Please enter your PIN.
暗証番号(あんしょうばんごう)を忘(わす)れてしまった。
I forgot my PIN number.
暗証番号(あんしょうばんごう)は他人(たにん)に教(おし)えないでください。
Please don't tell your PIN to others.

COMPONENTS:
暗証(あんしょう) (secret code/password) + 番号(ばんごう) (number)

COMMON COLLOCATIONS:

  • 暗証番号(あんしょうばんごう)を入力(にゅうりょく)する - to enter one's PIN
  • 暗証番号(あんしょうばんごう)を設定(せってい)する - to set a PIN
  • 暗証番号(あんしょうばんごう)を変更(へんこう)する - to change one's PIN
  • 暗証番号(あんしょうばんごう)を忘(わす)れる - to forget one's PIN

SECURITY NOTE:
誕生日(たんじょうび)などわかりやすい番号(ばんごう)は避(さ)けましょう - Avoid using easily guessable numbers like your birthday.
