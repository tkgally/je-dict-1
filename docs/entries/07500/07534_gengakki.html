弦楽器(げんがっき)

げんがっき
noun
string instrument
1. string instrument; stringed instrument
Musical instruments that produce sound by vibrating strings.
バイオリンは弦楽器(げんがっき)の代表(だいひょう)だ。
The violin is a representative string instrument.
弦楽器(げんがっき)の弦(げん)を張(は)り替(か)える。
Replace the strings on a string instrument.
弦楽(げんがく)四重奏(しじゅうそう)は4つの弦楽器(げんがっき)で演奏(えんそう)する。
A string quartet is performed with four string instruments.

WORD STRUCTURE:
弦(げん) (string) + 楽器(がっき) (musical instrument)

TYPES OF STRING INSTRUMENTS:

**擦弦(さつげん)楽器(がっき) (Bowed strings):**

  • バイオリン - violin
  • ビオラ - viola
  • チェロ - cello
  • コントラバス - double bass

**撥弦(はつげん)楽器(がっき) (Plucked strings):**

  • ギター - guitar
  • ハープ - harp
  • 琴(こと) - koto
  • 三味線(しゃみせん) - shamisen
  • ウクレレ - ukulele

**打弦(だげん)楽器(がっき) (Struck strings):**

  • ピアノ - piano (also classified as keyboard)

RELATED TERMS:

  • 管楽器(かんがっき) - wind instruments
  • 打楽器(だがっき) - percussion instruments
  • 弓(ゆみ) - bow (for bowed instruments)

COLLOCATIONS:

  • 弦楽器(げんがっき)を弾(ひ)く - to play a string instrument
  • 弦楽(げんがく)合奏(がっそう) - string ensemble
