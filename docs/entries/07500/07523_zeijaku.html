脆弱(ぜいじゃく)

ぜいじゃく
noun, na-adjective
vulnerability; fragility; weakness
1. fragility; weakness; vulnerability
The state of being easily damaged, broken, or attacked. Used for physical structures, systems, or situations.
脆弱(ぜいじゃく)な地盤(じばん)の上(うえ)に建(た)てられた。
It was built on fragile ground.
経済(けいざい)の脆弱性(ぜいじゃくせい)が露呈(ろてい)した。
The fragility of the economy was exposed.
2. security vulnerability
In IT context, a weakness in a system that can be exploited by attackers.
セキュリティの脆弱性(ぜいじゃくせい)が発見(はっけん)された。
A security vulnerability was discovered.

WORD STRUCTURE:
脆(ぜい/もろ) (brittle, fragile) + 弱(じゃく) (weak)

COMMON FORMS:

  • 脆弱(ぜいじゃく)な (na-adjective)
  • 脆弱性(ぜいじゃくせい) (vulnerability - noun with 性(せい))

IT/SECURITY CONTEXT:

  • 脆弱性(ぜいじゃくせい)診断(しんだん) - vulnerability assessment
  • 脆弱性(ぜいじゃくせい)対策(たいさく) - vulnerability countermeasures
  • ゼロデイ脆弱性(ぜいじゃくせい) - zero-day vulnerability
  • 脆弱性(ぜいじゃくせい)を突(つ)く - to exploit a vulnerability

OTHER CONTEXTS:

  • 脆弱(ぜいじゃく)な基盤(きばん) - fragile foundation
  • 精神的(せいしんてき)に脆弱(ぜいじゃく) - mentally fragile
  • 脆弱(ぜいじゃく)な立場(たちば) - vulnerable position

ANTONYM:
堅牢(けんろう) - robust, solid
