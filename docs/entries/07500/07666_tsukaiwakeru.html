使(つか)い分(わ)ける

つかいわける
verb
to use properly according to situation; to use selectively
1. to use properly according to situation; to use selectively; to differentiate in usage
To choose and use different things or methods appropriately depending on the situation, purpose, or context.
敬語(けいご)と普通(ふつう)語(ご)を使(つか)い分(わ)ける。
To use honorific language and casual language appropriately.
場面(ばめん)によって言葉(ことば)を使(つか)い分(わ)ける必要(ひつよう)がある。
You need to use different words depending on the situation.
SNSのアカウントを目的別(もくてきべつ)に使(つか)い分(わ)けている。
I use different social media accounts for different purposes.

VERB TYPE:
他動詞(たどうし) (transitive verb)
Ichidan verb (一段動詞(いちだんどうし)/下一段(しもいちだん))

CONJUGATION:

  • 使(つか)い分(わ)けない (negative)
  • 使(つか)い分(わ)けて (te-form)
  • 使(つか)い分(わ)けた (past)

COMMON OBJECTS:

  • 言葉(ことば)を使(つか)い分(わ)ける - to use different words appropriately
  • 敬語(けいご)を使(つか)い分(わ)ける - to use keigo appropriately
  • 道具(どうぐ)を使(つか)い分(わ)ける - to use different tools for different purposes

NOUN FORM:
使(つか)い分(わ)け - differentiated use, selective use
