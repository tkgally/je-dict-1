未読(みどく)

みどく
noun, no-adjective
unread
1. unread
Status indicating that a message, email, or document has not been read yet. Common in digital communication contexts.
未読(みどく)メッセージが100件(けん)ある。
I have 100 unread messages.
未読(みどく)のままにしておいた。
I left it unread.
LINEの未読(みどく)無視(むし)は失礼(しつれい)だと思(おも)う。
I think ignoring LINE messages as unread is rude.

ETYMOLOGY:
未(み) (not yet) + 読(どく) (reading) - not yet read.

USAGE:

Modern usage is primarily digital:

  • 未読(みどく)メール - unread email
  • 未読(みどく)メッセージ - unread message
  • 未読(みどく)スルー/未読(みどく)無視(むし) - deliberately leaving messages unread

COMMON COMPOUNDS:

  • 未読(みどく)本(ほん) - unread book
  • 未読(みどく)通知(つうち) - unread notification

CONTRAST:

  • 既読(きどく) - already read (opposite)
