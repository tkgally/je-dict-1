マナーモード

まなーもーど
noun
silent mode; vibrate mode; manner mode
1. silent mode; vibrate mode
A phone setting that silences the ringtone, typically switching to vibration only.
携帯(けいたい)をマナーモードにした。
I put my phone on silent mode.
映画館(えいがかん)ではマナーモードにしてください。
Please put your phone on silent mode in the cinema.
マナーモードに設定(せってい)するのを忘(わす)れていた。
I forgot to set it to silent mode.

ORIGIN:
Japanese-English (wasei-eigo) combining "manner" + "mode" - emphasizing phone etiquette.

CULTURAL NOTE:
In Japan, using phones on public transport is considered impolite. Announcements on trains commonly remind passengers to set phones to マナーモード and refrain from calls.

RELATED PHONE MODES:

  • 機内(きない)モード - airplane mode
  • 消音(しょうおん) - mute
  • サイレントモード - silent mode (also used)

COLLOCATIONS:

  • マナーモードにする/に設定(せってい)する - to set to silent mode
  • マナーモードを解除(かいじょ)する - to turn off silent mode
