殺虫剤(さっちゅうざい)

さっちゅうざい
noun
insecticide

Definitions

1. insecticide; bug spray; pesticide
A chemical product used to kill insects.

Examples

蚊(か)に殺虫剤(さっちゅうざい)をかけた。
I sprayed insecticide on the mosquito.
殺虫剤(さっちゅうざい)を撒(ま)く前(まえ)に窓(まど)を開(あ)けてください。
Please open the windows before spraying insecticide.
ゴキブリ(ごきぶり)用(よう)の殺虫剤(さっちゅうざい)を買(か)った。
I bought insecticide for cockroaches.

Notes

FORMATION:
殺虫(さっちゅう) (killing insects) + 剤(ざい) (agent/chemical)

TYPES:

  • スプレー式(しき) - spray type
  • 煙(けむり)タイプ - smoke/fumigation type
  • 置(お)き型(がた) - plug-in/standing type

COLLOCATIONS:

  • 殺虫剤(さっちゅうざい)を撒(ま)く - to spray insecticide
  • 殺虫剤(さっちゅうざい)をかける - to spray insecticide (on something)
  • 殺虫剤(さっちゅうざい)を使(つか)う - to use insecticide

RELATED PRODUCTS:

  • 蚊取(かと)り線香(せんこう) - mosquito coil
  • 防虫剤(ぼうちゅうざい) - insect repellent (for prevention)
