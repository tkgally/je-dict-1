返送(へんそう)

へんそう
noun
return shipping; sending back

Definitions

1. return shipping; sending back
The act of sending something back, typically packages or documents, to the sender or a specified location.

Examples

不良品(ふりょうひん)を返送(へんそう)した。
I sent back the defective product.
返送(へんそう)料(りょう)は当社(とうしゃ)負担(ふたん)です。
Our company will cover the return shipping cost.
書類(しょるい)に記入(きにゅう)して返送(へんそう)してください。
Please fill out the documents and send them back.

Notes

FORMATION:
返(へん) (return) + 送(そう) (send)

VERB FORM:

  • 返送(へんそう)する (to send back)

COMMON COLLOCATIONS:

  • 返送(へんそう)料(りょう)/返送(へんそう)費用(ひよう) (return shipping cost)
  • 着払(ちゃくばら)いで返送(へんそう)する (to return with postage due)
  • 元払(もとばら)いで返送(へんそう)する (to return prepaid)

RELATED:

  • 送付(そうふ) (sending - forward direction)
  • 返品(へんぴん) (product return)

Related Words

Contrast: 送付(そうふ) (sending)
