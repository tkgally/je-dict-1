報告書(ほうこくしょ)

ほうこくしょ
noun
report; written report; statement

Definitions

1. written report; formal report
A formal document presenting information or findings on a particular matter.

Examples

報告書(ほうこくしょ)を作成(さくせい)する。
To write a report.
月末(げつまつ)までに報告書(ほうこくしょ)を提出(ていしゅつ)してください。
Please submit the report by the end of the month.
調査(ちょうさ)報告書(ほうこくしょ)が公開(こうかい)された。
The investigation report was published.

Notes

FORMATION:
報告(ほうこく) (report) + 書(しょ) (document)

TYPES OF REPORTS:

  • 調査(ちょうさ)報告書(ほうこくしょ) (investigation report)
  • 出張(しゅっちょう)報告書(ほうこくしょ) (business trip report)
  • 年次(ねんじ)報告書(ほうこくしょ) (annual report)
  • 中間(ちゅうかん)報告書(ほうこくしょ) (interim report)
  • 最終(さいしゅう)報告書(ほうこくしょ) (final report)

COMMON VERBS:

  • 報告書(ほうこくしょ)を書(か)く (to write a report)
  • 報告書(ほうこくしょ)を提出(ていしゅつ)する (to submit a report)
  • 報告書(ほうこくしょ)をまとめる (to compile a report)

SIMILAR WORDS:

  • レポート - report (loanword, often for academic papers)
  • 報告(ほうこく) - report (can be verbal or written)
