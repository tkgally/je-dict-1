防犯(ぼうはん)カメラ

ぼうはんかめら
noun
security camera; surveillance camera
1. security camera; surveillance camera
A camera installed to monitor and record activity for crime prevention and security purposes.
この店(みせ)には防犯(ぼうはん)カメラが設置(せっち)されている。
This store has security cameras installed.
防犯(ぼうはん)カメラの映像(えいぞう)で犯人(はんにん)が特定(とくてい)された。
The culprit was identified from the security camera footage.
防犯(ぼうはん)カメラ作動中(さどうちゅう)。
Security cameras in operation.

COMPOSITION: 防犯(ぼうはん) (crime prevention) + カメラ (camera).

SYNONYMS:

  • 監視(かんし)カメラ: surveillance camera (emphasizes monitoring)
  • CCTV: closed-circuit television

COMMON LOCATIONS:

  • 店舗(てんぽ): stores
  • 駅(えき): train stations
  • コンビニ: convenience stores
  • 駐車場(ちゅうしゃじょう): parking lots
  • 住宅街(じゅうたくがい): residential areas
  • 銀行(ぎんこう): banks

SIGNAGE:

  • 防犯(ぼうはん)カメラ作動中(さどうちゅう) (security cameras in operation)
  • 録画中(ろくがちゅう) (recording in progress)

RELATED VOCABULARY:

  • 防犯(ぼうはん): crime prevention
  • 監視(かんし): surveillance, monitoring
  • 映像(えいぞう): footage, video
  • 録画(ろくが): recording
  • 画像解析(がぞうかいせき): image analysis
