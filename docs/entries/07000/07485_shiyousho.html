仕様書(しようしょ)

しようしょ
noun
specification document; specs
1. specification document; specifications; spec sheet
A detailed document that describes the technical requirements, features, and standards for a product, system, or project. Used extensively in IT, manufacturing, and construction.
仕様書(しようしょ)に基(もと)づいて開発(かいはつ)を進(すす)める。
Proceed with development based on the specifications.
仕様書(しようしょ)の変更(へんこう)があった場合(ばあい)はご連絡(れんらく)ください。
Please contact us if there are any changes to the specifications.
仕様書(しようしょ)どおりに製品(せいひん)を作(つく)る。
Make the product according to the specifications.

WORD STRUCTURE:
仕様(しよう) (specifications, method) + 書(しょ) (document)

TYPES OF 仕様書(しようしょ):

  • 機能(きのう)仕様書(しようしょ) - functional specifications
  • 技術(ぎじゅつ)仕様書(しようしょ) - technical specifications
  • 設計(せっけい)仕様書(しようしょ) - design specifications
  • 要件(ようけん)仕様書(しようしょ) - requirements specifications

COMMON IN:

  • IT/ソフトウェア開発(かいはつ) - software development
  • 製造業(せいぞうぎょう) - manufacturing
  • 建設業(けんせつぎょう) - construction
  • 製品(せいひん)開発(かいはつ) - product development

COMMON EXPRESSIONS:

  • 仕様書(しようしょ)を作成(さくせい)する - to create specifications
  • 仕様書(しようしょ)を確認(かくにん)する - to review specifications
  • 仕様(しよう)変更(へんこう) - specification change
  • 仕様書(しようしょ)どおり - according to specifications

RELATED TERMS:

  • スペック (spec) - casual/abbreviated form
  • 要件定義書(ようけんていぎしょ) - requirements document
