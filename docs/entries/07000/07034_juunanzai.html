柔軟剤(じゅうなんざい)

じゅうなんざい
noun
fabric softener
1. fabric softener; fabric conditioner
A laundry product that softens clothes and reduces static electricity.
洗濯(せんたく)の時(とき)に柔軟剤(じゅうなんざい)を入(い)れる。
I add fabric softener when doing laundry.
この柔軟剤(じゅうなんざい)はいい香(かお)りがする。
This fabric softener has a nice scent.
柔軟剤(じゅうなんざい)を使(つか)うとタオルがふわふわになる。
Towels become fluffy when you use fabric softener.

柔軟剤(じゅうなんざい) is fabric softener. Formation: 柔軟(じゅうなん) 'soft, pliable' + 剤(ざい) 'agent, preparation' — the same suffix as in 洗剤(せんざい) and 漂白剤(ひょうはくざい).

It goes into a separate compartment from the detergent and is released during the rinse, so it is not mixed in at the start of the wash.

Collocations:

  • 柔軟剤(じゅうなんざい)を入(い)れる: to add fabric softener
  • 柔軟剤(じゅうなんざい)の香(かお)り: the scent of fabric softener — a heavily marketed selling point in Japan
  • 無香料(むこうりょう)の柔軟剤(じゅうなんざい): unscented fabric softener
