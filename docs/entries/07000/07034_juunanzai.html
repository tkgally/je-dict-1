柔軟剤(じゅうなんざい)

じゅうなんざい
noun
fabric softener

Definitions

1. fabric softener; fabric conditioner
A laundry product that softens clothes and reduces static electricity.

Examples

洗濯(せんたく)の時(とき)に柔軟剤(じゅうなんざい)を入(い)れる。
I add fabric softener when doing laundry.
この柔軟剤(じゅうなんざい)はいい香(かお)りがする。
This fabric softener has a nice scent.
柔軟剤(じゅうなんざい)を使(つか)うとタオル(たおる)がふわふわになる。
Towels become fluffy when you use fabric softener.

Notes

FORMATION:
柔軟(じゅうなん) (soft/flexible) + 剤(ざい) (agent/chemical)

RELATED LAUNDRY PRODUCTS:

  • 洗剤(せんざい) - detergent
  • 漂白剤(ひょうはくざい) - bleach
  • 洗濯(せんたく)のり - laundry starch

COLLOCATIONS:

  • 柔軟剤(じゅうなんざい)を入(い)れる - to add fabric softener
  • 柔軟剤(じゅうなんざい)の香(かお)り - fabric softener fragrance
  • 無香料(むこうりょう)の柔軟剤(じゅうなんざい) - unscented fabric softener

USAGE NOTE:
Fabric softener is added during the rinse cycle, not with the detergent.
