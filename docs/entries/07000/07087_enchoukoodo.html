延長(えんちょう)コード

えんちょうこーど
noun
extension cord
1. extension cord
An electrical cord with a plug on one end and one or more outlets on the other, used to extend the reach of power sources.
コンセントが遠(とお)いので延長(えんちょう)コードが必要(ひつよう)だ。
The outlet is far away, so I need an extension cord.
3メートルの延長(えんちょう)コードを買(か)った。
I bought a 3-meter extension cord.
延長(えんちょう)コードを使(つか)いすぎると危険(きけん)だ。
Using too many extension cords is dangerous.

COMMON COLLOCATIONS:

  • 延長(えんちょう)コードを使(つか)う (to use an extension cord)
  • 延長(えんちょう)コードを繋(つな)ぐ (to connect an extension cord)
  • 延長(えんちょう)コードを巻(ま)く (to coil an extension cord)

SAFETY NOTES:

  • タコ足(あし)配線(はいせん)は危険(きけん) (daisy-chaining is dangerous)
  • 容量(ようりょう)オーバーに注意(ちゅうい) (beware of overloading)

RELATED TERMS:

  • 電源(でんげん)タップ (power strip)
  • コンセント (outlet/socket)
  • テーブルタップ (power strip/extension socket)
