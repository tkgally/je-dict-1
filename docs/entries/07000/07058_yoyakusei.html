予約制(よやくせい)

よやくせい
noun
reservation system; by appointment only

Definitions

1. reservation system; appointment system; by reservation only
A system requiring advance booking or reservation before visiting or using a service.

Examples

このレストランは予約制(よやくせい)です。
This restaurant is by reservation only.
予約制(よやくせい)なので、事前(じぜん)に電話(でんわ)してください。
Since it's by reservation, please call in advance.
病院(びょういん)は完全(かんぜん)予約制(よやくせい)になった。
The hospital has switched to a complete appointment system.

Notes

FORMATION:
予約(よやく) (reservation) + 制(せい) (system)

VARIATIONS:

  • 予約制(よやくせい) - reservation system
  • 完全(かんぜん)予約制(よやくせい) - completely by reservation only
  • 一部(いちぶ)予約制(よやくせい) - partially by reservation

COLLOCATIONS:

  • 予約制(よやくせい)を導入(どうにゅう)する - to implement a reservation system
  • 予約制(よやくせい)になる - to become by reservation only
  • 予約制(よやくせい)です - it's by reservation only

CONTRAST:

  • 予約制(よやくせい) - by reservation
  • 先着順(せんちゃくじゅん) - first-come, first-served
  • 自由(じゆう)席(せき) - open seating (no reservation)

CONTEXTS:

  • 病院(びょういん) - hospitals/clinics
  • レストラン - restaurants
  • 美容院(びよういん) - beauty salons
  • 美術館(びじゅつかん) - museums

Related Words
