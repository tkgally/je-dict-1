ストレージ

すとれーじ
noun
storage (digital/data)

Definitions

1. storage; data storage
Digital storage space for files and data, especially in computing contexts.

Examples

スマホのストレージが足(た)りなくなった。
My phone's storage is running out.
クラウドストレージに写真(しゃしん)を保存(ほぞん)している。
I save my photos in cloud storage.
ストレージ容量(ようりょう)を確認(かくにん)してください。
Please check the storage capacity.

Notes

ORIGIN:
From English "storage"

TYPES:

  • クラウドストレージ - cloud storage
  • 外部(がいぶ)ストレージ - external storage
  • 内部(ないぶ)ストレージ - internal storage
  • オンラインストレージ - online storage

COLLOCATIONS:

  • ストレージ容量(ようりょう) (storage capacity)
  • ストレージを増(ふ)やす (to add storage)
  • ストレージを解放(かいほう)する (to free up storage)
  • ストレージが一杯(いっぱい) (storage is full)

RELATED TERMS:

  • 保存(ほぞん) - saving (data)
  • メモリ - memory
  • ハードディスク - hard disk
