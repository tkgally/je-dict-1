やすり

やすり
noun
file (tool); rasp
1. file (metal or wood working tool)
A hand tool with a rough surface used for smoothing, shaping, or removing material from wood, metal, or other materials.
やすりで木(き)の表面(ひょうめん)を滑(なめ)らかにした。
I smoothed the wood surface with a file.
金属(きんぞく)やすりで角(かど)を丸(まる)くする。
Round off the corners with a metal file.
爪(つめ)やすりで爪(つめ)を整(ととの)えた。
I shaped my nails with a nail file.

KANJI: Can be written as 鑢(やすり), though hiragana is more common.

TYPES OF FILES:

  • 金属(きんぞく)やすり: metal file
  • 木工(もっこう)やすり: woodworking file
  • 爪(つめ)やすり: nail file
  • 紙(かみ)やすり: sandpaper
  • ダイヤモンドやすり: diamond file

SHAPES:

  • 平(ひら)やすり: flat file
  • 丸(まる)やすり: round file
  • 半丸(はんまる)やすり: half-round file
  • 三角(さんかく)やすり: triangular file
  • 四角(しかく)やすり: square file

COARSENESS:

  • 粗目(あらめ): coarse
  • 中目(なかめ): medium
  • 細目(ほそめ)/細目(さいめ): fine

RELATED TOOLS:

  • 紙(かみ)やすり: sandpaper
  • サンダー: electric sander
  • グラインダー: grinder
