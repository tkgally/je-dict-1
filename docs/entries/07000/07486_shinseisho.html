申請書(しんせいしょ)

しんせいしょ
noun
application form; request form

Definitions

1. application form; request form; application document
A formal document used to request something officially, such as leave, permits, licenses, or services. Common in both government and corporate settings.

Examples

休暇(きゅうか)申請書(しんせいしょ)を提出(ていしゅつ)する。
Submit a leave request form.
申請書(しんせいしょ)に必要事項(ひつようじこう)を記入(きにゅう)してください。
Please fill in the required information on the application form.
パスポートの申請書(しんせいしょ)はどこでもらえますか。
Where can I get a passport application form?

Notes

WORD STRUCTURE:
申請(しんせい) (application, request) + 書(しょ) (document)

COMMON TYPES:

  • 休暇(きゅうか)申請書(しんせいしょ) - leave request form
  • 経費(けいひ)申請書(しんせいしょ) - expense claim form
  • 許可(きょか)申請書(しんせいしょ) - permit application
  • 補助金(ほじょきん)申請書(しんせいしょ) - subsidy application
  • 出張(しゅっちょう)申請書(しんせいしょ) - business trip request
  • 採用(さいよう)申請書(しんせいしょ) - hiring request form

GOVERNMENT APPLICATIONS:

  • パスポート申請書(しんせいしょ) - passport application
  • 住民票(じゅうみんひょう)申請書(しんせいしょ) - residence certificate application
  • ビザ申請書(しんせいしょ) - visa application

COMMON EXPRESSIONS:

  • 申請書(しんせいしょ)を記入(きにゅう)する - to fill out an application
  • 申請書(しんせいしょ)を提出(ていしゅつ)する - to submit an application
  • 申請書(しんせいしょ)が受理(じゅり)される - application is accepted

RELATED:

  • 申込書(もうしこみしょ) - enrollment/registration form (less formal)
