弦楽器(げんがっき)

げんがっき
noun
string instrument

Definitions

1. string instrument; instrument played by plucking or bowing strings
A musical instrument that produces sound from vibrating strings, either by plucking, bowing, or striking them.

Examples

弦楽器(げんがっき)の音(おと)が好(す)きだ。
I like the sound of string instruments.
ギターもバイオリンも弦楽器(げんがっき)だ。
Both guitar and violin are string instruments.
弦楽器(げんがっき)は弦(げん)の張(は)り具合(ぐあい)が大事(だいじ)だ。
String tension is important for string instruments.
弦楽器(げんがっき)の四重奏(しじゅうそう)を聴(き)いた。
I listened to a string quartet.

Notes

ETYMOLOGY:
弦(げん) (string) + 楽器(がっき) (musical instrument)

EXAMPLES OF STRING INSTRUMENTS:

Bowed strings (擦弦楽器(さつげんがっき)):

  • バイオリン: violin
  • ビオラ: viola
  • チェロ: cello
  • コントラバス: double bass

Plucked strings:

  • ギター: guitar
  • ハープ: harp
  • ウクレレ: ukulele
  • 三味線(しゃみせん): shamisen
  • 琴(こと): koto
  • 琵琶(びわ): biwa

INSTRUMENT CATEGORIES:

  • 打楽器(だがっき): percussion instruments
  • 管楽器(かんがっき): wind instruments
  • 弦楽器(げんがっき): string instruments

RELATED TERMS:

  • 弦(げん): string (of an instrument)
  • 弦楽四重奏(げんがくしじゅうそう): string quartet

COUNTER: 本(ほん) or 挺(ちょう) (for some traditional instruments)
