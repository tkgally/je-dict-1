今朝(けさ)

けさ
noun
this morning
1. this morning
The morning of the current day.
今朝(けさ)は早(はや)く起(お)きた。
I woke up early this morning.
今朝(けさ)何(なに)を食(た)べましたか。
What did you eat this morning?
今朝(けさ)の天気(てんき)は良(よ)かった。
The weather was good this morning.

今朝(けさ) means this morning. Note the irregular reading.

READING:
Read as けさ (NOT こんあさ or いまあさ). This is a special compound reading.

RELATED TIME EXPRESSIONS:

  • 今日(きょう): today
  • 今晩(こんばん): tonight
  • 今夜(こんや): tonight
  • 昨日(きのう): yesterday
  • 明日(あした): tomorrow

COMMON PATTERNS:

  • 今朝(けさ)の新聞(しんぶん): this morning's newspaper
  • 今朝(けさ)から: since this morning
  • 今朝(けさ)は早(はや)く起(お)きた: I woke up early this morning

SIMILAR IRREGULAR READINGS:

  • 今日(きょう): today (not こんにち)
  • 昨日(きのう): yesterday (not さくじつ)
