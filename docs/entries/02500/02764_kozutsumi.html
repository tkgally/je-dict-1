小包(こづつみ)

こづつみ
noun
parcel, package
1. parcel, package
A wrapped package sent by mail.
小包(こづつみ)を送(おく)る。
To send a parcel.
小包(こづつみ)が届(とど)いた。
A package arrived.
海外(かいがい)から小包(こづつみ)を受(う)け取(と)った。
I received a package from overseas.

小包(こづつみ) is a parcel or package sent by mail.

COMMON PATTERNS:

  • 小包(こづつみ)を送(おく)る (to send a parcel)
  • 小包(こづつみ)を受(う)け取(と)る (to receive a parcel)
  • 小包(こづつみ)が届(とど)く (a parcel arrives)

POSTAL SERVICES:

  • 郵便(ゆうびん)小包(こづつみ) (postal parcel)
  • 国際(こくさい)小包(こづつみ) (international parcel)
  • 航空(こうくう)小包(こづつみ) (airmail parcel)

SIMILAR WORDS:

  • 小包(こづつみ): parcel (postal term)
  • 荷物(にもつ): package, luggage (general)
  • 宅配便(たくはいびん): home delivery service
