地図(ちず)

ちず
noun
map
1. map
A visual representation of an area.
地図(ちず)を見(み)て道(みち)を探(さが)す。
To look for a road by looking at the map.
日本(にほん)の地図(ちず)
A map of Japan.
スマホで地図(ちず)アプリを使(つか)う。
To use a map app on a smartphone.

地図(ちず) means 'map'—a visual representation of an area showing locations, roads, and geographical features.

WORD FORMATION:

  • 地(ち) (earth, ground) + 図(ず) (diagram, drawing) = map

TYPES OF MAPS:

  • 世界(せかい)地図(ちず): world map
  • 日本(にほん)地図(ちず): map of Japan
  • 道路(どうろ)地図(ちず): road map
  • 観光(かんこう)地図(ちず): tourist map
  • 地下鉄(ちかてつ)路線図(ろせんず): subway map
  • 地図(ちず)アプリ: map app (Google Maps, etc.)

COMMON EXPRESSIONS:

  • 地図(ちず)を見(み)る: to look at a map
  • 地図(ちず)を広(ひろ)げる: to spread out/open a map
  • 地図(ちず)で調(しら)べる: to check on a map
  • 地図(ちず)に載(の)っている: to be on the map

RELATED WORDS:

  • 案内図(あんないず): guide map, directory map
  • 路線図(ろせんず): route map (trains, buses)
  • 白地図(はくちず): blank map (for studying)
  • GPS / ナビ: navigation system
