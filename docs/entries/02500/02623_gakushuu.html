1. study, learning
The process of acquiring knowledge or skills through study.
毎日(まいにち)英語(えいご)を学習(がくしゅう)している。
I study English every day.
学習(がくしゅう)塾(じゅく)に通(かよ)っている。
I go to a cram school.
子供(こども)の学習(がくしゅう)意欲(いよく)を高(たか)めることが大切(たいせつ)だ。
It is important to increase children's motivation to learn.
2. learning (in computing/AI)
The process by which a system improves its performance based on experience.
AIの機械(きかい)学習(がくしゅう)が進歩(しんぽ)している。
Machine learning in AI is advancing.
この機械(きかい)は学習(がくしゅう)を重(かさ)ねて精度(せいど)が上(あ)がる。
This machine improves in accuracy through repeated learning.
大量(たいりょう)のデータを使(つか)って学習(がくしゅう)させたモデルが、画像(がぞう)認識(にんしき)で高(たか)い成績(せいせき)を出(だ)した。
A model trained on a large amount of data achieved high scores in image recognition.

学習(がくしゅう) is a more formal word for studying than 勉強(べんきょう).

TRANSITIVITY:

  • Type: 他動詞(たどうし) (transitive)
  • No standard intransitive pair
  • Pattern: [noun]を学習(がくしゅう)する

COMMON PATTERNS:

  • 学習(がくしゅう)する (to study, to learn)
  • 学習(がくしゅう)を続(つづ)ける (to continue studying)

COMPOUND WORDS:

  • 学習(がくしゅう)塾(じゅく) (cram school)
  • 学習(がくしゅう)教材(きょうざい) (learning materials)
  • 自己(じこ)学習(がくしゅう) (self-study)
  • 機械(きかい)学習(がくしゅう) (machine learning)
  • 生涯(しょうがい)学習(がくしゅう) (lifelong learning)

SIMILAR WORDS:

  • 学習(がくしゅう): study, learning (formal, academic)
  • 勉強(べんきょう): study (everyday word)
  • 学(まな)ぶ: to learn (verb)
