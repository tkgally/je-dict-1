どっち

どっち
pronoun
which (of two), which way
1. which (of two)
Used to ask about one of two options.
どっちがいい？
Which one is better?
コーヒーと紅茶(こうちゃ)、どっちにする？
Coffee or tea, which will you have?
赤(あか)と青(あお)、どっちが好(す)き？
Red or blue, which do you like?
どっちでもいいよ。
Either one is fine.
どっちが正(ただ)しい？
Which one is correct?
2. which way, which direction
Used to ask about direction.
駅(えき)はどっちですか。
Which way is the station?
どっちに行(い)けばいい？
Which way should I go?
出口(でぐち)はどっち？
Which way is the exit?
東(ひがし)と西(にし)、どっちに曲(ま)がる？
East or west, which way do we turn?
どっちから来(き)たの？
Which way did you come from?

どっち is the casual form of どちら, used to ask "which one" (of two) or "which way."

KO-SO-A-DO SERIES:

  • こっち: this way / this one (near speaker)
  • そっち: that way / that one (near listener)
  • あっち: over there / that one (far from both)
  • どっち: which way / which one (question)

FORMALITY:

  • どっち: casual (used with friends, family)
  • どちら: polite (used in formal situations, with strangers)

COMMON PATTERNS:

  • どっちがいい？: Which one is better?
  • どっちでもいい: Either is fine.
  • どっちにする？: Which will you choose?
  • どっちかというと: if I had to choose / rather

NOTE:
Used for choosing between two options. For three or more, use どれ (casual) or どれか.
