どっち

どっち
pronoun
which (of two), which way
1. which (of two)
Used to ask about one of two options.
どっちがいい？
Which one is better?
コーヒーと紅茶(こうちゃ)、どっちにする？
Coffee or tea, which will you have?
赤(あか)と青(あお)、どっちが好(す)き？
Red or blue, which do you like?
Sense 1: which (of two)
どっちでもいいよ。
Either one is fine.
Sense 1: which (of two)
どっちが正(ただ)しい？
Which one is correct?
Sense 1: which (of two)
2. which way, which direction
Used to ask about direction.
駅(えき)はどっちですか。
Which way is the station?
どっちに行(い)けばいい？
Which way should I go?
Sense 2: which direction
出口(でぐち)はどっち？
Which way is the exit?
Sense 2: which way
東(ひがし)と西(にし)、どっちに曲(ま)がる？
East or west, which way do we turn?
Sense 2: which direction
どっちから来(き)たの？
Which way did you come from?
Sense 2: which direction

どっち is the casual form of どちら.

KO-SO-A-DO SERIES:

  • こっち (this way)
  • そっち (that way - near you)
  • あっち (over there)
  • どっち (which way - question)

FORMALITY:

  • どっち (casual)
  • どちら (polite)

NOTE: Used for choosing between two options. For more than two, use どれ.
