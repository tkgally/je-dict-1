文章(ぶんしょう)

ぶんしょう
noun
sentence, text, writing
1. sentence, text
A written composition of sentences.
文章(ぶんしょう)を書(か)く。
To write a text.
この文章(ぶんしょう)は難(むずか)しい。
This text is difficult.
文章(ぶんしょう)を読(よ)んで答(こた)えてください。
Please read the passage and answer.
2. writing style
The manner in which something is written.

文章(ぶんしょう) refers to written text or passages.

RELATED TERMS:

  • 文(ぶん) (sentence - single)
  • 段落(だんらく) (paragraph)
  • 作文(さくぶん) (composition, essay)

COMMON PHRASES:

  • 文章(ぶんしょう)を書(か)く (to write text)
  • 文章(ぶんしょう)力(りょく) (writing ability)
general
