文章(ぶんしょう)

ぶんしょう
noun
sentence, text, writing
1. sentence, text
A written composition of sentences.
文章(ぶんしょう)を書(か)く。
To write a text.
この文章(ぶんしょう)は難(むずか)しい。
This text is difficult.
文章(ぶんしょう)を読(よ)んで答(こた)えてください。
Please read the passage and answer.
2. writing style
The manner in which something is written.

文章(ぶんしょう) refers to written text, passages, or writing style.

KANJI BREAKDOWN:
文(ぶん) (writing, sentence) + 章(しょう) (chapter, section)

HIERARCHY OF TEXT:

  • 字(じ): character
  • 語(ご)/単語(たんご): word
  • 文(ぶん): sentence
  • 文章(ぶんしょう): text/passage
  • 段落(だんらく): paragraph

COMMON EXPRESSIONS:

  • 文章(ぶんしょう)を書(か)く: to write text
  • 文章(ぶんしょう)を読(よ)む: to read a passage
  • 文章(ぶんしょう)力(りょく): writing ability
  • 文章(ぶんしょう)構成(こうせい): text structure

RELATED WORDS:

  • 作文(さくぶん): composition, essay
  • 論文(ろんぶん): thesis, paper
  • 文体(ぶんたい): writing style
