空(す)いている

すいている
expression (verb て-form + いる)
to be empty, to be vacant
1. to be empty, to be uncrowded
A place that is not crowded or has few people.
今日(きょう)は電車(でんしゃ)が空(す)いている。
The train is empty today.
午前中(ごぜんちゅう)は店(みせ)が空(す)いているから行(い)こう。
The store is less crowded in the morning, so let's go then.
2. to be vacant, to be available
A seat or space that is unoccupied and available for use.
この席(せき)は空(す)いていますか。
Is this seat available?
Very common question in restaurants, trains, etc.

空(す)いている is the ている form of 空(す)く, describing the state of being empty or uncrowded.

BASE VERB:

  • 空(す)く (to become empty, to become less crowded)
  • This is an intransitive verb (自動詞(じどうし))

ASPECT (ている):

  • 空(す)いている describes a resulting state: 'is empty/uncrowded'

COMMON PATTERNS:

  • 席(せき)が空(す)いている (seat is available)
  • 電車(でんしゃ)が空(す)いている (train is uncrowded)
  • 道(みち)が空(す)いている (road is clear)

ANTONYM:

  • 混(こ)んでいる (to be crowded)

NOTE: Don't confuse with お腹(なか)が空(す)いている (to be hungry), which uses the same verb but refers to an empty stomach.

Related Words

Antonym: 混(こ)んでいる (crowded)
