赤(あか)

あか
noun / no-adjective
red
1. red
The color red.
赤(あか)い花(はな)
Red flowers.
信号(しんごう)が赤(あか)だ。
The traffic light is red.
赤(あか)いりんごを買(か)った。
I bought red apples.

赤(あか) is one of the basic Japanese color words. Can function as a noun, no-adjective, or the base of the i-adjective 赤(あか)い.

FORMS:

  • Noun: 赤(あか)が好(す)き (I like red)
  • No-adjective: 赤(あか)の他人(たにん) (complete stranger)
  • I-adjective: 赤(あか)い花(はな) (red flower)

COMMON EXPRESSIONS:

  • 赤(あか)ちゃん: baby
  • 赤(あか)ワイン: red wine
  • 真(ま)っ赤(か): bright red; blatant (lie)
  • 赤(あか)の他人(たにん): complete stranger
  • 赤字(あかじ): deficit, in the red

IDIOM:
真(ま)っ赤(か)な嘘(うそ): a blatant lie
