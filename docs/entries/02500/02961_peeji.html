ページ

ぺーじ
noun
page
1. page
One side of a sheet of paper in a book or document.
10ページを開(ひら)いてください。
Please open to page 10.
この本(ほん)は300ページあります。
This book has 300 pages.
次(つぎ)のページに進(すす)む。
To go to the next page.

ページ is a loanword from English 'page' used for both printed and digital pages.

COUNTING:
Pages are counted with the counter ページ directly attached to numbers: 1ページ, 2ページ, 10ページ.

COMMON EXPRESSIONS:

  • 〜ページ目(め): the ~th page
  • 〜ページを開(ひら)く: to open to page ~
  • 次(つぎ)のページ: next page
  • 前(まえ)のページ: previous page
  • ウェブページ: web page
  • トップページ: home page

ALTERNATIVE:
頁(ページ) uses the kanji 頁(ページ), but the katakana form is more common in modern usage.
