卓球台(たっきゅうだい)

たっきゅうだい
noun
table tennis table; ping-pong table
1. table tennis table; ping-pong table
The table on which table tennis is played, divided by a net across the middle. Built from 卓球(たっきゅう) (table tennis) + 台(だい) (stand; table).
体育館(たいいくかん)に卓球台(たっきゅうだい)を並(なら)べた。
We lined up the table tennis tables in the gym.
卓球台(たっきゅうだい)を折(お)りたたんで片付(かたづ)けた。
We folded up the ping-pong table and put it away.
温泉旅館(おんせんりょかん)のロビーに卓球台(たっきゅうだい)が置(お)いてあって、家族(かぞく)で楽(たの)しんだ。
There was a ping-pong table in the lobby of the hot-spring inn, and our family enjoyed it.

The playing table for table tennis. A folding 卓球台(たっきゅうだい) is a familiar fixture of school gyms and hot-spring inns.

COMMON COLLOCATIONS:

  • 卓球台(たっきゅうだい)を並(なら)べる: to set up table tennis tables
  • 折(お)りたたみ卓球台(たっきゅうだい): a folding ping-pong table

SIMILAR WORDS:

  • 卓球(たっきゅう): table tennis; ping-pong — the sport itself
  • ピンポン: ping-pong — a casual loanword for the game
