時限式(じげんしき)

じげんしき
noun
timed type; time-delayed; set to a timer
1. timed type; time-delayed; set to go off at a preset time
Describes a device or mechanism set to activate at a predetermined time or after a set interval. Most familiar in 時限式(じげんしき)爆弾(ばくだん) (time bomb), but also used of locks and switches.
時限式(じげんしき)の爆弾(ばくだん)が見(み)つかった。
A time bomb was found.
この金庫(きんこ)は時限式(じげんしき)のロックがついている。
This safe has a time-delay lock.
照明(しょうめい)を時限式(じげんしき)にして、決(き)まった時間(じかん)に自動(じどう)で消(き)えるようにした。
I made the lighting timer-controlled so it turns off automatically at a set time.

Formed from 時限(じげん) (time limit, set period) + 式(しき) (type, style, system). Used attributively, usually as 時限式(じげんしき)の + noun.

COMMON COLLOCATIONS:

  • 時限式(じげんしき)爆弾(ばくだん): time bomb
  • 時限式(じげんしき)ロック: time-delay lock
  • 時限式(じげんしき)の装置(そうち): a timed device

SIMILAR WORDS:

  • 自動(じどう): automatic — acts on its own, but not necessarily at a preset time
  • タイマー: timer — the device itself; 時限式(じげんしき) describes the manner of operation
