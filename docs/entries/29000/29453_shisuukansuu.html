指数関数

しすうかんすう
noun
exponential function
1. exponential function
In mathematics, a function of the form y = a^x, in which the variable appears in the exponent. Its rapid growth is the basis of the everyday phrase 'to grow exponentially.'
指数関数(しすうかんすう)を学(まな)ぶ。
to study exponential functions.
この曲線(きょくせん)は指数関数(しすうかんすう)で表(あらわ)される。
This curve is expressed by an exponential function.
感染者(かんせんしゃ)数(すう)が指数関数(しすうかんすう)的(てき)に増(ふ)えていった。
The number of infected people increased exponentially.

A mathematics term; the adjectival form 指数関数的(しすうかんすうてき) ('exponential, exponentially') is common in everyday writing about rapid growth.

COMMON COLLOCATIONS:

  • 指数関数(しすうかんすう)的(てき)に増(ふ)える: to increase exponentially
  • 指数関数(しすうかんすう)のグラフ: the graph of an exponential function
  • 自然(しぜん)指数関数(しすうかんすう): the natural exponential function

SIMILAR WORDS:

  • 対数関数(たいすうかんすう): logarithmic function — the inverse of the exponential function
  • 一次関数(いちじかんすう): linear function — grows at a constant rate, not by multiplication
