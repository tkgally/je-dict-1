字数(じすう)

じすう
noun
number of characters; character count
1. number of characters; character count
The count of written characters (kana, kanji, numerals, etc.) in a piece of text. Used for essays, application forms, and online posts that impose length limits.
字数(じすう)を数(かぞ)える。
Count the number of characters.
レポートの字数(じすう)が足(た)りない。
The report doesn't have enough characters.
この作文(さくぶん)は字数(じすう)制限(せいげん)が八百字(はっぴゃくじ)だ。
This essay has a character limit of 800.

Refers to how many characters a text contains, counting each kana, kanji, or symbol as one.

COMMON COLLOCATIONS:

  • 字数(じすう)制限(せいげん): character limit
  • 字数(じすう)を数(かぞ)える: to count the characters
  • 字数(じすう)が足(た)りる: to have enough characters
  • 字数(じすう){オーバー}: over the character limit

SIMILAR WORDS:

  • 文字数(もじすう): character count — near-synonym, more common when talking about digital text and input fields
