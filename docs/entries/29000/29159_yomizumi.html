読(よ)み済(ず)み

よみずみ
noun
already read; read (of a message or document)
1. already read; having been read
Indicates that something (a book, message, email, or document) has already been read. Used both for physical reading and digital read-receipt status in apps such as LINE.
この本(ほん)はもう読(よ)み済(ず)みだ。
I've already read this book.
読(よ)み済(ず)みのメールをフォルダに移動(いどう)した。
I moved the emails I had already read to a folder.
LINEのメッセージが読(よ)み済(ず)みになっているのに返信(へんじ)が来(こ)ない。
The LINE message shows as read, but no reply has come.

The 済(す)み component comes from 済(す)む (to be done, to be finished). Common in both physical contexts (books, documents) and digital messaging.

COMMON COLLOCATIONS:

  • 読(よ)み済(ず)みにする: to mark as read
  • 読(よ)み済(ず)みのメール: read emails
  • 未読(みどく) (unread) ↔ 読(よ)み済(ず)み (read) — common contrast in email/message apps

SIMILAR WORDS:

  • 既読(きどく): read (especially in LINE context); same meaning but shorter; used in 既読(きどく)スルー (seen but no reply)
  • 未読(みどく): unread — the opposite
