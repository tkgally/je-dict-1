使(つか)い走(ばし)り

つかいばしり
noun
errand boy; gofer; running errands
1. errand boy; gofer
A person who is sent to run errands or do minor tasks for someone else. Often carries a negative nuance of being treated as a subordinate.
先輩(せんぱい)の使(つか)い走(ばし)りをさせられた。
I was made to run errands for my senior.
いつまでも使(つか)い走(ばし)りの役(やく)は嫌(いや)だ。
I don't want to be stuck playing the gofer forever.
新人(しんじん)のころは毎日(まいにち)使(つか)い走(ばし)りばかりだった。
When I was new, all I did every day was run errands.
2. running errands
The act of going somewhere to carry out small tasks on behalf of someone else.
ちょっと使(つか)い走(ばし)りを頼(たの)まれた。
I was asked to run a quick errand.
使(つか)い走(ばし)りに行(い)ってくる。
I'm going to run an errand.
買(か)い物(もの)の使(つか)い走(ばし)りで一日(いちにち)終(お)わった。
The whole day was spent running shopping errands.

USAGE:
When referring to a person (sense 1), it often implies being treated as a lowly subordinate. Common in workplace and school hierarchies. Also written as 使(つか)いっ走(ぱし)り with a geminate consonant in casual speech.

COMMON COLLOCATIONS:

  • 使(つか)い走(ばし)りをさせる (to make someone run errands)
  • 使(つか)い走(ばし)りをさせられる (to be made to run errands)
  • 使(つか)い走(ばし)りに行(い)く (to go on an errand)
