動(うご)き出(だ)す

うごきだす
verb-godan
to start moving; to get going
1. to start moving; to begin to move; to get into motion
To begin moving after being still. Used for physical objects, vehicles, and figuratively for projects, plans, or situations that begin to progress.
電車(でんしゃ)がゆっくり動(うご)き出(だ)した。
The train slowly started moving.
計画(けいかく)がやっと動(うご)き出(だ)した。
The plan finally got into motion.
春(はる)になると、冬眠(とうみん)していた動物(どうぶつ)たちが動(うご)き出(だ)す。
When spring comes, the hibernating animals begin to stir.

FORMATION:
Compound verb: 動(うご)く (to move) + 出(だ)す (to begin). The ～出(だ)す pattern indicates the beginning of an action: 歩(ある)き出(だ)す (to start walking), 泣(な)き出(だ)す (to start crying), 降(ふ)り出(だ)す (to start raining).

COMMON COLLOCATIONS:

  • ゆっくり動(うご)き出(だ)す (to start moving slowly)
  • いよいよ動(うご)き出(だ)す (to finally get going)
  • 一斉(いっせい)に動(うご)き出(だ)す (to all start moving at once)

SIMILAR WORDS:

  • 動(うご)き始(はじ)める: to begin to move — synonymous, slightly more formal
  • 始動(しどう)する: to start up — technical, for machines and engines
  • 発進(はっしん)する: to depart, to set off — for vehicles
