1. expansion; addition; installation of more
Adding more of something that already exists — more facilities, equipment, lines, or capacity to an existing system or structure.
メモリーを増設(ぞうせつ)する。
I'll add more memory.
駐車場(ちゅうしゃじょう)を増設(ぞうせつ)する計画(けいかく)がある。
There is a plan to add more parking spaces.
利用者(りようしゃ)の増加(ぞうか)に対応(たいおう)するため、窓口(まどぐち)を二(ふた)つ増設(ぞうせつ)した。
Two more service counters were added to accommodate the increase in users.

Used as both a noun and a suru-verb (増設(ぞうせつ)する). The key nuance is adding more of something that already exists, not building something new from scratch. Common objects include 設備(せつび) (equipment/facilities), メモリー (computer memory), 教室(きょうしつ) (classrooms), and 路線(ろせん) (routes/lines). Contrasts with 新設(しんせつ) (newly establishing something that didn't exist before).
