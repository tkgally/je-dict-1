コース

こーす
noun
course
1. course, route, track
A designated path or route for activities such as running, driving, or golf.
マラソンのコースを走(はし)る。
I run the marathon course.
ゴルフコースに行(い)った。
I went to a golf course.
この散歩(さんぽ)コースは景色(けしき)がきれいで気持(きも)ちいい。
This walking course has beautiful scenery and feels refreshing.
2. course, plan, set menu
A structured program, plan, or set of dishes served in sequence at a restaurant.
コース料理(りょうり)を注文(ちゅうもん)した。
I ordered the set course meal.
飲(の)み放題(ほうだい)コースにする。
I'll go with the all-you-can-drink course.
このレストランでは三千円(さんぜんえん)からコース料理(りょうり)が楽(たの)しめる。
At this restaurant, you can enjoy course meals starting from 3,000 yen.

コース comes from English "course" and is used in several contexts.

SENSE 1 (route/track):

  • マラソンコース: marathon course
  • ゴルフコース: golf course
  • 散歩(さんぽ)コース: walking route
  • ドライブコース: driving route

SENSE 2 (program/set menu):

  • コース料理(りょうり): course meal, set menu
  • 飲(の)み放題(ほうだい)コース: all-you-can-drink plan
  • 初心者(しょしんしゃ)コース: beginner's course (study program)

NOTE:
At Japanese restaurants, コース料理(りょうり) refers to a multi-dish set menu served in sequence, as opposed to ordering individual dishes (一品(いっぴん)料理(りょうり)). It is very common for group dining and parties.
