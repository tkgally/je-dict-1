かな

かな
particle
I wonder
1. I wonder; I'm not sure if
Sentence-ending particle expressing uncertainty, wondering, or thinking aloud. Used when the speaker is uncertain about something or musing to themselves.
明日(あした)、晴(は)れるかな。
I wonder if it'll be sunny tomorrow.
あの店(みせ)、まだ開(あ)いているかな。
I wonder if that shop is still open.
この色(いろ)、似合(にあ)うかな。
I wonder if this color suits me.
来週(らいしゅう)の試験(しけん)、大丈夫(だいじょうぶ)かな。ちょっと心配(しんぱい)だ。
I wonder if next week's exam will be okay. I'm a little worried.

かな is a sentence-ending particle expressing the speaker's uncertainty or wondering.

CONJUGATION:

  • Verb plain form + かな: 行(い)くかな (I wonder if [someone] will go)
  • い-adjective + かな: 高(たか)いかな (I wonder if it's expensive)
  • な-adjective / noun + かな: 静(しず)かかな / 先生(せんせい)かな

VARIATIONS:

  • かな: standard, slightly casual
  • かなあ: drawn-out, more contemplative
  • かしら: similar meaning, traditionally feminine

USAGE NOTE:
かな is primarily used in monologue or self-directed speech. It can also be used in conversation when thinking aloud. It is casual; in formal speech, でしょうか replaces it.

Related Words

Contrast: かしら (I wonder (traditionally feminine))
Related: か (question particle (かな = か + な))
