設(もう)ける

もうける
verb-ichidan
to establish, to set up, to prepare
1. to establish, to set up, to create
To create or put in place a system, facility, rule, or opportunity. Often used for formal or institutional arrangements.
新(あたら)しいルールを設(もう)けた。
A new rule was established.
会社(かいしゃ)は相談(そうだん)窓口(まどぐち)を設(もう)けた。
The company set up a consultation desk.
制限(せいげん)時間(じかん)を設(もう)けないと、会議(かいぎ)が長引(ながび)く。
If you don't set a time limit, the meeting will drag on.
2. to prepare, to arrange
To make preparations, such as setting up a seat for someone or preparing an occasion. More formal than simple preparation words.
来客(らいきゃく)のために席(せき)を設(もう)けた。
I prepared a seat for the guest.
話(はな)し合(あ)いの場(ば)を設(もう)けましょう。
Let's arrange an opportunity to talk.
歓迎会(かんげいかい)の席(せき)を設(もう)けて、新(あたら)しいメンバーを迎(むか)えた。
We arranged a welcome party and received the new members.

USAGE:
設(もう)ける is an ichidan verb. It is used in formal and semi-formal contexts for creating systems, rules, or occasions. It is distinct from the homophone 儲(もう)ける (to earn a profit), which uses a different kanji.

COMMON COLLOCATIONS:

  • 規則(きそく)を設(もう)ける: to establish rules
  • 制限(せいげん)を設(もう)ける: to set limits
  • 機会(きかい)を設(もう)ける: to create an opportunity
  • 場(ば)を設(もう)ける: to arrange a venue/occasion
  • 窓口(まどぐち)を設(もう)ける: to set up a service desk

CAUTION:
Do not confuse with 儲(もう)ける (to profit, to make money). The kanji are different: 設(もう)ける uses 設(せつ) (establish), while 儲(もう)ける uses 儲(もう) (profit).
