番号通知(ばんごうつうち)

ばんごうつうち
noun
caller ID; number notification
1. caller ID; number display; number notification
A telephone feature that displays the caller's phone number on the recipient's screen before the call is answered.
番号通知(ばんごうつうち)がオフになっている。
Caller ID is turned off.
番号通知(ばんごうつうち)なしの電話(でんわ)には出(で)ないことにしている。
I've decided not to answer calls without caller ID.
迷惑(めいわく)電話(でんわ)が多(おお)いので、番号通知(ばんごうつうち)を確認(かくにん)してから出(で)るようにしている。
Since I get a lot of spam calls, I check the caller ID before answering.

Composed of 番号(ばんごう) (number) and 通知(つうち) (notification). In Japan, NTT's caller ID service is called ナンバーディスプレイ, but 番号通知(ばんごうつうち) is the more general, carrier-neutral term used for the concept itself.

Calls made without displaying the number are described as 非通知(ひつうち) (withheld number), and many Japanese people automatically reject 非通知(ひつうち) calls due to the prevalence of phone scams.

COMMON COLLOCATIONS:

  • 番号通知(ばんごうつうち)サービス: caller ID service
  • 番号通知(ばんごうつうち)を設定(せってい)する: to set up caller ID
  • 番号通知(ばんごうつうち)拒否(きょひ): blocking calls without caller ID

SIMILAR WORDS:

  • ナンバーディスプレイ: Number Display — NTT's branded caller ID service
  • 非通知(ひつうち): withheld number; anonymous call
  • 着信(ちゃくしん)履歴(りれき): call history; call log
