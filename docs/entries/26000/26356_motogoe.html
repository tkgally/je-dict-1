元肥(もとごえ)

もとごえ
noun
base fertilizer; basal dressing
1. base fertilizer; basal dressing
Fertilizer mixed into the soil before planting seeds or transplanting seedlings. Provides essential nutrients for the early growth stage of plants.
植(う)え付(つ)け前(まえ)に元肥(もとごえ)を入(い)れる。
Apply base fertilizer before planting.
元肥(もとごえ)をしっかり与(あた)えておくと、苗(なえ)の育(そだ)ちが良(よ)くなる。
If you apply enough base fertilizer, the seedlings will grow better.
家庭菜園(かていさいえん)では、堆肥(たいひ)を元肥(もとごえ)として使(つか)うのが効果的(こうかてき)だ。
In home vegetable gardens, using compost as base fertilizer is effective.

Composed of 元(もと) (base, foundation) and 肥(こえ) (fertilizer). An essential term in gardening and agriculture. The 元肥(もとごえ) is applied once before planting, in contrast to 追肥(ついひ) which is applied during the growing season.

COMMON COLLOCATIONS:

  • 元肥(もとごえ)を入(い)れる: to add base fertilizer
  • 元肥(もとごえ)を施(ほどこ)す: to apply base fertilizer (formal)
  • 元肥(もとごえ)入(い)りの土(つち): soil with base fertilizer already mixed in

SIMILAR WORDS:

  • 追肥(ついひ): top-dressing fertilizer — fertilizer applied after planting during the growth period
  • 堆肥(たいひ): compost — organic matter used as fertilizer
  • 液肥(えきひ): liquid fertilizer — fertilizer in liquid form
