記憶装置(きおくそうち)

きおくそうち
noun
storage device; memory unit
1. storage device; memory unit; data storage
A hardware device used to store digital data. The formal Japanese term for computer storage, covering hard drives, SSDs, USB drives, and other media that retain data.
パソコンの記憶装置(きおくそうち)を交換(こうかん)した。
I replaced the computer's storage device.
外部(がいぶ)記憶装置(きおくそうち)にデータのバックアップを取(と)っておこう。
Let's back up the data to an external storage device.
記憶装置(きおくそうち)の容量(ようりょう)が足(た)りなくなったので、大(おお)きいものに買(か)い替(か)えた。
I ran out of storage space, so I bought a larger one.

Composed of 記憶(きおく) (memory, storage) and 装置(そうち) (device, apparatus). This is the formal/technical Japanese term for computer storage. In everyday conversation, loanwords like ストレージ (storage) or ハードディスク (hard disk) are more common, but 記憶装置(きおくそうち) appears in technical documentation, textbooks, and formal product specifications.

COMMON COLLOCATIONS:

  • 外部(がいぶ)記憶装置(きおくそうち): external storage device
  • 内部(ないぶ)記憶装置(きおくそうち): internal storage
  • 補助(ほじょ)記憶装置(きおくそうち): secondary storage (as opposed to primary memory/RAM)

SIMILAR WORDS:

  • ストレージ: storage — the common loanword used in everyday tech conversation
  • 主記憶装置(しゅきおくそうち): main memory — specifically refers to RAM, the primary working memory
  • メモリ: memory — the loanword for RAM, often contrasted with storage in colloquial usage
