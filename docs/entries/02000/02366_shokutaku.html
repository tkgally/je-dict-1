食卓(しょくたく)

しょくたく
noun
dining table

Definitions

1. dining table, dinner table
A table at which meals are eaten.

Examples

家族(かぞく)全員(ぜんいん)が食卓(しょくたく)を囲(かこ)んだ。
The whole family gathered around the dining table.
食卓(しょくたく)に料理(りょうり)を並(なら)べた。
I set out the dishes on the table.
食卓(しょくたく)での会話(かいわ)は大切(たいせつ)だ。
Conversation at the dinner table is important.

Notes

食卓(しょくたく) specifically refers to a table used for eating meals.

COMMON COLLOCATIONS:

  • 食卓(しょくたく)を囲(かこ)む (to gather around the table)
  • 食卓(しょくたく)に並(なら)べる (to set on the table)
  • 食卓(しょくたく)塩(しお) (table salt)

COMPARISON:

  • 食卓(しょくたく): dining table (formal)
  • テーブル: table (general loanword)
  • ちゃぶ台(だい): low Japanese-style table
