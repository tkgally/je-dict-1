築(きず)く

きずく
verb (godan)
to build, to establish
1. to build, to construct
To create a structure.
城(しろ)を築(きず)く。
To build a castle.
堤防(ていぼう)を築(きず)く。
To build an embankment.
Sense 1: construct
壁(かべ)を築(きず)く。
To build a wall.
Sense 1: build
土台(どだい)を築(きず)く。
To lay a foundation.
Sense 1: construct
砦(とりで)を築(きず)く。
To build a fortress.
Sense 1: build
2. to establish, to build up
To create something abstract like a relationship or career.
信頼(しんらい)関係(かんけい)を築(きず)く。
To build a trusting relationship.
財産(ざいさん)を築(きず)いた。
I built up a fortune.
キャリア}を{築(きず)く。
To build a career.
Sense 2: establish
人脈(じんみゃく)を築(きず)く。
To build a network of contacts.
Sense 2: build up
基盤(きばん)を築(きず)く。
To establish a foundation.
Sense 2: establish

築(きず)く means to build or establish.

COMMON USES:

  • 関係(かんけい)を築(きず)く: to build a relationship
  • 財産(ざいさん)を築(きず)く: to build wealth
  • 地位(ちい)を築(きず)く: to establish a position

DON'T CONFUSE:

  • 築(きず)く: to build
  • 気(き)づく: to notice (different kanji)
