機械(きかい)

きかい
noun
machine, machinery
See also: 機会(きかい) (opportunity (機会)), 器械(きかい) (apparatus (器械))
1. machine, machinery
A device with moving parts that performs work.
機械(きかい)を動(うご)かす。
To operate a machine.
機械(きかい)が壊(こわ)れた。
The machine broke.
この工場(こうじょう)では新(あたら)しい機械(きかい)を使(つか)って製品(せいひん)を作(つく)っている。
This factory uses new machines to make products.

機械(きかい) refers to machines—devices with moving parts that perform work or operations.

HOMOPHONE:

  • 機械(きかい): machine (this word)
  • 機会(きかい): opportunity, chance (different kanji!)

COMMON EXPRESSIONS:

  • 機械(きかい)を動(うご)かす: to operate a machine
  • 機械(きかい)が壊(こわ)れる: machine breaks down
  • 機械(きかい)を修理(しゅうり)する: to repair a machine

RELATED WORDS:

  • 機械的(きかいてき): mechanical (also figuratively: done without thought)
  • 機器(きき): equipment, apparatus
  • 器械(きかい): instrument, apparatus (especially exercise equipment)
