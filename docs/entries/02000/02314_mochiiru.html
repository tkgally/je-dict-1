1. to use, to employ
To make use of something (formal).
新(あたら)しい方法(ほうほう)を用(もち)いる。
To use a new method.
正(ただ)しい言葉(ことば)を用(もち)いる。
To use the correct words.
この技術(ぎじゅつ)は医療(いりょう)に用(もち)いられている。
This technology is used in medicine.
研究(けんきゅう)では新(あたら)しい方法(ほうほう)が用(もち)いられた。
A new method was used in the research.
様々(さまざま)な道具(どうぐ)を用(もち)いて実験(じっけん)を行(おこな)った。
We conducted the experiment using various tools.

用(もち)いる is a formal verb meaning to use or employ, primarily used in written language.

TRANSITIVITY:
Type: 他動詞(たどうし) (transitive)

REGISTER:

  • 用(もち)いる: formal, written style
  • 使(つか)う: neutral, everyday use

COMMON PATTERNS:

  • 方法(ほうほう)を用(もち)いる: to use a method
  • 技術(ぎじゅつ)を用(もち)いる: to employ technology
  • 〜に用(もち)いられる: to be used in ~

COMMON IN:

  • Academic writing
  • Technical documents
  • News articles
  • Business reports
