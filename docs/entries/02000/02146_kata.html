型(かた)

かた
noun
type, model, pattern, mold
1. type, model
A category or style of something.
A型(がた)です。
I'm blood type A.
新(あたら)しい型(かた)のスマホが出(で)た。
A new model of smartphone came out.
この車(くるま)は旧型(きゅうがた)だが、まだよく走(はし)る。
This car is an old model, but it still runs well.
2. mold, form
A container used to give shape to something.
ケーキの型(かた)を買(か)った。
I bought a cake mold.
クッキーの型(かた)で生地(きじ)を抜(ぬ)く。
To cut out dough with a cookie cutter.
鋳型(いがた)に金属(きんぞく)を流(なが)し込(こ)む。
To pour metal into a mold.
3. pattern, kata
A set form or sequence of movements in martial arts.
空手(からて)の型(かた)。
A karate kata.
型(かた)の練習(れんしゅう)をする。
To practice kata.
柔道(じゅうどう)では型(かた)を通(とお)して技(わざ)を身(み)につける。
In judo, you learn techniques through practicing kata.

型(かた) has multiple related meanings: type/model, mold/form, and pattern (martial arts).

COMMON COMPOUNDS:

  • 血液型(けつえきがた): blood type
  • 新型(しんがた): new model
  • 旧型(きゅうがた): old model
  • 型紙(かたがみ): pattern (sewing)
  • 大型(おおがた): large size/type
  • 小型(こがた): small size/type

AS SUFFIX:
〜型(がた) indicates "type" or "model": A型(がた) (Type A).

MARTIAL ARTS:
型(かた) (kata) is a set sequence of movements for training in karate, judo, etc.

IDIOM:
型(かた)にはまる: to be conventional, to follow a set pattern.
