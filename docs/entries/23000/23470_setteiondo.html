設定温度(せっていおんど)

せっていおんど
noun
set temperature; target temperature
1. set temperature; target temperature; thermostat setting
The temperature that a device such as an air conditioner, heater, oven, or refrigerator is set to maintain or reach.
エアコンの設定温度(せっていおんど)を下(さ)げた。
I lowered the air conditioner's set temperature.
冬場(ふゆば)の設定温度(せっていおんど)は二十度(にじゅうど)が目安(めやす)だ。
A guideline set temperature for winter is 20 degrees.
省(しょう)エネのために、夏(なつ)は設定温度(せっていおんど)を二十八度(にじゅうはちど)にするよう呼(よ)びかけている。
To save energy, they are calling for the set temperature to be kept at 28 degrees in summer.

A compound of 設定(せってい) (setting, configuration) and 温度(おんど) (temperature). A practical everyday term used when talking about air conditioners, heaters, ovens, refrigerators, and other temperature-controlled appliances.

COMMON COLLOCATIONS:

  • 設定温度(せっていおんど)を上(あ)げる: to raise the set temperature
  • 設定温度(せっていおんど)を下(さ)げる: to lower the set temperature
  • 設定温度(せっていおんど)に達(たっ)する: to reach the set temperature
  • エアコンの設定温度(せっていおんど): air conditioner's set temperature
  • 推奨(すいしょう)設定温度(せっていおんど): recommended set temperature

CULTURAL NOTE:
In Japan, the government-recommended air conditioning temperature is 二十八度(にじゅうはちど) (28°C) in summer as part of the クールビズ (Cool Biz) energy-saving campaign. In winter, the recommended heating temperature is 二十度(にじゅうど) (20°C) under the ウォームビズ (Warm Biz) initiative. These guidelines are widely followed in offices and public buildings.

SIMILAR WORDS:

  • 室温(しつおん): room temperature — the actual current temperature of a room, not the target setting
  • 適温(てきおん): suitable temperature — the ideal temperature for a particular purpose
