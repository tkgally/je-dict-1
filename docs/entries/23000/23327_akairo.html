赤色(あかいろ)

あかいろ
noun
red; the color red
1. red; the color red
The color red, named explicitly as a color term. More formal and technical than the plain adjective or noun 赤(あか), used when the context calls for a precise reference to the color itself.
赤色(あかいろ)の花(はな)。
A red flower.
信号(しんごう)が赤色(あかいろ)に変(か)わった。
The traffic light turned red.
この地図(ちず)では、危険(きけん)地域(ちいき)が赤色(あかいろ)で示(しめ)されている。
On this map, the dangerous areas are shown in red.
夕日(ゆうひ)に染(そ)まった空(そら)は鮮(あざ)やかな赤色(あかいろ)になった。
The sky, dyed by the setting sun, became a vivid red.

A color name formed by 赤(あか) (red) + 色(いろ) (color). Compared with the plain word 赤(あか), adding 色(いろ) produces a slightly more technical or explicit reference — the kind of word used on color swatches, map legends, product descriptions, and in scientific contexts.

COMMON COLLOCATIONS:

  • 赤色(あかいろ)の花(はな): a red flower
  • 赤色(あかいろ)に染(そ)まる: to be dyed red
  • 鮮(あざ)やかな赤色(あかいろ): a vivid red
  • 暗(くら)い赤色(あかいろ): a dark red
  • 赤色(あかいろ)灯(とう): red light / red warning light

SIMILAR WORDS:

  • 赤(あか): red — the everyday word; used for both the color and things that are red. More common in speech.
  • 紅(くれない): crimson; deep red — a poetic or literary word, often used for dye, lipstick, or autumn leaves.
  • 朱色(しゅいろ): vermilion — a specific shade of red-orange, used for traditional shrine gates and seals.

USAGE:
Use 赤色(あかいろ) when you need to name the color precisely, as in "displayed in red" or "a button in red color." In everyday speech, 赤(あか) alone is more natural: 赤(あか)いリンゴ (a red apple), not 赤色(あかいろ)のリンゴ (though the latter is not wrong).
