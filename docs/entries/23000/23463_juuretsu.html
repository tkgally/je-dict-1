縦列(じゅうれつ)

じゅうれつ
noun
column; vertical row; single file
1. column; vertical row; things arranged in a line from front to back
A line of people, vehicles, or objects arranged one behind the other, extending in depth rather than width. Also used for vertical columns in tables and charts.
縦列(じゅうれつ)に並(なら)ぶ。
To line up in a column.
縦列(じゅうれつ)駐車(ちゅうしゃ)は苦手(にがて)な人(ひと)が多(おお)い。
Many people find parallel parking difficult.
兵士(へいし)たちは縦列(じゅうれつ)を組(く)んで行進(こうしん)した。
The soldiers formed a column and marched.

A compound of 縦(じゅう) (vertical, lengthwise) and 列(れつ) (row, line). Describes things arranged one after another in a line extending forward and back, as opposed to side by side.

COMMON COLLOCATIONS:

  • 縦列(じゅうれつ)駐車(ちゅうしゃ): parallel parking (literally 'column parking' — parking in single file along the curb)
  • 縦列(じゅうれつ)に並(なら)ぶ: to line up in a column
  • 縦列(じゅうれつ)行進(こうしん): marching in column formation
  • 縦列(じゅうれつ)を組(く)む: to form a column

SIMILAR WORDS:

  • 横列(おうれつ): horizontal row — things arranged side by side in a line extending left and right
  • 列(れつ): row, line — a general term that can refer to any kind of line or queue
  • 隊列(たいれつ): formation, file — specifically a military or organized group marching in order

NOTE:
Despite the English term 'parallel parking,' the Japanese 縦列(じゅうれつ)駐車(ちゅうしゃ) literally means 'column parking' — describing how the cars are lined up in single file along the street.
