実数(じっすう)

じっすう
noun
real number (math); actual number / actual count
1. in mathematics, any number that can be represented as a point on the number line, including rational numbers (such as 1/2 or -3) and irrational numbers (such as √2 and π); a real number
The mathematical term for the full set of numbers on the continuous number line, excluding only the imaginary and complex numbers. The real numbers include integers, fractions, and non-terminating decimals such as π and √2. Introduced in Japanese high-school mathematics when the number system is extended beyond rationals. The set is written ℝ, which in Japanese textbooks is usually explained as 'the set of all 実数(じっすう).'
実数(じっすう)の中(なか)には無理数(むりすう)も含(ふく)まれる。
Irrational numbers are also included among the real numbers.
この方程式(ほうていしき)の解(かい)は実数(じっすう)ではない。
The solution to this equation is not a real number.
高校(こうこう)数学(すうがく)では、実数(じっすう)は数直線(すうちょくせん)上(じょう)のすべての点(てん)に対応(たいおう)すると習(なら)う。
In high-school math, we learn that the real numbers correspond to all the points on the number line.
2. the actual number or actual count of people, things, or events, as opposed to an estimated, listed, or nominal figure; the real number, the actual count
In everyday usage, 実数(じっすう) refers to the real, actual count of something — how many people actually showed up, how many copies were actually sold, how many cases actually occurred — as opposed to planned, rounded, publicly announced, or rate-based figures. Often contrasted with percentages, ratios, or official estimates.
参加者(さんかしゃ)の実数(じっすう)は三百人(さんびゃくにん)だった。
The actual number of participants was three hundred.
割合(わりあい)ではなく、実数(じっすう)で示(しめ)してください。
Please show it in actual numbers, not as a percentage.
感染者(かんせんしゃ)の実数(じっすう)は発表(はっぴょう)された数(かず)より多(おお)いと考(かんが)えられている。
The actual number of infected people is thought to be larger than the announced figure.

Composed of 実(じつ) ('real, actual, true') + 数(すう) ('number'). The two meanings — 'real number' (math) and 'actual count' (everyday) — share the same underlying idea of 'real / actual number.'

COMMON COLLOCATIONS (Sense 1 — math):

  • 実数(じっすう)の集合(しゅうごう): the set of real numbers
  • 実数(じっすう)解(かい): real(-valued) solution
  • 実数(じっすう)全体(ぜんたい): all of the real numbers (as a set)
  • 負(ふ)の実数(じっすう): negative real number
  • 実数(じっすう)の範囲(はんい)で: within the real numbers (standard math phrasing)

COMMON COLLOCATIONS (Sense 2 — everyday):

  • 実数(じっすう)を把握(はあく)する: to grasp the actual numbers
  • 実数(じっすう)で示(しめ)す: to show in actual figures
  • 実数(じっすう)と割合(わりあい): actual number and percentage
  • 参加者(さんかしゃ)の実数(じっすう): the actual number of participants
  • 実数(じっすう)ベース: on an actual-numbers basis

MATH NUMBER SYSTEMS:

  • 自然数(しぜんすう): natural numbers (1, 2, 3, ...)
  • 整数(せいすう): integers (..., -1, 0, 1, 2, ...)
  • 有理数(ゆうりすう): rational numbers (fractions)
  • 無理数(むりすう): irrational numbers (√2, π, ...)
  • 実数(じっすう): real numbers (rational + irrational)
  • 虚数(きょすう): imaginary numbers
  • 複素数(ふくそすう): complex numbers (real + imaginary)

SIMILAR WORDS:

  • 実数値(じっすうち): actual numerical value — often used interchangeably with sense 2, especially in statistics.
  • 総数(そうすう): total number — the overall count.
  • 正味(しょうみ): net amount — actual amount after subtracting what does not count.
  • 実勢(じっせい)価格(かかく): the actual market price (as opposed to list price) — uses 実(じつ) in a related 'real / actual' sense.

ANTONYMS / CONTRASTS:

  • (Sense 1) 虚数(きょすう): imaginary number.
  • (Sense 2) 割合(わりあい) / 比率(ひりつ): percentage / ratio — the abstract rate shown instead of an actual count.
  • (Sense 2) 推計(すいけい): estimated figure — the calculated estimate that 実数(じっすう) is being contrasted with.

REGISTER:
Sense 1 is technical and confined to mathematics. Sense 2 is neutral and widely used in journalism, business, statistics, and everyday conversation.
