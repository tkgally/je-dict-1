二段階認証(にだんかいにんしょう)

にだんかいにんしょう
noun
two-factor authentication; 2FA
1. two-factor authentication; two-step verification
a security process requiring two different forms of identification to access an account, typically a password plus a code sent to a phone
二段階認証(にだんかいにんしょう)を設定(せってい)する。
Set up two-factor authentication.
セキュリティのため二段階認証(にだんかいにんしょう)を有効(ゆうこう)にした。
I enabled two-factor authentication for security.
銀行(ぎんこう)のアプリは二段階認証(にだんかいにんしょう)が必須(ひっす)だ。
The bank app requires two-factor authentication.

SECURITY TERM:
二段階認証(にだんかいにんしょう) adds an extra layer of security beyond just a password.

SYNONYMS:

  • 2FA - two-factor authentication (English abbreviation)
  • 二要素認証(にようそにんしょう) - two-factor authentication (more technical)
  • 多要素認証(たようそにんしょう) - multi-factor authentication

TYPES OF SECOND FACTOR:

  • SMS認証(にんしょう) - SMS verification code
  • 認証(にんしょう)アプリ - authenticator app
  • 生体認証(せいたいにんしょう) - biometric authentication
  • ハードウェアキー - hardware key

COMMON COLLOCATIONS:

  • 二段階認証(にだんかいにんしょう)を設定(せってい)する - set up 2FA
  • 二段階認証(にだんかいにんしょう)を有効(ゆうこう)にする - enable 2FA
  • 二段階認証(にだんかいにんしょう)を解除(かいじょ)する - disable 2FA
