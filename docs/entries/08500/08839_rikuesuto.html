リクエスト

りくえすと
noun, verb (suru)
request
1. request; special order
a polite ask or demand for something, often for songs, services, or items
ラジオに曲(きょく)をリクエストした。
I requested a song on the radio.
お客様(きゃくさま)のリクエストに応(こた)える。
To respond to a customer's request.
リクエストがあれば何(なん)でも言(い)ってください。
Please tell me if you have any requests.

COMMON USAGES:

  • 曲(きょく)のリクエスト - song request
  • リクエストに応(こた)える - to fulfill a request
  • リクエスト曲(きょく) - requested song

CONTEXTS:

  • ラジオ/DJ - radio/DJ requests
  • カラオケ - karaoke song requests
  • レストラン - restaurant special orders
  • ホテル - hotel service requests

RELATED EXPRESSIONS:

  • ご要望(ようぼう) - request/wish (more formal)
  • お願(ねが)い - request/favor
  • 注文(ちゅうもん) - order (for products/food)

SOCIAL MEDIA:

  • フォローリクエスト - follow request
  • フレンドリクエスト - friend request
