USB

ゆーえすびー
noun
USB, Universal Serial Bus
1. USB, Universal Serial Bus
A standard for connecting devices to computers and other electronics for data transfer and power supply.
USBで充電(じゅうでん)する。
Charge via USB.
USBメモリにデータ(でーた)を保存(ほぞん)した。
I saved the data on a USB drive.
このパソコンにはUSBポートが三(みっ)つ付(つ)いている。
This computer has three USB ports.

USB (Universal Serial Bus) is extremely common in daily life in Japan for charging devices, transferring data, and connecting peripherals.

COMMON EXPRESSIONS:

  • USBメモリ / USBメモリー(めもりー): USB flash drive
  • USBケーブル(けーぶる): USB cable
  • USBポート: USB port
  • USB充電(じゅうでん)器(き): USB charger
  • USB-C / USBタイプ(たいぷ)C: USB Type-C connector

USB is written in the English alphabet in Japanese text.
