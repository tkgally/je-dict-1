抽象(ちゅうしょう)

ちゅうしょう
noun
abstraction; abstract
1. abstraction; abstract
the quality of dealing with ideas rather than concrete things
この説明(せつめい)は抽象(ちゅうしょう)的(てき)すぎる。
This explanation is too abstract.
抽象(ちゅうしょう)的(てき)な概念(がいねん)を具体(ぐたい)例(れい)で説明(せつめい)する。
I explain abstract concepts with concrete examples.
ピカソの抽象(ちゅうしょう)画(が)は世界(せかい)中(じゅう)で有名(ゆうめい)だ。
Picasso's abstract paintings are famous worldwide.

COMMON FORMS:

  • 抽象(ちゅうしょう)的(てき) (な) - abstract (na-adjective)
  • 抽象(ちゅうしょう)化(か) - abstraction (process)
  • 抽象(ちゅうしょう)画(が) - abstract painting
  • 抽象(ちゅうしょう)概念(がいねん) - abstract concept

OPPOSITE:
具体(ぐたい)(的(てき)) - concrete, specific

PROGRAMMING:
抽象(ちゅうしょう)化(か) is commonly used in software development to describe abstraction of code.
