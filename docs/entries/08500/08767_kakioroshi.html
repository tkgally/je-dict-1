書(か)き下(お)ろし

かきおろし
noun
newly written work; original composition
1. newly written work; original composition
a literary work, song, screenplay, etc. that is written specifically for a particular purpose or publication, rather than being a reprint or adaptation
この小説(しょうせつ)は書(か)き下(お)ろしだ。
This novel is newly written (for this publication).
映画(えいが)のための書(か)き下(お)ろし楽曲(がっきょく)を発表(はっぴょう)した。
They released a song written specifically for the movie.
人気(にんき)作家(さっか)の書(か)き下(お)ろしエッセイが収録(しゅうろく)されている。
The book contains a newly written essay by a popular author.

PUBLISHING/CREATIVE TERM:
書(か)き下(お)ろし emphasizes that a work was created fresh, specifically for the occasion, rather than being recycled or adapted from existing material.

COMMON COLLOCATIONS:

  • 書(か)き下(お)ろし小説(しょうせつ) - newly written novel
  • 書(か)き下(お)ろし楽曲(がっきょく) - newly composed song
  • 書(か)き下(お)ろしエッセイ - newly written essay
  • 書(か)き下(お)ろし脚本(きゃくほん) - original screenplay

CONTRAST:

  • 書(か)き下(お)ろし - written new for this occasion
  • 再録(さいろく) - reprint
  • 改稿(かいこう) - revised version

NOTE:
In music, a 書(か)き下(お)ろし song means one composed specifically for that project (film, anime, drama), not a pre-existing track.
