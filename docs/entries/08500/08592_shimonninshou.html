指紋認証(しもんにんしょう)

しもんにんしょう
noun
fingerprint authentication
1. fingerprint authentication; fingerprint-based verification
a biometric technology that identifies or verifies a person using their fingerprint patterns
指紋認証(しもんにんしょう)でログインする。
Log in using fingerprint authentication.
指紋認証(しもんにんしょう)は顔認証(かおにんしょう)より速(はや)い。
Fingerprint authentication is faster than facial recognition.
指紋認証(しもんにんしょう)センサーに指(ゆび)を当(あ)てる。
Place your finger on the fingerprint sensor.

TECHNOLOGY TERM:
指紋認証(しもんにんしょう) combines 指紋(しもん) (fingerprint) + 認証(にんしょう) (authentication). One of the oldest and most widely used biometric authentication methods.

COMMON APPLICATIONS:

  • スマートフォン - smartphones
  • ノートパソコン - laptops
  • 出退勤(しゅったいきん)システム - time clock systems
  • 銀行(ぎんこう)ATM - bank ATMs

COMMON COLLOCATIONS:

  • 指紋認証(しもんにんしょう)を設定(せってい)する - set up fingerprint authentication
  • 指紋認証(しもんにんしょう)センサー - fingerprint sensor
  • 指紋認証(しもんにんしょう)でロック解除(かいじょ) - unlock with fingerprint

ADVANTAGES:

  • 高速(こうそく) - fast
  • 簡単(かんたん) - easy to use
  • 精度(せいど)が高(たか)い - high accuracy

RELATED TERMS:

  • 顔認証(かおにんしょう) - facial recognition
  • 生体認証(せいたいにんしょう) - biometric authentication
  • 二段階認証(にだんかいにんしょう) - two-factor authentication
