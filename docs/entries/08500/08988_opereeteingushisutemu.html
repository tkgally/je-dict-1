オペレーティングシステム

おぺれーてぃんぐしすてむ
noun
operating system; OS
1. operating system; OS
The fundamental software that manages computer hardware and provides services for other programs. Examples include Windows, macOS, Linux, iOS, and Android.
オペレーティングシステムを更新(こうしん)した。
I updated the operating system.
このソフトはどのオペレーティングシステムに対応(たいおう)していますか？
Which operating systems does this software support?
オペレーティングシステムが古(ふる)いとセキュリティ上(じょう)危険(きけん)だ。
An outdated operating system is a security risk.

オペレーティングシステム is the full form of OS (オーエス).

COMMON ABBREVIATION:

  • OS (オーエス): Much more commonly used in everyday speech

MAJOR OPERATING SYSTEMS:

  • Windows: デスクトップ向(む)け
  • macOS: Apple Mac用(よう)
  • Linux: オープンソース
  • iOS: iPhone/iPad用(よう)
  • Android: Google系(けい)スマホ用(よう)

RELATED TERMS:

  • OS更新(こうしん): OS update
  • OS再(さい)インストール: OS reinstallation
  • 基本(きほん)ソフト: basic software (synonym)

NOTE:
In conversation, the abbreviation OS is almost always used. The full form オペレーティングシステム appears more in formal writing or technical documentation.
