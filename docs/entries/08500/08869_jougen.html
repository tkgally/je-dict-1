上弦(じょうげん)

じょうげん
noun
first quarter moon
1. first quarter moon
The moon phase when the right half is illuminated, occurring about a week after the new moon.
今夜(こんや)は上弦(じょうげん)の月(つき)だ。
Tonight is a first quarter moon.
上弦(じょうげん)の月(つき)は右半分(みぎはんぶん)が光(ひか)っている。
A first quarter moon has the right half illuminated.
上弦(じょうげん)から満月(まんげつ)まで約(やく)一週間(いっしゅうかん)かかる。
It takes about one week from first quarter to full moon.

上弦(じょうげん) refers to the first quarter moon phase. The name comes from the shape resembling a bow (弓(ゆみ)) with the string on top (上(うえ)).

MOON PHASES IN JAPANESE:

  • 新月(しんげつ): new moon
  • 上弦(じょうげん)の月(つき): first quarter moon
  • 満月(まんげつ): full moon
  • 下弦(かげん)の月(つき): last quarter moon (left half illuminated)

MEMORY AID:

  • 上弦(じょうげん): String on top → right side lit (first quarter)
  • 下弦(かげん): String on bottom → left side lit (last quarter)

Note: These terms are used in astronomy, traditional calendars, and sometimes weather forecasts.
