クラウドサービス

くらうどさーびす
noun
cloud service; cloud computing service
1. cloud service; cloud computing
internet-based services that provide data storage, software, or computing resources accessible from anywhere
クラウドサービスを利用(りよう)する。
Use a cloud service.
写真(しゃしん)をクラウドサービスに保存(ほぞん)する。
Save photos to a cloud service.
会社(かいしゃ)がクラウドサービスを導入(どうにゅう)してデータ共有(きょうゆう)が楽(らく)になった。
After the company introduced cloud services, data sharing became easier.

TECHNOLOGY TERM:
クラウドサービス refers to services accessed via the internet rather than stored locally.

TYPES:

  • クラウドストレージ - cloud storage (Google Drive, iCloud, Dropbox)
  • SaaS (Software as a Service) - software delivered via cloud
  • 動画(どうが)ストリーミング - video streaming services

COMMON SERVICES:

  • Google Drive
  • iCloud
  • Dropbox
  • OneDrive
  • Amazon Web Services (AWS)

COMMON COLLOCATIONS:

  • クラウドサービスに保存(ほぞん)する - save to cloud
  • クラウドサービスを契約(けいやく)する - subscribe to cloud service
  • クラウドサービスの容量(ようりょう) - cloud storage capacity

RELATED TERMS:

  • クラウド - cloud
  • オンラインストレージ - online storage
  • 同期(どうき) - sync
