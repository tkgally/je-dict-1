PDF

ぴーでぃーえふ
noun
PDF, portable document format
1. PDF, portable document format
A file format for documents that preserves formatting across different devices and systems.
PDFで送(おく)ってください。
Please send it as a PDF.
PDF形式(けいしき)で保存(ほぞん)した。
I saved it in PDF format.
資料(しりょう)をPDFに変換(へんかん)してメールで送(おく)りました。
I converted the document to PDF and sent it by email.

PDF stands for Portable Document Format. It is a widely used file format created by Adobe.

COMMON COLLOCATIONS:

  • PDFファイル: PDF file
  • PDF形式(けいしき): PDF format
  • PDF変換(へんかん): PDF conversion
  • PDFを開(ひら)く: to open a PDF
  • PDFを作成(さくせい)する: to create a PDF
  • PDFリーダー: PDF reader

USAGE NOTES:

  • PDF is the standard format for official documents in Japan
  • Most government and business forms are distributed as PDFs
  • 履歴書(りれきしょ) (résumé) submissions often require PDF format
