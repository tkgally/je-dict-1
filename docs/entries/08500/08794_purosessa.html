プロセッサ

ぷろせっさ
noun
processor
1. processor; CPU
the main computing chip in a computer, phone, or other electronic device that performs calculations and executes instructions
このパソコンは高性能(こうせいのう)なプロセッサを搭載(とうさい)している。
This computer is equipped with a high-performance processor.
プロセッサの速度(そくど)が上(あ)がった。
The processor speed increased.
最新(さいしん)のスマホには強力(きょうりょく)なプロセッサが入(はい)っている。
The latest smartphones have powerful processors.

COMPUTING TERM:
プロセッサ (processor) is often used interchangeably with CPU (シーピーユー, Central Processing Unit).

TYPES:

  • CPU - 中央(ちゅうおう)演算(えんざん)処理(しょり)装置(そうち)
  • GPU (グラフィックプロセッサ) - graphics processor
  • マイクロプロセッサ - microprocessor

COMMON COLLOCATIONS:

  • プロセッサ速度(そくど) - processor speed
  • デュアルコアプロセッサ - dual-core processor
  • プロセッサを搭載(とうさい)する - to be equipped with a processor
  • プロセッサの性能(せいのう) - processor performance

RELATED TERMS:

  • メモリ - memory
  • チップ - chip
  • 演算(えんざん)処理(しょり) - computational processing
