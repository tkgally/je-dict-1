音声入力(おんせいにゅうりょく)

おんせいにゅうりょく
noun
voice input; speech-to-text
1. voice input; entering data by speaking
a technology that converts spoken words into text or commands
音声入力(おんせいにゅうりょく)で文章(ぶんしょう)を書(か)く。
Write text using voice input.
音声入力(おんせいにゅうりょく)機能(きのう)が便利(べんり)だ。
The voice input feature is convenient.
スマホの音声入力(おんせいにゅうりょく)で検索(けんさく)する。
Search using voice input on my smartphone.

TECHNOLOGY TERM:
音声入力(おんせいにゅうりょく) combines 音声(おんせい) (voice/speech) + 入力(にゅうりょく) (input). It's used for various speech-to-text and voice control features.

COMMON APPLICATIONS:

  • スマートフォン - smartphones
  • スマートスピーカー - smart speakers
  • 音声(おんせい)アシスタント - voice assistants
  • 文字(もじ)起(お)こし - transcription

COMMON COLLOCATIONS:

  • 音声入力(おんせいにゅうりょく)を使(つか)う - to use voice input
  • 音声入力(おんせいにゅうりょく)機能(きのう) - voice input function
  • 音声入力(おんせいにゅうりょく)に対応(たいおう) - supports voice input

RELATED TERMS:

  • 音声認識(おんせいにんしき) - speech recognition
  • 音声(おんせい)コマンド - voice command
  • 顔認証(かおにんしょう) - facial recognition
  • 指紋認証(しもんにんしょう) - fingerprint authentication
