窓(まど)拭(ふ)き

まどふき
noun
window cleaning; washing windows
1. window cleaning; washing windows
the act of cleaning or wiping windows
窓拭(まどふ)きは大掃除(おおそうじ)の定番(ていばん)だ。
Window cleaning is a staple of major house cleaning.
今日(きょう)は窓拭(まどふ)きをする予定(よてい)だ。
I'm planning to clean the windows today.
新聞紙(しんぶんし)を使(つか)うと窓拭(まどふ)きが簡単(かんたん)になる。
Using newspaper makes window cleaning easier.

COMPOUND:
窓(まど) (window) + 拭(ふ)き (wiping)

TOOLS:

  • 雑巾(ぞうきん) - cloth/rag
  • 新聞紙(しんぶんし) - newspaper (traditional Japanese method)
  • スクイージー - squeegee
  • ガラスクリーナー - glass cleaner

SEASONAL CLEANING:
窓拭(まどふ)き is typically done during 大掃除(おおそうじ) (major cleaning) at year-end or spring cleaning.

SIMILAR ～拭(ふ)き COMPOUNDS:

  • 床拭(ゆかふ)き - floor wiping
  • から拭(ぶ)き - dry wiping
