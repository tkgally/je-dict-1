SOS

えすおーえす
noun
SOS, distress signal
1. SOS, distress signal
An internationally recognized distress signal, used to request help in emergencies.
SOSを発信(はっしん)する。
I send an SOS signal.
船(ふね)がSOSを出(だ)した。
The ship sent out an SOS.
遭難(そうなん)者(しゃ)がSOSの信号(しんごう)を送(おく)った。
The person in distress sent an SOS signal.
2. cry for help, urgent appeal
A figurative request for help or assistance in a difficult situation.
助(たす)けを求(もと)めてSOSを出(だ)す。
I send out an SOS asking for help.
人手(ひとで)不足(ぶそく)でSOSの状態(じょうたい)だ。
We're in SOS mode due to staff shortage.
締(し)め切(き)り前(まえ)に同僚(どうりょう)にSOSを出(だ)した。
I sent an SOS to my colleague before the deadline.

SOS is the international Morse code distress signal (· · · — — — · · ·).

COMMON COLLOCATIONS:

  • SOSを出(だ)す: to send an SOS
  • SOSを発信(はっしん)する: to transmit an SOS
  • SOS信号(しんごう): SOS signal
  • 緊急(きんきゅう)SOS: emergency SOS

FIGURATIVE USAGE:

  • Often used to describe desperate situations
  • SOSの状態(じょうたい): in crisis mode
  • SOSを求(もと)める: to ask for urgent help
