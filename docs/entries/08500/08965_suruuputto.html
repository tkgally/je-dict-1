スループット

するーぷっと
noun
throughput
1. throughput; processing capacity; data transfer rate
A technical term for the amount of data, work, or material that passes through a system in a given time period. Commonly used in IT, networking, and manufacturing contexts.
ネットワークのスループットを測定(そくてい)する。
Measure the network throughput.
このサーバーは高(たか)いスループットを誇(ほこ)る。
This server boasts high throughput.
工場(こうじょう)のスループットを改善(かいぜん)するために新(あたら)しい設備(せつび)を導入(どうにゅう)した。
We introduced new equipment to improve the factory's throughput.

スループット is an IT/engineering loanword from English "throughput."

USAGE CONTEXTS:

  • Networking: data transfer speed (bps, Mbps)
  • Computing: processing capacity per time unit
  • Manufacturing: production volume per time period

RELATED TERMS:

  • 帯域(たいいき): bandwidth
  • 処理(しょり)速度(そくど): processing speed
  • レイテンシ: latency (delay)
  • ボトルネック: bottleneck

NOTE:
スループット measures actual performance, while 帯域(たいいき) (bandwidth) refers to theoretical maximum capacity.
