その前(まえ)

そのまえ
adverb / noun
before that; previously
1. before that; previously; prior to that
refers to the time period before a previously mentioned event or point in time
東京(とうきょう)に引(ひ)っ越(こ)す前(まえ)、その前(まえ)は大阪(おおさか)に住(す)んでいた。
Before moving to Tokyo, before that I lived in Osaka.
会議(かいぎ)が始(はじ)まる。その前(まえ)に資料(しりょう)を確認(かくにん)しよう。
The meeting will start. Let's check the documents before that.
その前(まえ)の週(しゅう)は忙(いそが)しかった。
The week before that was busy.

COMPOUND:
その (that) + 前(まえ) (before)

USAGE:

  • Can refer to time: before that event
  • Can refer to position: in front of that
  • その前(まえ)に is a common pattern meaning "before doing that"

PATTERN:

その + noun pattern:

  • そのため - therefore
  • その後(ご) - after that
  • その間(あいだ) - meanwhile
  • その時(とき) - at that time

CONTRAST:

  • その前(まえ) ↔ その後(ご)/後(あと) (before ↔ after)
