URL

ゆーあーるえる
noun
URL, web address
1. URL, web address
Uniform Resource Locator, the address used to access a webpage or resource on the internet.
URLを入力(にゅうりょく)する。
I enter the URL.
URLをクリックしてください。
Please click the URL.
このURLを友達(ともだち)にシェアした。
I shared this URL with my friend.

URL stands for Uniform Resource Locator. It identifies the address of a resource on the internet.

COMMON COLLOCATIONS:

  • URLを入力(にゅうりょく)する: to enter a URL
  • URLをコピーする: to copy a URL
  • URLを貼(は)り付(つ)ける: to paste a URL
  • URLを共有(きょうゆう)する: to share a URL
  • 短縮(たんしゅく)URL: shortened URL

JAPANESE TERMINOLOGY:

  • ウェブアドレス: web address
  • リンク: link
  • ホームページ: homepage (often used for any website in Japanese)

Also written as ユーアールエル in full katakana.
