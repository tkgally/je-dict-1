フラッシュ

ふらっしゅ
noun
flash
1. flash (photography); camera flash
the brief burst of bright light used in photography to illuminate subjects
フラッシュをたいて写真(しゃしん)を撮(と)った。
I took a photo using flash.
フラッシュ撮影(さつえい)禁止(きんし)です。
Flash photography is prohibited.
暗(くら)いところではフラッシュが必要(ひつよう)だ。
Flash is necessary in dark places.
2. flash (memory); flash storage
a type of non-volatile computer memory used in USB drives, memory cards, and solid-state drives
フラッシュメモリに保存(ほぞん)する。
Save to flash memory.
フラッシュドライブにデータをコピーした。
I copied the data to a flash drive.
SSDはフラッシュストレージの一種(いっしゅ)だ。
SSD is a type of flash storage.
3. flash; sudden burst
a sudden, brief appearance or occurrence

PHOTOGRAPHY:

  • フラッシュをたく - to use flash
  • フラッシュ撮影(さつえい) - flash photography
  • 内蔵(ないぞう)フラッシュ - built-in flash
  • 外付(そとづ)けフラッシュ - external flash

COMPUTING:

  • フラッシュメモリ - flash memory
  • フラッシュドライブ / USBメモリ - flash drive
  • フラッシュストレージ - flash storage
  • SSD (Solid State Drive) - uses flash memory

OTHER USES:

  • ニュースフラッシュ - news flash
  • フラッシュバック - flashback (memory)
