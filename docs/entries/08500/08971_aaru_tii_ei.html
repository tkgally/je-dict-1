RTA

あーるてぃーえー
noun
real-time attack; speedrun
1. real-time attack; speedrun (gaming)
A gaming term for completing a game or section as fast as possible using real time, including all loading times and pauses. Popular in the Japanese gaming community.
このゲームのRTAに挑戦(ちょうせん)している。
I'm attempting a speedrun of this game.
世界(せかい)記録(きろく)のRTA動画(どうが)を見(み)た。
I watched a video of the world record speedrun.
RTAは練習(れんしゅう)と運(うん)の両方(りょうほう)が必要(ひつよう)だ。
Speedrunning requires both practice and luck.

RTA (Real-Time Attack) is a speedrunning category that measures total time in real time.

RTA CATEGORIES:

  • Any%: 最速(さいそく)クリア (fastest completion, any method)
  • 100%: 完全(かんぜん)クリア (all items/objectives)
  • Glitchless: バグなし (no exploits)

RELATED TERMS:

  • TAS (Tool-Assisted Speedrun): 機械(きかい)による自動(じどう)プレイ
  • 走者(そうしゃ): speedrunner
  • 通(とお)しプレイ: full run (from start to end)
  • タイムアタック: time attack

RTA differs from TAS (tool-assisted speedrun) in that RTA is performed by human players in real time without frame-by-frame manipulation.
