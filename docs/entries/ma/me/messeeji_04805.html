メッセージ

めっせーじ
noun
message

Definitions

1. message
Written or spoken communication sent from one person to another.

Examples

メッセージを送(おく)った。
I sent a message.
メッセージを読(よ)んでください。
Please read the message.
彼女(かのじょ)からメッセージが届(とど)いた。
A message arrived from her.

Notes

メッセージ is commonly used for digital messages and also for meaningful communications.

COMMON EXPRESSIONS:

  • メッセージを送(おく)る: to send a message
  • メッセージを残(のこ)す: to leave a message
  • メッセージを込(こ)める: to put a message/meaning into something
  • ダイレクトメッセージ (DM): direct message
  • メッセージカード: message card
  • メッセージアプリ: messaging app

RELATED WORDS:

  • 伝言(でんごん): message (traditional)
  • 連絡(れんらく): contact, communication
  • ショートメール: text message (SMS)
