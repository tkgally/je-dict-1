実例(じつれい)

じつれい
noun
example, actual case
1. example, actual case, real instance
A real occurrence or case that illustrates a point or serves as evidence.
実例(じつれい)を挙(あ)げて説明(せつめい)してください。
Please explain with an actual example.
これは成功(せいこう)した実例(じつれい)の一(ひと)つです。
This is one example of a successful case.
具体的(ぐたいてき)な実例(じつれい)がないと理解(りかい)しにくい。
It's hard to understand without concrete examples.

COMMON PATTERNS:

  • 実例(じつれい)を挙(あ)げる (to give an example)
  • 実例(じつれい)を示(しめ)す (to show an example)
  • 具体的(ぐたいてき)な実例(じつれい) (concrete example)

SIMILAR WORDS:

  • 例(れい) - example (general term)
  • 事例(じれい) - case, instance (often professional/legal)
  • 実例(じつれい) - actual example (emphasizes it really happened)
  • 例(たと)え - analogy, metaphor

実例(じつれい) emphasizes that the example is a real occurrence, not hypothetical.
