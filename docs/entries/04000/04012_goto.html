〜毎(ごと)

ごと
suffix
every; each
1. every; each
Attached to nouns to indicate 'every X' or 'for each X'. Indicates repetition or distribution.
日(ひ){ごと}に寒(さむ)くなる。
It gets colder day by day.
3時間(じかん){ごと}に薬(くすり)を飲(の)む。
Take medicine every 3 hours.
人(ひと)それぞれ、国(くに){ごと}に習慣(しゅうかん)が違(ちが)う。
Customs differ from country to country.

WRITING: Can be written as 毎(ごと) or ごと in hiragana.

PATTERN: Noun + {ごと}

COMMON EXPRESSIONS:

  • 日(ひ){ごと}に (day by day)
  • 年(ねん)/{ごと}に (every year)
  • 家(いえ){ごと}に (for each house)
  • 人(ひと){ごと}に (for each person)
  • 〜時間(じかん){ごと}に (every ~ hours)

NOTE: Not to be confused with the expression 〜ごとく (like, as if), which has a different origin.

SIMILAR: 毎(まい)〜 (every ~) is a prefix, while 〜{ごと} is a suffix.
