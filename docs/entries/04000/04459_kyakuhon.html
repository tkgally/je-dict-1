脚本(きゃくほん)

きゃくほん
noun
script
1. script, screenplay
A written text containing dialogue, stage directions, and other instructions for a play, film, or TV show.
脚本(きゃくほん)を書(か)く。
I write scripts.
この映画(えいが)の脚本(きゃくほん)は素晴(すば)らしい。
The screenplay for this movie is excellent.
脚本(きゃくほん)家(か)を目指(めざ)している。
I'm aiming to become a screenwriter.

COMPOUND: 脚(きゃく) (leg, base) + 本(ほん) (book, script)

COMMON COLLOCATIONS:

  • 脚本(きゃくほん)を書(か)く (to write a script)
  • 脚本(きゃくほん)家(か) (screenwriter, playwright)
  • 脚本(きゃくほん)賞(しょう) (screenplay award)
  • オリジナル脚本(きゃくほん) (original screenplay)

RELATED TERMS:

  • 台本(だいほん) (script - for TV/radio, more casual)
  • シナリオ (scenario, screenplay)
  • 演出(えんしゅつ) (direction, production)
  • 監督(かんとく) (director)

CONTEXTS:

  • 映画(えいが) (film)
  • ドラマ (TV drama)
  • 舞台(ぶたい) (stage play)
  • アニメ (anime)
