1. notice, notification, announcement
An official or formal communication informing someone about something. Can be verbal or written.
合格(ごうかく)通知(つうち)が届(とど)いた。
The acceptance notice arrived.
変更(へんこう)があれば通知(つうち)します。
We will notify you if there are any changes.
{スマホ}の通知(つうち)を切(き)った。
I turned off my smartphone notifications.
Modern usage for app notifications

COMMON COLLOCATIONS:

  • 通知(つうち)する (to notify)
  • 通知(つうち)を受(う)ける (to receive a notice)
  • 通知(つうち)書(しょ) (written notification)
  • 合格(ごうかく)通知(つうち) (acceptance notice)
  • 不合格(ふごうかく)通知(つうち) (rejection notice)
  • 事前(じぜん)通知(つうち) (advance notice)

MODERN USAGE:

  • {プッシュ}通知(つうち) (push notification)
  • 通知(つうち)音(おん) (notification sound)
  • 通知(つうち)をオフにする (to turn off notifications)

FORMAL DOCUMENTS:

  • 通知(つうち)状(じょう) / 通知(つうち)書(しょ) (notification letter)
