索引(さくいん)

さくいん
noun
index, indices
1. index, indices
An alphabetical list of topics, names, etc. at the end of a book, with references to the pages where they appear.
本(ほん)の巻末(かんまつ)に索引(さくいん)がある。
There is an index at the end of the book.
索引(さくいん)を使(つか)って調(しら)べた。
I looked it up using the index.
五十音(ごじゅうおん)順(じゅん)の索引(さくいん)になっている。
It is an index in Japanese alphabetical order.
この辞書(じしょ)には用語(ようご)索引(さくいん)と人名(じんめい)索引(さくいん)がついている。
This dictionary has both a glossary index and a name index.
論文(ろんぶん)を書(か)き終(お)わったら、最後(さいご)に索引(さくいん)を作(つく)って読者(どくしゃ)が情報(じょうほう)を探(さが)しやすくする。
After finishing the paper, I create an index at the end so readers can easily find information.

索引(さくいん) refers to an index - an alphabetical or organized list that helps locate information in a book or database.

COMMON COLLOCATIONS:

  • 索引(さくいん)を引(ひ)く: to look up in an index
  • 索引(さくいん)を作(つく)る: to create an index
  • 索引(さくいん)付(つ)き: indexed (with an index)
  • 巻末(かんまつ)索引(さくいん): back-of-book index
  • 五十音(ごじゅうおん)順(じゅん)の索引(さくいん): index in Japanese alphabetical order

TYPES:

  • 用語(ようご)索引(さくいん): glossary index
  • 人名(じんめい)索引(さくいん): name index
  • データベース索引(さくいん): database index

RELATED TERMS:

  • 目次(もくじ): table of contents (sequential)
  • 検索(けんさく): search
  • インデックス: index (loanword, also used)
