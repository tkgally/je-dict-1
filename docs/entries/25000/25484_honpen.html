本編(ほんぺん)

ほんぺん
noun
main part; main story; this volume
1. main part; main story; main feature
The primary or main portion of a work, as opposed to supplementary material such as spin-offs, sequels, bonus content, or behind-the-scenes footage.
本編(ほんぺん)は来月(らいげつ)公開(こうかい)される。
The main feature will be released next month.
この映画(えいが)の本編(ほんぺん)は二時間(にじかん)ある。
The main feature of this movie is two hours long.
スピンオフが人気(にんき)だが、やはり本編(ほんぺん)のストーリーが一番(いちばん)面白(おもしろ)い。
The spin-off is popular, but the main story is still the most interesting.
2. this volume; the present work
A reference to the current book, document, or work being discussed.
詳(くわ)しくは本編(ほんぺん)第三章(だいさんしょう)を参照(さんしょう)してください。
Please refer to Chapter 3 of this volume for details.
本編(ほんぺん)の内容(ないよう)は前作(ぜんさく)の知識(ちしき)がなくても楽(たの)しめる。
You can enjoy this volume even without knowledge of the previous work.
本編(ほんぺん)では基礎的(きそてき)な理論(りろん)を解説(かいせつ)し、応用例(おうようれい)は別冊(べっさつ)に譲(ゆず)る。
This volume covers basic theory, and application examples are left to a separate volume.

A compound of 本(ほん) (main; this) and 編(ぺん) (compilation; volume). Very commonly used in entertainment media — anime, manga, movies, video games — to distinguish the main story from side stories, OVAs, bonus episodes, or behind-the-scenes content.

COMMON COLLOCATIONS:

  • 本編(ほんぺん)に戻(もど)る: to return to the main story
  • 本編(ほんぺん)の内容(ないよう): the content of the main part
  • 本編(ほんぺん)映像(えいぞう): main feature footage
  • 本編(ほんぺん)とは別(べつ)に: separately from the main story

SIMILAR WORDS:

  • 番外編(ばんがいへん): side story; extra episode — content outside the main narrative
  • 外伝(がいでん): side story; spin-off — a separate story featuring secondary characters or events
  • 続編(ぞくへん): sequel; continuation — the next installment following the main story
  • 前編(ぜんぺん): first part — the first half of a work divided into parts
