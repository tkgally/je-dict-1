型式(けいしき)

けいしき
noun
model; type; model number
1. model; type; model number; type designation
The specific model or type designation of a manufactured product, vehicle, or piece of equipment. Used in technical, industrial, and automotive contexts to identify a particular design or version.
この車(くるま)の型式(けいしき)を教(おし)えてください。
Please tell me the model designation of this car.
型式(けいしき)が違(ちが)うと部品(ぶひん)が合(あ)わない場合(ばあい)がある。
If the model type is different, the parts may not fit.
車検証(しゃけんしょう)に記載(きさい)されている型式(けいしき)を確認(かくにん)してから、適合(てきごう)する部品(ぶひん)を注文(ちゅうもん)してください。
Please check the model number listed on the vehicle inspection certificate before ordering compatible parts.

Written with the characters 型(かた) (mold, type) and 式(しき) (style, formula), but read as けいしき. This is a homophone of 形式(けいしき) (format, formality), but the two have different meanings: 型式(けいしき) refers to a product model designation, while 形式(けいしき) refers to format, form, or formality.

Particularly common in the automotive industry, where the 型式(けいしき) code uniquely identifies a vehicle's specifications.

COMMON COLLOCATIONS:

  • 型式(けいしき)番号(ばんごう): model number
  • 型式(けいしき)認定(にんてい): type approval, type certification
  • 型式(けいしき)を確認(かくにん)する: to check the model type
  • 型式(けいしき)指定(してい): type designation

SIMILAR WORDS:

  • 形式(けいしき): format, form, formality — same pronunciation, different meaning and characters
  • 機種(きしゅ): model (of a device) — used for electronic devices and aircraft
  • 品番(ひんばん): product number — a broader product identification code
