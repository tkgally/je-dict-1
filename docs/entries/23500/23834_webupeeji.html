ウェブページ

うぇぶぺーじ
noun
web page
1. web page; a single document on the World Wide Web
A document accessible through a web browser, typically written in HTML, and identified by a URL. In everyday Japanese, ウェブページ refers to an individual page, while ウェブサイト or ホームページ refers to a collection of pages making up a site.
このウェブページは読(よ)みやすい。
This web page is easy to read.
気(き)になった記事(きじ)のウェブページをブックマークに登録(とうろく)した。
I bookmarked the web page of an article I was interested in.
このウェブページはスマートフォンでも快適(かいてき)に閲覧(えつらん)できるように最適化(さいてきか)されている。
This web page has been optimized for comfortable viewing on smartphones as well.

Loanword from English 'web page'. Written in katakana with a small ェ to represent the /we/ sound. An older spelling ウェッブページ occasionally appears but is now uncommon.

USAGE:

  • Strictly speaking, a ウェブページ is one document, while a ウェブサイト is a collection of pages under one domain. In everyday Japanese, ホームページ is loosely used for either, especially by non-technical speakers.
  • Verbs commonly paired: 見(み)る, 開(ひら)く, 閲覧(えつらん)する ('to view'), 表示(ひょうじ)する ('to display'), 更新(こうしん)する ('to reload/update').
  • The URL itself is called URL (ユーアールエル) or アドレス.

COMMON COLLOCATIONS:

  • ウェブページを見(み)る: to view a web page
  • ウェブページを開(ひら)く: to open a web page
  • ウェブページを作成(さくせい)する: to create a web page
  • ウェブページを更新(こうしん)する: to reload/update a web page
  • 公式(こうしき)のウェブページ: official web page
  • 商品(しょうひん)紹介(しょうかい)のウェブページ: product introduction page

SIMILAR WORDS:

  • ウェブサイト: website — a collection of related pages under one domain; broader than a single ウェブページ.
  • ホームページ: homepage — strictly the top/landing page of a site, but in Japan often used loosely to mean 'website' or 'web page'.
  • サイト: site — short for ウェブサイト; very common in casual use.
  • ページ: page — can refer to a web page when context is clear, or to a page of a book/document.
