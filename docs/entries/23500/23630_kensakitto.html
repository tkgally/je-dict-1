検査(けんさ)キット

けんさきっと
noun
test kit; testing kit
1. test kit; testing kit (for medical, laboratory, or diagnostic tests)
A self-contained kit with the reagents, swabs, strips, and instructions needed to carry out a specific test — most often a diagnostic test for infection, pregnancy, drug use, water quality, or the like. Became a very familiar word in Japan during the COVID-19 pandemic, when home PCR and antigen test kits were widely sold.
薬局(やっきょく)で検査(けんさ)キットを買(か)った。
I bought a test kit at the pharmacy.
家(いえ)で検査(けんさ)キットを使(つか)って結果(けっか)を確認(かくにん)した。
I used a test kit at home and checked the result.
市販(しはん)の検査(けんさ)キットで陽性(ようせい)が出(で)た場合(ばあい)は、医療機関(いりょうきかん)に連絡(れんらく)してください。
If an over-the-counter test kit shows a positive result, please contact a medical facility.
パンデミックの影響(えいきょう)で、各家庭(かくかてい)に検査(けんさ)キットを備(そな)えておくという習慣(しゅうかん)が広(ひろ)まった。
Due to the pandemic, the practice of keeping test kits on hand in each household became widespread.

Composed of 検査(けんさ) (inspection, test, examination) and キット (kit — loanword from English). A compound that became familiar to nearly all Japanese speakers during the COVID-19 pandemic.

USAGE:

The word is generic: the type of test is usually specified by another word placed before it, such as:

  • 抗原(こうげん)検査(けんさ)キット: antigen test kit
  • PCR検査(けんさ)キット: PCR test kit
  • 妊娠(にんしん)検査(けんさ)薬(やく) — note: for pregnancy tests, 検査薬(けんさやく) (test drug/reagent) is more common than 検査(けんさ)キット
  • 水質(すいしつ)検査(けんさ)キット: water-quality test kit

COMMON COLLOCATIONS:

  • 検査(けんさ)キットを使(つか)う: to use a test kit
  • 検査(けんさ)キットで調(しら)べる: to check using a test kit
  • 市販(しはん)の検査(けんさ)キット: an over-the-counter / commercially available test kit
  • 検査(けんさ)キットが陽性(ようせい) / 陰性(いんせい): the test kit is positive / negative

RELATED TERMS:

  • 検査(けんさ): test, inspection, examination — the base word
  • 検査薬(けんさやく): testing reagent, test drug (often for pregnancy tests)
  • 抗原(こうげん)検査(けんさ): antigen test
  • PCR 検査(けんさ): PCR test
  • 自己(じこ)検査(けんさ): self-testing
  • セルフチェック: self-check (a loanword with similar meaning)
