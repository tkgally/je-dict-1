利用者(りようしゃ)カード

りようしゃかーど
noun
user card; library card; patron card
1. user card; library card; patron card
A registration card issued to the users of a facility or service — most typically a public library card, but also used at sports centers, community centers, and other membership-based public facilities. It identifies the holder as a registered user and is shown when borrowing items or using services.
利用者(りようしゃ)カードをお持(も)ちですか。
Do you have a user card?
図書館(としょかん)の利用者(りようしゃ)カードを作(つく)りたい。
I'd like to make a library card.
本(ほん)を借(か)りるときは、必(かなら)ず利用者(りようしゃ)カードを持参(じさん)してください。
When borrowing books, please be sure to bring your library card.
引(ひ)っ越(こ)したので、新(あたら)しい住所(じゅうしょ)で利用者(りようしゃ)カードを作(つく)り直(なお)しました。
Since I moved, I re-registered for a user card with my new address.

Composed of 利用者(りようしゃ) (user, patron) and カード (card). The standard neutral term used at public facilities — especially libraries — for the registration card issued to people entitled to use the service.

USAGE:
Most often encountered in the context of public libraries (図書館(としょかん))、where 利用者(りようしゃ)カード is essentially the Japanese equivalent of 'library card'. The same term is used at municipal sports centers, community halls, and archives. In commercial contexts — gyms, video rental, loyalty programs — カタカナ names like メンバーズカード} or {会員(かいいん)カード are more common.

COMMON COLLOCATIONS:

  • 利用者(りようしゃ)カードを作(つく)る: to make / apply for a user card
  • 利用者(りようしゃ)カードを提示(ていじ)する: to present one's user card
  • 利用者(りようしゃ)カードの更新(こうしん): renewal of the user card
  • 利用者(りようしゃ)カードを紛失(ふんしつ)する: to lose one's user card

SIMILAR WORDS:

  • 会員(かいいん)カード / {メンバーズカード}: membership card — used for private/commercial memberships (gyms, clubs, stores)
  • 貸出(かしだし)カード: lending card — an older term for a library card, emphasizing the lending function
  • 図書館(としょかん)カード: library card — a more transparent synonym when the context is specifically a library
