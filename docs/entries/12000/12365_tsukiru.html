尽(つ)きる

つきる
verb (ichidan)
to run out, to be exhausted
1. to run out, to be exhausted, to be used up
For a supply, resource, or abstract quality to be completely depleted or exhausted. Describes reaching the end of something finite.
体力(たいりょく)が尽(つ)きた。
My stamina ran out.
食料(しょくりょう)が尽(つ)きて困(こま)っている。
We're in trouble because the food supply has run out.
話題(わだい)が尽(つ)きることなく、朝(あさ)まで語(かた)り合(あ)った。
Without running out of topics, we talked until morning.

GRAMMAR:
Often used in the pattern Xが尽(つ)きる (X runs out). The negative form 尽(つ)きない and the pattern 尽(つ)きることなく (without running out) are common.

COLLOCATIONS:

  • 体力(たいりょく)が尽(つ)きる — stamina runs out
  • 食料(しょくりょう)が尽(つ)きる — food supply runs out
  • 忍耐(にんたい)が尽(つ)きる — patience runs out
  • 話題(わだい)が尽(つ)きない — topics never run out
  • 言葉(ことば)に尽(つ)きない — beyond words, inexpressible

SIMILAR WORDS:
なくなる is the everyday word for running out or disappearing. 尽(つ)きる is more literary and emphasizes complete exhaustion. 切(き)れる can also mean to run out (e.g., バッテリーが切(き)れる) but focuses on breaking or disconnecting.
