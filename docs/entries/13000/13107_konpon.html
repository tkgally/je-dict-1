根本(こんぽん)

こんぽん
noun, no-adjective
root, foundation, fundamental
1. root, foundation, basis, fundamental
The most basic and essential element from which everything else arises. Used to describe the underlying cause, principle, or foundation of something.
根本(こんぽん)から見直(みなお)す必要(ひつよう)がある。
We need to reconsider it from the ground up.
これが問題(もんだい)の根本(こんぽん)的(てき)な原因(げんいん)だ。
This is the fundamental cause of the problem.
制度(せいど)の根本(こんぽん)を変(か)えなければ、同(おな)じ問題(もんだい)が繰(く)り返(かえ)される。
If we don't change the foundation of the system, the same problems will keep recurring.

COMMON COLLOCATIONS:

  • 根本(こんぽん)的(てき)な: fundamental, radical
  • 根本(こんぽん)原因(げんいん): root cause
  • 根本(こんぽん)から変(か)える: to change from the roots
  • 根本(こんぽん)から見直(みなお)す: to fundamentally reconsider

SIMILAR WORDS:
根本(こんぽん) emphasizes going back to the very origin or basis. 基本(きほん) (basic, fundamental) is more neutral and practical, referring to the basics one builds on. 根底(こんてい) (foundation) is similar but often used in the phrase 根底(こんてい)にある (to underlie).
