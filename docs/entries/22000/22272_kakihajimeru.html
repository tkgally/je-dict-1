1. to begin writing; to start writing
To start the act of writing — a letter, essay, novel, or any text. A compound verb formed from 書(か)く and 始(はじ)める.
手紙(てがみ)を書(か)き始(はじ)めた。
I started writing a letter.
彼(かれ)は高校生(こうこうせい)の頃(ころ)から小説(しょうせつ)を書(か)き始(はじ)めた。
He started writing novels when he was in high school.
日記(にっき)を書(か)き始(はじ)めてから、毎日(まいにち)が楽(たの)しくなった。
Since I started writing a diary, every day has become more enjoyable.

A compound verb combining 書(か)く (to write) + 始(はじ)める (to begin). Follows the standard V-stem + 始(はじ)める pattern used to express the beginning of an action.

COMMON COLLOCATIONS:

  • 手紙(てがみ)を書(か)き始(はじ)める: to start writing a letter
  • 小説(しょうせつ)を書(か)き始(はじ)める: to start writing a novel
  • 日記(にっき)を書(か)き始(はじ)める: to start writing a diary
  • レポートを書(か)き始(はじ)める: to start writing a report

COMPOUND VERB PATTERN:

V-stem + 始(はじ)める is a productive pattern:

  • 読(よ)み始(はじ)める: to start reading
  • 食(た)べ始(はじ)める: to start eating
  • 走(はし)り始(はじ)める: to start running

SIMILAR WORDS:

  • 書(か)き出(だ)す: to begin writing — more spontaneous or sudden onset
  • 執筆(しっぴつ)する: to write (professionally) — formal, for authoring books/articles
