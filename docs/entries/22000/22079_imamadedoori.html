今(いま)まで通(どお)り

いままでどおり
expression
as usual; as before; same as always
1. as usual; as before; same as always
Expresses that something should stay or will stay the same as it has been up to now, emphasizing continuity and the absence of change. Very natural in both spoken and written Japanese.
今(いま)まで通(どお)りでいい。
The same as before is fine.
今(いま)まで通(どお)りの生活(せいかつ)を送(おく)りたい。
I want to live the same life as before.
部長(ぶちょう)が変(か)わっても、今(いま)まで通(どお)りのやり方(かた)で仕事(しごと)を進(すす)めてください。
Even though the department head has changed, please continue working the same way as before.

A very common expression combining 今(いま)まで (until now) and 通(どお)り (as, in the manner of). Used to express continuity — that something should stay or will stay the same as it has been. Natural in both spoken and written Japanese.

COMMON PATTERNS:

  • 今(いま)まで通(どお)り + verb: to do something as usual
  • 今(いま)まで通(どお)りの + noun: the same ~ as usual
  • 今(いま)まで通(どお)りに暮(く)らす: to live as one always has

SIMILAR WORDS:

  • 以前(いぜん)通(どお)り — as before (slightly more formal; emphasizes a past reference point)
  • 従来(じゅうらい)通(どお)り — as has been conventionally done (formal/institutional)
  • いつも通(どお)り — as always (focuses on habitual pattern)
