枯渇(こかつ)

こかつ
noun
exhaustion, depletion, drying up
1. exhaustion, depletion, drying up
The state of resources, supplies, or sources becoming completely used up or depleted. Used for both physical resources (water, oil) and abstract ones (ideas, energy, funds).
資金(しきん)が枯渇(こかつ)する。
Funds are running dry.
水源(すいげん)の枯渇(こかつ)が心配(しんぱい)される。
There are concerns about the depletion of water sources.
アイデアが枯渇(こかつ)してしまった。
I've run out of ideas.
石油(せきゆ)資源(しげん)の枯渇(こかつ)が懸念(けねん)されている。
The depletion of oil resources is a concern.

枯渇(こかつ) combines 枯(か)れる (to wither, dry up) and 渇(かわ)く (to dry up, be thirsty), creating a strong image of complete depletion.

Usage:

  • 枯渇(こかつ)する (to become depleted, run dry)
  • 枯渇(こかつ)させる (to deplete, exhaust)

Commonly used with:

  • 資源(しげん) (resources)
  • 資金(しきん) (funds)
  • 水源(すいげん) (water sources)
  • アイデア (ideas)
  • 体力(たいりょく) (physical energy)

Related words:

  • 底(そこ)をつく: to run out, be exhausted
  • 尽(つ)きる: to be used up
  • 払底(ふってい): running out, becoming scarce
