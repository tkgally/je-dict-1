要請(ようせい)

ようせい
noun / suru verb
request; demand; appeal
1. request; demand; appeal
A formal or earnest request for something to be done.
政府(せいふ)に支援(しえん)を要請(ようせい)する。
To request support from the government.
住民(じゅうみん)からの要請(ようせい)に応(こた)える。
To respond to requests from residents.
緊急(きんきゅう)要請(ようせい)が出(だ)された。
An urgent request was issued.

要請(ようせい) is a formal request or demand.

COMMON EXPRESSIONS:

  • 要請(ようせい)に応(こた)じる: to comply with a request
  • 要請(ようせい)を受(う)ける: to receive a request
  • 緊急(きんきゅう)要請(ようせい): urgent request

SIMILAR WORDS:

  • 依頼(いらい): request (more casual)
  • 要求(ようきゅう): demand (stronger)
  • お願(ねが)い: request (polite, casual)
