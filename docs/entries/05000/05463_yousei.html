1. request; demand; appeal
A formal or earnest request for something to be done.
会社(かいしゃ)に要請(ようせい)する。
To make a request to the company.
学校(がっこう)から要請(ようせい)があった。
There was a request from the school.
政府(せいふ)に支援(しえん)を要請(ようせい)した。
A request for support was made to the government.
住民(じゅうみん)からの要請(ようせい)を受(う)けて、対策(たいさく)が取(と)られた。
Measures were taken in response to requests from residents.
緊急(きんきゅう)要請(ようせい)が出(だ)されたので、すぐに対応(たいおう)しなければならない。
An urgent request was issued, so we must respond immediately.

要請(ようせい) is a formal request, typically from an authority or organization to another party. Stronger and more official than 依頼(いらい) but less forceful than 要求(ようきゅう).

COMMON COLLOCATIONS:

  • 要請(ようせい)する: to make a formal request
  • 要請(ようせい)に応(おう)じる: to comply with a request
  • 要請(ようせい)を受(う)ける: to receive a request
  • 緊急(きんきゅう)要請(ようせい): urgent request
  • 協力(きょうりょく)要請(ようせい): request for cooperation
  • 支援(しえん)要請(ようせい): request for assistance

USAGE:
Often used in government, military, and institutional contexts: 政府(せいふ)が自粛(じしゅく)を要請(ようせい)した (the government requested restraint). Common during disasters and emergencies.

FORMALITY SCALE (request words):

  • お願(ねが)い: request (polite, everyday)
  • 依頼(いらい): request (business-level)
  • 要請(ようせい): formal request (official/institutional)
  • 要求(ようきゅう): demand (strongest)
