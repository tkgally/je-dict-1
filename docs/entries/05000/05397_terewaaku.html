テレワーク

てれわーく
noun
telework; remote work
1. telework; remote work; working from home
Working outside of a traditional office, typically from home, using telecommunications technology.
今日(きょう)はテレワークです。
I'm working from home today.
テレワークが普及(ふきゅう)した。
Remote work has become widespread.
テレワークと出社(しゅっしゃ)を組(く)み合(あ)わせている。
I combine remote work and going to the office.

テレワーク (from 'telework') refers to remote work using telecommunications technology.

ETYMOLOGY:
テレ (tele-, remote) + ワーク (work)

SYNONYMS:

  • リモートワーク: remote work
  • 在宅(ざいたく)勤務(きんむ): working from home
  • 在宅(ざいたく)ワーク: work-from-home

RELATED TERMS:

  • ハイブリッドワーク: hybrid work (combining remote and office)
  • オンライン会議(かいぎ): online meeting
  • 出社(しゅっしゃ): going to the office
  • 時差(じさ)出勤(しゅっきん): staggered commuting

COMMON EXPRESSIONS:

  • テレワークをする: to work remotely
  • テレワーク可能(かのう): remote work possible
  • テレワーク導入(どうにゅう): introducing telework

USAGE:
Became widespread in Japan during the COVID-19 pandemic. Now a standard work option at many companies.
