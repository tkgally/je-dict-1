プログラマー

ぷろぐらまー
noun
programmer
1. programmer, coder
A person who writes computer programs and code to create software applications.
プログラマーとして働(はたら)くには論理的思考(ろんりてきしこう)が必要(ひつよう)だ。
You need logical thinking to work as a programmer.
彼(かれ)は独学(どくがく)でプログラマーになった。
He became a programmer through self-study.
プログラマーの仕事(しごと)は締(し)め切(き)りとの戦(たたか)いだ。
A programmer's job is a battle against deadlines.

プログラマー is a loanword from English "programmer," referring to someone who writes computer code.

COMMON EXPRESSIONS:

  • プログラマーになる: to become a programmer
  • プログラマーとして働(はたら)く: to work as a programmer
  • フリーランスプログラマー: freelance programmer
  • 独学(どくがく)でプログラマーになる: to become a self-taught programmer

RELATED IT VOCABULARY:

  • エンジニア: engineer (often SE = システムエンジニア)
  • デベロッパー: developer
  • プログラミング: programming
  • コーディング: coding
  • コード: code

JAPANESE WORK CULTURE:
In Japan, programmers often work in teams as part of an IT部門(ぶもん) (IT department) or at a 開発(かいはつ)会社(がいしゃ) (development company).
