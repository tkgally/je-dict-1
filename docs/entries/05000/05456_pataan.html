パターン

ぱたーん
noun
pattern

Definitions

1. pattern; recurring model
A repeated design, sequence, or way of doing things.

Examples

いつも同(おな)じパターンで失敗(しっぱい)する。
I always fail following the same pattern.
試験(しけん)にはいくつかのパターンがある。
There are several patterns in the exam.
行動(こうどう)パターンを分析(ぶんせき)する。
To analyze behavior patterns.

Notes

パターン is a loanword from English "pattern."

COMMON EXPRESSIONS:

  • パターン化(か)する: to become patterned/routine
  • 行動(こうどう)パターン: behavior pattern
  • 思考(しこう)パターン: thought pattern
  • いつものパターン: the usual pattern

Used widely in various contexts from design to behavior analysis.
