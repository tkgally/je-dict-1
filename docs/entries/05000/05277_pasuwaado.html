パスワード

ぱすわーど
noun
password

Definitions

1. password
A secret word or phrase used to gain access to a computer system or account.

Examples

パスワードを入力(にゅうりょく)してください。
Please enter your password.
パスワードを忘(わす)れた。
I forgot my password.
定期的(ていきてき)にパスワードを変更(へんこう)した方(ほう)がいい。
It's better to change your password regularly.

Notes

パスワード is a loanword from English "password."

COMMON PATTERNS:

  • パスワードを入力(にゅうりょく)する: to enter a password
  • パスワードを変更(へんこう)する: to change a password
  • パスワードを忘(わす)れる: to forget a password
  • パスワードをリセットする: to reset a password

SECURITY TERMS:

  • 暗証番号(あんしょうばんごう): PIN number
  • 二段階認証(にだんかいにんしょう): two-factor authentication
  • 指紋認証: fingerprint authentication
