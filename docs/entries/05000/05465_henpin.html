返品(へんぴん)

へんぴん
noun / suru verb
return (of goods)

Definitions

1. return of goods; product return
Sending purchased items back to the seller.

Examples

返品(へんぴん)は可能(かのう)ですか？
Is it possible to return this?
不良品(ふりょうひん)は返品(へんぴん)できます。
Defective products can be returned.
返品(へんぴん)期限(きげん)は購入(こうにゅう)から30日(にち)です。
The return period is 30 days from purchase.

Notes

返品(へんぴん) means returning purchased goods.

COMMON EXPRESSIONS:

  • 返品(へんぴん)可(か): returnable
  • 返品(へんぴん)不可(ふか): non-returnable
  • 返品(へんぴん)期限(きげん): return deadline
  • 返品(へんぴん)手続(てつづ)き: return procedure

RELATED TERMS:

  • 返金(へんきん): refund
  • 交換(こうかん): exchange
