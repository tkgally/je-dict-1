参考書(さんこうしょ)

さんこうしょ
noun
reference book
1. reference book, study guide
A book used as a source of information for studying or research, particularly for exam preparation.
参考書(さんこうしょ)を買(か)った。
I bought a reference book.
この参考書(さんこうしょ)は分(わ)かりやすい。
This reference book is easy to understand.
試験(しけん)のために参考書(さんこうしょ)を3冊(さつ)買(か)って、毎日(まいにち)勉強(べんきょう)した。
I bought three reference books for the exam and studied every day.

参考書(さんこうしょ) is a reference book used for supplementary study, especially for exam preparation. Distinct from a textbook (教科書(きょうかしょ)), which is the primary study material.

COMMON COLLOCATIONS:

  • 参考書(さんこうしょ)を使(つか)う: to use a reference book
  • 参考書(さんこうしょ)で勉強(べんきょう)する: to study with a reference book
  • 参考書(さんこうしょ)を買(か)う: to buy a reference book
  • 受験(じゅけん)参考書(さんこうしょ): exam prep book

RELATED TERMS:

  • 教科書(きょうかしょ): textbook (official school text)
  • 問題集(もんだいしゅう): workbook, problem collection
  • 辞書(じしょ): dictionary
  • 参考(さんこう): reference (the base noun, without 書(しょ))

COMPOSITION:
参考(さんこう) (reference) + 書(しょ) (book/document). The suffix 書(しょ) appears in many book-related words: 教科書(きょうかしょ), 辞書(じしょ), 説明書(せつめいしょ).
