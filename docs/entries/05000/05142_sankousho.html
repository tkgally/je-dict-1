参考書(さんこうしょ)

さんこうしょ
noun
reference book

Definitions

1. reference book, study guide
A book used as a source of information for studying or research, particularly for exam preparation.

Examples

試験(しけん)のために参考書(さんこうしょ)を買(か)った。
I bought a reference book for the exam.
この参考書(さんこうしょ)は分(わ)かりやすい。
This reference book is easy to understand.
英語(えいご)の参考書(さんこうしょ)を読(よ)んでいる。
I'm reading an English reference book.

Notes

COMMON COLLOCATIONS:

  • 参考書(さんこうしょ)を使(つか)う (to use a reference book)
  • 参考書(さんこうしょ)で勉強(べんきょう)する (to study with a reference book)
  • 受験(じゅけん)参考書(さんこうしょ) (exam prep book)

RELATED TERMS:

  • 教科書(きょうかしょ) (textbook)
  • 問題集(もんだいしゅう) (workbook, practice problems)
  • 辞書(じしょ) (dictionary)
