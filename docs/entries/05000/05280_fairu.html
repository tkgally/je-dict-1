ファイル

ふぁいる
noun
file; folder
1. file (computer)
A digital document or data stored on a computer.
ファイルを保存(ほぞん)する。
To save a file.
ファイルを添付(てんぷ)してメールを送(おく)る。
To attach a file and send an email.
古(ふる)いファイルを削除(さくじょ)して容量(ようりょう)を空(あ)けた。
I deleted old files to free up space.
2. file; folder; binder
A physical folder or binder for organizing documents.
書類(しょるい)をファイルに綴(と)じる。
To put documents in a binder.
クリアファイルに資料(しりょう)を入(い)れる。
To put materials in a clear folder.
会議(かいぎ)の書類(しょるい)をファイルにまとめておいてください。
Please organize the meeting documents in a binder.

ファイル is a loanword from English "file," used for both digital and physical files.

COMPUTER USAGE:

  • ファイルを開(ひら)く: to open a file
  • ファイルを保存(ほぞん)する: to save a file
  • ファイルを削除(さくじょ)する: to delete a file
  • 添付(てんぷ)ファイル: attached file
  • ファイルを転送(てんそう)する: to transfer a file

OFFICE/PHYSICAL USAGE:

  • クリアファイル: clear plastic folder
  • リングファイル: ring binder
  • ファイルに綴(と)じる: to file (documents)

RELATED:

  • フォルダ: folder (computer)
  • 書類(しょるい): documents
