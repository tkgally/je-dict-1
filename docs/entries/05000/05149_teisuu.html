定数(ていすう)

ていすう
noun
constant, fixed number
1. constant, fixed number
In mathematics and programming, a value that does not change, as opposed to a variable.
πは円周率(えんしゅうりつ)の定数(ていすう)だ。
π is the constant for pi (the ratio of circumference to diameter).
プログラムで定数(ていすう)を定義(ていぎ)する。
To define a constant in a program.
この式(しき)では、aが定数(ていすう)で、xが変数(へんすう)を表(あらわ)している。
In this formula, 'a' represents a constant and 'x' represents a variable.

定数(ていすう) means a constant or fixed number, used in mathematics, science, and programming.

CONTRAST WITH VARIABLE:

  • 定数(ていすう): constant (unchanging value)
  • 変数(へんすう): variable (changing value)

COMMON COLLOCATIONS:

  • 定数(ていすう)を定義(ていぎ)する: to define a constant
  • 定数(ていすuu)項(こう): constant term
  • 物理(ぶつり)定数(ていすう): physical constant
  • 数学(すうがく)定数(ていすう): mathematical constant

EXAMPLES:

  • π (円周率(えんしゅうりつ)): pi
  • e (自然(しぜん)対数(たいすう)の底(てい)): Euler's number

RELATED TERMS:

  • 係数(けいすう): coefficient
  • 数値(すうち): numerical value
