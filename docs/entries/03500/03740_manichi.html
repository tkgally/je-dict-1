万一(まんいち)

まんいち
adverb / noun
by some chance, in the unlikely event
1. by some chance, if by any chance
Indicates an unlikely but possible scenario.
万一(まんいち)遅(おく)れる場合(ばあい)は連絡(れんらく)してください。
Please contact us if by any chance you're going to be late.
2. one in ten thousand, remote possibility
As a noun, refers to a very unlikely chance or emergency.
万一(まんいち)に備(そな)えて保険(ほけん)に入(はい)った。
I got insurance in case of emergency.
万一(まんいち)のことがあったら、この番号(ばんごう)に電話(でんわ)してください。
If anything (bad) happens, please call this number.
万一(まんいち)のこと = emergency, worst case

Literally means "one in ten thousand" (万(まん) = 10,000, 一(いち) = 1), suggesting very low probability.

COMMON PATTERNS:

  • 万一(まんいち)〜たら/〜ば (if by any chance ~)
  • 万一(まんいち)の場合(ばあい) (in the unlikely event)
  • 万一(まんいち)のこと (emergency, worst case scenario)
  • 万一(まんいち)に備(そな)えて (in preparation for emergencies)

SIMILAR EXPRESSIONS:

  • もし〜たら (if - general)
  • もしも〜たら (if - emphatic)
  • 万一(まんいち)〜たら (if by some unlikely chance)
