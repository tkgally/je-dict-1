エンジン

えんじん
noun
engine
1. engine, motor
A machine that converts fuel into mechanical motion, especially in vehicles.
エンジンをかけて出発(しゅっぱつ)した。
I started the engine and set off.
エンジンをかける = to start the engine
エンジンの調子(ちょうし)が悪(わる)いので、修理(しゅうり)に出(だ)す。
The engine isn't running well, so I'm taking it in for repairs.
この車(くるま)は燃費(ねんぴ)の良(よ)いエンジンを搭載(とうさい)している。
This car is equipped with a fuel-efficient engine.

COMMON PATTERNS:

  • エンジンをかける (to start the engine)
  • エンジンを切(き)る (to turn off the engine)
  • エンジンが止(と)まる (the engine stops/stalls)
  • エンジンがかからない (the engine won't start)
  • エンジン音(おん) (engine sound)

TYPES:

  • ガソリンエンジン (gasoline engine)
  • ディーゼルエンジン (diesel engine)
  • ジェットエンジン (jet engine)
  • 電気(でんき)モーター (electric motor - different from エンジン)
