翌(よく)〜

よく
prefix
next; following
1. next; following (the next day/year/etc.)
Prefix indicating the time period immediately after a reference point.
翌日(よくじつ)、熱(ねつ)が下(さ)がった。
The next day, my fever went down.
翌(よく) + 日(じつ) = the next day
翌年(よくねん)、彼(かれ)は会社(かいしゃ)を辞(や)めた。
The following year, he quit the company.
翌(よく) + 年(ねん) = the following year
翌朝(よくあさ)、早(はや)く起(お)きた。
The next morning, I woke up early.
翌(よく) + 朝(あさ) = the next morning

翌(よく)〜 is a prefix meaning 'the next' or 'the following,' always referring to a time after a specified reference point.

COMMON COMPOUNDS:

  • 翌日(よくじつ) (the next day; the following day)
  • 翌朝(よくあさ) (よくちょう とも) (the next morning)
  • 翌年(よくねん) (よくとし とも) (the following year)
  • 翌月(よくげつ) (よくつき とも) (the following month)
  • 翌週(よくしゅう) (the following week)

DIFFERENCE FROM 来(らい)〜:

  • 翌(よく)〜: the next one AFTER a reference point (in narratives/past events)
  • 来(らい)〜: the next one FROM NOW (present perspective)

Example:

  • 翌日(よくじつ) = 'the next day' (in a story about the past)
  • 明日(あした) = 'tomorrow' (from today)

翌(よく)〜 is primarily used in written narratives and formal contexts.
