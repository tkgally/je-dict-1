1. to be prepared; to be ready
A state where everything needed is in place.
準備(じゅんび)が整(ととの)った。
The preparations are complete.
環境(かんきょう)が整(ととの)ってから始(はじ)めましょう。
Let's start once the environment is set up.
[Note: 整(ととの)ってから = 'once ~ is ready']
やっと条件(じょうけん)が整(ととの)って、契約(けいやく)できた。
The conditions were finally met, and we could sign the contract.
2. to be in order; to be organized
Things being properly arranged or structured.
部屋(へや)が整(ととの)っていて気持(きも)ちがいい。
The room is tidy and feels nice.
書類(しょるい)が整(ととの)っているか確認(かくにん)してください。
Please check whether the documents are in order.
制度(せいど)が整(ととの)っていない国(くに)もある。
There are also countries where the systems are not in place.
3. to be well-balanced; to be harmonious
Features or elements being in good proportion.
彼女(かのじょ)は顔立(かおだ)ちが整(ととの)っている。
She has well-proportioned features.
味(あじ)のバランスが整(ととの)っている料理(りょうり)だ。
This is a dish with well-balanced flavors.
彼(かれ)の文章(ぶんしょう)はいつも整(ととの)っていて読(よ)みやすい。
His writing is always well-organized and easy to read.

整(ととの)う is an intransitive verb (自動詞(じどうし)). The transitive pair is 整(ととの)える (to prepare, to arrange).

ASPECT (ている):
The ている form indicates a resulting state (準備(じゅんび)が整(ととの)っている = 'preparations are in place').

PARTICLE PATTERNS:

  • [thing]が整(ととの)う (~ becomes ready/organized)

COMMON PATTERNS:

  • 準備(じゅんび)が整(ととの)う (preparations are complete)
  • 体制(たいせい)が整(ととの)う (system is in place)
  • 条件(じょうけん)が整(ととの)う (conditions are met)
  • 顔立(かおだ)ちが整(ととの)っている (have well-proportioned features)
