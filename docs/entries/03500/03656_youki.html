容器(ようき)

ようき
noun
container, vessel

Definitions

1. container, vessel, receptacle
An object used to hold or store things, such as bottles, boxes, or jars.

Examples

食品(しょくひん)は清潔(せいけつ)な容器(ようき)に保存(ほぞん)してください。
Please store food in a clean container.
この容器(ようき)は電子(でんし)レンジで使(つか)えます。
This container can be used in the microwave.
密閉(みっぺい)容器(ようき)に入(い)れて保管(ほかん)する。
Store in an airtight container.
密閉容器 = airtight container

Notes

USAGE: 容器(ようき) is a general term for containers of all types. It's commonly used in contexts involving food storage, chemicals, or packaging.

COMMON PATTERNS:

  • 密閉(みっぺい)容器(ようき) (airtight container)
  • 保存(ほぞん)容器(ようき) (storage container)
  • プラスチック容器(ようき) (plastic container)
  • 容器(ようき)に入(い)れる (to put in a container)

NOTE: Do not confuse with 陽気(ようき) (cheerful), which has the same reading.
