メッセージ

めっせーじ
noun
message
1. message
A written, spoken, or recorded communication sent to someone.
メッセージが届(とど)いた。
A message arrived.
メッセージを送(おく)った。
I sent a message.
留守番(るすばん)電話(でんわ)にメッセージを残(のこ)しておいてください。
Please leave a message on the answering machine.
2. message, meaning (underlying)
The main point or theme that something conveys.
この歌(うた)のメッセージは深(ふか)い。
The message of this song is profound.
この映画(えいが)のメッセージは何(なん)ですか。
What is the message of this movie?
Refers to the underlying theme or meaning
この小説(しょうせつ)には平和(へいわ)の大切(たいせつ)さというメッセージが込(こ)められている。
This novel contains a message about the importance of peace.

USAGE: メッセージ is a widely used loanword for messages of all types - text messages, voicemails, written notes, or figurative meanings in art/media.

COMMON PATTERNS:

  • メッセージを送(おく)る (to send a message)
  • メッセージを残(のこ)す (to leave a message)
  • メッセージを伝(つた)える (to convey a message)
  • メッセージが届(とど)く (a message arrives)
  • メッセージ性(せい) (having a message/meaning)

RELATED:

  • ショートメッセージ/SMS (text message)
  • ボイスメッセージ (voice message)
  • メッセージカード (greeting card)
