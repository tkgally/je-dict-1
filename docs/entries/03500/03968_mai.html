毎(まい)〜

まい
prefix
every; each
1. every; each
Prefix indicating regular occurrence or all instances of something.
毎日(まいにち)運動(うんどう)している。
I exercise every day.
毎(まい) + 日(にち) = every day
毎週(まいしゅう)金曜日(きんようび)に会議(かいぎ)がある。
There's a meeting every Friday.
毎(まい) + 週(しゅう) = every week
毎回(まいかい)同(おな)じ間違(まちが)いをする。
I make the same mistake every time.
毎(まい) + 回(かい) = every time

毎(まい)〜 is a very common prefix meaning 'every.'

TIME EXPRESSIONS:

  • 毎日(まいにち) (every day)
  • 毎週(まいしゅう) (every week)
  • 毎月(まいつき/まいげつ) (every month)
  • 毎年(まいとし/まいねん) (every year)
  • 毎朝(まいあさ) (every morning)
  • 毎晩(まいばん) (every night)
  • 毎度(まいど) (every time; each time)
  • 毎回(まいかい) (every time; each occasion)

NOTE ON READINGS:

  • 毎月(まいつき) (colloquial) vs 毎月(まいげつ) (formal)
  • 毎年(まいとし) (colloquial) vs 毎年(まいねん) (formal)

OTHER USES:

  • 毎食(まいしょく) (every meal)
  • 毎秒(まいびょう) (every second)
  • 毎時(まいじ) (every hour; hourly)
