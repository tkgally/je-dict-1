悲劇(ひげき)

ひげき
noun
tragedy
1. tragedy (drama)
A serious dramatic work with an unhappy ending, typically involving the downfall of the main character.
シェイクスピアの悲劇(ひげき)を読(よ)んだ。
I read Shakespeare's tragedies.
2. tragedy, tragic event
A very sad, unfortunate, or disastrous event or situation.
戦争(せんそう)は多(おお)くの悲劇(ひげき)を生(う)んだ。
The war created many tragedies.
この悲劇(ひげき)を繰(く)り返(かえ)してはならない。
We must not repeat this tragedy.

USAGE: 悲劇(ひげき) refers to both the dramatic genre (tragedy) and real-world tragic events.

COMMON PATTERNS:

  • 悲劇(ひげき)を生(う)む (to create tragedy)
  • 悲劇(ひげき)を繰(く)り返(かえ)す (to repeat tragedy)
  • 悲劇(ひげき)に見舞(みま)われる (to be struck by tragedy)
  • 悲劇(ひげき)的(てき) (tragic)

COMMON COMPOUNDS:

  • 悲劇(ひげき)的(てき) (tragic - adjective)
  • 悲劇(ひげき)俳優(はいゆう) (tragic actor)
  • 四大(しだい)悲劇(ひげき) (four great tragedies - Shakespeare)

ANTONYM:

  • 喜劇(きげき) (comedy)

LITERARY NOTE: The four great tragedies of Shakespeare (ハムレット, オセロ, リア王(おう), マクベス) are called 四大(しだい)悲劇(ひげき) in Japanese.
