1. set, combination
A group of items sold or used together.
ランチセットを頼(たの)んだ。
I ordered a lunch set.
ハンバーガーとドリンクのセットを注文(ちゅうもん)した。
I ordered a hamburger and drink set.
この工具(こうぐ)セットには必要(ひつよう)なものが全部(ぜんぶ)入(はい)っているので便利(べんり)だ。
This tool set has everything you need in it, so it's convenient.
2. set (in tennis/volleyball)
A unit of play in certain sports.
第(だい)1セットを取(と)った。
I won the first set.
Sports term
試合(しあい)は3セットまで進(すす)んだ。
The match went to three sets.
最後(さいご)のセットで相手(あいて)に逆転(ぎゃくてん)されて負(ま)けてしまった。
I was overtaken by my opponent in the final set and lost.
3. set, setting
The act of arranging or preparing something.
目覚(めざ)まし時計(どけい)を7時(じ)にセットした。
I set the alarm clock for 7 o'clock.

Please set up the projector and screen for tomorrow's meeting.

From English "set." Extremely common loanword with three main meanings in Japanese.

SENSE 1 — COMBINATION:

  • ランチセット: lunch set (a meal combo)
  • セットメニュー: set menu
  • 工具(こうぐ)セット: tool set
  • Very common at restaurants — ordering a セット gets a main dish plus sides/drink

SENSE 2 — SPORTS:

  • 第(だい)〜セット: set number ~ (in tennis, volleyball, etc.)
  • セットを取(と)る: to win a set

SENSE 3 — SETTING/ARRANGING:

  • 髪(かみ)をセットする: to style hair
  • アラームをセットする: to set an alarm
  • 〜をセットする: to set up/prepare ~

In restaurant contexts, セット is often the most economical option, combining several items at a discount.
