定期(ていき)

ていき
noun, no-adjective
fixed term, regular, commuter pass

Definitions

1. fixed term, fixed period, regular
Something that occurs or is valid for a set period of time.
2. commuter pass (abbreviation)
Short for 定期券(ていきけん), a pass for unlimited train/bus rides over a set period.

Examples

定期(ていき)を買(か)った。
I bought a commuter pass.
定期(ていき)検査(けんさ)を受(う)けてください。
Please have a regular checkup.
定期(ていき)が切(き)れた。
My commuter pass expired.

Notes

COMMON MEANINGS:
As a standalone noun, 定期(ていき) usually means 'commuter pass' (定期券(ていきけん)). As a prefix, it means 'regular' or 'fixed-term.'

COMMON COMPOUND WORDS:

  • 定期券(ていきけん) (commuter pass)
  • 定期(ていき)検査(けんさ) (regular inspection/checkup)
  • 定期(ていき)預金(よきん)/貯金(ちょきん) (fixed-term deposit)
  • 定期(ていき)便(びん) (regular service, scheduled flight)
  • 定期(ていき)試験(しけん) (regular examination)

ANTONYM:

  • 不定期(ふていき) (irregular, non-scheduled)

Related Words

Antonym: 不定期(ふていき) (irregular)
