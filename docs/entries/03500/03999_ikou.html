以降(いこう)

いこう
noun, suffix
from...onward; after
1. from...onward; after; since
Indicates a time point and everything following it. The starting point is typically included.
10時(じ)以降(いこう)は静(しず)かにしてください。
Please be quiet after 10 o'clock.
来週(らいしゅう)以降(いこう)は忙(いそが)しくなる。
From next week onward, I'll be busy.
2020年(にせんにじゅうねん)以降(いこう)、在宅(ざいたく)勤務(きんむ)が増(ふ)えた。
Remote work has increased since 2020.

USAGE: Attached to time expressions to indicate 'from that point onward.' The reference point is usually included.

COMMON PATTERNS:

  • Time + 以降(いこう) (from [time] onward)
  • 以降(いこう) at the start of a sentence (from then on)

SIMILAR EXPRESSIONS:

  • 以来(いらい) (since - emphasizes continuation from the past)
  • 以後(いご) (after - slightly more formal)
  • 後(あと) (after - more casual)

NOTE: 以降(いこう) typically includes the reference point, so 10時(じ)以降(いこう) means '10 o'clock and after.'
