宛名(あてな)

あてな
noun
address; recipient's name

Definitions

1. recipient's name and address
The name and address written on mail or packages indicating where they should be delivered.

Examples

宛名(あてな)を書(か)いてください。
Please write the recipient's address.
宛名(あてな)が間違(まちが)っていた。
The address was wrong.
封筒(ふうとう)に宛名(あてな)を書(か)く。
To write the address on an envelope.

Notes

USAGE: Specifically refers to the name/address of the recipient on mail, packages, or documents.

COMMON COLLOCATIONS:

  • 宛名(あてな)を書(か)く (to write the address)
  • 宛名(あてな)書(が)き (addressing mail)
  • 宛名(あてな)ラベル(らべる) (address label)

ON JAPANESE ENVELOPES:

  • 宛名(あてな) goes on the front center
  • 差出人(さしだしにん) (sender) goes on the back flap

RELATED:

  • 住所(じゅうしょ) - address (location)
  • 送り先(おくりさき) - destination address
