反(はん)〜

はん
prefix
anti-; counter-; opposition
1. anti-; counter-; against
Prefix indicating opposition or being against something.
反対(はんたい)の意見(いけん)を述(の)べた。
I stated an opposing opinion.
反(はん) + 対(たい) = opposition
反戦(はんせん)デモが行(おこな)われた。
An anti-war demonstration was held.
反(はん) + 戦(せん) = anti-war
その発言(はつげん)は反感(はんかん)を買(か)った。
That statement aroused antipathy.
反(はん) + 感(かん) = antipathy

反(はん)〜 is a prefix meaning 'anti-' or 'counter-.'

COMMON COMPOUNDS:

  • 反対(はんたい) (opposition; opposite)
  • 反感(はんかん) (antipathy; ill will)
  • 反省(はんせい) (reflection; reconsideration)
  • 反応(はんのう) (reaction; response)
  • 反論(はんろん) (counterargument)
  • 反発(はんぱつ) (repulsion; opposition)
  • 反戦(はんせん) (anti-war)
  • 反社会的(はんしゃかいてき) (antisocial)
  • 反抗(はんこう) (resistance; defiance)
  • 反則(はんそく) (foul; violation)

NOTE:

Different from 半(はん)〜 (half), which is a homophone.

  • 反(はん)対(たい) = opposition
  • 半(はん)分(ぶん) = half
