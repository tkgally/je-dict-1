舞台(ぶたい)

ぶたい
noun
stage, setting

Definitions

1. stage (theater)
A raised platform where performances take place.
2. setting, scene
The location where events take place, including in stories or films.

Examples

俳優(はいゆう)が舞台(ぶたい)に立(た)った。
The actor stepped onto the stage.
この小説(しょうせつ)の舞台(ぶたい)は江戸(えど)時代(じだい)だ。
This novel is set in the Edo period.
世界(せかい)を舞台(ぶたい)に活躍(かつやく)する。
To be active on the world stage.

Notes

USAGE: 舞台(ぶたい) refers both to physical theater stages and to settings/scenes where action takes place.

COMMON PATTERNS:

  • 舞台(ぶたい)に立(た)つ (to stand on stage, to perform)
  • 舞台(ぶたい)にする (to set [a story] in)
  • 舞台(ぶたい)裏(うら) (backstage, behind the scenes)
  • 表(おもて)舞台(ぶたい) (public stage, limelight)

COMPOUNDS:

  • 舞台(ぶたい)俳優(はいゆう) (stage actor)
  • 舞台(ぶたい)装置(そうち) (stage set)
  • 舞台(ぶたい)衣装(いしょう) (stage costume)
