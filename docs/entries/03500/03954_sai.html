最(さい)〜

さい
prefix
most; -est; utmost
See also: 再(さい)〜 (re-; again)
1. most; -est; utmost
Prefix indicating the superlative degree.
これは最高(さいこう)の映画(えいが)だ。
This is the best movie.
最(さい) + 高(こう) = highest/best
最近(さいきん)、運動(うんどう)を始(はじ)めた。
I started exercising recently.
最(さい) + 近(きん) = most recent; lately
最悪(さいあく)の事態(じたい)を想定(そうてい)する。
To assume the worst-case scenario.
最(さい) + 悪(あく) = worst

最(さい)〜 is a superlative prefix equivalent to English '-est' or 'most.'

COMMON COMPOUNDS:

  • 最高(さいこう) (highest; best; supreme)
  • 最低(さいてい) (lowest; minimum; worst)
  • 最大(さいだい) (largest; maximum)
  • 最小(さいしょう) (smallest; minimum)
  • 最近(さいきん) (recently; latest)
  • 最初(さいしょ) (first; beginning)
  • 最後(さいご) (last; final)
  • 最新(さいしん) (newest; latest)
  • 最終(さいしゅう) (final; last)
  • 最悪(さいあく) (worst)
  • 最善(さいぜん) (best - in effort)
  • 最強(さいきょう) (strongest)

NOTE:
最(さい)〜 creates superlatives from sino-Japanese words. For native Japanese adjectives, use 一番(いちばん) (e.g., 一番(いちばん)高(たか)い).
