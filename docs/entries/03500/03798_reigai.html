例外(れいがい)

れいがい
noun
exception
1. exception
Something that does not follow a general rule or pattern; a case that differs from the norm.
例外(れいがい)なく全員(ぜんいん)が参加(さんか)した。
Everyone participated without exception.
例外なく = without exception
これは例外(れいがい)的(てき)なケースだ。
This is an exceptional case.
例外的 = exceptional
例外(れいがい)を認(みと)めることはできない。
We cannot allow any exceptions.

USAGE: 例外(れいがい) refers to something that deviates from a rule or standard pattern.

COMMON PATTERNS:

  • 例外(れいがい)なく (without exception)
  • 例外(れいがい)を設(もう)ける (to make an exception)
  • 例外(れいがい)を認(みと)める (to allow an exception)
  • 例外(れいがい)的(てき) (exceptional - na-adjective)
  • 例外(れいがい)処理(しょり) (exception handling - programming term)

CONTRAST:

  • 例外(れいがい) - exception (to a rule)
  • 特例(とくれい) - special case, special exemption
