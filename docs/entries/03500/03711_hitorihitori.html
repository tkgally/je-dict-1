一人一人(ひとりひとり)

ひとりひとり
noun / adverb
each person, one by one
1. each person, one by one
Every individual person, considered separately.
一人一人(ひとりひとり)に聞(き)いた。
I asked each person.
一人一人(ひとりひとり)に挨拶(あいさつ)した。
I greeted each person individually.
生徒(せいと)一人一人(ひとりひとり)の個性(こせい)を大切(たいせつ)にする。
We value each student's individuality.
先生(せんせい)は一人一人(ひとりひとり)の名前(なまえ)を呼(よ)んで出席(しゅっせき)を取(と)った。
The teacher called each person's name to take attendance.
一人一人(ひとりひとり)の力(ちから)は小(ちい)さいが、集(あつ)まれば大(おお)きな力(ちから)になる。
Each individual's power may be small, but together it becomes a great force.

一人一人(ひとりひとり) emphasizes treating each individual separately within a group. It functions as both a noun and an adverb.

ALTERNATIVE WRITING:

  • 一人一人(ひとりひとり) (all kanji)
  • 一人(ひとり)ひとり (mixed — common in print)
  • ひとりひとり (all hiragana)

COMMON PATTERNS:

  • 一人一人(ひとりひとり)に: to each person
  • 一人一人(ひとりひとり)の + noun: each person's ~
  • 一人一人(ひとりひとり)が: each person (as subject)

SIMILAR EXPRESSIONS:

  • それぞれ: each, respectively (general — can apply to things too)
  • 各々(おのおの): each one (formal/literary)
  • 個々(ここ)に: individually (more abstract)
  • めいめい: each person (slightly old-fashioned)
