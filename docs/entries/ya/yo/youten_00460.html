要点(ようてん)

ようてん
noun
main point, gist, essentials

Definitions

1. main point, gist, essentials
The most important or central part of something. The key points that summarize the essence.

Examples

要点(ようてん)をまとめてください。
Please summarize the main points.
要点(ようてん)を押(お)さえましょう。
Let's grasp the key points.
Common expression
話(はなし)の要点(ようてん)が分(わ)かりません。
I don't understand the gist of what you're saying.

Notes

要点(ようてん) refers to the main points or essentials.

COMMON PATTERNS:

  • 要点(ようてん)をまとめる (summarize the main points)
  • 要点(ようてん)を押(お)さえる (grasp the key points)
  • 要点(ようてん)を整理(せいり)する (organize the main points)
  • 要点(ようてん)筆記(ひっき) (note-taking of key points)

SIMILAR WORDS:

  • ポイント: point (loanword, casual)
  • 要点(ようてん): main point (formal)
  • 概要(がいよう): summary, outline
  • 要旨(ようし): gist, summary (written)
