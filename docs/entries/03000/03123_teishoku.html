定食(ていしょく)

ていしょく
noun
set meal
1. set meal, fixed-price meal
A complete meal offered at a fixed price, typically including a main dish, rice, miso soup, and side dishes. Common at Japanese restaurants.
焼(や)き魚(ざかな)定食(ていしょく)をください。
I'll have the grilled fish set meal, please.
この店(みせ)の定食(ていしょく)は安(やす)くておいしい。
The set meals at this restaurant are cheap and delicious.
定食(ていしょく)には味噌汁(みそしる)と漬物(つけもの)が付(つ)きます。
The set meal comes with miso soup and pickles.

COMPOUND: 定(てい) (fixed, regular) + 食(しょく) (meal)

TYPICAL 定食(ていしょく) COMPONENTS:

  • Main dish (meat, fish, etc.)
  • ご飯(はん) (rice)
  • 味噌汁(みそしる) (miso soup)
  • 漬物(つけもの) (pickles)
  • 小鉢(こばち) (small side dishes)

COMMON TYPES:

  • 焼(や)き魚(ざかな)定食(ていしょく) (grilled fish set)
  • 唐揚(からあ)げ定食(ていしょく) (fried chicken set)
  • 豚(ぶた)カツ定食(ていしょく) (pork cutlet set)
  • 生姜焼(しょうがや)き定食(ていしょく) (ginger pork set)
  • 日替(ひが)わり定食(ていしょく) (daily special set)

定食(ていしょく) is a popular, economical lunch option in Japan.
