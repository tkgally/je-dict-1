図書(としょ)

としょ
noun
books, library books
1. books, library materials
Books, especially in the context of libraries and institutional collections. A somewhat formal term for books.
図書館(としょかん)で本(ほん)を借(か)りた。
I borrowed books from the library.
図書館 = library
図書(としょ)室(しつ)は3階(かい)にあります。
The library room is on the third floor.
図書室 = library room (in school)
図書(としょ)委員(いいん)として働(はたら)いている。
I work as a library committee member.
図書(としょ)カードを作(つく)りたいのですが。
I'd like to make a library card.
学校(がっこう)の図書(としょ)室(しつ)には新(あたら)しい本(ほん)がたくさん入(はい)った。
Many new books were added to the school library room.

USAGE: 図書(としょ) is primarily used in compound words related to libraries and book collections. For 'book' in general, 本(ほん) is more common.

COMMON COMPOUNDS:

  • 図書館(としょかん) (library - public building)
  • 図書(としょ)室(しつ) (library room - in schools)
  • 図書(としょ)カード (library card)
  • 図書(としょ)券(けん) (book voucher/gift certificate)
  • 図書(としょ)委員(いいん) (library committee member)
  • 図書(としょ)目録(もくろく) (book catalog)
  • 参考(さんこう)図書(としょ) (reference books)

SIMILAR WORDS:

  • 本(ほん) - book (everyday word)
  • 書籍(しょせき) - books (formal)
  • 書物(しょもつ) - books (literary/formal)
  • 文献(ぶんけん) - literature, documents (academic)

Related Words
