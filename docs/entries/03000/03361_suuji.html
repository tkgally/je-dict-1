数字(すうじ)

すうじ
noun
numeral, figure, digit
1. numeral, figure, digit
A written symbol representing a number (0, 1, 2, etc.).
数字(すうじ)を入力(にゅうりょく)してください。
Please enter the numbers.
売上(うりあげ)の数字(すうじ)を確認(かくにん)する。
Check the sales figures.
アラビア数字(すうじ)とローマ数字(すうじ)がある。
There are Arabic numerals and Roman numerals.

数字(すうじ) refers to the written symbols for numbers.

COMMON COLLOCATIONS:

  • 数字(すうじ)を入力(にゅうりょく)する (to input numbers)
  • 数字(すうじ)を読(よ)む (to read numbers)
  • アラビア数字(すうじ) (Arabic numerals: 1, 2, 3...)
  • ローマ数字(すうじ) (Roman numerals: I, II, III...)
  • 漢数字(かんすうじ) (Chinese/Japanese numerals: 一(いち), 二(に), 三(さん)...)

SIMILAR WORDS:

  • 数字(すうじ): numeral, digit (the written symbol)
  • 数(かず)/数(すう): number (abstract quantity)
  • 番号(ばんごう): number (assigned for identification)
