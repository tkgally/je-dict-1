人数(にんずう)

にんずう
noun
number of people
1. number of people, headcount
The count or total of people in a group or at an event.
参加(さんか)人数(にんずう)を教(おし)えてください。
Please tell me the number of participants.
人数(にんずう)が多(おお)すぎる。
There are too many people.
人数(にんずう)分(ぶん)のお弁当(べんとう)を注文(ちゅうもん)した。
I ordered lunches for everyone (the number of people).

COMPOUND: 人(にん) (person) + 数(すう) (number)

COMMON EXPRESSIONS:

  • 人数(にんずう)を数(かぞ)える (count the number of people)
  • 人数(にんずう)制限(せいげん) (capacity limit)
  • 人数(にんずう)分(ぶん) (for the number of people)
  • 最低(さいてい)人数(にんずう) (minimum number of people)

PRONUNCIATION NOTE: にんずう is the standard reading. にんず is also sometimes used.

RELATED:

  • 定員(ていいん) (capacity, fixed number of people)
  • 人員(じんいん) (personnel, staff)
  • 人口(じんこう) (population)
