たまらない

たまらない
i-adjective
unbearable, irresistible

1. unbearable, intolerable, cannot stand
Used to express that something is so intense (unpleasant or sometimes pleasant) that one cannot endure it.
暑(あつ)くてたまらない。
It's unbearably hot.
会(あ)いたくてたまらない。
I'm dying to see you.
〜たくてたまらない = desperately want to
足(あし)が痛(いた)くてたまらないので病院(びょういん)に行(い)った。
My foot hurt so badly that I went to the hospital.
2. irresistible, extremely appealing
Used to express that something is so wonderful or appealing that one cannot resist it.
この料理(りょうり)は美味(おい)しくてたまらない。
This dish is irresistibly delicious.
新(あたら)しい猫(ねこ)が可愛(かわい)くてたまらない。
The new cat is irresistibly cute.
温泉(おんせん)に入(はい)った後(あと)のビールがたまらない。
Beer after a hot spring bath is irresistible.

GRAMMAR PATTERNS:

  • {〜て}たまらない: So ~ that one can't stand it
  • {〜たくて}たまらない: Desperately want to ~
  • {〜で}たまらない: So ~ (with na-adj/noun)

NUANCE:

  • Can be used for both negative sensations (pain, heat, boredom) and positive ones (deliciousness, excitement)
  • When positive, conveys overwhelming appeal or satisfaction

SIMILAR EXPRESSIONS:

  • たまらない: Unbearable/irresistible
  • 堪(た)えられない: Cannot endure (more formal)
  • 〜てしょうがない: Can't help but ~ (similar pattern)
