申込書(もうしこみしょ)

もうしこみしょ
noun
application form
1. application form
A document to be filled out when applying for something.
申込書(もうしこみしょ)に記入(きにゅう)してください。
Please fill out the application form.
申込書(もうしこみしょ)を提出(ていしゅつ)した。
I submitted the application form.
申込書(もうしこみしょ)はどこでもらえますか。
Where can I get an application form?

COMPOUND: 申(もう)し込(こ)み (application) + 書(しょ) (document)

Note: Also written as 申(もう)し込(こ)み用紙(ようし) (application form/paper).

COMMON COLLOCATIONS:

  • 申込書(もうしこみしょ)に記入(きにゅう)する (fill out an application form)
  • 申込書(もうしこみしょ)を提出(ていしゅつ)する (submit an application form)
  • 申込書(もうしこみしょ)をダウンロードする (download an application form)

SIMILAR DOCUMENT NAMES:

  • 履歴書(りれきしょ) (resume)
  • 申請書(しんせいしょ) (official application/petition)
  • 入会(にゅうかい)申込書(もうしこみしょ) (membership application form)
