互(たが)い

たがい
noun
mutual, each other
1. mutual, each other, one another
Referring to a reciprocal relationship or action between two or more parties.
お互(たが)いに助(たす)け合(あ)いましょう。
Let's help each other.
お互いに = mutually, each other (polite)
互(たが)いの意見(いけん)を尊重(そんちょう)する。
To respect each other's opinions.
お互(たが)い様(さま)だ。
It's the same for both of us. / We're in the same boat.
Common expression

COMMON PATTERNS:

  • お互(たが)いに: Mutually, each other (adverbial)
  • 互(たが)いの + noun: Each other's (noun)
  • お互(たが)い様(さま): We're in the same situation (expression)

COMMON COLLOCATIONS:

  • お互(たが)いに理解(りかい)する (to understand each other)
  • お互(たが)いに助(たす)け合(あ)う (to help each other)
  • お互(たが)いに尊重(そんちょう)する (to respect each other)

NOTE: The prefix お is commonly added for politeness (お互(たが)い), though 互(たが)い alone is also used.
