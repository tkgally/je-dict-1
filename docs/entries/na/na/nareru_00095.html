慣(な)れる

なれる
verb (ichidan)
to get used to

Definitions

1. to get used to, to become accustomed to
To become familiar with something through repeated exposure or practice. The thing one gets used to takes the particle に.

Examples

新(あたら)しい仕事(しごと)に慣(な)れました。
I got used to the new job.
日本(にほん)の生活(せいかつ)に慣(な)れましたか。
Have you gotten used to life in Japan?
まだ慣(な)れていません。
I'm not used to it yet.

Notes

TRANSITIVITY: 自動詞(じどうし) (intransitive). No pair verb. Pattern: Xに慣(な)れる (get used to X).

ASPECT: ている indicates resulting state. 慣(な)れている = 'is used to' (accustomed state).

COMMON PATTERNS:

  • 仕事(しごと)に慣(な)れる (get used to work)
  • 生活(せいかつ)に慣(な)れる (get used to life)
  • まだ慣(な)れていない (not used to it yet)
  • 慣(な)れた (got used to it)

Uses に particle. Different from 習(なら)う (to learn) - similar reading, different meaning.
