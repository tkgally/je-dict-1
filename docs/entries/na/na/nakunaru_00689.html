なくなる

なくなる
verb (godan)
to disappear, to run out

Definitions

1. to disappear, to be gone
To cease to exist or be present.
2. to run out, to be used up
For supplies to be exhausted.

Examples

お金(かね)がなくなった。
The money is gone.
痛(いた)みがなくなった。
The pain is gone.
在庫(ざいこ)がなくなった。
We're out of stock.

Notes

なくなる means to disappear or run out.

DON'T CONFUSE:

  • なくなる: to disappear, run out (ない + なる)
  • 亡(な)くなる: to pass away (euphemism for death)

FORMATION:

  • ない (not exist) + なる (become) = なくなる
