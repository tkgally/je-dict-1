早(はや)い者勝(ものが)ち

はやいものがち
expression
first come, first served
1. first come, first served; the early bird gets it
Set phrase stating that whoever acts first gets the thing, with no allowance made for fairness, need, or waiting one's turn. Literally 'the fast one wins'. Used both as a rule announced in advance and as a wry comment after the fact.
席(せき)は早(はや)い者勝(ものが)ちです。
Seats are first come, first served.
数量限定(すうりょうげんてい)なので早(はや)い者勝(ものが)ちですよ。
Quantities are limited, so it's first come, first served.
申(もう)し込(こ)みは先着順(せんちゃくじゅん)、つまり早(はや)い者勝(ものが)ちだ。
Applications are handled in order of arrival — in other words, first come, first served.
いい物件(ぶっけん)は早(はや)い者勝(ものが)ちだから、迷(まよ)っているうちに決(き)まってしまう。
Good properties go to whoever moves first, so while you're hesitating it'll be taken.

Built from 早(はや)い + 者(もの) (person) + 勝(が)ち (winning). Extremely common in sales copy, event notices, and casual speech about anything in short supply.

COMMON COLLOCATIONS:

  • 早(はや)い者勝(ものが)ちです: it's first come, first served
  • 早(はや)い者勝(ものが)ちの世界(せかい): a world where speed decides everything
  • 残(のこ)りわずか、早(はや)い者勝(ものが)ち: only a few left — first come, first served

SIMILAR WORDS:

  • 先着順(せんちゃくじゅん): in order of arrival — the neutral administrative wording used on official notices
  • 抽選(ちゅうせん): lottery; drawing — the usual alternative allocation method, and its natural opposite
