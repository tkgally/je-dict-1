駅名(えきめい)

えきめい
noun
station name
1. station name; the name of a railway station
The official name of a train or subway station, as shown on platform signs, route maps, and in announcements.
駅名(えきめい)を確(たし)かめる。
I check the station name.
来年(らいねん)から駅名(えきめい)が変(か)わるそうだ。
I hear the station name will change from next year.
地元(じもと)の地名(ちめい)をそのまま使(つか)った駅名(えきめい)が多(おお)いが、近(ちか)くの学校(がっこう)や寺(てら)の名前(なまえ)が付(つ)くこともある。
Many station names simply use the local place name, but sometimes the name of a nearby school or temple is used.

駅(えき) (station) + 名(めい) (name). The 名(めい) suffix forms this whole family of words: 地名(ちめい) (place name), 社名(しゃめい) (company name), 書名(しょめい) (book title).

COMMON COLLOCATIONS:

  • 駅名(えきめい)を確(たし)かめる: to check the station name
  • 駅名(えきめい)が変(か)わる: the station name changes
  • 駅名(えきめい)標(ひょう): station name sign (on the platform)
  • 駅名(えきめい)を読(よ)み上(あ)げる: to read out the station names

CULTURAL CONTEXT:
Station renaming is a small but regular news item in Japan, and companies sometimes pay for a station to carry their name. Because station names double as informal neighborhood names, a change affects addresses in conversation too.

SIMILAR WORDS:

  • 地名(ちめい): place name — the wider term; a station name often comes from one
  • 路線名(ろせんめい): line name — the name of the railway line rather than the stop
