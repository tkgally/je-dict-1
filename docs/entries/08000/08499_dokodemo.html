どこでも

どこでも
adverb
anywhere; everywhere
1. anywhere; everywhere
refers to any place without restriction, or all places in a given context
どこでも行(い)ける。
I can go anywhere.
どこでもいいから座(すわ)って。
Sit anywhere you like.
スマホがあれば、どこでも仕事(しごと)ができる。
With a smartphone, I can work anywhere.

COMPOUND:
どこ (where) + でも (even, any)

PATTERN:

The ~でも pattern creates "any-" words:

  • 誰(だれ)でも - anyone
  • 何(なん)でも - anything
  • いつでも - anytime
  • どちらでも - either one

POPULAR CULTURE:
ドラえもん's iconic gadget is called どこでもドア (Anywhere Door) - a door that can transport you anywhere.

CONTRAST:

  • どこでも (anywhere) ↔ どこか (somewhere)
  • どこでも (anywhere) ↔ どこも + neg (nowhere)
  • どこでも (anywhere) ↔ どこにも + neg (to nowhere)
