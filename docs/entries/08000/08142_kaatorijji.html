カートリッジ

かーとりっじ
noun
cartridge; ink cartridge; game cartridge
1. ink cartridge
a replaceable container of ink for printers
インクカートリッジを交換(こうかん)する。
To replace the ink cartridge.
プリンターのカートリッジが切(き)れた。
The printer cartridge has run out.
互換(ごかん)カートリッジを使(つか)っている。
I use compatible cartridges.
2. game cartridge
a removable memory container for video game consoles
ゲームカートリッジを差(さ)し込(こ)む。
To insert a game cartridge.
ファミコンのカートリッジを集(あつ)めている。
I collect Famicom cartridges.
3. cartridge (general)
any removable container or capsule containing material for use in a device
浄水器(じょうすいき)のカートリッジを定期的(ていきてき)に交換(こうかん)する。
Replace the water filter cartridge regularly.

COMMON TYPES:

  • インクカートリッジ (ink cartridge)
  • トナーカートリッジ (toner cartridge)
  • ゲームカートリッジ (game cartridge)
  • 浄水(じょうすい)カートリッジ (water filter cartridge)

RELATED TERMS:

  • 純正(じゅんせい)カートリッジ (genuine/OEM cartridge)
  • 互換(ごかん)カートリッジ (compatible cartridge)
  • 詰(つ)め替(か)え (refill)
general
