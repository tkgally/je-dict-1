1. encryption; encoding
the process of converting data into a coded format to prevent unauthorized access
データを暗号化(あんごうか)して送信(そうしん)する。
Encrypt the data before sending it.
暗号化(あんごうか)された通信(つうしん)は安全(あんぜん)だ。
Encrypted communication is secure.
パスワードは暗号化(あんごうか)して保存(ほぞん)される。
Passwords are stored encrypted.

FORMATION:
暗号(あんごう) (code, cipher) + 化(か) (change into) → turning into code

VERB FORM:
暗号化(あんごうか)する (to encrypt)

ANTONYM:
復号(ふくごう) (decryption)

TECHNICAL TERMS:

  • 暗号化(あんごうか)鍵(かぎ) / 暗号(あんごう)鍵(かぎ) (encryption key)
  • 公開鍵暗号(こうかいかぎあんごう) (public-key encryption)
  • 対称(たいしょう)暗号化(あんごうか) (symmetric encryption)
  • エンドツーエンド暗号化(あんごうか) (end-to-end encryption)
