お返(かえ)し

おかえし
noun
return gift; reciprocal gift
1. a return gift; a reciprocal gift given in response to receiving a gift
a gift given to someone who previously gave you a gift, as part of Japanese gift-giving etiquette
バレンタインのお返(かえ)しを渡(わた)した。
I gave a return gift for Valentine's Day.
結婚式(けっこんしき)の祝儀(しゅうぎ)へのお返(かえ)しを準備(じゅんび)している。
I'm preparing return gifts for the wedding gift money.
お返(かえ)しは頂(いただ)いた金額(きんがく)の半分(はんぶん)ぐらいが目安(めやす)です。
A return gift should be about half the value of what you received.

FORMATION:
お (honorific prefix) + 返(かえ)し (returning) → returning (a favor/gift)

JAPANESE GIFT CULTURE:
お返(かえ)し is an important part of Japanese social customs. When you receive a gift, you are generally expected to give something in return.

COMMON お返(かえ)し OCCASIONS:

  • ホワイトデー (White Day - return for Valentine's)
  • 内祝(うちいわ)い (return gift for celebratory gifts)
  • 香典返(こうでんがえ)し (return gift for condolence money)

VALUE GUIDELINES:

  • 半返(はんがえ)し: Return gift worth half the original value (standard)
  • 三分(さんぶ)の一(いち)返(がえ)し: Return gift worth one-third

RELATED TERMS:

  • 内祝(うちいわ)い (celebratory return gift)
  • 香典返(こうでんがえ)し (funeral return gift)
  • 引(ひき)出物(でもの) (wedding favor)
