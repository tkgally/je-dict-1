記憶力(きおくりょく)

きおくりょく
noun
memory; memory capacity
1. memory; memory capacity
the mental ability to retain and recall information and experiences
彼女(かのじょ)は記憶力(きおくりょく)がいい。
She has a good memory.
年(とし)とともに記憶力(きおくりょく)が衰(おとろ)える。
Memory declines with age.
記憶力(きおくりょく)を鍛(きた)えるゲームをしている。
I'm playing games to train my memory.

FORMATION:
記憶(きおく) (memory) + 力(りょく) (power, ability) → power of memory

COMMON COLLOCATIONS:

  • 記憶力(きおくりょく)がいい/わるい (to have good/bad memory)
  • 記憶力(きおくりょく)を鍛(きた)える (to train one's memory)
  • 記憶力(きおくりょく)が衰(おとろ)える (memory declines)
  • 驚異的(きょういてき)な記憶力(きおくりょく) (incredible memory)

RELATED WORDS:

  • 物忘(ものわす)れ (forgetfulness)
  • 暗記(あんき) (memorization)
  • 記憶術(きおくじゅつ) (memory techniques)
