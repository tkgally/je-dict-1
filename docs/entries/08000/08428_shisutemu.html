システム

しすてむ
noun
system
1. system; organized structure or method
an organized set of principles, procedures, or components working together as a unified whole
システムに障害(しょうがい)が発生(はっせい)した。
A system failure occurred.
新(あたら)しいシステムを導入(どうにゅう)する。
To introduce a new system.
このシステムは使(つか)いやすい。
This system is easy to use.

LOANWORD:
From English "system."

COMMON COMPOUND TERMS:

  • システム開発(かいはつ) (system development)
  • システム管理者(かんりしゃ) (system administrator)
  • システム障害(しょうがい) (system failure)
  • オペレーティングシステム (operating system/OS)

RELATED:

  • 制度(せいど) (system - institutional/social)
  • 体系(たいけい) (system - organized structure)
  • 仕組(しく)み (mechanism, system)
