設立(せつりつ)する

せつりつする
verb-suru
to establish; to found; to set up
See also: 設立(せつりつ) (noun form)
1. to establish; to found; to set up (an organization or institution)
To officially create a new organization, company, institution, or system. Implies formal, deliberate creation with legal or institutional backing.
新(あたら)しい会社(かいしゃ)を設立(せつりつ)した。
I established a new company.
この大学(だいがく)は1900年(ねん)に設立(せつりつ)された。
This university was founded in 1900.
地域(ちいき)の問題(もんだい)を解決(かいけつ)するために、住民(じゅうみん)が協力(きょうりょく)してNPOを設立(せつりつ)した。
To solve local problems, residents cooperated to establish an NPO.

USAGE:
Used for the formal creation of organizations, institutions, and companies. Not used for casual or personal projects. The noun form 設立(せつりつ) is also very common.

COMMON COLLOCATIONS:

  • 会社(かいしゃ)を設立(せつりつ)する (to establish a company)
  • 法人(ほうじん)を設立(せつりつ)する (to establish a corporation)
  • 委員会(いいんかい)を設立(せつりつ)する (to set up a committee)
  • 設立(せつりつ)年(ねん) (year of establishment)
  • 設立(せつりつ)者(しゃ) (founder)

SIMILAR WORDS:

  • 創立(そうりつ): to found — very similar, but emphasizes being the first to create something
  • 創業(そうぎょう): to start a business — specifically about starting commercial operations
  • 設置(せっち): to set up, to install — used for physical things or departments within organizations
