1. to start up; to boot; to launch (a machine or program)
To turn on or activate a computer, application, machine, or system so that it begins operating. The standard term for booting a computer or launching software.
パソコンを起動(きどう)する。
To start up the computer.
アプリを起動(きどう)したが、画面(がめん)が真(ま)っ白(しろ)のままだ。
I launched the app, but the screen stayed blank.
パソコンが正常(せいじょう)に起動(きどう)しない場合(ばあい)は、電源(でんげん)を切(き)って数分(すうふん)待(ま)ってからもう一度(いちど)試(ため)してください。
If the computer does not start up normally, turn off the power, wait a few minutes, and try again.

USAGE:
Used both transitively (パソコンを起動(きどう)する 'start up the computer') and intransitively (パソコンが起動(きどう)する 'the computer starts up'). Essential vocabulary for anyone using computers or smartphones in Japanese.

COMMON COLLOCATIONS:

  • パソコンを起動(きどう)する (boot a computer)
  • アプリを起動(きどう)する (launch an app)
  • 起動(きどう)時間(じかん) (startup time)
  • 起動(きどう)画面(がめん) (startup screen)
  • 再(さい)起動(きどう)する (restart/reboot)

SIMILAR WORDS:

  • 立(た)ち上(あ)げる: to start up/launch — more colloquial synonym
  • 再(さい)起動(きどう)する: to restart/reboot — very commonly used for troubleshooting
