裸足(はだし)

はだし
noun
barefoot; bare feet
1. barefoot; bare feet
The state of not wearing shoes or socks, with feet directly touching the ground.
裸足(はだし)で歩(ある)く。
To walk barefoot.
子(こ)どもたちは裸足(はだし)で砂浜(すなはま)を走(はし)り回(まわ)った。
The children ran around barefoot on the sandy beach.
裸足(はだし)で芝生(しばふ)の上(うえ)を歩(ある)くと気持(きも)ちがいい。
It feels good to walk barefoot on the grass.
2. to put someone to shame (figurative)
Used in the pattern 〜も裸足(はだし)で逃(に)げる to mean someone is so skilled that even a professional would run away barefoot in defeat.
プロも裸足(はだし)で逃(に)げる腕前(うでまえ)だ。
His skill is so great that even professionals would run away barefoot.
彼女(かのじょ)の料理(りょうり)は、シェフも裸足(はだし)で逃(に)げるほどだ。
Her cooking is so good that even chefs would run away barefoot.
素人(しろうと)なのに玄人(くろうと)も裸足(はだし)の出来(でき)だった。
Although an amateur, the result would put professionals to shame.

USAGE:
Also written as 素足(はだし) or はだし in kana. In Japan, going barefoot indoors (after removing slippers) is common in traditional settings, but going barefoot outdoors has the same connotations as in Western cultures.

The figurative expression 〜も裸足(はだし)で逃(に)げる (even ~ would run away barefoot) is an idiom meaning someone is so skilled that professionals would flee in defeat.

COMMON COLLOCATIONS:

  • 裸足(はだし)で歩(ある)く (to walk barefoot)
  • 裸足(はだし)で走(はし)る (to run barefoot)
  • 裸足(はだし)で逃(に)げる (to run away barefoot — figurative for being outclassed)
