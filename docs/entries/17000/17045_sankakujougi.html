三角定規(さんかくじょうぎ)

さんかくじょうぎ
noun
set square; triangle ruler
1. set square; triangle ruler
A triangular drafting tool used for drawing straight lines and angles. In Japan, students typically use a set of two: one with 30-60-90 degree angles and one with 45-45-90 degree angles.
三角定規(さんかくじょうぎ)で線(せん)を引(ひ)いた。
I drew a line with a set square.
算数(さんすう)の授業(じゅぎょう)で三角定規(さんかくじょうぎ)の使(つか)い方(かた)を習(なら)った。
We learned how to use a set square in math class.
二(ふた)種類(しゅるい)の三角定規(さんかくじょうぎ)を組(く)み合(あ)わせると、いろいろな角度(かくど)の線(せん)が引(ひ)ける。
By combining two types of set squares, you can draw lines at various angles.

USAGE:
A standard school supply in Japan. Elementary school students learn to use set squares in arithmetic class. The two standard types are the 30-60-90 triangle and the 45-45-90 triangle. Part of the standard stationery set alongside a ruler (定規(じょうぎ)), compass (コンパス(こんぱす)), and protractor (分度器(ぶんどき)).

COMMON COLLOCATIONS:

  • 三角定規(さんかくじょうぎ)で角度(かくど)を測(はか)る (to measure angles with a set square)
  • 三角定規(さんかくじょうぎ)のセット (a set of triangle rulers)
