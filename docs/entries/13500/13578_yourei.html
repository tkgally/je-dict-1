用例(ようれい)

ようれい
noun
example, usage example
1. usage example, example of use
An example showing how a word, phrase, expression, or tool is actually used. Common in dictionaries, grammar references, and technical documentation.
辞書(じしょ)には豊富(ほうふ)な用例(ようれい)が載(の)っている。
The dictionary contains abundant usage examples.
用例(ようれい)を見(み)れば、使(つか)い方(かた)がよく分(わ)かる。
If you look at the usage examples, you can easily understand how to use it.
この文法書(ぶんぽうしょ)は用例(ようれい)が少(すく)ないので、実際(じっさい)にどう使(つか)うのか分(わ)かりにくい。
This grammar book has few usage examples, so it's hard to understand how the items are actually used.

USAGE:
用例(ようれい) refers specifically to examples that demonstrate how something is used in practice. Most commonly found in discussions about dictionaries, language learning materials, and technical documentation.

COMMON COLLOCATIONS:

  • 用例(ようれい)を示(しめ)す (show usage examples)
  • 用例(ようれい)を集(あつ)める (collect usage examples)
  • 豊富(ほうふ)な用例(ようれい) (abundant examples)
  • 用例(ようれい)検索(けんさく) (example search)

SIMILAR WORDS:

  • 例文(れいぶん): example sentence (specifically a sentence, often in language study)
  • 例(れい): example (general, broader)
  • 実例(じつれい): actual example, real-world case (emphasis on being from real situations)
