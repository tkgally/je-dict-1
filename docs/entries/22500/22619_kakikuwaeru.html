1. to add (in writing); to write in addition; to append
To insert or attach additional written content to an existing document, note, or text, such as appending a remark to a memo or adding a clause to a contract.
メモに一言(ひとこと)書(か)き加(くわ)えた。
I added a word to the memo.
報告書(ほうこくしょ)に新(あたら)しいデータを書(か)き加(くわ)えた。
I added new data to the report.
契約書(けいやくしょ)に条件(じょうけん)を一(ひと)つ書(か)き加(くわ)えてもらえますか。
Could you add one condition to the contract?

A compound verb formed from 書(か)く (to write) and 加(くわ)える (to add). Used when appending or inserting additional written content to an existing document or text.

USAGE:

The target document is marked by に, and the content being added is marked by を:

  • 〜に〜を書(か)き加(くわ)える

COMMON COLLOCATIONS:

  • メモに書(か)き加(くわ)える: to add to a memo
  • 注釈(ちゅうしゃく)を書(か)き加(くわ)える: to add an annotation
  • 補足(ほそく)を書(か)き加(くわ)える: to add a supplement
  • 余白(よはく)に書(か)き加(くわ)える: to write in the margin

SIMILAR WORDS:

  • 付(つ)け加(くわ)える: to add on — more general, not limited to writing
  • 追記(ついき)する: to add a postscript — more formal, often at the end of a document
  • 書(か)き足(た)す: to write more, to supplement — very similar, slightly more casual
