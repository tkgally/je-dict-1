応募書類(おうぼしょるい)

おうぼしょるい
noun
application documents
1. application documents; application materials
The set of documents required when applying for a job, contest, grant, or program. Typically includes a resume, cover letter, and any additional required materials.
応募書類(おうぼしょるい)を準備(じゅんび)する。
I prepare the application documents.
応募書類(おうぼしょるい)の締(し)め切(き)りは来週(らいしゅう)の金曜日(きんようび)です。
The deadline for application documents is next Friday.
応募書類(おうぼしょるい)に不備(ふび)があった場合(ばあい)、選考(せんこう)の対象外(たいしょうがい)となります。
If there are deficiencies in the application documents, you will be excluded from the selection process.

Composed of 応募(おうぼ) (application, entry) and 書類(しょるい) (documents, papers). A common compound in job hunting (就活(しゅうかつ)), scholarship applications, and contest entries.

COMMON COLLOCATIONS:

  • 応募書類(おうぼしょるい)を提出(ていしゅつ)する: to submit application documents
  • 応募書類(おうぼしょるい)の締(し)め切(き)り: application document deadline
  • 応募書類(おうぼしょるい)選考(せんこう): document screening (first stage of hiring)
  • 応募書類(おうぼしょるい)に不備(ふび)がある: deficiencies in application documents

RELATED TERMS:

  • 履歴書(りれきしょ): resume, CV — the standard Japanese-format resume
  • 職務経歴書(しょくむけいれきしょ): work history document — detailed career history, used alongside the resume
  • エントリーシート: entry sheet — a company-specific application form, common in Japanese new-graduate hiring
