切(き)りがない

きりがない
expression
endless; no end to it; boundless
1. endless; no end to it; there is no limit
Expresses that something has no clear stopping point or that it is pointless to continue because there is no end in sight. Often used when one could keep doing something indefinitely but decides it is futile.
言(い)い出(だ)したら切(き)りがない。
Once you start talking about it, there's no end.
心配(しんぱい)しても切(き)りがないから、寝(ね)よう。
There's no end to worrying, so let's go to sleep.
欲(ほ)しいものを数(かぞ)えたら切(き)りがないので、予算(よさん)を決(き)めてから買(か)い物(もの)に行(い)こう。
If you count all the things you want, there's no end, so let's set a budget before going shopping.

A very common expression meaning there is no end or limit to something, often implying futility. The 切(き)り refers to a natural stopping or breaking point. Used when one recognizes that continuing an action would be pointless because it could go on forever.

COMMON PATTERNS:

  • ～たら切(き)りがない: if you start doing X, there's no end
  • ～ても切(き)りがない: even if you do X, there's no end
  • ～出(だ)したら切(き)りがない: once you start X-ing, there's no end

COMMON COLLOCATIONS:

  • 言(い)い出(だ)したら切(き)りがない: once you start listing things, there's no end
  • 数(かぞ)えたら切(き)りがない: if you count them, there's no end
  • 挙(あ)げたら切(き)りがない: if you list them, there's no end

SIMILAR WORDS:

  • 際限(さいげん)がない: limitless — more formal, often used in written Japanese
  • 果(は)てしない: endless — emphasizes physical or temporal vastness
  • きりがない is the most conversational and commonly used in daily speech
