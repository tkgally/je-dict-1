1. to write incorrectly; to misspell; to make a writing error
To make a mistake while writing, such as writing the wrong character, spelling something incorrectly, or writing the wrong number.
名前(なまえ)を書(か)き間違(まちが)えた。
I wrote the name wrong.
漢字(かんじ)を書(か)き間違(まちが)えることがよくある。
I often write kanji incorrectly.
住所(じゅうしょ)を書(か)き間違(まちが)えたせいで、荷物(にもつ)が届(とど)かなかった。
The package didn't arrive because I wrote the address wrong.

A compound verb combining 書(か)く (to write) + 間違(まちが)える (to make a mistake). This is a productive pattern in Japanese where a verb stem + 間違(まちが)える means 'to do [verb] incorrectly.'

COMMON COLLOCATIONS:

  • 漢字(かんじ)を書(か)き間違(まちが)える: to write a kanji wrong
  • 名前(なまえ)を書(か)き間違(まちが)える: to write a name incorrectly
  • 住所(じゅうしょ)を書(か)き間違(まちが)える: to write an address wrong
  • 数字(すうじ)を書(か)き間違(まちが)える: to write a number wrong

RELATED COMPOUND VERBS:

  • 読(よ)み間違(まちが)える: to read incorrectly
  • 聞(き)き間違(まちが)える: to mishear
  • 言(い)い間違(まちが)える: to say incorrectly

TRANSITIVITY:
Transitive. Takes an object with を.
