1. to pack in a box; to box up
To place items into a box for storage, shipping, or presentation. Also used as a noun to describe items that have been boxed.
みかんを箱詰(はこづ)めする。
To pack oranges in a box.
お菓子(かし)を箱詰(はこづ)めにして贈(おく)る。
To box up sweets and give them as a gift.
引(ひ)っ越(こ)しのために荷物(にもつ)を箱詰(はこづ)めする作業(さぎょう)に丸(まる)1日(にち)かかった。
It took a whole day to pack up the belongings in boxes for the move.

Often used as a noun (箱詰(はこづ)め) to describe boxed goods, especially food products sold as gifts.

COMMON COLLOCATIONS:

  • 箱詰(はこづ)めにする: to box up
  • 箱詰(はこづ)めの果物(くだもの): boxed fruit
  • 箱詰(はこづ)めギフト: boxed gift set
  • 箱詰(はこづ)め作業(さぎょう): packing work

SIMILAR WORDS:

  • 梱包(こんぽう)する: to pack, package — more formal, used for shipping
  • 詰(つ)める: to pack, stuff — general verb for filling a container
  • 包装(ほうそう)する: to wrap, package — focuses on wrapping
