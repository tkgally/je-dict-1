おむつ

おむつ
noun
diaper; nappy
1. diaper; nappy
An absorbent garment worn by babies or those who are incontinent. Originally from むつき (swaddling cloth) with the honorific prefix お. Both disposable (紙おむつ) and cloth (布おむつ) types exist.
おむつを替(か)える時間(じかん)だ。
It's time to change the diaper.
赤(あか)ちゃんが泣(な)いているのは、おむつが濡(ぬ)れているからだろう。
The baby is probably crying because the diaper is wet.
子供(こども)が二歳(にさい)になったので、そろそろおむつを外(はず)す練習(れんしゅう)を始(はじ)めたい。
My child has turned two, so I'd like to start potty training soon.

USAGE:
おむつ is the standard everyday word for diapers. The お prefix is not felt as honorific in modern usage — it is simply part of the word.

COMMON COLLOCATIONS:

  • おむつを替(か)える (change a diaper)
  • おむつを外(はず)す (stop using diapers; begin potty training)
  • 紙(かみ)おむつ (disposable diaper)
  • 布(ぬの)おむつ (cloth diaper)
  • おむつ交換台(こうかんだい) (diaper changing table)

RELATED:
おむつが取(と)れる means a child has finished potty training and no longer needs diapers.
