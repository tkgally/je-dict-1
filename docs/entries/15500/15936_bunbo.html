分母(ぶんぼ)

ぶんぼ
noun
denominator
1. denominator
The bottom number in a fraction, which indicates how many equal parts the whole is divided into. Also used figuratively to mean the base or total number in a ratio.
分母(ぶんぼ)が同(おな)じ分数(ぶんすう)を足(た)す。
Add fractions with the same denominator.
分母(ぶんぼ)を揃(そろ)えてから計算(けいさん)してください。
Please find a common denominator before calculating.
合格率(ごうかくりつ)の分母(ぶんぼ)には欠席者(けっせきしゃ)も含(ふく)まれている。
The denominator of the pass rate includes absentees as well.

USAGE:
分母(ぶんぼ) is a basic math term learned in elementary school. Beyond mathematics, it is used in everyday language to discuss rates and ratios — for example, when discussing what counts in the "total" for a percentage.

COMMON COLLOCATIONS:

  • 分母(ぶんぼ)を揃(そろ)える (to find a common denominator)
  • 分母(ぶんぼ)が大(おお)きい (the denominator is large)
  • 分母(ぶんぼ)を増(ふ)やす (to increase the denominator)

RELATED WORDS:
分子(ぶんし) is the numerator (the top number in a fraction). Note that 分子(ぶんし) also means "molecule" in a scientific context.
