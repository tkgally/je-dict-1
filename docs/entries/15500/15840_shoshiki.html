書式(しょしき)

しょしき
noun
format; form; document format
1. format; form; prescribed layout
The standard layout or template for writing documents, letters, or forms. Refers to both the structure of the document and blank forms to be filled in.
書式(しょしき)に従(したが)って記入(きにゅう)してください。
Please fill it in according to the format.
申請(しんせい)書(しょ)の書式(しょしき)はウェブサイトからダウンロードできる。
The application form format can be downloaded from the website.
レポートの書式(しょしき)が決(き)まっているので、必(かなら)ずそれに合(あ)わせて書(か)いてください。
The report format is fixed, so please be sure to follow it when writing.

USAGE:
書式(しょしき) is used in business, academic, and administrative contexts to refer to the prescribed layout or template of documents. In computing, it can also refer to file format or text formatting.

COMMON COLLOCATIONS:

  • 書式(しょしき)に従(したが)う (to follow the format)
  • 書式(しょしき)を整(ととの)える (to format properly)
  • 書式(しょしき)設定(せってい) (format settings, in software)
