それぞれ

それぞれ
noun
each, respectively
1. each, respectively, individually
Used to refer to each thing or person in a group separately.
それぞれの国(くに)に文化(ぶんか)がある。
Each country has its own culture.
学生(がくせい)たちはそれぞれ違(ちが)う意見(いけん)を持(も)っている。
The students each have different opinions.
それぞれの部屋(へや)がある。
Each person has their own room.
メニューを見(み)て、それぞれ好(す)きなものを選(えら)んでください。
Look at the menu and each of you please choose what you like.
卒業(そつぎょう)後(ご)、三人(さんにん)はそれぞれ違(ちが)う道(みち)に進(すす)んだが、今(いま)でも連絡(れんらく)を取(と)り合(あ)っている。
After graduation, the three went their separate ways, but they still keep in touch.

それぞれ means "each" or "respectively," referring to individual members of a group.

GRAMMAR:

  • それぞれの + noun: each (noun)
  • それぞれ + verb: each (does something)
  • Can function as noun or adverb

COMMON PATTERNS:

  • それぞれの国(くに): each country
  • それぞれ違(ちが)う: each different
  • それぞれの意見(いけん): each person's opinion
  • それぞれの道(みち)を行(い)く: to go one's separate ways

SIMILAR WORDS:

  • 各(かく): each (more formal, used with counters)
  • 個々(ここ): individual, each one
  • めいめい: each (older expression)
