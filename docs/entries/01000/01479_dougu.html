道具(どうぐ)

どうぐ
noun
tool, equipment
1. tool, implement, equipment
An object used for a particular purpose.
料理(りょうり)の道具(どうぐ)を揃(そろ)えた。
I gathered cooking utensils.
大工(だいく)道具(どうぐ)を使(つか)う。
I use carpentry tools.
道具(どうぐ)を片(かた)づける。
I put away the tools.

道具(どうぐ) is a general term for tools, implements, and equipment used for specific purposes.

COMMON TYPES:

  • 料理(りょうり)道具(どうぐ): cooking utensils
  • 大工(だいく)道具(どうぐ): carpentry tools
  • 掃除(そうじ)道具(どうぐ): cleaning tools
  • 文房具(ぶんぼうぐ): stationery (writing tools)

COMMON EXPRESSIONS:

  • 道具(どうぐ)を使(つか)う: to use tools
  • 道具(どうぐ)を揃(そろ)える: to gather/prepare tools
  • 道具(どうぐ)を片(かた)づける: to put away tools

SIMILAR WORDS:

  • 工具(こうぐ): mechanical/industrial tools
  • 器具(きぐ): instruments, apparatus
  • 用具(ようぐ): equipment, supplies

道具(どうぐ) is the broadest term, covering everything from kitchen utensils to craft supplies.
