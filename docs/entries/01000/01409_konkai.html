今回(こんかい)

こんかい
noun
this time
1. this time, now
The present occasion or instance.
今回(こんかい)は失敗(しっぱい)した。
I failed this time.
今回(こんかい)の旅行(りょこう)はどうでしたか。
How was this trip?
今回(こんかい)は参加(さんか)できません。
I can't participate this time.
今回(こんかい)の試験(しけん)は難(むずか)しかった。
This exam was difficult.
今回(こんかい)で三回目(さんかいめ)です。
This is the third time.

今回(こんかい) means "this time" or "this occasion," often implying comparison with other times.

COMMON PATTERNS:

  • 今回(こんかい)は〜: this time...
  • 今回(こんかい)の〜: this (current) ...
  • 今回(こんかい)で何回目(なんかいめ): which time is this?
  • 今回(こんかい)に限(かぎ)り: this time only

RELATED 〜回(かい) WORDS:

  • 前回(ぜんかい): last time
  • 次回(じかい): next time
  • 毎回(まいかい): every time
  • 初回(しょかい): first time
  • 今回(こんかい): this time

SIMILAR EXPRESSIONS:

  • 今度(こんど): this time, next time (ambiguous)
  • 今回(こんかい): this time (current occasion, clearer)

NOTE:
今回(こんかい) is commonly used in news and formal contexts to refer to "the current case/incident."
