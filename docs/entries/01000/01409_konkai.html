今回(こんかい)

こんかい
noun
this time
1. this time, now
The present occasion or instance.
今回(こんかい)はだめだった。
It was no good this time.
今回(こんかい)は楽(たの)しかったです。
It was fun this time.
今回(こんかい)の仕事(しごと)は大変(たいへん)だった。
The work this time was tough.
今回(こんかい)は行(い)けなかったけど、今度(こんど)は行(い)きたいと思(おも)う。
I couldn't go this time, but I want to go next time.
今回(こんかい)は時間(じかん)がなくて大変(たいへん)だったが、次(つぎ)はもっとよくしたいと思(おも)う。
This time I didn't have enough time and it was hard, but I want to do better next time.

今回(こんかい) means "this time" or "this occasion," often implying comparison with other times.

COMMON PATTERNS:

  • 今回(こんかい)は〜: this time...
  • 今回(こんかい)の〜: this (current) ...
  • 今回(こんかい)で何回目(なんかいめ): which time is this?
  • 今回(こんかい)に限(かぎ)り: this time only

RELATED 〜回(かい) WORDS:

  • 前回(ぜんかい): last time
  • 次回(じかい): next time
  • 毎回(まいかい): every time
  • 初回(しょかい): first time
  • 今回(こんかい): this time

SIMILAR EXPRESSIONS:

  • 今度(こんど): this time, next time (ambiguous)
  • 今回(こんかい): this time (current occasion, clearer)

NOTE:
今回(こんかい) is commonly used in news and formal contexts to refer to "the current case/incident."
