工具(こうぐ)

こうぐ
noun
tool, implement
1. tool, implement, instrument
A device used to carry out a particular function, especially in manual work.
工具(こうぐ)を使(つか)って修理(しゅうり)した。
I fixed it using tools.
工具(こうぐ)はどこにありますか。
Where are the tools?
電気(でんき)工具(こうぐ)は危険(きけん)だから気(き)をつけて。
Be careful because power tools are dangerous.

工具(こうぐ) refers to tools used for manual work, construction, or repair.

COMMON EXPRESSIONS:

  • 工具(こうぐ)を使(つか)う: to use tools
  • 工具(こうぐ)を揃(そろ)える: to prepare tools
  • 電動(でんどう)工具(こうぐ): power tools

COMPOUNDS:

  • 工具(こうぐ)箱(ばこ): toolbox
  • 工具(こうぐ)セット: tool set
  • 大工(だいく)道具(どうぐ): carpentry tools

SIMILAR WORDS:

  • 道具(どうぐ): tool, instrument (broader meaning, includes household items)
  • 器具(きぐ): utensil, apparatus (often for specific purposes)
  • 用具(ようぐ): equipment, supplies

NOTE:
工具(こうぐ) specifically implies tools for construction, repair, or technical work, while 道具(どうぐ) is more general.

Related Words

Synonym: 道具(どうぐ) (tool (general))
general
