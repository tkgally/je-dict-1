よう

よう
noun
appearance, manner; like, as if

Definitions

1. appearance, manner, way
Describes how something appears or the manner in which something is done.
2. like, as if, similar to
Used to make comparisons or indicate similarity.
3. (in order) to, so that
Expresses purpose or aim when followed by に.

Examples

夢(ゆめ)のようです。
It's like a dream.
Comparison usage
分(わ)かるように説明(せつめい)してください。
Please explain so that I can understand.
Purpose usage with ように
彼(かれ)は怒(おこ)っているようです。
It seems like he's angry.
Appearance/seeming usage

Notes

よう is versatile: 1) ～のよう (like, similar to), 2) ～ようだ/です (seems like, appears to be), 3) ～ように (in order to, so that). The kanji 様 can be used. Related patterns: ような (like a ~), ように (like, in the manner of; so that), ようにする (to make sure to), ようになる (to come to be able to).
