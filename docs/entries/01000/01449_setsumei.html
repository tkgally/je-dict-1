説明(せつめい)

せつめい
noun (verbal)
explanation
1. explanation, description
A statement that makes something clear.
説明(せつめい)を聞(き)いてください。
Please listen to the explanation.
使(つか)い方(かた)を説明(せつめい)します。
I'll explain how to use it.
説明(せつめい)が分(わ)かりやすかった。
The explanation was easy to understand.

説明(せつめい) means explanation or description. As a verbal noun, it forms 説明(せつめい)する (to explain).

COMMON PATTERNS:

  • 説明(せつめい)する: to explain
  • 説明(せつめい)を聞(き)く: to listen to an explanation
  • 説明(せつめい)を受(う)ける: to receive an explanation
  • ～について説明(せつめい)する: to explain about ~

COMMON COMPOUNDS:

  • 説明書(せつめいしょ): instruction manual
  • 説明会(せつめいかい): information session, briefing
  • 自己(じこ)説明(せつめい): self-explanation

SIMILAR WORDS:

  • 解説(かいせつ): commentary, detailed explanation
  • 紹介(しょうかい): introduction
  • 案内(あんない): guidance, information

The phrase 説明(せつめい)が足(た)りない (explanation is insufficient) is common for expressing that something wasn't explained well enough.
