説明(せつめい)

せつめい
noun (verbal)
explanation

Definitions

1. explanation, description
A statement that makes something clear.

Examples

説明(せつめい)を聞(き)いてください。
Please listen to the explanation.
使(つか)い方(かた)を説明(せつめい)します。
I'll explain how to use it.

Notes

説明(せつめい)する is the verbal form. Related: 説明書(せつめいしょ) (instruction manual, explanation document).
