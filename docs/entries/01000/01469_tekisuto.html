テキスト

てきすと
noun
textbook, text
1. textbook
A book used for study in a particular subject.
テキストを開(ひら)いてください。
Please open your textbook.
新(あたら)しいテキストを買(か)った。
I bought a new textbook.
テキストの内容(ないよう)を確認(かくにん)してください。
Please check the content of the textbook.
2. text
Written or printed words.
テキストを入力(にゅうりょく)した。
I entered the text.
テキストをコピーしてください。
Please copy the text.
長(なが)いテキストを読(よ)むのは大変(たいへん)だ。
Reading long text is hard.

テキスト from English "text" has two main meanings in Japanese.

MEANINGS:
1. Textbook: A book used for study (synonym: 教科書(きょうかしょ))
2. Text: Written content, especially in digital contexts

COMMON EXPRESSIONS (textbook):

  • テキストを開(ひら)く: to open a textbook
  • テキストを使(つか)う: to use a textbook
  • テキスト代(だい): textbook fee

COMMON EXPRESSIONS (digital text):

  • テキストを入力(にゅうりょく)する: to input text
  • テキストファイル: text file
  • テキストメッセージ: text message

CONTRAST:
In educational contexts, テキスト sounds slightly more casual than 教科書(きょうかしょ) (official textbook).
