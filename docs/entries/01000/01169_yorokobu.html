1. to be delighted, to be glad, to rejoice
To feel or express happiness about something.
プレゼントをもらって喜(よろこ)んだ。
I was delighted to receive the present.
彼(かれ)は合格(ごうかく)を喜(よろこ)んでいる。
He's happy about passing.
喜(よろこ)んでお手伝(てつだ)いします。
I'd be happy to help.
喜(よろこ)んで = gladly, with pleasure

TRANSITIVITY: Can be both. Pattern: Xを喜(よろこ)ぶ (be happy about X) / Xが喜(よろこ)ぶ (X is happy).

ASPECT: ている indicates state. 喜(よろこ)んでいる = 'is happy/delighted.'

COMMON PATTERNS:

  • Xを喜(よろこ)ぶ (be happy about X)
  • 喜(よろこ)んで (gladly, with pleasure)
  • 喜(よろこ)ばせる (make someone happy—causative)
  • 大喜(おおよろこ)び (great joy)
  • お喜(よろこ)び (congratulations—polite noun)

SET EXPRESSIONS:

  • 喜(よろこ)んで！ (With pleasure! / Gladly!)
  • お喜(よろこ)び申(もう)し上(あ)げます (Congratulations—formal)

RELATED:

  • 喜(よろこ)び (joy, happiness—noun)
  • 嬉(うれ)しい (happy, glad—adjective, more common in casual speech)
