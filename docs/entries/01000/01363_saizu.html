サイズ

さいず
noun
size
1. size
The dimensions or magnitude of something, especially clothing or shoes.
サイズは何(なん)ですか。
What size is it?
このサイズは合(あ)わない。
This size doesn't fit.
Mサイズをください。
Please give me a medium size.

サイズ is a loanword from English "size," used for clothing, shoes, and products.

CLOTHING SIZES:

  • Sサイズ: small
  • Mサイズ: medium
  • Lサイズ: large
  • LLサイズ/XLサイズ: extra large
  • フリーサイズ: one size fits all

COMMON EXPRESSIONS:

  • サイズは何(なん)ですか: What size is it?
  • サイズが合(あ)う: the size fits
  • サイズが合(あ)わない: the size doesn't fit
  • サイズを測(はか)る: to measure the size

RELATED:

  • 寸法(すんぽう): dimensions (technical)
  • 大(おお)きさ: size (native Japanese word)

NOTE:
For drinks and food portions, S/M/L sizes are also used: Mサイズのコーヒー (medium coffee).

Related Words

Synonym: 大(おお)きさ (size (native Japanese))
