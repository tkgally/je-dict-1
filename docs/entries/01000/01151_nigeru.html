逃(に)げる

にげる
verb (ichidan)
to escape, to run away
1. to escape, to flee
To get away from a dangerous or unpleasant situation by leaving quickly.
2. to run away, to avoid
To avoid confrontation or responsibility by leaving.
泥棒(どろぼう)が逃(に)げた。
The thief ran away.
火事(かじ)から逃(に)げる。
Escape from a fire.
から marks what you're escaping from
責任(せきにん)から逃(に)げてはいけない。
You shouldn't run away from responsibility.
Figurative usage

TRANSITIVITY: 自動詞(じどうし) (intransitive). Pair: 逃(に)がす (transitive, to let escape). Pattern: Xから逃(に)げる (escape from X).

ASPECT: ている indicates completed action or ongoing state. 逃(に)げている = 'has escaped' or 'is on the run.'

COMMON PATTERNS:

  • 危険(きけん)から逃(に)げる (escape from danger)
  • 警察(けいさつ)から逃(に)げる (run from police)
  • 責任(せきにん)から逃(に)げる (run from responsibility)
  • 逃(に)げ出(だ)す (run away, make a break for it)
  • 逃(に)げ回(まわ)る (run around trying to escape)

CONTRAST:

  • 逃(に)げる (intransitive): escape, run away
  • 逃(に)がす (transitive): let escape, miss (an opportunity)

RELATED:

  • 逃(に)げ道(みち) (escape route)
  • 逃(とう)亡 (flight, escape—noun, formal)
