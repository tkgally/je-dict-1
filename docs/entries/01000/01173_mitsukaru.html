見(み)つかる

みつかる
verb (godan)
to be found, to be discovered
1. to be found, to be discovered
For something that was lost or hidden to become found. The intransitive form.
2. to be caught, to be detected
For a person doing something wrong to be discovered.
財布(さいふ)が見(み)つかった。
The wallet was found.
仕事(しごと)が見(み)つからない。
I can't find a job.
Common for job hunting
サボっているのが見(み)つかった。
I was caught slacking off.
'Be caught' meaning

TRANSITIVITY: 自動詞(じどうし) (intransitive). Pair: 見(み)つける (transitive, to find). Pattern: Xが見(み)つかる (X is found).

ASPECT: ている indicates resulting state. 見(み)つかっている = 'has been found.'

COMMON PATTERNS:

  • Xが見(み)つかる (X is found)
  • 見(み)つからない (can't be found, can't find)
  • 仕事(しごと)が見(み)つかる (find a job—passive sense)
  • 答(こた)えが見(み)つかる (find an answer)

CONTRAST:

  • 見(み)つかる (intransitive): X is found
  • 見(み)つける (transitive): find X

Example pair:

  • 財布(さいふ)が見(み)つかった (The wallet was found)
  • 財布(さいふ)を見(み)つけた (I found the wallet)
