無(な)くなる

なくなる
verb (godan)
to disappear, to run out
1. to disappear, to be gone
For something to cease to exist or to no longer be present.
本(ほん)が無(な)くなった。
The book is gone.
痛(いた)みが無(な)くなりました。
The pain has gone away.
財布(さいふ)が無(な)くなった。
My wallet is gone.
不安(ふあん)が無(な)くなった。
My anxiety is gone.
問題(もんだい)が無(な)くなった。
The problem has disappeared.
2. to run out, to be used up
For a supply of something to be exhausted or depleted.
お金(かね)が無(な)くなってしまった。
The money ran out.
牛乳(ぎゅうにゅう)が無(な)くなったので、買(か)いに行(い)きます。
The milk has run out, so I'll go buy some.
ガソリンが無(な)くなりそうだ。
We're about to run out of gas.
電池(でんち)が無(な)くなった。
The battery ran out.
時間(じかん)が無(な)くなってきた。
We're running out of time.
在庫(ざいこ)が無(な)くなった。
The stock has run out.
3. to pass away (euphemism)
A polite way to say someone has died (often written as 亡くなる with a different kanji).
祖父(そふ)は去年(きょねん)亡(な)くなりました。長(なが)い間(あいだ)病気(びょうき)でしたが、最後(さいご)は静(しず)かでした。
My grandfather passed away last year. He had been ill for a long time, but the end was peaceful.
亡くなる is the euphemistic 'pass away' sense with different kanji
父(ちち)は三(さん)年前(ねんまえ)に亡(な)くなりました。
My father passed away three years ago.
有名(ゆうめい)な作家(さっか)が亡(な)くなった。
A famous writer passed away.
若(わか)くして亡(な)くなった。
They passed away young.
近所(きんじょ)のおばあさんが先月(せんげつ)亡(な)くなって、家族(かぞく)みんなで悲(かな)しんでいます。
The elderly woman in our neighborhood passed away last month, and our whole family is saddened.

TRANSITIVITY: 自動詞(じどうし) (intransitive). Pair: 無(な)くす (transitive). Pattern: Xが無(な)くなる (X disappears/runs out).

ASPECT: ている indicates resulting state. 無(な)くなっている = 'is gone/has run out.'

COMMON PATTERNS:

  • お金(かね)が無(な)くなる (money runs out)
  • 痛(いた)みが無(な)くなる (pain goes away)
  • 無(な)くなってしまった (it's all gone)
  • 亡(な)くなる (pass away - different kanji)

PAIR: 無(な)くす (transitive) - 財布(さいふ)を無(な)くした (lost wallet). 亡(な)くなる is polite 'pass away'.
