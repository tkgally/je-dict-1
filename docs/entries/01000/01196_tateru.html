立(た)てる

たてる
verb (ichidan)
to stand up, to erect

Definitions

1. to stand (something) up, to erect
To place something in an upright position. The transitive form of 立(た)つ.
2. to make, to establish
To create or establish plans, rules, or abstract things.

Examples

旗(はた)を立(た)てる。
Raise a flag.
計画(けいかく)を立(た)てる。
Make a plan.
Very common expression
音(おと)を立(た)てないでください。
Please don't make noise.
音(おと)を立(た)てる = make a sound

Notes

TRANSITIVITY: 他動詞(たどうし) (transitive). Pair: 立(た)つ (intransitive, to stand). Pattern: Xを立(た)てる (stand X up / make X).

ASPECT: ている indicates resulting state. 立(た)てている = 'has set up' or 'is standing (something).'

COMMON PATTERNS:

  • 計画(けいかく)を立(た)てる (make a plan)
  • 予定(よてい)を立(た)てる (make a schedule)
  • 目標(もくひょう)を立(た)てる (set a goal)
  • 音(おと)を立(た)てる (make a sound)
  • 旗(はた)を立(た)てる (raise a flag)
  • 腹(はら)を立(た)てる (get angry)

HOMOPHONE: Don't confuse with 建(た)てる (to build), which has the same reading.

  • 立(た)てる (立): to stand up, erect (general)
  • 建(た)てる (建): to build (structures)

CONTRAST:

  • 立(た)てる (transitive): stand X up
  • 立(た)つ (intransitive): X stands
