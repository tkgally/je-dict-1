行(ぎょう)

ぎょう
noun, counter
line; row
1. line; row (of text)
A horizontal or vertical line of text in writing, printing, or on a screen. Used when referring to specific positions in documents, code, or printed material.
次(つぎ)の行(ぎょう)を読(よ)んでください。
Please read the next line.
この文章(ぶんしょう)は全部(ぜんぶ)で何行(なんぎょう)ありますか。
How many lines does this passage have in total?
三(さん)行目(ぎょうめ)の最初(さいしょ)の単語(たんご)に誤(あやま)りがあるので、修正(しゅうせい)してください。
There is an error in the first word on the third line, so please correct it.
2. row (in the kana chart)
A row of the Japanese syllabary chart (五十音図), grouping kana that share the same consonant.
「か」は何行(なにぎょう)ですか。
Which row is 'ka' in?
五十音図(ごじゅうおんず)の各行(かくぎょう)には五(いつ)つのかなが並(なら)んでいる。
Each row of the kana chart has five kana lined up.
「さ行(ぎょう)」には「さ・し・す・せ・そ」の五(いつ)つの音(おん)が含(ふく)まれる。
The 'sa row' includes the five sounds 'sa, shi, su, se, so.'

Read as ぎょう, this word refers to a line of text or a row in a chart. Do not confuse with other readings of the same kanji: 行(い)く (to go), 行(おこな)う (to carry out), or 行(こう) (used in compounds like 銀行(ぎんこう)).

As a counter, 行(ぎょう) counts lines of text: 一行(いちぎょう) (one line), 二行(にぎょう) (two lines), 三行(さんぎょう) (three lines). The suffix 行目(ぎょうめ) specifies the ordinal position: 一行目(いちぎょうめ) (first line).

COMMON COLLOCATIONS:

  • 行(ぎょう)を変(か)える: to start a new line
  • 行(ぎょう)間(かん): line spacing
  • 空白行(くうはくぎょう): blank line
  • 行(ぎょう)番号(ばんごう): line number
  • 改行(かいぎょう): line break; new line

KANA CHART USAGE:
In the 五十音図(ごじゅうおんず), each consonant group is called a 行(ぎょう): あ行(あぎょう), か行(かぎょう), さ行(さぎょう), etc. Each column is called a 段(だん) (だん): あ段(あだん), い段(いだん), etc.
