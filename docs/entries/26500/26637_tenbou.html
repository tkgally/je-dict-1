点棒(てんぼう)

てんぼう
noun
point sticks (mahjong scoring sticks)
1. point sticks; scoring sticks used in mahjong
Narrow stick-shaped tokens used to keep score in mahjong. Each player starts with a set number of points represented by these sticks, which are exchanged when a hand is won or lost.
点棒(てんぼう)を配(くば)ってゲームを始(はじ)める。
Distribute the point sticks and start the game.
負(ま)けた人(ひと)は勝(か)った人(ひと)に点棒(てんぼう)を渡(わた)す。
The loser passes point sticks to the winner.
点棒(てんぼう)が全部(ぜんぶ)なくなると飛(と)びとなり、その時点(じてん)で対局(たいきょく)は終了(しゅうりょう)する。
When all point sticks are lost, it's called tobi (bust), and the game ends at that point.

A compound of 点(てん) (points) and 棒(ぼう) (stick/rod). Standard mahjong sets include four denominations of point sticks, each distinguished by colored dots: 100 points, 1,000 points, 5,000 points, and 10,000 points.

COMMON COLLOCATIONS:

  • 点棒(てんぼう)を払(はら)う: pay point sticks
  • 点棒(てんぼう)を受(う)け取(と)る: receive point sticks
  • 点棒(てんぼう)がなくなる: run out of point sticks
  • 点棒(てんぼう)を数(かぞ)える: count point sticks

SIMILAR WORDS:

  • 持(も)ち点(てん): one's current point total
  • 配給(はいきゅう)原点(げんてん): starting point allocation (typically 25,000 or 30,000 points)
  • 牌(はい): mahjong tiles

CULTURAL NOTE:
In Japanese mahjong (麻雀(マージャン)), physical 点棒(てんぼう) are used in live play to track scores. Online mahjong games display the score digitally but the terminology remains the same. The expression 点棒(てんぼう)が飛(と)ぶ (point sticks fly) means to go bankrupt in a game.
