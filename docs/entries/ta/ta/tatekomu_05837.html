立(た)て込(こ)む

たてこむ
verb (godan, intransitive)
to be crowded; to be busy

Definitions

1. to be crowded; to be packed
For a place to be densely crowded with buildings or people.
2. to be busy; to be swamped
To be occupied with many tasks or appointments in succession.

Examples

今日(きょう)は予定(よてい)が立(た)て込(こ)んでいます。
I'm swamped with appointments today.
建物(たてもの)が立(た)て込(こ)んでいる地域(ちいき)だ。
It's an area densely packed with buildings.
仕事(しごと)が立(た)て込(こ)んでいて会(あ)えない。
I'm too busy with work to meet.

Notes

COMPOUND VERB:
立(た)てる (to set up) + 込(こ)む (to become crowded)

TRANSITIVITY:
自動詞(じどうし) (intransitive)

COMMON COLLOCATIONS:

  • 予定(よてい)が立(た)て込(こ)む: to be swamped with appointments
  • 仕事(しごと)が立(た)て込(こ)む: to be busy with work
  • 建物(たてもの)が立(た)て込(こ)む: buildings are densely packed

NUANCE:
Often used to politely decline invitations or explain unavailability—implies being unavoidably busy.
