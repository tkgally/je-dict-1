足(た)す

たす
verb (godan)
to add

Definitions

1. to add (numbers)
To perform mathematical addition.
2. to add, to supplement
To add more of something to make it sufficient.

Examples

3足(た)す5は8です。
3 plus 5 is 8.
Mathematical addition
塩(しお)を足(た)してください。
Please add more salt.
Adding to make sufficient
足(た)りなければ足(た)します。
If it's not enough, I'll add more.

Notes

TRANSITIVITY: 他動詞(たどうし) (transitive). Pattern: Xを足(た)す (add X) / AにBを足(た)す (add B to A).

ASPECT: ている indicates completed action. 足(た)している = 'has added.'

COMMON PATTERNS:

  • 数(かず)を足(た)す (add numbers)
  • AにBを足(た)す (add B to A)
  • 足(た)し算(ざん) (addition—noun)
  • 足(た)りないものを足(た)す (add what's missing)

MATH VOCABULARY:

  • 足(た)す: add (+)
  • 引(ひ)く: subtract (−)
  • 掛(か)ける: multiply (×)
  • 割(わ)る: divide (÷)

RELATED:

  • 足(た)りる: to be sufficient (different verb)
  • 足(た)し算(ざん): addition (noun)
