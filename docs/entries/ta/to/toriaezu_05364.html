とりあえず

とりあえず
adverb
for now; for the time being; first of all

Definitions

1. for now; for the time being
Indicates doing something as a temporary or provisional measure.
2. first of all; to start with
Indicates something as the first step before other things.

Examples

とりあえずビールで乾杯(かんぱい)しよう。
Let's start with beer for now.
Very common at izakayas
とりあえずこれで大丈夫(だいじょうぶ)だと思(おも)います。
I think this is fine for now.
時間(じかん)がないから、とりあえず始(はじ)めよう。
We don't have time, so let's just start.

Notes

とりあえず is extremely common in everyday Japanese.

KANJI: Can be written as 取(と)り敢(あ)えず, though hiragana is more common.

COMMON USES:

  • とりあえずビール: 'beer first' (famous phrase at restaurants)
  • とりあえず連絡(れんらく)します: I'll contact you for now
  • とりあえずOK: It's okay for now

SIMILAR:

  • 一旦(いったん): temporarily, for the moment
  • 差(さ)し当(あ)たり: for the time being (more formal)
