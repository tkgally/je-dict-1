どの

どの
pre-noun adjectival
which (+ noun)

Definitions

1. which
A question word used before a noun to ask which specific item. Always followed by a noun.

Examples

どの本(ほん)が欲(ほ)しいですか？
Which book do you want?
どの電車(でんしゃ)に乗(の)りますか？
Which train will you take?
どの人(ひと)が田中(たなか)さんですか？
Which person is Mr. Tanaka?

Notes

Must be followed by a noun. Part of the こそあど series: この (this), その (that), あの (that over there), どの (which). Compare with どれ (which one) used independently.
