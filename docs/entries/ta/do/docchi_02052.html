どっち

どっち
pronoun
which (of two), which way

Definitions

1. which (of two)
Used to ask about one of two options.
2. which way, which direction
Used to ask about direction.

Examples

どっちがいい？
Which one is better?
駅(えき)はどっちですか。
Which way is the station?
コーヒーと紅茶(こうちゃ)、どっちにする？
Coffee or tea, which will you have?

Notes

どっち is the casual form of どちら.

KO-SO-A-DO SERIES:

  • こっち (this way)
  • そっち (that way - near you)
  • あっち (over there)
  • どっち (which way - question)

FORMALITY:

  • どっち (casual)
  • どちら (polite)

NOTE: Used for choosing between two options. For more than two, use どれ.
