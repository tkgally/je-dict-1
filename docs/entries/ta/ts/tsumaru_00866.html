詰(つ)まる

つまる
verb (godan)
to be packed, to be blocked

Definitions

1. to be packed, to be stuffed
To be filled tightly.
2. to be blocked, to be clogged
To be obstructed.
3. to be stuck (in speech)
Unable to continue speaking.

Examples

鼻(はな)が詰(つ)まっている。
My nose is stuffed up.
言葉(ことば)に詰(つ)まる。
To be at a loss for words.

Notes

詰(つ)まる is intransitive.

TRANSITIVITY:

  • 詰(つ)まる (intransitive): to be blocked
  • 詰(つ)める (transitive): to pack

EXPRESSIONS:

  • つまり: in short, that is to say
