データ

でーた
noun
data

Definitions

1. data; information
Facts, statistics, or information stored or processed by computers.

Examples

データを保存(ほぞん)した。
I saved the data.
データを分析(ぶんせき)している。
I'm analyzing the data.
データが消(き)えてしまった。
The data was lost.

Notes

データ comes from English 'data' and is extremely common in modern Japanese.

COMMON PATTERNS:

  • データを集(あつ)める (collect data)
  • データを入力(にゅうりょく)する (input data)
  • データを削除(さくじょ)する (delete data)
  • データを送(おく)る (send data)
  • データをバックアップ(バックアップ)する (back up data)

DATA TYPES:

  • 個人(こじん)データ (personal data)
  • ビッグデータ (big data)
  • 統計(とうけい)データ (statistical data)
  • 生(なま)データ (raw data)

COMPUTER CONTEXT:

  • データベース (database)
  • データ通信(つうしん) (data communication)
  • データ容量(ようりょう) (data capacity)
  • データセンター (data center)

RELATED WORDS:

  • 情報(じょうほう) (information)
  • 資料(しりょう) (materials, documents)
  • ファイル (file)
