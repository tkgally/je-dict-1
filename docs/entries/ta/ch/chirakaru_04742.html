散(ち)らかる

ちらかる
verb (godan)
to be in disorder, to be messy

Definitions

1. to be in disorder, to be messy, to be cluttered
For a space or area to be in a state of untidiness, with things scattered about.

Examples

部屋(へや)が散(ち)らかっている。
The room is messy.
机(つくえ)の上(うえ)が書類(しょるい)で散(ち)らかっている。
The desk is cluttered with documents.
おもちゃ}が{床(ゆか)に散(ち)らかっていた。
Toys were scattered on the floor.

Notes

TRANSITIVITY: 自動詞(じどうし) (intransitive). Transitive pair: 散(ち)らかす (to make messy).

ASPECT: ている indicates resulting state. 散(ち)らかっている = 'is messy' (state).

COMMON PATTERNS:

  • 部屋(へや)が散(ち)らかる (room becomes messy)
  • Xが散(ち)らかっている (X is scattered/messy)
  • 散(ち)らかった部屋(へや) (a messy room)

TRANSITIVE PAIR:

  • 散(ち)らかる (intransitive) - to be messy
  • 散(ち)らかす (transitive) - to make messy

SIMILAR WORDS:

  • 乱(みだ)れる - to be in disorder (more general)
  • 散(ち)る - to scatter, fall (like petals)

Related Words

Related: 散(ち)らかす (transitive pair)
