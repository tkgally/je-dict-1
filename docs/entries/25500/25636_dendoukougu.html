電動工具(でんどうこうぐ)

でんどうこうぐ
noun
power tool; electric tool
1. power tool; electric tool
A tool powered by electricity or a battery, such as a drill, saw, or sander, as opposed to a hand tool.
電動工具(でんどうこうぐ)を使(つか)うときは安全(あんぜん)に注意(ちゅうい)する。
Be careful about safety when using power tools.
DIYを始(はじ)めるなら、まず基本的(きほんてき)な電動工具(でんどうこうぐ)を揃(そろ)えよう。
If you're starting DIY, first put together a basic set of power tools.
ホームセンターでは電動工具(でんどうこうぐ)のレンタルサービスもあるので、買(か)わなくても気軽(きがる)に使(つか)える。
Home improvement stores also offer power tool rental services, so you can easily use them without buying.

A compound of 電動(でんどう) (electric-powered) and 工具(こうぐ) (tool, implement). DIY (日曜大工(にちようだいく)) culture has grown significantly in Japan, making this a practical everyday term.

COMMON COLLOCATIONS:

  • 電動工具(でんどうこうぐ)セット: power tool set
  • 充電式(じゅうでんしき)電動工具(でんどうこうぐ): rechargeable power tool
  • 電動工具(でんどうこうぐ)を使(つか)いこなす: to master using power tools
  • 電動工具(でんどうこうぐ)売(う)り場(ば): power tools section (of a store)

SIMILAR WORDS:

  • 手工具(てこうぐ): hand tool — tools operated by hand without a motor
  • 工具(こうぐ): tool — the general term for any tool or implement
  • 電動(でんどう)ドリル: electric drill — one common type of power tool
