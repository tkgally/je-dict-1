時間目(じかんめ)

じかんめ
suffix
...th period (of a lesson)
1. ...th period (of a school class)
A suffix attached to numbers to indicate the ordinal period or class session in a school day. For example, 1時間目 means 'first period.'
一(いち)時間目(じかんめ)は数学(すうがく)だ。
First period is math.
三(さん)時間目(じかんめ)の授業(じゅぎょう)に遅(おく)れた。
I was late for the third-period class.
今日(きょう)は六(ろく)時間目(じかんめ)まであるから、帰(かえ)りが遅(おそ)くなる。
Today there are classes up to sixth period, so I'll be home late.

USAGE:
Used with numbers to refer to specific class periods in a school day. Japanese schools typically have 5-6 periods per day. The number comes before 時間目(じかんめ): 一(いち)時間目(じかんめ) (1st period), 二(に)時間目(じかんめ) (2nd period), etc.

COMMON COLLOCATIONS:

  • 一(いち)時間目(じかんめ) (first period)
  • 何(なん)時間目(じかんめ) (which period?)
  • 最後(さいご)の時間目(じかんめ) (last period)
