効(き)く

きく
verb (godan)
to be effective, to work
1. to be effective, to work
To have the intended effect or result.
薬(くすり)が効(き)く。
The medicine is working.
冷房(れいぼう)が効(き)いている。
The air conditioning is on.
2. to be possible, to be able to
To be able to function or be done.
融通(ゆうずう)が効(き)く。
To be flexible.

効(き)く means to be effective or work.

DON'T CONFUSE:

  • 効(き)く: to be effective
  • 聞(き)く: to listen, hear, ask
  • 利(き)く: to work, function

COMMON EXPRESSIONS:

  • 気(き)が利(き)く: to be attentive/thoughtful
  • 融通(ゆうずう)が利(き)く: to be flexible
  • ブレーキが効(き)く: brakes work
