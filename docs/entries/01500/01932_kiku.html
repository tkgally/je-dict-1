効(き)く

きく
verb (godan)
to be effective, to work
1. to be effective, to work
To have the intended effect or result.
薬(くすり)が効(き)く。
The medicine is working.
冷房(れいぼう)が効(き)いている。
The air conditioning is on.
ブレーキがよく効(き)く。
The brakes work well.
Sense 1: be effective
注射(ちゅうしゃ)が効(き)いてきた。
The injection is starting to work.
Sense 1: be effective
暖房(だんぼう)が効(き)いている。
The heating is working.
Sense 1: work
麻酔(ますい)が効(き)いてきた。
The anesthesia is taking effect.
Sense 1: be effective
2. to be possible, to be able to
To be able to function or be done.
融通(ゆうずう)が効(き)く。
To be flexible.
小回(こまわ)りが効(き)く。
It's maneuverable.
Sense 2: be able to
無理(むり)が効(き)く体(からだ)だ。
It's a body that can handle strain.
Sense 2: be possible
応用(おうよう)が効(き)く技術(ぎじゅつ)だ。
It's a versatile skill.
Sense 2: be applicable

効(き)く means to be effective or work.

DON'T CONFUSE:

  • 効(き)く: to be effective
  • 聞(き)く: to listen, hear, ask
  • 利(き)く: to work, function

COMMON EXPRESSIONS:

  • 気(き)が利(き)く: to be attentive/thoughtful
  • 融通(ゆうずう)が利(き)く: to be flexible
  • ブレーキが効(き)く: brakes work
