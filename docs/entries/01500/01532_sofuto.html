ソフト

そふと
noun
soft, software
1. software
Computer programs and applications.
このソフトは使(つか)いやすい。
This software is easy to use.
新(あたら)しいソフトをインストールした。
I installed new software.
無料(むりょう)のソフトをダウンロードして、写真(しゃしん)を編集(へんしゅう)している。
I downloaded free software and am editing photos with it.
2. soft
Not hard or firm; gentle.
ソフトな色(いろ)が好(す)きだ。
I like soft colors.
ソフトクリームを食(た)べた。
I ate soft-serve ice cream.
彼(かれ)はソフトな話(はな)し方(かた)をするので、話(はな)しやすい。
He speaks in a gentle way, so he's easy to talk to.

ソフト is a loanword from English "soft" with two main meanings: software and soft (texture/manner).

SOFTWARE MEANING:

  • ソフト(ウェア): software, applications
  • ソフトを入(い)れる: to install software
  • ソフトを使(つか)う: to use software

SOFT (TEXTURE) MEANING:

  • ソフトな感(かん)じ: soft feeling
  • ソフトな色(いろ): soft colors
  • ソフトな対応(たいおう): gentle response

COMMON COMPOUNDS:

  • ソフトウェア: software
  • ソフトクリーム: soft-serve ice cream
  • ソフトドリンク: soft drink
  • ソフトボール: softball

CONTRAST:

  • ソフト(ウェア): software ↔ ハード(ウェア): hardware
  • ソフト: soft ↔ ハード: hard
