ソフト

そふと
noun
soft, software
1. software
Computer programs and applications.
新(あたら)しいソフトをインストールした。
I installed new software.
このソフトは使(つか)いやすい。
This software is easy to use.
無料(むりょう)のソフトをダウンロードして、写真(しゃしん)を編集(へんしゅう)している。
I downloaded free software and am editing photos with it.
2. soft
Not hard or firm; gentle.
ソフトクリームを食(た)べた。
I ate soft-serve ice cream.
ソフトな色(いろ)が好(す)きだ。
I like soft colors.
彼(かれ)はソフトな話(はな)し方(かた)をするので、話(はな)しやすい。
He speaks in a gentle way, so he's easy to talk to.

From English "soft." Common compounds: ソフトウェア (software), ソフトクリーム (soft-serve ice cream).
