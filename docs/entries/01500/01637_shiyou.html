使用(しよう)

しよう
noun, suru verb
use, usage
1. use, usage, utilization
The act of using something for a particular purpose.
この機械(きかい)の使用(しよう)方法(ほうほう)を教(おし)えてください。
Please teach me how to use this machine.
携帯(けいたい)電話(でんわ)の使用(しよう)は禁止(きんし)されています。
The use of mobile phones is prohibited.
このソフトを使用(しよう)しています。
I am using this software.
使用(しよう)前(まえ)に説明書(せつめいしょ)をよく読(よ)んでください。
Please read the manual carefully before use.
この部屋(へや)は会議(かいぎ)で使用(しよう)中(ちゅう)ですので、お待(ま)ちください。
This room is currently in use for a meeting, so please wait.

使用(しよう) is a formal noun/suru verb meaning use.

TRANSITIVITY (as suru verb):

  • Type: 他動詞(たどうし) (transitive)
  • Pattern: Xを使用(しよう)する (use X)

COMMON PATTERNS:

  • 使用(しよう)方法(ほうほう) (method of use)
  • 使用(しよう)禁止(きんし) (use prohibited)
  • 使用(しよう)中(ちゅう) (in use)
  • 使用(しよう)料(りょう) (usage fee)
  • 使用(しよう)説明書(せつめいしょ) (user manual)

SIMILAR WORDS:

  • 使(つか)う: to use (casual verb)
  • 使用(しよう)する: to use (formal)
  • 利用(りよう)する: to utilize, make use of (broader scope)
