同時(どうじ)

どうじ
noun
simultaneous, same time
1. simultaneous, at the same time
Occurring or done at the same moment in time.
二(ふた)つのことを同時(どうじ)にできません。
I can't do two things at the same time.
同時(どうじ)に始(はじ)めましょう。
Let's start at the same time.
それと同時(どうじ)に、問題(もんだい)も生(しょう)じた。
At the same time, problems also arose.
Common conjunctive use
同時(どうじ)通訳(つうやく)は難(むずか)しい仕事(しごと)だ。
Simultaneous interpretation is a difficult job.
彼(かれ)は仕事(しごと)と勉強(べんきょう)を同時(どうじ)にこなしている。
He is managing work and studies at the same time.

同時(どうじ) means at the same time or simultaneous.

COMMON PATTERNS:

  • 同時(どうじ)に (at the same time)
  • ～と同時(どうじ)に (at the same time as ~)
  • 同時(どうじ)通訳(つうやく) (simultaneous interpretation)
  • 同時(どうじ)進行(しんこう) (simultaneous progress)

GRAMMAR NOTE:
～と同時(どうじ)に is often used as a conjunction meaning 'at the same time as' or 'while also.'
