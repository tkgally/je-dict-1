久(ひさ)しぶり

ひさしぶり
noun, na-adjective
long time (no see)
1. a long time, after a long time
Indicates that something is happening for the first time in a while, or that you haven't seen someone for a long time.
お久(ひさ)しぶりです。
Long time no see. / It's been a while.
Very common greeting
久(ひさ)しぶりに映画(えいが)を見(み)た。
I watched a movie for the first time in a while.
久(ひさ)しぶりの休(やす)みだ。
It's my first day off in a long time.

久(ひさ)しぶり is extremely common in daily conversation.

COMMON PATTERNS:

  • お久(ひさ)しぶりです: Long time no see (polite)
  • 久(ひさ)しぶり！: Long time no see! (casual)
  • 久(ひさ)しぶりに〜する: to do ~ for the first time in a while
  • 久(ひさ)しぶりの〜: ~ for the first time in a while

VARIATIONS:

  • お久(ひさ)しぶりです (polite)
  • 久(ひさ)しぶり (casual)
  • 久々(ひさびさ) (casual, same meaning)

Note: Often written in hiragana or as ひさしぶり in casual contexts.
