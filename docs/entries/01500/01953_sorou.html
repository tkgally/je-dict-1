1. to be complete, to be gathered
For all members or items to be present.
全員(ぜんいん)揃(そろ)った。
Everyone has gathered.
道具(どうぐ)が揃(そろ)った。
The tools are all here.
{メンバー}が揃(そろ)ったら始(はじ)めましょう。
Let's start once everyone is here.
2. to be uniform, to match
For things to be the same or aligned.
意見(いけん)が揃(そろ)う。
Opinions are aligned.
サイズ(さいず)が揃(そろ)っている。
The sizes are uniform.
色(いろ)が揃(そろ)っていて綺麗(きれい)だ。
The colors are uniform and beautiful.

揃(そろ)う has two core meanings: (1) all members/items being present, and (2) things being uniform or aligned.

TRANSITIVITY:

  • Type: 自動詞(じどうし) (intransitive)
  • Pair: 揃(そろ)える (transitive, to arrange/gather)

ASPECT (ている):
揃(そろ)っている indicates a resulting state where everything is now complete or uniform.

COMMON PATTERNS:

  • 全員(ぜんいん)が揃(そろ)う: everyone gathers/is present
  • 道具(どうぐ)が揃(そろ)う: tools are complete
  • 意見(いけん)が揃(そろ)う: opinions are aligned
  • サイズが揃(そろ)っている: sizes are uniform
  • 息(いき)が揃(そろ)う: to be in sync

RELATED EXPRESSIONS:

  • お揃(そろ)い: matching (clothes, items)
  • 揃(そろ)い踏(ぶ)み: lineup, full cast appearing
