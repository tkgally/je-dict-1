タイプ

たいぷ
noun (verbal)
type
1. type, kind
A category of things having common characteristics.
彼女(かのじょ)は私(わたし)のタイプだ。
She's my type.
どんなタイプの映画(えいが)が好(す)き?
What type of movie do you like?
彼(かれ)は真面目(まじめ)なタイプだから、仕事(しごと)を任(まか)せても安心(あんしん)だ。
He's a serious type, so I can trust him with work.
2. typing
Writing using a keyboard.
タイプが速(はや)い。
I type fast.
書類(しょるい)をタイプする。
I'll type up the documents.
毎日(まいにち)パソコンを使(つか)っているので、タイプが速(はや)くなった。
I use a computer every day, so my typing has gotten faster.

タイプ has two distinct meanings from English "type."

MEANINGS:
1. Type/kind: A category or someone's preferred characteristics
2. Typing: Writing with a keyboard (verb form: タイプする)

COMMON EXPRESSIONS (type/kind):

  • 〜のタイプ: the type of ~
  • タイプじゃない: not one's type (romantically)
  • 好(この)みのタイプ: preferred type
  • 〜タイプの人(ひと): a ~-type person

COMMON EXPRESSIONS (typing):

  • タイプする: to type
  • タイプ速度(そくど): typing speed
  • ブラインドタッチ: touch typing

USAGE:
When discussing romantic preferences, 「私(わたし)のタイプ」 (my type) is very common. For keyboard input, タイプする competes with 入力(にゅうりょく)する (to input) and 打(う)つ (to type/hit keys).
