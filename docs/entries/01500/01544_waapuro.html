ワープロ

わーぷろ
noun
word processor
1. word processor
A device or software for creating text documents.
ワープロで文書(ぶんしょ)を作(つく)った。
I created a document with a word processor.
ワープロの使(つか)い方(かた)を教(おし)えてください。
Please teach me how to use the word processor.
昔(むかし)はワープロで書類(しょるい)を作(つく)っていたが、今(いま)はパソコンを使(つか)っている。
I used to create documents with a word processor, but now I use a computer.

ワープロ is an abbreviation of ワードプロセッサー (word processor).

HISTORY:
In the 1980s-90s, dedicated word processor machines were extremely popular in Japan. These standalone devices were specifically designed for Japanese text input and document creation.

COMMON EXPRESSIONS:

  • ワープロで打(う)つ: to type on a word processor
  • ワープロ文書(ぶんしょ): word-processed document
  • ワープロ検定(けんてい): word processor certification exam

USAGE:
Now somewhat dated as パソコン (personal computer) has replaced dedicated word processors. Still used to refer to word processing software, though 文書(ぶんしょ)作成(さくせい)ソフト is more precise.
