出来(でき)る

できる
verb (ichidan)
to be able to, to be made
1. to be able to, can
To have the ability to do something.
日本語(にほんご)が出来(でき)る。
I can speak Japanese.
出来(でき)るだけ早(はや)く。
As soon as possible.
2. to be made, to be completed
For something to come into existence.
準備(じゅんび)が出来(でき)た。
The preparations are done.

出来(でき)る is an ichidan verb with two main meanings: ability and completion/creation.

TRANSITIVITY:
Type: 自動詞(じどうし) (intransitive)

PATTERNS FOR ABILITY:

  • Xが出来(でき)る: can do X, be able to do X
  • V-ることが出来(でき)る: can do V (more formal than V-られる)

PATTERNS FOR COMPLETION:

  • 準備(じゅんび)が出来(でき)た: preparations are done
  • ご飯(はん)が出来(でき)た: the meal is ready

COMMON EXPRESSIONS:

  • 出来(でき)るだけ: as much as possible
  • 出来(でき)れば: if possible
  • 出来(でき)るかぎり: to the best of one's ability

NOTE:
Often written in hiragana as できる in casual writing.
