出来(でき)る

できる
verb (ichidan)
to be able to, to be made

Definitions

1. to be able to, can
To have the ability to do something.
2. to be made, to be completed
For something to come into existence.

Examples

日本語(にほんご)が出来(でき)る。
I can speak Japanese.
準備(じゅんび)が出来(でき)た。
The preparations are done.
出来(でき)るだけ早(はや)く。
As soon as possible.

Notes

出来(でき)る means to be able to or be made.

PATTERNS:

  • Xが出来(でき)る: can do X
  • V-ることが出来(でき)る: can do V

EXPRESSIONS:

  • 出来(でき)るだけ: as much as possible
  • 出来(でき)れば: if possible
