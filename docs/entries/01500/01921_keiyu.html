経由(けいゆ)

けいゆ
noun / suru-verb
via, by way of

Definitions

1. via, by way of, through
Passing through an intermediate point on the way to a destination.

Examples

大阪(おおさか)経由(けいゆ)で東京(とうきょう)へ行(い)く。
To go to Tokyo via Osaka.
成田(なりた)空港(くうこう)経由(けいゆ)
Via Narita Airport.
友人(ゆうじん)を経由(けいゆ)して連絡(れんらく)した。
I contacted them through a friend.
この荷物(にもつ)は香港(ほんこん)を経由(けいゆ)して届(とど)けられたので、配送(はいそう)に時間(じかん)がかかった。
This package was delivered via Hong Kong, so shipping took a long time.

Notes

経由(けいゆ) indicates passing through a point.

COMMON PATTERNS:

  • 〜経由(けいゆ)で (via ~)
  • 〜を経由(けいゆ)して (through ~)
  • 〜経由(けいゆ)の便(びん) (flight via ~)

USAGE:

  • Physical routes: 大阪(おおさか)経由(けいゆ)
  • Communication: 友人(ゆうじん)を経由(けいゆ)して
  • Systems: サーバーを経由(けいゆ)する
