輸入(ゆにゅう)

ゆにゅう
noun, verb (suru)
import

Definitions

1. import, importation
Bringing goods or services into a country from abroad.

Examples

日本(にほん)は石油(せきゆ)を輸入(ゆにゅう)しています。
Japan imports oil.
この車(くるま)は輸入(ゆにゅう)品(ひん)です。
This car is an imported product.
輸入(ゆにゅう)規制(きせい)が厳(きび)しい。
Import regulations are strict.

Notes

輸入(ゆにゅう) means to import goods.

COMMON COLLOCATIONS:

  • 輸入(ゆにゅう)する: to import
  • 輸入(ゆにゅう)品(ひん): imported goods
  • 輸入(ゆにゅう)業者(ぎょうしゃ): importer
  • 輸入(ゆにゅう)規制(きせい): import regulations
  • 輸入(ゆにゅう)禁止(きんし): import ban

OPPOSITE: 輸出(ゆしゅつ) (export)

RELATED: 貿易(ぼうえき) (trade)

Related Words

Antonym: 輸出(ゆしゅつ) (export)
