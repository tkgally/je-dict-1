利用(りよう)

りよう
noun, verb (suru)
use, utilization
1. use, utilization
Making use of something for a purpose.
このサービス(さーびす)は無料(むりょう)で利用(りよう)できます。
You can use this service for free.
図書館(としょかん)を利用(りよう)しています。
I use the library.
時間(じかん)を有効(ゆうこう)に利用(りよう)してください。
Please use your time effectively.

利用(りよう) means to use or make use of.

COMMON PATTERNS:

  • 〜を利用(りよう)する: to use ~
  • 利用(りよう)できる: can use/is available
  • ご利用(りよう)ください: please use (polite)

COMMON COLLOCATIONS:

  • 利用(りよう)者(しゃ): user
  • 利用(りよう)料(りょう): usage fee
  • 利用(りよう)規約(きやく): terms of use

SIMILAR WORDS:

  • 使(つか)う: to use (general)
  • 利用(りよう): to utilize (purposeful use)
