コンピューター

こんぴゅーたー
noun
computer
1. computer
An electronic device for processing data.
コンピューターを使(つか)って仕事(しごと)をする。
I work using a computer.
コンピューターが壊(こわ)れた。
The computer broke.
今(いま)の仕事(しごと)ではコンピューターを毎日(まいにち)使(つか)うので、基本的(きほんてき)な操作(そうさ)は覚(おぼ)えておいた方(ほう)がいい。
You use computers every day in today's jobs, so you should learn the basic operations.

コンピューター is the general term for computer.

ETYMOLOGY:
From English "computer." Also written as コンピュータ (without final long vowel).

COMMON EXPRESSIONS:

  • コンピューターを使(つか)う: to use a computer
  • コンピューターで作業(さぎょう)する: to work on a computer
  • コンピューターが動(うご)かない: the computer won't work

RELATED TERMS:

  • パソコン: personal computer (abbreviation of パーソナルコンピューター)
  • ノートパソコン: laptop
  • デスクトップ: desktop computer
  • タブレット: tablet

COMPOUNDS:

  • コンピューターウイルス: computer virus
  • コンピューターグラフィックス: computer graphics
  • 量子(りょうし)コンピューター: quantum computer
