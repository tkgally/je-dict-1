暗記(あんき)

あんき
noun/suru verb
memorization, learning by heart
1. memorization, learning by heart
Committing something to memory so it can be recalled without reference.
単語(たんご)を暗記(あんき)する。
To memorize vocabulary.
公式(こうしき)を暗記(あんき)しました。
I memorized the formulas.
丸(まる)暗記(あんき)は効果的(こうかてき)ではない。
Rote memorization isn't effective.
丸(まる)暗記(あんき) = rote memorization

暗記(あんき) means memorization, typically through repetition.

COMMON PATTERNS:

  • 暗記(あんき)する (to memorize)
  • 暗記(あんき)できる (can memorize)
  • 丸(まる)暗記(あんき) (rote memorization)

RELATED WORDS:

  • 記憶(きおく): memory (the faculty or stored information)
  • 暗記(あんき): memorization (the act of memorizing)
  • 暗唱(あんしょう): recitation from memory
