プログラム

ぷろぐらむ
noun
program
1. program, schedule
A planned series of events or activities.
今日(きょう)のプログラムを確認(かくにん)した。
I checked today's program.
コンサートのプログラムをもらった。
I got the concert program.
研修(けんしゅう)のプログラムが変更(へんこう)になったので、参加者(さんかしゃ)に連絡(れんらく)した。
The training program changed, so I contacted the participants.
2. computer program
A set of instructions for a computer.
プログラムを書(か)いている。
I'm writing a program.
プログラムにバグがあった。
There was a bug in the program.
新(あたら)しいプログラムを開発(かいはつ)して、仕事(しごと)の効率(こうりつ)を上(あ)げることができた。
I developed a new program and was able to improve work efficiency.

プログラム from English "program" has two main meanings in Japanese.

MEANINGS:
1. Schedule/program: A planned sequence of events (concerts, ceremonies, etc.)
2. Computer program: Software instructions

COMMON EXPRESSIONS (schedule):

  • プログラムを確認(かくにん)する: to check the program
  • 研修(けんしゅう)プログラム: training program
  • 番組(ばんぐみ)プログラム: TV program schedule

COMMON EXPRESSIONS (computer):

  • プログラムを書(か)く/作(つく)る: to write/create a program
  • プログラムを実行(じっこう)する: to run a program
  • プログラミング: programming
  • プログラマー: programmer

USAGE:
Context usually clarifies meaning. For TV shows, 番組(ばんぐみ) is more common than プログラム.
