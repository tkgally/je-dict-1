各(かく)〜

かく
prefix
each ~, every ~

Definitions

1. each, every
A prefix meaning each individual item in a group.

Examples

各自(かくじ)で用意(ようい)してください。
Please prepare individually.
各国(かっこく)の代表(だいひょう)が集(あつ)まった。
Representatives from each country gathered.
各地(かくち)で地震(じしん)が起(お)きた。
Earthquakes occurred in various places.

Notes

各(かく)〜 is a prefix meaning 'each' or 'every,' used before nouns.

COMMON COMPOUNDS:

  • 各自(かくじ): each person, individually
  • 各国(かっこく): each country, various countries
  • 各地(かくち): various places, each place
  • 各社(かくしゃ): each company
  • 各種(かくしゅ): various kinds
  • 各駅(かくえき): each station (各駅停車(かくえきていしゃ) = local train)
  • 各位(かくい): everyone (formal address)

PRONUNCIATION NOTE:

Before か, 各(かく) becomes かっ (gemination):

  • 各国(かっこく) (not かくこく)
  • 各階(かっかい) (each floor)
