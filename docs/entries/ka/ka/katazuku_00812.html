片付(かたづ)く

かたづく
verb (godan)
to be put in order, to be settled

Definitions

1. to be put in order, to be tidied up
For things to become organized.
2. to be settled, to be resolved
For a matter to be concluded.

Examples

部屋(へや)が片付(かたづ)いた。
The room is tidied up.
問題(もんだい)が片付(かたづ)いた。
The problem is resolved.
仕事(しごと)が片付(かたづ)いたら連絡(れんらく)する。
I'll contact you when work is done.

Notes

片付(かたづ)く is intransitive.

TRANSITIVITY:

  • 片付(かたづ)く (intransitive): to be tidied up
  • 片付(かたづ)ける (transitive): to tidy up

COMMON USES:

  • 部屋(へや)が片付(かたづ)く: room gets cleaned up
  • 問題(もんだい)が片付(かたづ)く: problem gets solved
  • 用事(ようじ)が片付(かたづ)く: tasks get done
