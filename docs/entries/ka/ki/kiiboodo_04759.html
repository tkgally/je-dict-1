キーボード

きーぼーど
noun
keyboard

Definitions

1. keyboard (computer)
An input device for computers with keys for typing letters, numbers, and commands.
2. keyboard (musical)
An electronic musical instrument with piano-like keys.

Examples

キーボードを打(う)つのが速(はや)い。
You type fast on the keyboard.
新(あたら)しいキーボードを買(か)った。
I bought a new keyboard.
バンドでキーボードを担当(たんとう)している。
I play keyboard in a band.
Musical keyboard

Notes

From English "keyboard."

COMPUTER KEYBOARD COLLOCATIONS:

  • キーボードを打(う)つ (to type on the keyboard)
  • キーボードを接続(せつぞく)する (to connect a keyboard)
  • ワイヤレスキーボード (wireless keyboard)
  • 日本語(にほんご)キーボード (Japanese keyboard)

MUSICAL KEYBOARD:

  • 電子(でんし)キーボード (electronic keyboard)
  • シンセサイザー (synthesizer)

RELATED TERMS:

  • マウス (mouse)
  • タイピング (typing)
