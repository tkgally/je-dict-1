切(き)れる

きれる
verb (ichidan)
to be cut, to run out

Definitions

1. to be cut, to break
For something to become severed.
2. to run out, to expire
For something to be used up or end.
3. to snap, to lose one's temper
To suddenly become angry.

Examples

糸(いと)が切(き)れた。
The thread broke.
電池(でんち)が切(き)れた。
The battery ran out.
彼(かれ)は切(き)れた。
He snapped (lost his temper).
Colloquial

Notes

切(き)れる means to be cut, run out, or snap.

TRANSITIVITY:

  • 切(き)れる (intransitive): to be cut
  • 切(き)る (transitive): to cut

COMMON USES:

  • 電池(でんち)が切(き)れる: battery dies
  • 期限(きげん)が切(き)れる: expires
  • 息(いき)が切(き)れる: out of breath
