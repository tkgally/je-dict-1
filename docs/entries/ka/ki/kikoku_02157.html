帰国(きこく)

きこく
noun
return to one's country

Definitions

1. return to one's country
To go back to one's home country.

Examples

来月(らいげつ)帰国(きこく)する。
I'll return to my country next month.
帰国(きこく)予定(よてい)。
Scheduled return.
帰国後(きこくご)に連絡(れんらく)する。
I'll contact you after returning.

Notes

帰国(きこく) is a noun/suru-verb meaning to return to one's home country.

COMMON PATTERNS:

  • 帰国(きこく)する (to return to one's country)
  • 帰国(きこく)予定(よてい) (scheduled return)
  • 帰国後(きこくご) (after returning)
  • 一時(いちじ)帰国(きこく) (temporary return home)

RELATED WORDS:

  • 出国(しゅっこく): leaving one's country
  • 入国(にゅうこく): entering a country
  • 帰省(きせい): returning to one's hometown (within same country)
