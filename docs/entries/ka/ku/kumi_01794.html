組(くみ)

くみ
noun / suffix
group, class, team; set

Definitions

1. group, team, set
A collection of people or things organized together.
2. class (in school)
A group of students studying together.
3. (suffix) pair, set of
Used as a counter for sets or pairs of items.

Examples

私(わたし)は３年(ねん)２組(くみ)です。
I'm in Year 3, Class 2.
二人(ふたり)組(ぐみ)で練習(れんしゅう)する。
To practice in pairs.
[Note: 組 becomes ぐみ when used as a suffix]
このグラス一組(ひとくみ)ください。
One set of these glasses, please.

Notes

組(くみ) refers to organized groups or sets.

AS SCHOOL CLASS:

  • ３年(ねん)２組(くみ) (Year 3, Class 2)
  • 同(おな)じ組(くみ) (same class)

AS SUFFIX (becomes ぐみ):

  • 二人(ふたり)組(ぐみ) (pair, duo)
  • 三人(さんにん)組(ぐみ) (trio)
  • 親子(おやこ)組(ぐみ) (parent-child pair)

AS SET:

  • 一組(ひとくみ) (one set)
  • 茶碗(ちゃわん)一組(ひとくみ) (a set of tea bowls)

RELATED WORDS:

  • 組(く)む (to form a group)
  • 組合(くみあい) (union, association)
