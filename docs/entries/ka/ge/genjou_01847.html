現状(げんじょう)

げんじょう
noun
present condition, current state, status quo

Definitions

1. present condition, current state
The current situation or state of affairs.

Examples

現状(げんじょう)を維持(いじ)する。
To maintain the status quo.
現状(げんじょう)を把握(はあく)する。
To grasp the current situation.
現状(げんじょう)に満足(まんぞく)していない。
I am not satisfied with the current situation.

Notes

現状(げんじょう) is the current state of affairs.

COMMON PATTERNS:

  • 現状(げんじょう)維持(いじ) (maintaining the status quo)
  • 現状(げんじょう)分析(ぶんせき) (situation analysis)
  • 現状(げんじょう)を打破(だは)する (to break through the current situation)
