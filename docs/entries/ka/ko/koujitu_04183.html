口実(こうじつ)

こうじつ
noun
excuse, pretext

Definitions

1. excuse, pretext
A reason given to justify an action, often not the true reason; a pretense.

Examples

仕事(しごと)を口実(こうじつ)にして、約束(やくそく)を断(ことわ)った。
I used work as an excuse to turn down the invitation.
〜を口実にして = using ~ as an excuse
病気(びょうき)を口実(こうじつ)に会社(かいしゃ)を休(やす)んだ。
I took a day off from work using illness as an excuse.
それは単(たん)なる口実(こうじつ)に過(す)ぎない。
That's nothing but an excuse.
〜に過ぎない = nothing more than

Notes

USAGE NOTE:
口実(こうじつ) has a negative connotation, implying the stated reason is not the true reason. It suggests deception or avoidance.

COMMON PATTERNS:

  • 〜を口実(こうじつ)にする (to use ~ as an excuse)
  • 〜を口実(こうじつ)にして (using ~ as a pretext)
  • 口実(こうじつ)を設(もう)ける (to make up an excuse)

SIMILAR WORDS:

  • 言(い)い訳(わけ) - excuse, justification (can be legitimate or not)
  • 理由(りゆう) - reason (neutral)
  • 弁解(べんかい) - explanation, defense
