広報(こうほう)

こうほう
noun
public relations; PR; publicity

Definitions

1. public relations; PR; publicity
Activities and communications aimed at promoting a positive image of an organization to the public.

Examples

広報(こうほう)部(ぶ)で働(はたら)いている。
I work in the PR department.
会社(かいしゃ)の広報(こうほう)活動(かつどう)を担当(たんとう)する。
I'm in charge of the company's PR activities.
市(し)の広報(こうほう)誌(し)を読(よ)んだ。
I read the city's public information magazine.

Notes

広報(こうほう) covers both corporate PR and government public information.

COMMON COLLOCATIONS:

  • 広報(こうほう)部(ぶ): PR department
  • 広報(こうほう)活動(かつどう): PR activities
  • 広報(こうほう)担当(たんとう): PR representative
  • 広報(こうほう)誌(し): public information magazine

SIMILAR:

  • PR (ピーアール): public relations
  • 宣伝 (せんでん): advertising, promotion
