メモリー

めもりー
noun
memory (computing); storage; memory (personal)
1. memory; storage (computing)
Computer memory or data storage capacity. Refers to RAM, flash memory, or storage space on devices like smartphones, cameras, and USB drives.
メモリーが足(た)りない。
There isn't enough memory.
スマホのメモリーを増(ふ)やしたい。
I want to increase my smartphone's storage.
パソコンのメモリーを16GBに増設(ぞうせつ)したら、動作(どうさ)が速(はや)くなった。
After upgrading the computer's memory to 16GB, it started running faster.
2. memory; recollection; keepsake
A personal memory or memento. Often used in a sentimental or nostalgic context, especially in song titles, product names, and expressions.
大切(たいせつ)なメモリー。
A precious memory.
旅(たび)のメモリーとして写真(しゃしん)を撮(と)った。
I took photos as travel memories.
学生時代(がくせいじだい)のメモリーが詰(つ)まったアルバムを久(ひさ)しぶりに開(ひら)いた。
I opened an album full of memories from my student days for the first time in a while.

A loanword from English "memory." The computing sense is dominant in everyday usage.

USAGE:
In daily conversation, メモリー most often refers to computer or device memory/storage. The "personal memory" sense is more common in creative and commercial contexts — song titles, photo album branding, event names — and sounds more sentimental than the native 思い出(おもいで). For actual cognitive memory (the ability to remember), 記憶(きおく) is the standard word.

COMMON COLLOCATIONS:

  • メモリー不足(ぶそく): insufficient memory
  • メモリーカード: memory card
  • USBメモリー: USB flash drive
  • メモリーを解放(かいほう)する: to free up memory
  • メモリー増設(ぞうせつ): memory upgrade

SIMILAR WORDS:

  • 記憶(きおく): memory — the native word for the mental faculty of remembering; also used in computing (記憶(きおく)装置(そうち) = storage device)
  • 思い出(おもいで): memory, recollection — the everyday native word for personal memories and reminiscences
  • ストレージ: storage — specifically data storage capacity, distinct from RAM
