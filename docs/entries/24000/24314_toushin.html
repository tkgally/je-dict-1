等身(とうしん)

とうしん
noun
life-size; life-sized; actual size
1. life-size; life-sized; actual size
The same size as the real person or object, used especially for figures, statues, and representations.
寺(てら)に等身(とうしん)の仏像(ぶつぞう)がある。
There is a life-size Buddha statue at the temple.
等身大(とうしんだい)のフィギュアが展示(てんじ)されている。
A life-size figure is on display.
等身大(とうしんだい)の自分(じぶん)でいることが大切(たいせつ)だ。
It's important to be your authentic self.
美術館(びじゅつかん)には等身大(とうしんだい)の蝋人形(ろうにんぎょう)が並(なら)んでいて、まるで本物(ほんもの)の人(ひと)のようだった。
Life-size wax figures were lined up in the museum, looking just like real people.

Used on its own mainly in set compounds such as 等身(とうしん)の仏像(ぶつぞう) (life-size Buddha statue) and 等身(とうしん)像(ぞう) (life-size statue). In everyday Japanese it is almost always used in the compound 等身大(とうしんだい) (life-size). The literal meaning is physical size equal to the actual body, but it has a popular figurative use meaning "natural, authentic, unpretentious" — being one's true size without exaggeration.

COMMON COLLOCATIONS:

  • 等身大(とうしんだい)の — life-size; true-to-life
  • 等身大(とうしんだい)の自分(じぶん) — one's true/authentic self
  • 等身大(とうしんだい)のパネル — life-size standee/panel
  • 等身大(とうしんだい)で生(い)きる — live authentically

USAGE NOTE:
等身大(とうしんだい)の自分(じぶん) is a popular expression meaning to live without pretension, accepting oneself as one is. This figurative use is extremely common in self-help, personal essays, and everyday conversation.

SIMILAR WORDS:

  • 実物大(じつぶつだい) — actual size; similar meaning but emphasizes matching the real object, used more for objects than people
  • 原寸大(げんすんだい) — full scale, actual size; more technical, often used in design and architecture
