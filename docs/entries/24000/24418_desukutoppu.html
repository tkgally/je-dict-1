デスクトップ

ですくとっぷ
noun
desktop; desktop computer
1. desktop computer
A personal computer designed for stationary use on a desk, as opposed to a laptop.
デスクトップパソコンを買(か)った。
I bought a desktop computer.
ゲームにはデスクトップのほうが向(む)いている。
A desktop is better suited for gaming.
会社(かいしゃ)ではデスクトップを使(つか)っているが、自宅(じたく)ではノートパソコンだ。
I use a desktop at work, but a laptop at home.
2. desktop; computer screen background
The main screen of a computer operating system where icons, files, and shortcuts are displayed.
デスクトップにファイルを保存(ほぞん)した。
I saved the file to the desktop.
デスクトップの壁紙(かべがみ)を変(か)えた。
I changed the desktop wallpaper.
デスクトップがアイコンだらけで散(ち)らかっている。
My desktop is cluttered with icons.

A loanword from English "desktop." In Japanese, it functions both as a type of computer and as the screen workspace, just as in English. The abbreviated form デスクトップ is sometimes shortened further to just デスク in casual tech conversation, but this can be confused with the furniture meaning.

COMMON COLLOCATIONS:

  • デスクトップパソコン: desktop PC
  • デスクトップ画面(がめん): desktop screen
  • デスクトップ壁紙(かべがみ): desktop wallpaper
  • デスクトップに置(お)く: to place on the desktop
  • デスクトップ型(がた): desktop type

SIMILAR WORDS:

  • ノートパソコン: laptop — the portable alternative
  • タブレット: tablet — a touchscreen device
  • ラップトップ: laptop — less common than ノートパソコン in Japanese
