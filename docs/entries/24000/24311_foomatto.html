1. format; layout; template
The arrangement, structure, or style in which data, documents, or media are organized.
書類(しょるい)のフォーマットを整(ととの)えた。
I tidied up the document format.
履歴書(りれきしょ)のフォーマットをダウンロードした。
I downloaded a resume template.
ファイルのフォーマットが対応(たいおう)していないため、開(ひら)けなかった。
I couldn't open it because the file format wasn't supported.
2. formatting; initialization (of a disk or device)
The process of preparing a storage device for use by erasing data and setting up a file system.
USBメモリをフォーマットした。
I formatted the USB drive.
フォーマットするとデータが全部(ぜんぶ)消(き)えるので注意(ちゅうい)してください。
Please be careful, as formatting will erase all the data.
ハードディスクをフォーマットしてから、新(あたら)しいOSをインストールした。
After formatting the hard disk, I installed a new OS.

A loanword from English "format" used widely in business, IT, and media contexts. Sense 1 (layout/structure) is used for documents, files, and media types. Sense 2 (disk initialization) is a computing term. Can be used as a noun or with する as a verb (フォーマットする).

COMMON COLLOCATIONS:

  • フォーマットする — to format (a disk)
  • ファイルフォーマット — file format
  • フォーマットに従(したが)う — follow the format
  • フォーマットを変更(へんこう)する — change the format

SIMILAR WORDS:

  • 書式(しょしき) — format, form; the native Japanese term, often used for official document layouts and form templates
  • 形式(けいしき) — form, format, formality; broader term covering the structure or style of something
  • テンプレート — template; specifically a reusable model or pattern, while フォーマット is more about the overall structure
