暗号(あんごう)

あんごう
noun
code, cipher
1. cipher, code
A secret message or system of writing that conceals meaning.
暗号(あんごう)を解読(かいどく)する。
Decrypt a code.
子供(こども)のころ、友達(ともだち)と暗号(あんごう)を作(つく)って手紙(てがみ)を交換(こうかん)した。
When I was a child, my friends and I created codes and exchanged letters.
戦時中(せんじちゅう)、軍(ぐん)は暗号(あんごう)を使(つか)って秘密(ひみつ)の命令(めいれい)を送(おく)っていた。
During wartime, the military used codes to send secret orders.
2. encryption
The process of encoding information to protect it.
データを暗号化(あんごうか)する。
Encrypt the data.
暗号(あんごう)通貨(つうか)に投資(とうし)する。
Invest in cryptocurrency.
メールを暗号化(あんごうか)して送(おく)れば、第三者(だいさんしゃ)に内容(ないよう)を読(よ)まれる心配(しんぱい)がない。
If you encrypt and send the email, there's no worry about a third party reading the contents.

暗号(あんごう) means code, cipher, or encryption - used in both traditional spy/mystery contexts and modern computing.

KANJI BREAKDOWN:
暗(あん) (dark, secret) + 号(ごう) (sign, number) = secret code

COMMON COMPOUNDS:

  • 暗号化(あんごうか): encryption (process)
  • 暗号(あんごう)解読(かいどく): decryption, code-breaking
  • 暗号(あんごう)通貨(つうか): cryptocurrency
  • 暗号(あんごう)キー: encryption key
  • 暗号(あんごう)文(ぶん): ciphertext, coded message

COMMON EXPRESSIONS:

  • 暗号(あんごう)を解(と)く: to crack a code
  • 暗号(あんごう)で送(おく)る: to send in code
  • 暗号(あんごう)を作(つく)る: to create a code

RELATED:

  • 符号(ふごう): code, symbol (more general)
  • パスワード: password
  • 秘密(ひみつ): secret
