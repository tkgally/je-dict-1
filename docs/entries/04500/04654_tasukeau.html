助(たす)け合(あ)う

たすけあう
godan verb
to help each other, to cooperate
1. to help each other, to help one another
To provide mutual assistance, with each party helping the other.
困(こま)った時(とき)は助(たす)け合(あ)いましょう。
Let's help each other when in trouble.
家族(かぞく)は助(たす)け合(あ)って生(い)きていくものだ。
Families are meant to help each other and live together.
災害(さいがい)の時(とき)、地域(ちいき)の人(ひと)たちが助(たす)け合(あ)った。
During the disaster, people in the community helped each other.
2. to cooperate, to support each other
To work together by providing mutual support.

助(たす)け合(あ)う is an intransitive verb (自動詞(じどうし)) meaning to help each other.

COMPOUND STRUCTURE:

  • 助(たす)ける (to help) + 合(あ)う (each other) → to help each other

ASPECT (ている):
助(たす)け合(あ)っている indicates an ongoing state of mutual help.

COMMON PATTERNS:

  • 互(たが)いに助(たす)け合(あ)う (help each other mutually)
  • 困(こま)った時(とき)に助(たす)け合(あ)う (help each other in times of trouble)
  • 助(たす)け合(あ)いの精神(せいしん) (spirit of mutual help)

RELATED NOUN:

  • 助(たす)け合(あ)い: mutual help, mutual aid

SIMILAR COMPOUNDS WITH ～合(あ)う:

  • 支(ささ)え合(あ)う: to support each other
  • 競(きそ)い合(あ)う: to compete with each other
  • 話(はな)し合(あ)う: to discuss with each other
