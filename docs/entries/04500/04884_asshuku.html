圧縮(あっしゅく)

あっしゅく
noun, suru-verb
compression
1. compression
The act of reducing volume or size by applying pressure.
空気(くうき)を圧縮(あっしゅく)する。
Compress air.
2. compression (computing)
The process of reducing file size using algorithms.
ファイルを圧縮(あっしゅく)して送(おく)る。
Compress the file and send it.
圧縮(あっしゅく)ファイルを解凍(かいとう)する。
Extract a compressed file.

圧縮(あっしゅく) means compression, used both physically and in computing. Functions as noun and suru-verb.

WORD FORMATION:
圧(あつ) (pressure) + 縮(しゅく) (shrink)

COMMON EXPRESSIONS:

  • 圧縮(あっしゅく)する: to compress
  • 圧縮(あっしゅく)ファイル: compressed file
  • 圧縮(あっしゅく)率(りつ): compression ratio
  • 圧縮(あっしゅく)空気(くうき): compressed air

COMPUTING TERMS:

  • ZIP圧縮(あっしゅく): ZIP compression
  • 画像(がぞう)圧縮(あっしゅく): image compression
  • 解凍(かいとう)する: to decompress/extract
  • 展開(てんかい)する: to expand (files)

ANTONYM:
解凍(かいとう) (decompression) or 展開(てんかい) (expansion) for computing contexts.
