インストール

いんすとーる
noun (verbal)
install

Definitions

1. install
The process of setting up software or an app on a device.

Examples

アプリをインストールする。
Install an app.
ソフトウェアのインストールが完了(かんりょう)した。
The software installation is complete.
このプログラムをインストールしてください。
Please install this program.

Notes

From English "install." Often shortened to インスト in casual speech.

Common expressions:

  • インストールする (to install)
  • インストール中(ちゅう) (installing)
  • 再(さい)インストール (reinstall)

Related Words

Antonym: アンインストール (uninstall)
