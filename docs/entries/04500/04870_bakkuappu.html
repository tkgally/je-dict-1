1. backup (data)
A copy of data stored separately to protect against loss.
データのバックアップを取(と)る。
Make a backup of the data.
定期的(ていきてき)にバックアップしている。
I back up regularly.
バックアップを取(と)っていなかったので、大事(だいじ)なファイルが全部(ぜんぶ)消(き)えてしまった。
Because I hadn't made a backup, all my important files were lost.
クラウドに自動(じどう)バックアップする設定(せってい)にしておけば、パソコンが壊(こわ)れてもデータは安全(あんぜん)だ。
If you set up automatic cloud backup, your data is safe even if your computer breaks.
2. backup (support)
Support or assistance provided to someone.
チームがバックアップしてくれる。
The team provides support.
先輩(せんぱい)がいつもバックアップしてくれるので、安心(あんしん)して仕事(しごと)ができる。
My senior colleague always backs me up, so I can work with peace of mind.

バックアップ is a loanword from English "backup" with two main meanings: data backup and support/assistance.

SENSE 1 - DATA BACKUP:

  • バックアップを取(と)る: to make a backup
  • バックアップする: to back up (data)
  • 自動(じどう)バックアップ: automatic backup
  • バックアップファイル: backup file
  • クラウドバックアップ: cloud backup

SENSE 2 - SUPPORT:

  • バックアップする: to support, to back up (a person/team)
  • バックアップ体制(たいせい): support system

USAGE NOTE: In computing contexts, this is an essential term. Regular バックアップを取(と)る is strongly recommended for important data.
