挟(はさ)まる

はさまる
verb (godan)
to be caught between; to be sandwiched

Definitions

1. to be caught between; to be sandwiched
To become stuck or trapped between two things.
2. to be inserted; to be placed between
For something to be positioned between two objects.

Examples

歯(は)に食(た)べ物(もの)が挟(はさ)まった。
Food got stuck between my teeth.
指(ゆび)がドアに挟(はさ)まって痛(いた)い。
My finger got caught in the door and it hurts.
本(ほん)の間(あいだ)に古(ふる)い写真(しゃしん)が挟(はさ)まっていた。
An old photograph was tucked between the books.

Notes

挟(はさ)まる is an intransitive verb (自動詞(じどうし)).

TRANSITIVITY:

  • Type: Intransitive (自動詞(じどうし))
  • Pair: 挟(はさ)む (transitive - to pinch, insert)
  • Pattern: Xが〜に挟(はさ)まる

ASPECT ({ている}):
挟(はさ)まっている describes the result state where something is currently stuck or placed between.

COMMON PATTERNS:

  • 歯(は)に挟(はさ)まる (to get stuck in teeth)
  • ドアに挟(はさ)まる (to get caught in a door)
  • 間(あいだ)に挟(はさ)まる (to be caught/placed between)

Often used to describe uncomfortable situations like getting fingers caught or food stuck in teeth.
