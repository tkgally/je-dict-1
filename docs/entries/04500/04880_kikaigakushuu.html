機械学習(きかいがくしゅう)

きかいがくしゅう
noun
machine learning
1. machine learning
A type of artificial intelligence that enables computers to learn from data without explicit programming.
機械学習(きかいがくしゅう)でパターンを認識(にんしき)する。
Recognize patterns through machine learning.
機械学習(きかいがくしゅう)モデルを訓練(くんれん)する。
Train a machine learning model.
機械学習(きかいがくしゅう)を用(もち)いた予測(よそく)。
Predictions using machine learning.

A subfield of artificial intelligence.

Common expressions:

  • 機械学習(きかいがくしゅう)モデル (machine learning model)
  • 機械学習(きかいがくしゅう)アルゴリズム (machine learning algorithm)
  • 教師(きょうし)あり学習(がくしゅう) (supervised learning)
  • 教師(きょうし)なし学習(がくしゅう) (unsupervised learning)
