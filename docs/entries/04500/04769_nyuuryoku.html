入力(にゅうりょく)

にゅうりょく
noun (verbal)
input
1. input
The act of entering data into a computer or device.
パスワードを入力(にゅうりょく)してください。
Please enter your password.
データの入力(にゅうりょく)に時間(じかん)がかかる。
Data entry takes time.
入力(にゅうりょく)内容(ないよう)を確認(かくにん)する。
Verify the input content.

入力(にゅうりょく) means input or data entry, commonly used in computing contexts.

WORD FORMATION:
入(にゅう) (enter) + 力(りょく) (power/force) = entering data

GRAMMAR:
Used as a suru verb: 入力(にゅうりょく)する (to input, to enter)

COMMON EXPRESSIONS:

  • 入力(にゅうりょく)する: to input, to enter
  • 入力(にゅうりょく)ミス: input error, typo
  • 入力(にゅうりょく)フォーム: input form
  • 入力(にゅうりょく)内容(ないよう): input content
  • 音声(おんせい)入力(にゅうりょく): voice input
  • 文字(もじ)入力(にゅうりょく): text input

CONTRAST:

  • 入力(にゅうりょく): input
  • 出力(しゅつりょく): output

Related Words

Antonym: 出力(しゅつりょく) (output)
