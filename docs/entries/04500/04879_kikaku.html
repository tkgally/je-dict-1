企画(きかく)

きかく
noun, verb (suru)
planning, project
1. planning, project, proposal
The act of planning something; a planned project or event.
新(あたら)しい企画(きかく)を立(た)てる。
To create a new plan/project.
企画(きかく)部(ぶ)で働(はたら)いています。
I work in the planning department.
この企画(きかく)は面白(おもしろ)そうだ。
This project looks interesting.

Very common in business contexts. 企画(きかく)部(ぶ) (planning department), 企画(きかく)書(しょ) (project proposal). Can refer to both the planning process and the planned project itself.
