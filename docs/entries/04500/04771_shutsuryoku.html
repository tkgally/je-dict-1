1. output
Data or information produced by a computer or device.
データを出力(しゅつりょく)する。
Output the data.
プリンターで出力(しゅつりょく)する。
Print it out on the printer.
出力(しゅつりょく)結果(けっか)をファイルに保存(ほぞん)した。
I saved the output results to a file.
2. power output
The amount of power produced by an engine or machine.
出力(しゅつりょく)が大(おお)きい。
The power output is high.
このエンジンの出力(しゅつりょく)は200馬力(ばりき)だ。
This engine has an output of 200 horsepower.
太陽光(たいようこう)パネルの出力(しゅつりょく)は天気(てんき)によって変(か)わる。
The output of solar panels varies depending on the weather.

出力(しゅつりょく) means output - either data produced by a computer/device, or power generated by an engine.

COMMON EXPRESSIONS:

  • 出力(しゅつりょく)する: to output
  • 出力(しゅつりょく)結果(けっか): output result
  • 出力(しゅつりょく)形式(けいしき): output format
  • 最大(さいだい)出力(しゅつりょく): maximum output

CONTEXTS:

  • Computing: データを出力(しゅつりょく)する (output data)
  • Printing: プリンターで出力(しゅつりょく)する (print out)
  • Engineering: エンジンの出力(しゅつりょく) (engine output/horsepower)

CONTRAST:

  • 出力(しゅつりょく): output
  • 入力(にゅうりょく): input

These form a natural pair in computing contexts: 入力(にゅうりょく)と出力(しゅつりょく) (input and output, I/O).

Antonym: 入力(にゅうりょく) (input)
