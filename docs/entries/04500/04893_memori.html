メモリ

めもり
noun
memory
1. memory (computing)
A computer component used for temporary data storage during operation.
メモリを増設(ぞうせつ)する。
Add more memory.
メモリが不足(ふそく)している。
There is insufficient memory.
このパソコンは８GBのメモリを搭載(とうさい)している。
This computer has 8GB of memory installed.

メモリ refers to computer memory, specifically RAM (Random Access Memory).

COMMON EXPRESSIONS:

  • メモリ容量(ようりょう): memory capacity
  • メモリ不足(ふそく): insufficient memory
  • メモリを増設(ぞうせつ)する: to add more memory
  • メモリを解放(かいほう)する: to free up memory
  • USBメモリ: USB flash drive

RELATED TERMS:

  • RAM: RAM (technical term)
  • ストレージ: storage (for permanent data)
  • ハードディスク: hard disk
  • SSD: solid state drive

DISTINCTION:
メモリ (RAM) is for temporary data while the computer runs. ストレージ (storage) is for permanent data saved to disk.

Related Words

Contrast: ストレージ (storage (permanent))
Related: ハードディスク (hard disk)
