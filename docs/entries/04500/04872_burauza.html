ブラウザ

ぶらうざ
noun
browser
1. browser
A software application used to access and view websites on the internet.
ブラウザを開(ひら)く。
Open the browser.
どのブラウザを使(つか)っていますか。
Which browser do you use?
ブラウザの履歴(りれき)を削除(さくじょ)する。
Delete the browser history.

ブラウザ refers to software used to view websites on the internet.

ETYMOLOGY:
From English "browser." Also written as ブラウザー (with long vowel).

COMMON EXPRESSIONS:

  • ブラウザを開(ひら)く: to open the browser
  • ブラウザを閉(と)じる: to close the browser
  • ブラウザの履歴(りれき): browser history
  • ブラウザの拡張(かくちょう)機能(きのう): browser extension
  • ウェブブラウザ: web browser

COMPOUNDS:

  • ブラウザゲーム: browser game
  • モバイルブラウザ: mobile browser
  • デフォルトブラウザ: default browser

Popular browsers include Chrome, Safari, Firefox, and Edge.
