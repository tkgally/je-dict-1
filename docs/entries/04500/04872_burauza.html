ブラウザ

ぶらうざ
noun
browser

Definitions

1. browser
A software application used to access and view websites on the internet.

Examples

ブラウザを開(ひら)く。
Open the browser.
どのブラウザを使(つか)っていますか。
Which browser do you use?
ブラウザの履歴(りれき)を削除(さくじょ)する。
Delete the browser history.

Notes

From English "browser." Also written as ブラウザー.

Common expressions:

  • ウェブブラウザ (web browser)
  • ブラウザの履歴(りれき) (browser history)
  • ブラウザの拡張(かくちょう)機能(きのう) (browser extension)
