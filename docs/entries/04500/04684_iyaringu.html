イヤリング

いやりんぐ
noun
clip-on earrings

Definitions

1. clip-on earrings; non-pierced earrings
Ear ornaments that attach without requiring pierced ears, using clips or screws.

Examples

耳(みみ)に穴(あな)を開(あ)けたくないからイヤリングにしている。
I wear clip-on earrings because I don't want to pierce my ears.
このイヤリングは長時間(ちょうじかん)つけていると痛(いた)くなる。
These clip-on earrings hurt if worn for a long time.
真珠(しんじゅ)のイヤリングをもらった。
I received pearl clip-on earrings.

Notes

In Japanese, イヤリング specifically refers to clip-on earrings (without piercing), while ピアス refers to earrings for pierced ears.

IMPORTANT DISTINCTION:

  • イヤリング: Clip-on, no piercing required
  • ピアス: For pierced ears only

This is opposite to English usage where 'earring' is the general term and can refer to both types.

COMMON COLLOCATIONS:

  • イヤリングをつける (to put on clip-on earrings)
  • イヤリングを外(はず)す (to remove clip-on earrings)

TYPES:

  • クリップ式(しき)イヤリング (clip-style)
  • ネジ式(しき)イヤリング (screw-back style)
  • マグネットイヤリング (magnetic clip-on)

Related Words

Contrast: ピアス (pierced earrings)
