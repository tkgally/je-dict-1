データベース

でーたべーす
noun
database
1. database
An organized collection of data stored and accessed electronically, typically managed by a database management system.
顧客(こきゃく)データベースを検索(けんさく)する。
Search the customer database.
データベースに情報(じょうほう)を登録(とうろく)する。
Register information in the database.
データベースの構築(こうちく)に１年(ねん)かかった。
It took one year to build the database.

データベース is a loanword from English 'database'. Often abbreviated to DB.

COMMON TYPES:

  • リレーショナルデータベース (relational database)
  • クラウドデータベース (cloud database)
  • 顧客(こきゃく)データベース (customer database)

COMMON COLLOCATIONS:

  • データベースを構築(こうちく)する (to build a database)
  • データベースを管理(かんり)する (to manage a database)
  • データベースに登録(とうろく)する (to register in a database)
  • データベースから取(と)り出(だ)す (to retrieve from a database)

RELATED TERMS:

  • データ (data)
  • SQL (database query language)
  • バックアップ (backup)
