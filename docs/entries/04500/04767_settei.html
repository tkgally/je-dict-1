設定(せってい) is a verbal noun meaning to set up, configure, or establish. Functions as both noun and suru-verb.

MEANINGS:
1. Settings/configuration (technical): options on devices or software
2. Setting (creative): time, place, circumstances of a story

COMMON EXPRESSIONS:

  • 設定(せってい)する: to set up, configure
  • 設定(せってい)を変更(へんこう)する: to change settings
  • 設定(せってい)を確認(かくにん)する: to check settings

COMPOUNDS:

  • 初期(しょき)設定(せってい): default settings
  • 設定(せってい)画面(がめん): settings screen
  • 目標(もくひょう)設定(せってい): goal setting
  • 価格(かかく)設定(せってい): price setting

Note: Very common in technology contexts. The creative "setting" meaning is used when discussing stories, games, or films.
