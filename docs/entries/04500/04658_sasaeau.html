支(ささ)え合(あ)う

ささえあう
godan verb
to support each other
1. to support each other
To provide mutual support, with each party helping to sustain the other emotionally, physically, or financially.
夫婦(ふうふ)は支(ささ)え合(あ)って生(い)きていく。
A married couple lives by supporting each other.
辛(つら)い時(とき)こそ支(ささ)え合(あ)うことが大切(たいせつ)だ。
It's especially important to support each other during difficult times.
地域(ちいき)で支(ささ)え合(あ)う社会(しゃかい)を目指(めざ)す。
We aim for a society where the community supports each other.

支(ささ)え合(あ)う is an intransitive verb (自動詞(じどうし)) meaning to support each other.

COMPOUND STRUCTURE:

  • 支(ささ)える (to support) + 合(あ)う (each other) → to support each other

ASPECT (ている):
支(ささ)え合(あ)っている indicates an ongoing state of mutual support.

COMMON PATTERNS:

  • 互(たが)いに支(ささ)え合(あ)う (support each other mutually)
  • 困難(こんなん)を乗(の)り越(こ)えて支(ささ)え合(あ)う (support each other through difficulties)
  • 支(ささ)え合(あ)いの関係(かんけい) (mutually supportive relationship)

RELATED NOUN:

  • 支(ささ)え合(あ)い: mutual support

SIMILAR WORDS:

  • 助(たす)け合(あ)う: to help each other (more active assistance)
  • 支(ささ)え合(あ)う emphasizes ongoing support rather than immediate help
