社会保障(しゃかいほしょう)

しゃかいほしょう
noun
social security
1. social security, social welfare
Government programs providing assistance for healthcare, pensions, and other needs.
社会保障(しゃかいほしょう)制度(せいど)を改革(かいかく)する。
Reform the social security system.
社会保障(しゃかいほしょう)費(ひ)が増加(ぞうか)している。
Social security costs are increasing.
社会保障(しゃかいほしょう)に頼(たよ)る。
Rely on social security.

社会保障(しゃかいほしょう) refers to government programs providing financial support for healthcare, pensions, unemployment, and other welfare needs.

COMPONENTS:

  • 社会(しゃかい): society
  • 保障(ほしょう): guarantee, security

JAPAN'S SOCIAL SECURITY SYSTEM INCLUDES:

  • 年金(ねんきん): pensions
  • 医療保険(いりょうほけん): health insurance
  • 介護保険(かいごほけん): nursing care insurance
  • 雇用保険(こようほけん): unemployment insurance
  • 生活保護(せいかつほご): public assistance/welfare

COMMON COLLOCATIONS:

  • 社会保障(しゃかいほしょう)制度(せいど): social security system
  • 社会保障(しゃかいほしょう)費(ひ): social security expenses
  • 社会保障(しゃかいほしょう)番号(ばんごう): social security number (マイナンバー)
  • 社会保障(しゃかいほしょう)改革(かいかく): social security reform
