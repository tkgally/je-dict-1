アプリケーション

あぷりけーしょん
noun
application
1. application (software)
A computer program designed for a specific purpose.
アプリケーションを起動(きどう)する。
Launch an application.
新(あたら)しいアプリケーションを開発(かいはつ)する。
Develop a new application.
ビジネスアプリケーションを導入(どうにゅう)する。
Implement business applications.

アプリケーション refers to software applications, especially computer programs designed for specific tasks. Borrowed from English "application."

ABBREVIATION: Often shortened to アプリ in casual speech. This shortened form is very common, especially for mobile apps.

COMMON EXPRESSIONS:

  • アプリを起動(きどう)する: to launch an app
  • アプリを閉(と)じる: to close an app
  • アプリをインストールする: to install an app
  • アプリを削除(さくじょ)する: to delete an app

TYPES:

  • モバイルアプリ: mobile app
  • ウェブアプリケーション: web application
  • デスクトップアプリ: desktop application

RELATED TERMS:

  • ソフトウェア: software
  • ダウンロード: download
  • アップデート: update
