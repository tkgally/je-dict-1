アルゴリズム

あるごりずむ
noun
algorithm
1. algorithm
A step-by-step procedure or set of rules for solving a problem, especially in computing and mathematics.
検索(けんさく)アルゴリズムを改良(かいりょう)する。
Improve the search algorithm.
SNSのアルゴリズムがコンテンツを選(えら)ぶ。
The social media algorithm selects content.
効率的(こうりつてき)なアルゴリズムを設計(せっけい)する。
Design an efficient algorithm.

アルゴリズム is a loanword from English 'algorithm'.

COMMON TYPES:

  • 検索(けんさく)アルゴリズム (search algorithm)
  • 推薦(すいせん)アルゴリズム (recommendation algorithm)
  • 機械(きかい)学習(がくしゅう)アルゴリズム (machine learning algorithm)
  • 暗号(あんごう)アルゴリズム (encryption algorithm)

COMMON COLLOCATIONS:

  • アルゴリズムを開発(かいはつ)する (to develop an algorithm)
  • アルゴリズムを実装(じっそう)する (to implement an algorithm)
  • アルゴリズム取引(とりひき) (algorithmic trading)

MODERN USAGE:
The word has entered mainstream vocabulary through discussions of social media and AI, where algorithms determine what content users see.
