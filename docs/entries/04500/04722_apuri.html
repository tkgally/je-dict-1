アプリ

あぷり
noun
app, application
1. app, application
Software designed for a specific purpose, especially on smartphones. Short for アプリケーション.
この便利(べんり)なアプリをダウンロードしてください。
Please download this useful app.
最近(さいきん)、新(あたら)しいアプリを作(つく)っています。
I've been developing a new app recently.
このアプリは無料(むりょう)で使(つか)えます。
This app can be used for free.

アプリ is an abbreviation of アプリケーション (application), referring to software programs, especially for smartphones.

COMMON EXPRESSIONS:

  • アプリをダウンロードする: to download an app
  • アプリを入(い)れる: to install an app
  • アプリを消(け)す / 削除(さくじょ)する: to delete an app
  • アプリを開(ひら)く: to open an app
  • アプリを更新(こうしん)する: to update an app

TYPES OF APPS:

  • 無料(むりょう)アプリ: free app
  • 有料(ゆうりょう)アプリ: paid app
  • ゲームアプリ: game app
  • SNSアプリ: social media app

RELATED TERMS:

  • アプリ開発(かいはつ): app development
  • アプリ内課金(ないかきん): in-app purchase
  • アプリストア: app store
  • ウェブアプリ: web application
