クラウド

くらうど
noun
cloud
1. cloud (computing)
Internet-based computing services that store data and applications remotely.
データをクラウドに保存(ほぞん)する。
Save data to the cloud.
クラウドサービスを利用(りよう)している。
I use cloud services.
写真(しゃしん)はすべてクラウドに上(あ)げている。
I upload all my photos to the cloud.

クラウド is a loanword from English 'cloud,' used in computing contexts for internet-based services and storage.

NOT TO BE CONFUSED WITH:
雲(くも) = cloud (weather phenomenon)

COMMON COMPOUNDS:

  • クラウドサービス: cloud service
  • クラウドストレージ: cloud storage
  • クラウドコンピューティング: cloud computing
  • クラウド環境(かんきょう): cloud environment

COMMON EXPRESSIONS:

  • クラウドに保存(ほぞん)する: to save to the cloud
  • クラウドに上(あ)げる: to upload to the cloud
  • クラウドから取(と)り出(だ)す: to retrieve from the cloud
  • クラウド上(じょう)で: on the cloud
  • クラウドベース: cloud-based

RELATED TECH TERMS:

  • サーバー: server
  • データセンター: data center
  • バックアップ: backup
  • オンライン: online
