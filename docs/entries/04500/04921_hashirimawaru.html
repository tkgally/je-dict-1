走(はし)り回(まわ)る

はしりまわる
godan verb
to run around

Definitions

1. to run around
To run in various directions, typically with high energy, often used for children or animals.
2. to rush about, to run around busily
To be very busy running from place to place to get things done.

Examples

犬(いぬ)が庭(にわ)を走(はし)り回(まわ)っている。
The dog is running around the yard.
子供(こども)たちは元気(げんき)に走(はし)り回(まわ)っていた。
The children were energetically running around.
仕事(しごと)で一日中(いちにちじゅう)走(はし)り回(まわ)っていた。
I was running around all day for work.
[Note: Figurative use meaning to be very busy]

Notes

走(はし)り回(まわ)る is an intransitive verb (自動詞(じどうし)) meaning to run around.

COMPOUND STRUCTURE:

  • 走(はし)る (to run) + 回(まわ)る (to go around) → to run around

ASPECT (ている):
走(はし)り回(まわ)っている indicates an ongoing action of running around, often with energy.

COMMON PATTERNS:

  • 元気(げんき)に走(はし)り回(まわ)る (run around energetically)
  • あちこち走(はし)り回(まわ)る (run around everywhere)
  • 忙(いそが)しく走(はし)り回(まわ)る (run around busily)

USAGE NOTE:
Often used for children playing or animals being active. Also used figuratively to describe being very busy and having to go to many places.
