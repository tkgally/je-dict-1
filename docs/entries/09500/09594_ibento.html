イベント

いべんと
noun
event
1. event, happening, occasion
A planned public or social occasion.
駅前(えきまえ)広場(ひろば)でイベントが開(ひら)かれている。
An event is being held in the station square.
週末(しゅうまつ)にイベントがある。
There's an event this weekend.
イベントを企画(きかく)する。
To plan an event.

イベント is a loanword from English "event."

COMMON COLLOCATIONS:

  • イベントを開(ひら)く: to hold an event
  • イベントを企画(きかく)する: to plan an event
  • イベント会場(かいじょう): event venue
  • イベント情報(じょうほう): event information
  • 特別(とくべつ)イベント: special event

TYPES OF EVENTS:

  • スポーツイベント: sports event
  • 音楽(おんがく)イベント: music event
  • 企業(きぎょう)イベント: corporate event
