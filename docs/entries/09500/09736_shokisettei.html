初期(しょき)設定(せってい)

しょきせってい
noun
initial setup; default settings
1. initial setup; first-time setup
The process of configuring a new device, software, or account for the first time.
新(あたら)しいスマホの初期(しょき)設定(せってい)をした。
I did the initial setup on my new smartphone.
初期(しょき)設定(せってい)に30分(ぷん)くらいかかった。
The initial setup took about 30 minutes.
Wi-Fiの初期(しょき)設定(せってい)が難(むずか)しかった。
The Wi-Fi initial setup was difficult.
2. default settings; factory settings
The original configuration that a device or software comes with before any customization.
初期(しょき)設定(せってい)に戻(もど)す。
To restore to default settings.
初期(しょき)設定(せってい)のままで使(つか)っている。
I'm using it with the default settings.
不具合(ふぐあい)があったので初期(しょき)設定(せってい)にリセットした。
There was a problem, so I reset it to factory settings.

WORD FORMATION:
初期(しょき) (initial/early stage) + 設定(せってい) (settings/configuration). Has two distinct senses depending on context.

SENSE 1 — INITIAL SETUP:

The process of configuring something for the first time.

  • 初期(しょき)設定(せってい)をする: to do initial setup
  • 初期(しょき)設定(せってい)ガイド: setup guide
  • 初期(しょき)設定(せってい)画面(がめん): setup screen

SENSE 2 — DEFAULT SETTINGS:

The original/factory configuration before customization.

  • 初期(しょき)設定(せってい)に戻(もど)す: to restore to default settings
  • 初期(しょき)設定(せってい)のまま: as-is with default settings

RELATED TERMS:

  • 工場出荷時(こうじょうしゅっかじ)の設定(せってい): factory settings (more formal)
  • リセット: reset
  • デフォルト: default (loanword, also common in tech)
  • 初期化(しょきか): initialization/formatting (more drastic than resetting settings)
