問題集(もんだいしゅう)

もんだいしゅう
noun
workbook, problem set, exercise book
1. workbook, problem set, exercise book
A book containing practice problems or exercises for study, typically used for test preparation or skill building.
問題集(もんだいしゅう)を解(と)く。
To work through a problem set.
試験(しけん)対策(たいさく)のために問題集(もんだいしゅう)を買(か)った。
I bought a workbook for exam preparation.
この問題集(もんだいしゅう)には解説(かいせつ)が詳(くわ)しく載(の)っている。
This workbook has detailed explanations included.

問題集(もんだいしゅう) refers to books containing practice problems for study.

COMMON PATTERNS:

  • 問題集(もんだいしゅう)を解(と)く: to work through a problem set
  • 問題集(もんだいしゅう)を買(か)う: to buy a workbook
  • 〜の問題集(もんだいしゅう): workbook for ~ (e.g., 数学(すうがく)の問題集(もんだいしゅう))

COMMON TYPES:

  • 過去問(かこもん)問題集(もんだいしゅう): past exam question collection
  • 演習(えんしゅう)問題集(もんだいしゅう): practice exercise book
