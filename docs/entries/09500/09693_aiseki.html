相席(あいせき)

あいせき
noun
sharing a table
1. sharing a table; sitting at the same table as strangers
The practice of seating strangers together at the same table, common in busy restaurants.
相席(あいせき)でもいいですか。
Would sharing a table be okay?
混(こ)んでいたので相席(あいせき)をお願(ねが)いされた。
It was crowded, so I was asked to share a table.
ランチタイムは混雑(こんざつ)するため、相席(あいせき)のご協力(きょうりょく)をお願(ねが)いしております。
Due to lunch hour crowds, we kindly ask for your cooperation in sharing tables.

相席(あいせき) is a common practice in busy Japanese restaurants.

COMMON PATTERNS:

  • 相席(あいせき)でもいいですか (Is sharing a table okay?)
  • 相席(あいせき)をお願(ねが)いする (to request table sharing)
  • 相席(あいせき)になる (to end up sharing a table)

USAGE NOTES:

  • Common during lunch rush at ramen shops, gyudon chains, etc.
  • Staff usually ask 「相席(あいせき)でよろしいですか」

RELATED TERMS:

  • 席(せき): seat
  • 満席(まんせき): full, no seats available
