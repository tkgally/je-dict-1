警備員(けいびいん)

けいびいん
noun
security guard
1. security guard
A person employed to protect buildings, events, or people.
警備員(けいびいん)が入口(いりぐち)に立(た)っている。
A security guard is standing at the entrance.
警備員(けいびいん)に身分証(みぶんしょう)を見(み)せた。
I showed my ID to the security guard.
ビルの警備員(けいびいん)として働(はたら)いている。
I work as a security guard at a building.

警備員(けいびいん) refers to security guards.

COMMON CONTEXTS:

  • 建物(たてもの)の警備員(けいびいん): building security guard
  • イベントの警備員(けいびいん): event security
  • 夜間(やかん)警備員(けいびいん): night security guard

RELATED TERMS:

  • 警備(けいび): security, guard duty
  • 警備会社(けいびがいしゃ): security company
  • 警備(けいび)する: to guard, to provide security
  • 警察官(けいさつかん): police officer
  • {ガードマン}: security guard (loanword)
