即日(そくじつ)

そくじつ
noun
same day; immediate
1. same day; that very day
On the same day as another event or action; immediately without delay.
即日(そくじつ)配達(はいたつ)できます。
Same-day delivery is available.
申(もう)し込(こ)み即日(そくじつ)から使(つか)える。
You can use it from the same day you apply.
結果(けっか)は即日(そくじつ)発表(はっぴょう)されます。
The results will be announced on the same day.

即日(そくじつ) emphasizes that something happens on the very same day.

COMMON COLLOCATIONS:

  • 即日(そくじつ)配達(はいたつ) (same-day delivery)
  • 即日(そくじつ)発送(はっそう) (same-day shipping)
  • 即日(そくじつ)回答(かいとう) (same-day response)
  • 即日(そくじつ)開票(かいひょう) (same-day vote counting)

SIMILAR EXPRESSIONS:

  • 当日(とうじつ): on that day, the day in question
  • 本日(ほんじつ): today (formal)
