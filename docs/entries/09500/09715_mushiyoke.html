虫除(むしよ)け

むしよけ
noun
insect repellent
1. insect repellent; bug spray
A substance applied to skin or clothing to prevent insects, especially mosquitoes, from biting.
虫除(むしよ)けスプレーを買(か)った。
I bought insect repellent spray.
虫除(むしよ)けを塗(ぬ)ってからキャンプに行(い)った。
I applied insect repellent before going camping.
夏(なつ)は蚊(か)が多(おお)いので、虫除(むしよ)けが必須(ひっす)だ。
There are many mosquitoes in summer, so insect repellent is essential.

虫除(むしよ)け protects against insect bites.

COMMON COLLOCATIONS:

  • 虫除(むしよ)けスプレー (insect repellent spray)
  • 虫除(むしよ)けシート (insect repellent wipes)
  • 虫除(むしよ)けを塗(ぬ)る (to apply insect repellent)

COMMON PRODUCTS:

  • スプレー type (spray)
  • ジェル type (gel)
  • シート type (wipes)
  • リング type (wearable rings)

RELATED TERMS:

  • 蚊(か): mosquito
  • 蚊取(かと)り線香(せんこう): mosquito coil
  • 虫刺(むしさ)され: insect bite
