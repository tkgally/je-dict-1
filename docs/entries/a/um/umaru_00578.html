埋(う)まる

うまる
verb (godan)
to be buried, to be filled

Definitions

1. to be buried, to be covered
To be hidden under something.
2. to be filled, to be packed
To have all spaces occupied.

Examples

雪(ゆき)に埋(う)まる。
To be buried in snow.
席(せき)が埋(う)まった。
The seats are filled.
予定(よてい)が埋(う)まっている。
My schedule is full.

Notes

埋(う)まる means to be buried or filled.

TRANSITIVITY:

  • 埋(う)まる (intransitive): to be buried
  • 埋(う)める (transitive): to bury

COMMON USES:

  • 雪(ゆき)に埋(う)まる: to be buried in snow
  • 席(せき)が埋(う)まる: seats fill up
  • 予定(よてい)が埋(う)まる: schedule fills up
