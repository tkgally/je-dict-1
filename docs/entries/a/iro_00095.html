色(いろ)

いろ
noun
color

Definitions

1. color
A visual property of objects resulting from the light they reflect. Used to describe the hue of things like clothes, objects, or nature.

Examples

何(なに)色(いろ)が好(す)きですか。
What color do you like?
なにいろ is the common way to ask about colors
この色(いろ)はきれいですね。
This color is beautiful, isn't it?
赤(あか)い色(いろ)のかばんがほしいです。
I want a red-colored bag.

Notes

Used as a suffix with color words: 赤(あか) (red) + 色(いろ) = 赤色(あかいろ) (red color), though the shorter forms (赤(あか)、青(あお)、etc.) are more common in everyday speech. Also appears in expressions like 色々(いろいろ) (various).
