パイロット

パイロット
noun
pilot

Definitions

1. pilot (aircraft)
A person who operates the controls of an aircraft
2. pilot (experimental, trial)
Something done as a test or trial before full implementation

Examples

将来(しょうらい)パイロットになりたい。
I want to become a pilot in the future.
パイロットが機内(きない)アナウンスをした。
The pilot made an in-flight announcement.
新(あたら)しいシステムのパイロットテストを行(おこな)った。
We conducted a pilot test of the new system.

Notes

パイロット primarily refers to aircraft pilots.

AIRCRAFT PILOT:

  • 飛行機(ひこうき)のパイロット: airplane pilot
  • 機長(きちょう): captain (ranking pilot)
  • 副操縦士(ふくそうじゅうし): co-pilot
  • パイロットになる: to become a pilot

TRIAL/EXPERIMENTAL:

  • パイロット版(ばん): pilot version
  • パイロットテスト: pilot test
  • パイロット事業(じぎょう): pilot project

RELATED TERMS:

  • 操縦士(そうじゅうし): pilot (formal term)
  • 航空(こうくう)会社(がいしゃ): airline

NOTE:
For ship captains, 船長(せんちょう) is used, not パイロット.
