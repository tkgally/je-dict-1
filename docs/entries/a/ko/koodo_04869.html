コード

コード
noun
code, cord, chord

Definitions

1. code (programming, identification)
A system of symbols, numbers, or programming instructions
2. cord, cable
An electrical wire or cable
3. chord (music)
A combination of musical notes played together

Examples

商品(しょうひん)コードをスキャンしてください。
Please scan the product code.
パソコンの電源(でんげん)コードが短(みじか)すぎる。
The computer's power cord is too short.
このギターコードは難(むずか)しい。
This guitar chord is difficult.
プログラマーは毎日(まいにち)コードを書(か)いている。
Programmers write code every day.

Notes

コード represents three different English words: code, cord, and chord.

CODE:

  • プログラミングコード / ソースコード: programming code
  • バーコード: barcode
  • QRコード: QR code
  • 暗号(あんごう)コード: encryption code
  • ドレスコード: dress code

CORD/CABLE:

  • 電源(でんげん)コード: power cord
  • 延長(えんちょう)コード: extension cord
  • USBコード: USB cable

CHORD (music):

  • ギターコード: guitar chord
  • コード進行(しんこう): chord progression

Note: For thicker cables, ケーブル is more commonly used than コード.
