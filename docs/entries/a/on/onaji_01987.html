同(おな)じ

おなじ
pre-noun adjectival / na-adjective
same, identical

Definitions

1. same, identical
Being the exact thing or equal in value or quality.

Examples

同(おな)じ本(ほん)を持(も)っている。
I have the same book.
私(わたし)たちは同(おな)じ学校(がっこう)です。
We go to the same school.
これとそれは同(おな)じだ。
This and that are the same.

Notes

同(おな)じ means same or identical.

PATTERNS:

  • 同(おな)じ + noun: the same ~
  • 〜と同(おな)じ: same as ~
  • 〜と同(おな)じように: in the same way as ~

NOTE: 同(おな)じ is unusual - it acts like a pre-noun adjectival but can also be predicate (同(おな)じだ).
