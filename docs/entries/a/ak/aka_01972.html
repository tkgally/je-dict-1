赤(あか)

あか
noun / no-adjective
red

Definitions

1. red
The color red.

Examples

赤(あか)い花(はな)
Red flowers.
信号(しんごう)が赤(あか)だ。
The traffic light is red.
赤(あか)いりんごを買(か)った。
I bought red apples.

Notes

赤(あか) is a basic color word.

USAGE:

  • As noun: 赤(あか)が好(す)き (I like red)
  • As no-adjective: 赤(あか)の車(くるま) (red car)
  • As i-adjective: 赤(あか)い (red)

COMMON EXPRESSIONS:

  • 赤(あか)ちゃん (baby)
  • 赤(あか)ワイン (red wine)
  • 真(ま)っ赤(か) (bright red)
