降り出す

ふりだす
verb
to start to rain/snow

Definitions

1. to start to rain/snow
For rain or snow to begin falling.

Examples

雨(あめ)が降(ふ)り出(だ)した。
It started raining.
急(きゅう)に降(ふ)り出(だ)した。
It suddenly started raining.
雪(ゆき)が降(ふ)り出(だ)す。
It starts snowing.
