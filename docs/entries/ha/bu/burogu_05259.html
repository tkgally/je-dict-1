ブログ

ぶろぐ
noun
blog

Definitions

1. blog, weblog
A regularly updated website or web page, typically run by an individual or small group, written in an informal or conversational style.

Examples

毎日(まいにち)ブログを更新(こうしん)している。
I update my blog every day.
旅行(りょこう)のブログを読(よ)むのが好(す)きだ。
I like reading travel blogs.
有名(ゆうめい)なブロガーになりたい。
I want to become a famous blogger.

Notes

COMMON COLLOCATIONS:

  • ブログを書(か)く (to write a blog)
  • ブログを更新(こうしん)する (to update a blog)
  • ブログを読(よ)む (to read a blog)
  • ブログを始(はじ)める (to start a blog)
  • ブロガー (blogger)

RELATED TERMS:

  • SNS (social networking service)
  • 投稿(とうこう) (post)
  • 記事(きじ) (article)
