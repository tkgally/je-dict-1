欲(ほ)しい

ほしい
adjective (i-adjective)
wanted, desired

Definitions

1. wanted, desired
Used to express that you want something (a noun). The thing wanted is marked with が.
2. to want (someone) to do
In the pattern 「～てほしい」, expresses wanting someone else to do something.

Examples

新(あたら)しいパソコンが欲(ほ)しいです。
I want a new computer.
Object is marked with が, not を
何(なに)が欲(ほ)しいですか。
What do you want?
手伝(てつだ)ってほしいんです。
I want you to help me.
～てほしい pattern

Notes

欲しい conjugates as an i-adjective: 欲しくない (negative), 欲しくて (te-form), 欲しかった (past). Important: Use 欲しい for wanting things (nouns), but use ～たい for wanting to do actions (verbs). The pattern ～てほしい means you want someone else to do something.
