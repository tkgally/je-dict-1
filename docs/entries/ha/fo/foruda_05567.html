フォルダ

ふぉるだ
noun
folder

Definitions

1. folder (computer)
A virtual container in a computer file system that holds files and other folders.
2. folder (physical)
A paper or cardboard container for holding documents.

Examples

新(あたら)しいフォルダを作成(さくせい)する。
To create a new folder.
ファイルをフォルダに移動(いどう)した。
I moved the file to a folder.
書類(しょるい)をフォルダに整理(せいり)する。
To organize documents in a folder.

Notes

フォルダ is used both for computer folders and physical document folders.

COMPUTER TERMS:

  • フォルダを作成する: to create a folder
  • フォルダを開く: to open a folder
  • フォルダを削除する: to delete a folder

SYNONYM:
ディレクトリ (directory) is used more in technical/Unix contexts.
