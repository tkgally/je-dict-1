済(す)む

すむ
verb (godan)
to be finished, to be settled

Definitions

1. to be finished, to be done
For something to be completed.
2. to be settled, to be resolved
For a matter to be concluded.

Examples

仕事(しごと)が済(す)んだ。
The work is done.
これで済(す)む。
This will be enough.
謝(あやま)って済(す)む問題(もんだい)ではない。
This isn't something that can be resolved with an apology.

Notes

済(す)む means to be finished or settled.

PATTERNS:

  • Xが済(す)む: X is finished
  • V-て済(す)む: can get by with doing V
  • V-ないで済(す)む: can get by without doing V

TRANSITIVITY:

  • 済(す)む (intransitive): to be finished
  • 済(す)ませる (transitive): to finish
