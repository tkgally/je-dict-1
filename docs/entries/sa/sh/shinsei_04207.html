申請(しんせい)

しんせい
noun, suru-verb
application, petition

Definitions

1. application, request, petition
A formal request submitted to authorities or organizations for approval, permission, or services.

Examples

ビザの申請(しんせい)をした。
I applied for a visa.
申請(しんせい)書(しょ)を提出(ていしゅつ)してください。
Please submit your application form.
休暇(きゅうか)の申請(しんせい)が承認(しょうにん)された。
My leave application was approved.

Notes

COMMON COLLOCATIONS:

  • 申請(しんせい)する (to apply, to file an application)
  • 申請(しんせい)書(しょ) (application form)
  • 申請(しんせい)手続(てつづ)き (application procedure)
  • 申請(しんせい)を受(う)け付(つ)ける (to accept applications)
  • 申請(しんせい)中(ちゅう) (application pending)

COMMON TYPES:

  • ビザ申請(しんせい) (visa application)
  • 許可(きょか)申請(しんせい) (permit application)
  • 補助金(ほじょきん)申請(しんせい) (subsidy application)

SIMILAR WORDS:

  • 申(もう)し込(こ)み - application (less formal, for services/events)
  • 願書(がんしょ) - application form (especially for school admission)
  • 届(とど)け出(で) - notification, report (required filing)
