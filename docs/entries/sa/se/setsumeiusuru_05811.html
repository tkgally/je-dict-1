説明(せつめい)する

せつめいする
verb (suru)
to explain

Definitions

1. to explain, to describe
To make something clear or understandable by describing it in detail.

Examples

もう一度(いちど)説明(せつめい)してください。
Please explain it one more time.
彼女(かのじょ)は理由(りゆう)を詳(くわ)しく説明(せつめい)した。
She explained the reason in detail.
説明(せつめい)するまでもないことだ。
It goes without saying. / It needs no explanation.
Set expression

Notes

COMMON COLLOCATIONS:

  • 説明(せつめい)を求(もと)める: to ask for an explanation
  • 説明(せつめい)を聞(き)く: to listen to an explanation
  • 説明(せつめい)不足(ぶそく): lack of explanation

RELATED TERMS:

  • 説明書(せつめいしょ): instruction manual
  • 説明会(せつめいかい): briefing session, information session
