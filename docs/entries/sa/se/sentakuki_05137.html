洗濯機(せんたくき)

せんたくき
noun
washing machine

Definitions

1. washing machine
An electrical appliance used for washing clothes automatically.

Examples

洗濯機(せんたくき)を回(まわ)す。
Run the washing machine.
回す literally means 'to turn/spin'
洗濯機(せんたくき)が壊(こわ)れたので新(あたら)しいのを買(か)った。
I bought a new one because the washing machine broke.
ドラム式(しき)洗濯機(せんたくき)は節水(せっすい)できる。
Drum-type washing machines can save water.

Notes

Types:

  • 縦型(たてがた)/全自動(ぜんじどう)洗濯機(せんたくき) (top-loading, traditional in Japan)
  • ドラム式(しき) (front-loading/drum type)
  • 二槽式(にそうしき) (twin-tub) - older style with separate wash/spin tubs
  • 洗濯乾燥機(せんたくかんそうき) (washer-dryer combo)

Common settings/features:

  • 洗(あら)い (wash)
  • すすぎ (rinse)
  • 脱水(だっすい) (spin dry)
  • 乾燥(かんそう) (dry)
  • おしゃれ着(ぎ)コース (delicates cycle)

Collocations:

  • 洗濯機(せんたくき)に入(い)れる (put in the washing machine)
  • 洗濯機(せんたくき)から出(だ)す (take out of the washing machine)
  • 洗濯機(せんたくき)の容量(ようりょう) (washing machine capacity)
