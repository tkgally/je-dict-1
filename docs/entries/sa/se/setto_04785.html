セット

せっと
noun
set

Definitions

1. set, combination
A group of items that belong together or are used together.
2. set (in sports)
A portion of a match in games like tennis or volleyball.
3. set (hair)
Styling or arranging hair in a particular way.

Examples

ランチセットを注文(ちゅうもん)した。
I ordered a lunch set.
テニスの第(だい)1セットを取(と)った。
I won the first set in tennis.
髪(かみ)をセットする。
I style my hair.

Notes

セット is a versatile word with multiple uses in daily life.

COMMON EXPRESSIONS:

  • セットメニュー: set menu, combo meal
  • ランチセット: lunch set
  • ディナーセット: dinner set
  • セットで買(か)う: to buy as a set
  • 髪(かみ)をセットする: to style one's hair
  • セットアップ: setup

USAGE NOTE:
セットする can be used as a suru-verb meaning "to set" or "to arrange."
