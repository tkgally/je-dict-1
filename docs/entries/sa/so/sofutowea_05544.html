ソフトウェア

そふとうぇあ
noun
software

Definitions

1. software, computer programs
See notes for detailed explanation.

Examples

ソフトウェアを開発(かいはつ)している。
I am developing software.
新(あたら)しいソフトウェアをインストールした。
I installed new software.
このソフトウェアは無料(むりょう)で使(つか)える。
This software can be used for free.

Notes

ソフトウェア refers to computer programs and applications.

COMMON COLLOCATIONS:

  • ソフトウェアを開発(かいはつ)する (to develop software)
  • ソフトウェアをインストールする (to install software)
  • ソフトウェアを更新(こうしん)する (to update software)
  • ソフトウェア開発(かいはつ) (software development)
  • ソフトウェア会社(かいしゃ) (software company)

TYPES:

  • アプリケーションソフト (application software)
  • システムソフト (system software)
  • フリーソフト / 無料(むりょう)ソフト (free software)
  • 有料(ゆうりょう)ソフト (paid software)

SHORTENED FORM:

  • ソフト (soft) is commonly used as abbreviation

CONTRAST:

  • ソフトウェア: Programs, intangible
  • ハードウェア: Physical computer components
