それぞれ

それぞれ
noun
each, respectively

Definitions

1. each, respectively, individually
Used to refer to each thing or person in a group separately.

Examples

それぞれの国(くに)に文化(ぶんか)がある。
Each country has its own culture.
学生(がくせい)たちはそれぞれ違(ちが)う意見(いけん)を持(も)っている。
The students each have different opinions.

Notes

Can function as noun or adverb. Often followed by の when modifying nouns.
