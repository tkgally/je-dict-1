紛失届(ふんしつとどけ)

ふんしつとどけ
noun
report of lost property; lost item report
1. report of lost property; lost item report
An official report or form filed with the police or another authority to notify them that one has lost an item. Filed in the hope that the item may be found and returned.
紛失届(ふんしつとどけ)を出(だ)す。
To file a lost property report.
財布(さいふ)をなくしたので、警察(けいさつ)に紛失届(ふんしつとどけ)を提出(ていしゅつ)した。
I lost my wallet, so I filed a lost property report with the police.
パスポートを紛失(ふんしつ)した場合(ばあい)は、まず紛失届(ふんしつとどけ)を出(だ)してから再発行(さいはっこう)の手続(てつづ)きをする。
If you lose your passport, first file a lost property report, then proceed with the reissue process.

Composed of 紛失(ふんしつ) (loss) + 届(とどけ) (notification/report). This is the official term for the form filed at a police station (交番(こうばん) or 警察署(けいさつしょ)) when something is lost.

COMMON COLLOCATIONS:

  • 紛失届(ふんしつとどけ)を出(だ)す: to file a lost property report
  • 紛失届(ふんしつとどけ)を提出(ていしゅつ)する: to submit a lost property report (formal)
  • 紛失届(ふんしつとどけ)を受理(じゅり)する: to accept a lost property report

RELATED TERMS:

  • 遺失届(いしつとどけ): lost property report — a more formal synonym
  • 届出(とどけで): notification, report — the general term for official reports
  • 拾得届(しゅうとくとどけ): found property report — filed when finding someone else's lost item

CULTURAL NOTE:
Japan has a remarkably high rate of returning lost items. Filing a 紛失届(ふんしつとどけ) at a 交番(こうばん) (police box) is a common and effective step, as many lost items are turned in by finders.
