原文(げんぶん)

げんぶん
noun
original text; the original
1. original text; original wording; the original
The text in its original form before translation, editing, or adaptation.
原文(げんぶん)を確認(かくにん)する。
To check the original text.
この小説(しょうせつ)は原文(げんぶん)で読(よ)みたい。
I want to read this novel in the original.
翻訳(ほんやく)は良(よ)くできているが、原文(げんぶん)のニュアンスとは少(すこ)し違(ちが)う。
The translation is well done, but it differs slightly from the nuance of the original text.

Composed of 原(げん) (original/source) and 文(ぶん) (text/writing). Most commonly used when discussing translations, quotations, or edited works where comparison to the original is relevant.

COMMON COLLOCATIONS:

  • 原文(げんぶん)で読(よ)む: to read in the original language
  • 原文(げんぶん)のまま: as it is in the original
  • 原文(げんぶん)に忠実(ちゅうじつ): faithful to the original text
  • 原文(げんぶん)を引用(いんよう)する: to quote the original text

SIMILAR WORDS:

  • 原作(げんさく): original work — refers to the original creative work (novel, manga, etc.) that an adaptation is based on
  • 原稿(げんこう): manuscript, draft — a written document before publication
  • 原典(げんてん): original source — the primary source document, often academic
