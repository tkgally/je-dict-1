折(お)れ線(せん)グラフ

おれせんぐらふ
noun
line graph; line chart
1. line graph; line chart
A type of graph that displays data points connected by straight line segments. Used to show changes over time or trends.
折(お)れ線(せん)グラフを描(か)く。
To draw a line graph.
気温(きおん)の変化(へんか)を折(お)れ線(せん)グラフで表(あらわ)す。
To show temperature changes with a line graph.
この折(お)れ線(せん)グラフを見(み)ると、売(う)り上(あ)げが右肩上(みぎかたあ)がりに伸(の)びているのがわかる。
Looking at this line graph, you can see that sales have been steadily increasing.

Composed of 折(お)れ線(せん) (broken line / polyline) + グラフ (graph). The name comes from the zigzag shape formed when data points are connected by straight lines.

COMMON COLLOCATIONS:

  • 折(お)れ線(せん)グラフを描(か)く: to draw a line graph
  • 折(お)れ線(せん)グラフで表(あらわ)す: to represent with a line graph
  • 折(お)れ線(せん)グラフを読(よ)み取(と)る: to read/interpret a line graph

SIMILAR WORDS:

  • 棒(ぼう)グラフ: bar graph — uses rectangular bars to represent data
  • 円(えん)グラフ: pie chart — uses a circle divided into sectors
  • 帯(おび)グラフ: band graph / stacked bar chart

NOTE:
Line graphs are taught in Japanese elementary school math (算数(さんすう)) and are one of the basic graph types students learn alongside bar graphs and pie charts.
