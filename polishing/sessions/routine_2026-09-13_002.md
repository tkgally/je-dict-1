## Observations

- **[tooling]** Plain-text extraction for the accuracy reviewer strips furigana ruby, so a note
  that gives an alternate reading as `{脂性|あぶらせい}` renders to the model as bare `脂性` —
  indistinguishable from the headword. This produced at least two false "self-referential" or
  "typo" flags this run (23481_aburashou, and partly 23976_ichiwa's counting-pattern flags). Not
  urgent — precision was still fine overall (5.4% flagged) — but worth a mention if the reviewer
  prompt is revisited.
- **[entry]** 24193_bakkupakku (バックパック) is tagged `semantic: [travel, clothing]`; a backpack is
  not clothing. Checked the near-synonym リュック (04541_ryukku) and it carries the same `clothing`
  tag, so this looks like a small systemic pattern (bags-as-clothing) rather than an isolated typo —
  logged here rather than fixed solo, since fixing just one of the pair would leave them
  inconsistent. Worth a `systemic-fix` pass if there turn out to be more than a couple of these.
- **[entry]** 24083_rippou (立方) and 24208_uki (右記) are both missing the required `formality`
  field entirely (only `politeness` is set). Neither was touched this run (both of their flags were
  rejected), so I didn't add the field, but they should get one whenever they're next opened.
