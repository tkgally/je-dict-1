## What this run did

The dictionary's example sentences and notes link Japanese words to their entries. When a word had
no entry at the time of writing, the link was written as `noentry` and renders as plain text. Many
of those words have entries now, so the link is recoverable — the reader is currently looking at
dead text where a working link exists. This is the fourth batch of that repair working on
**short base forms** (2–3 characters), which need reading in context because a short word is much
more likely to be the wrong sense of a longer compound.

**Band worked**: entries **03167–03756** — 181 link pairs, 221 individual markers, across
131 entry files. All class A1/A2 (full headword match, exactly one candidate target entry).

Each pair was judged against a ±60-character window of the text around the marker, plus the
target entry's own senses. **All 181 were applied; zero rejections** — the second consecutive
fully clean band.

Families that made up the band (each checked once, then confirmed across its members):

- **Suffix entries** (〜家, 〜者, 〜的, 〜代, 〜戦). Worth flagging for future runs: the marker's
  visible surface is the bare kanji while the base form carries the tilde, so a context dump that
  prints the base looks wrong (「思想〜家として」) when the rendered sentence is fine.
- **Compound sets inside one entry's notes** — needles (縫い針/編み針/注射針/釣り針), fences
  (板塀/石塀), multiple births (三つ子/四つ子/双生児), physics fields (重力場/電磁場).
- **Katakana loanwords whose target entry holds the needed sense as a later sense** — ベスト →
  `04681` ("best", not "vest"), カード → `03836` (sense 1, identification/payment), マネー,
  タイル, シニア. This is the same shape as the フライ false positive from 2026-08-08; the
  discriminator is whether the target entry actually has the sense, not whether the word is
  polysemous.

Two marginal applies, recorded in the backlog for future runs:

- **年寄り臭い → `01133_kusai`** — the target's glosses ("smelly", "suspicious") do not cover the
  suffixal 〜くさい sense at issue, but its notes carry a full "AS A SUFFIX (〜くさい)" section, so
  the reader lands correctly. Judging on gloss text alone would have rejected this.
- **焼き物 → `04974_yakimono`** — lead gloss "grilled dish", with "pottery, ceramics" as a later
  sense; same reasoning as the 五段活用 → `28275` precedent.
